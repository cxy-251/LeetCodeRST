0345. Reverse Vowels of a String
================================

题目信息
--------

:题号: 0345
:难度: Easy
:主题: 双指针、字符串
:原题: `LeetCode 345 <https://leetcode.com/problems/reverse-vowels-of-a-string/>`_
:教学重点: 从两端寻找元音并交换，同时保持所有非元音字符的位置不变。

题目重述
--------

给定字符串，只反转其中所有元音字母出现的顺序。大小写元音都需要识别，其他字符保持原位置。

自建示例
--------

输入 ``"leetcode"``，元音顺序反转后返回 ``"leotcede"``。
