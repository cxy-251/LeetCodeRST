0328. Odd Even Linked List
==========================

题目信息
--------

:题号: 0328
:难度: Medium
:主题: 链表、双指针
:原题: `LeetCode 328 <https://leetcode.com/problems/odd-even-linked-list/>`_
:教学重点: 分离奇数位置和偶数位置的链表，再保持各自相对顺序进行拼接。

题目重述
--------

按照节点在链表中的位置，把所有奇数位置节点放在前面，偶数位置节点放在后面。节点位置从 ``1`` 开始，且两组内部相对顺序必须保持不变。

自建示例
--------

链表 ``1 -> 2 -> 3 -> 4 -> 5`` 重排后为 ``1 -> 3 -> 5 -> 2 -> 4``。
