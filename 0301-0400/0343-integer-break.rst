0343. Integer Break
===================

题目信息
--------

:题号: 0343
:难度: Medium
:主题: 数学、动态规划
:原题: `LeetCode 343 <https://leetcode.com/problems/integer-break/>`_
:教学重点: 比较动态规划分割与尽量使用 ``3`` 的数学最优结构。

题目重述
--------

给定正整数 ``n``，把它拆成至少两个正整数之和，使这些整数的乘积最大，返回能够得到的最大乘积。

自建示例
--------

``n = 10`` 时可拆为 ``3 + 3 + 4``，乘积为 ``36``，因此返回 ``36``。
