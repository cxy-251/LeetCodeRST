0301. Remove Invalid Parentheses
===============================

题目信息
--------

:题号: 0301
:难度: Hard
:主题: 字符串、回溯、广度优先搜索
:原题: `LeetCode 301 <https://leetcode.com/problems/remove-invalid-parentheses/>`_
:教学重点: 在保证删除数量最少的前提下，枚举所有不同的合法括号字符串。

题目重述
--------

给定一个可能含有字母和圆括号的字符串。每次可以删除一个左括号或右括号，要求删除尽可能少的括号，使剩余字符串中的括号配对合法。返回所有不同的最优结果，结果顺序不限。

自建示例
--------

输入 ``s = "()())()"``，输出可以是 ``["(())()", "()()()"]``。两个结果都只删除了一个右括号，并且不存在零次删除即可得到的合法字符串。
