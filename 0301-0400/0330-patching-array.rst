0330. Patching Array
====================

题目信息
--------

:题号: 0330
:难度: Hard
:主题: 贪心、数组
:原题: `LeetCode 330 <https://leetcode.com/problems/patching-array/>`_
:教学重点: 维护当前可表示的连续区间，当下一个数产生缺口时补入最小缺失值。

题目重述
--------

给定升序正整数数组 ``nums`` 和正整数 ``n``。可以向数组中加入若干正整数，要求最终能够用某些元素之和表示 ``[1,n]`` 中的每个整数。返回最少需要加入多少个数。

自建示例
--------

``nums = [1,5,10]``，``n = 20``，最少补入 ``2`` 和 ``4``，因此返回 ``2``。
