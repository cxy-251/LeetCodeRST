0306. Additive Number
=====================

题目信息
--------

:题号: 0306
:难度: Medium
:主题: 字符串、回溯、大整数运算
:原题: `LeetCode 306 <https://leetcode.com/problems/additive-number/>`_
:教学重点: 枚举前两个数并验证后续数字是否持续满足加法序列，同时处理前导零。

题目重述
--------

给定一个只含数字的字符串，判断它能否被切分成至少三个非负整数，使从第三个数开始，每个数都等于前两个数之和。除数字 ``0`` 本身外，任何数都不能以 ``0`` 开头。

自建示例
--------

``s = "112358"`` 返回 ``true``，因为可以切分为 ``1, 1, 2, 3, 5, 8``。``s = "1023"`` 返回 ``false``。
