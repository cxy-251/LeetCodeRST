0324. Wiggle Sort II
====================

题目信息
--------

:题号: 0324
:难度: Medium
:主题: 数组、排序、快速选择
:原题: `LeetCode 324 <https://leetcode.com/problems/wiggle-sort-ii/>`_
:教学重点: 围绕中位数重新分布元素，使相邻关系严格满足小于和大于交替。

题目重述
--------

原地重排数组，使其满足 ``nums[0] < nums[1] > nums[2] < nums[3]...``。题目保证至少存在一种合法排列。

自建示例
--------

输入 ``[1,5,1,1,6,4]``，一种合法结果为 ``[1,6,1,5,1,4]``。
