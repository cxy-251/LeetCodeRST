0312. Burst Balloons
====================

题目信息
--------

:题号: 0312
:难度: Hard
:主题: 数组、区间动态规划
:原题: `LeetCode 312 <https://leetcode.com/problems/burst-balloons/>`_
:教学重点: 逆向思考区间中最后一个被戳破的气球，从而消除操作顺序带来的依赖。

题目重述
--------

一排气球各有一个数值。戳破下标 ``i`` 的气球时，获得它当前左右相邻气球数值与自身数值的乘积；越界位置视为 ``1``。求戳破全部气球能够获得的最大硬币数。

自建示例
--------

输入 ``[3,1,5,8]``，最大收益为 ``167``。一种最优顺序是先戳 ``1``，再戳 ``5``，随后戳 ``3``，最后戳 ``8``。
