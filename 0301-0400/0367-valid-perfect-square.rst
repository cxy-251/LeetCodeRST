0367. Valid Perfect Square
==========================

题目信息
--------

:题号: 0367
:难度: Easy
:主题: 数学、二分查找
:原题: `LeetCode 367 <https://leetcode.com/problems/valid-perfect-square/>`_
:教学重点: 在不调用平方根函数的条件下，用二分查找或牛顿迭代判断完全平方数。

题目重述
--------

给定正整数 ``num``，判断是否存在整数 ``x``，使 ``x * x = num``。不能直接调用内置平方根函数。

自建示例
--------

``num = 49`` 返回 ``true``；``num = 50`` 返回 ``false``。
