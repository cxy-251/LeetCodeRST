0321. Create Maximum Number
===========================

题目信息
--------

:题号: 0321
:难度: Hard
:主题: 单调栈、贪心、归并
:原题: `LeetCode 321 <https://leetcode.com/problems/create-maximum-number/>`_
:教学重点: 分配两个数组的选取数量，分别求最大子序列，再按字典序合并。

题目重述
--------

给定两个保持内部相对顺序的数字数组，从两者合计选出恰好 ``k`` 个数字，组成字典序最大的长度为 ``k`` 的数组。选自同一数组的数字不能改变原顺序。

自建示例
--------

``nums1 = [3,4,6,5]``，``nums2 = [9,1,2,5,8,3]``，``k = 5``，返回 ``[9,8,6,5,3]``。
