0397. Integer Replacement
=========================

题目信息
--------

:题号: 0397
:难度: Medium
:主题: 贪心、位运算、记忆化搜索、动态规划
:原题: `LeetCode 397 <https://leetcode.com/problems/integer-replacement/>`_
:教学重点: 偶数直接除二；奇数根据二进制低位选择加一或减一，并单独处理特殊值。

题目重述
--------

给定正整数 ``n``。若 ``n`` 为偶数，可以替换为 ``n / 2``；若为奇数，可以替换为 ``n + 1`` 或 ``n - 1``。返回把它变成 ``1`` 所需的最少操作次数。

自建示例
--------

``n = 8`` 时执行 ``8 -> 4 -> 2 -> 1``，返回 ``3``。
