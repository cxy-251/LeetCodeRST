0342. Power of Four
===================

题目信息
--------

:题号: 0342
:难度: Easy
:主题: 整数、幂、指数、正数边界
:原题: `LeetCode 0342 <https://leetcode.com/problems/power-of-four/>`_
:重点: 指数必须是整数、``4^0`` 等于 1、二的幂不一定是四的幂、非正数均不满足

题目重述
--------

给定 32 位有符号整数 ``n``，判断是否存在整数 ``x`` 使 ``n = 4^x``。四的整数次幂始终为正数，因此零和负数不能满足条件。

``n`` 位于 ``[-2^31, 2^31-1]``。指数可以为 ``0``，所以 ``1 = 4^0`` 应返回 ``true``；某个数即使是二的幂，也只有指数为偶数时才是四的幂。进阶问题询问能否不使用循环或递归完成判断。

自建示例
--------

较高次幂：

.. code-block:: text

   输入：n = 256
   输出：true
   解释：256 = 4^4。

是二的幂但不是四的幂：

.. code-block:: text

   输入：n = 8
   输出：false
   解释：8 = 2^3，不存在整数 x 使 4^x=8。

指数为零：

.. code-block:: text

   输入：n = 1
   输出：true
   解释：1 = 4^0。
