0390. Elimination Game
======================

题目信息
--------

:题号: 0390
:难度: Medium
:主题: 整数序列、交替方向、隔项删除、最终剩余值
:原题: `LeetCode 0390 <https://leetcode.com/problems/elimination-game/>`_
:重点: 第一轮从左开始、每轮先删除当前方向的第一个元素并隔一个删除、方向持续交替

题目重述
--------

从按升序排列的整数序列 ``[1, 2, ..., n]`` 开始。第一轮从左向右，删除最左侧元素以及此后每隔一个元素；第二轮对剩余序列从右向左，删除最右侧元素以及此后每隔一个元素。之后不断交替方向并重复相同规则，直到序列只剩一个整数。

返回最后留下的整数。``n`` 位于 ``[1, 10^9]``。每一轮删除操作都基于上一轮保留下来的顺序；从右向左的一轮也必须先删除当时最右侧的元素。

自建示例
--------

偶数个初始元素：

.. code-block:: text

   输入：n = 6
   输出：4
   解释：[1,2,3,4,5,6] 从左删除后剩 [2,4,6]；再从右删除 6 和 2，最后只剩 4。

只有一个元素：

.. code-block:: text

   输入：n = 1
   输出：1
   解释：序列已经只含一个整数，不需要执行删除。
