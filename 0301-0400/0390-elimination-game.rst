0390. Elimination Game
======================

题目信息
--------

:题号: 0390
:难度: Medium
:主题: 数学、递归
:原题: `LeetCode 390 <https://leetcode.com/problems/elimination-game/>`_
:教学重点: 只追踪当前首项、步长、剩余数量和删除方向，避免真实构造序列。

题目重述
--------

从整数序列 ``1`` 到 ``n`` 开始，先从左向右删除第一个数以及之后每隔一个数，再从右向左执行同样操作，方向不断交替，直到只剩一个数。返回最后剩下的数。

自建示例
--------

``n = 9`` 时，序列依次变为 ``[2,4,6,8]``、``[2,6]``、``[6]``，返回 ``6``。
