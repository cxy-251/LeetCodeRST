0338. Counting Bits
===================

题目信息
--------

:题号: 0338
:难度: Easy
:主题: 非负整数、二进制表示、置位计数、结果数组
:原题: `LeetCode 0338 <https://leetcode.com/problems/counting-bits/>`_
:重点: 统计范围包含 0 和 n、结果下标就是对应整数、前导零不影响置位数量

题目重述
--------

给定非负整数 ``n``，返回长度为 ``n+1`` 的整数数组 ``answer``。对每个 ``i``（``0 <= i <= n``），``answer[i]`` 等于整数 ``i`` 的二进制表示中数值为 ``1`` 的位数。

``n`` 位于 ``[0, 10^5]``。结果必须从整数 ``0`` 开始按数值顺序排列，不能只返回总数或仅处理 ``1`` 到 ``n``；``0`` 的二进制置位数为 ``0``。进阶问题要求总体 ``O(n)`` 时间且避免对每个整数调用内置位计数函数。

自建示例
--------

包含多个不同置位数：

.. code-block:: text

   输入：n = 6
   输出：[0, 1, 1, 2, 1, 2, 2]
   解释：0 到 6 的二进制分别为 0、1、10、11、100、101、110，对应置位数如输出所示。

只处理整数零：

.. code-block:: text

   输入：n = 0
   输出：[0]
   解释：结果仍需包含下标 0 对应的计数。
