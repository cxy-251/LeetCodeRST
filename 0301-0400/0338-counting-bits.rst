0338. Counting Bits
===================

题目信息
--------

:题号: 0338
:难度: Easy
:主题: 位运算、动态规划
:原题: `LeetCode 338 <https://leetcode.com/problems/counting-bits/>`_
:教学重点: 利用 ``i`` 与 ``i >> 1`` 或 ``i & (i - 1)`` 的关系复用已计算结果。

题目重述
--------

给定非负整数 ``n``，返回长度为 ``n + 1`` 的数组，其中第 ``i`` 项是整数 ``i`` 的二进制表示中 ``1`` 的个数。

自建示例
--------

``n = 5`` 时返回 ``[0,1,1,2,1,2]``。
