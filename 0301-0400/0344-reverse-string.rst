0344. Reverse String
====================

题目信息
--------

:题号: 0344
:难度: Easy
:主题: 双指针、字符串
:原题: `LeetCode 344 <https://leetcode.com/problems/reverse-string/>`_
:教学重点: 使用左右指针原地交换字符，避免额外构造同长度数组。

题目重述
--------

给定字符数组 ``s``，要求原地将字符顺序反转，只能使用常数级额外空间。

自建示例
--------

输入 ``["h","e","l","l","o"]``，修改后为 ``["o","l","l","e","h"]``。
