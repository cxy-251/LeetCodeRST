0504. Base 7
============

题目信息
--------

:题号: 0504
:难度: Easy
:主题: 整数表示、七进制、负号、字符串输出
:原题: `LeetCode 0504 <https://leetcode.com/problems/base-7/>`_
:重点: 返回十进制整数的七进制字符串、负数保留负号、零单独表示、结果无前导零

题目重述
--------

给定一个十进制整数 ``num``，返回它的七进制字符串表示。正数和零按普通进制转换；负数的结果以 ``-`` 开头，其余部分表示绝对值。

``num`` 位于 ``[-10^7, 10^7]``。零必须返回 ``"0"``；其他结果除负号外不能包含前导零，数字字符只能来自 ``0`` 到 ``6``。

自建示例
--------

正数包含多个七进制位：

.. code-block:: text

   输入：num = 100
   输出："202"
   解释：100 = 2 * 49 + 0 * 7 + 2，因此七进制表示为 202。

负数保留符号：

.. code-block:: text

   输入：num = -49
   输出："-100"
   解释：49 等于 7 的平方，绝对值的七进制表示为 100，再在前面添加负号。
