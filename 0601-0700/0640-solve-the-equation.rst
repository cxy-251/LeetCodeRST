0640. Solve the Equation
========================

题目信息
--------

:题号: 0640
:难度: Medium
:主题: 一元一次方程、系数合并、唯一解、无解与无限解
:原题: `LeetCode 0640 <https://leetcode.com/problems/solve-the-equation/>`_
:重点: 方程只含整数常数和变量 x、等号两侧均可含加减项、输出格式区分唯一解、无解和无限多解

题目重述
--------

给定表示一元一次方程的字符串 ``equation``。方程恰好包含一个等号，两侧由整数常数、变量项 ``x``、加号和减号组成；变量项可以写成 ``x``、``-x`` 或带整数系数的形式。

求解该方程。若存在唯一整数解，返回 ``"x=value"``；若等号两侧化简后变量系数相同而常数不同，返回 ``"No solution"``；若两侧完全等价，返回 ``"Infinite solutions"``。输入保证格式合法且不存在空白字符，字符串长度位于 ``[3, 1000]``。

自建示例
--------

存在唯一解：

.. code-block:: text

   输入：equation = "3x+2=x+10"
   输出："x=4"
   解释：移项后得到 2x=8，因此唯一解为 x=4。

两侧恒等：

.. code-block:: text

   输入：equation = "2x+5=2x+5"
   输出："Infinite solutions"
   解释：任意 x 都使等号两侧相等，因此解有无限多个。

常数产生矛盾：

.. code-block:: text

   输入：equation = "x+1=x+2"
   输出："No solution"
   解释：消去两侧的 x 后得到 1=2，不存在满足方程的值。
