0679. 24 Game
=============

题目信息
--------

:题号: 0679
:难度: Hard
:主题: 四个数字、四则运算、括号、可行性判断
:原题: `LeetCode 0679 <https://leetcode.com/problems/24-game/>`_
:重点: 四个数必须各使用一次、只能使用加减乘除和括号、除法按实数计算、不能拼接数字或使用额外数字

题目重述
--------

给定恰好四个整数 ``cards``，每个数位于 ``1`` 到 ``9``。使用 ``+``、``-``、``*``、``/`` 和任意括号，把四个数各使用恰好一次，判断能否构造出结果为 ``24`` 的表达式。

运算顺序可以通过括号自由决定，减法和除法的操作数顺序会影响结果；除法使用实数结果，不要求中间值为整数。不能把两个数字拼接成多位数，不能使用一元负号或题目未提供的数字。浮点计算中与 ``24`` 的误差小于 ``10^-6`` 可视为相等。

自建示例
--------

需要使用分数中间结果：

.. code-block:: text

   输入：cards = [3,3,8,8]
   输出：true
   解释：表达式 8/(3-8/3) 的值为 24，四个数字都恰好使用一次。

四个数无法组成 24：

.. code-block:: text

   输入：cards = [1,1,1,1]
   输出：false
   解释：只使用四则运算和括号时，四个 1 无法得到 24。
