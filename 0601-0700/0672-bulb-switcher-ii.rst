0672. Bulb Switcher II
======================

题目信息
--------

:题号: 0672
:难度: Medium
:主题: 灯泡状态、四种翻转操作、精确按键次数、不同结果计数
:原题: `LeetCode 0672 <https://leetcode.com/problems/bulb-switcher-ii/>`_
:重点: 所有灯初始点亮、必须恰好按 presses 次、同一按钮可重复、只统计最终开关状态不同的方案

题目重述
--------

有编号 ``1`` 到 ``n`` 的灯泡，初始全部点亮。每次按键可以选择四种操作之一：翻转全部灯；翻转偶数编号灯；翻转奇数编号灯；翻转编号满足 ``3k+1`` 的灯，即 ``1,4,7,...``。

必须恰好执行 ``presses`` 次按键，同一操作可以重复选择。返回经过这些操作后可能出现的不同最终灯泡状态数量；不同按键顺序若得到相同状态只计一次。``n`` 位于 ``[1, 1000]``，``presses`` 位于 ``[0, 1000]``。

自建示例
--------

一个按键产生三个不同状态：

.. code-block:: text

   输入：n = 2，presses = 1
   输出：3
   解释：翻转全部得到 00，翻转偶数灯得到 10，翻转奇数灯或 3k+1 灯都得到 01，因此共有三种状态。

不执行任何操作：

.. code-block:: text

   输入：n = 5，presses = 0
   输出：1
   解释：必须恰好执行零次按键，唯一结果是五盏灯全部保持点亮。
