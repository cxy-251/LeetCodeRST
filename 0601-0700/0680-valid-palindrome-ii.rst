0680. Valid Palindrome II
=========================

题目信息
--------

:题号: 0680
:难度: Easy
:主题: 字符串、回文、至多删除一个字符
:原题: `LeetCode 0680 <https://leetcode.com/problems/valid-palindrome-ii/>`_
:重点: 可以删除零个或一个位置、剩余字符保持原顺序、删除后整个字符串必须是回文

题目重述
--------

给定只包含小写英文字母的字符串 ``s``，判断能否通过删除至多一个字符，使剩余字符串成为回文串。

可以选择完全不删除；若删除字符，只能删除一个数组位置，不能交换或修改其他字符。回文要求剩余字符串正向和反向读取相同。``s.length`` 位于 ``[1, 10^5]``。

自建示例
--------

删除末尾字符后成为回文：

.. code-block:: text

   输入：s = "deifiedx"
   输出：true
   解释：删除末尾的 x 后得到 "deified"，正向和反向读取相同。

删除任意一个字符仍不够：

.. code-block:: text

   输入：s = "abc"
   输出：false
   解释：删除一个字符后只能得到 "ab"、"ac" 或 "bc"，它们都不是回文串。
