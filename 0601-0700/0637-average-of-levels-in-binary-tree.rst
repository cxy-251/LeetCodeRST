0637. Average of Levels in Binary Tree
======================================

题目信息
--------

:题号: 0637
:难度: Easy
:主题: 二叉树、层级分组、算术平均值、浮点结果
:原题: `LeetCode 0637 <https://leetcode.com/problems/average-of-levels-in-binary-tree/>`_
:重点: 按根节点所在层开始逐层统计、每层只使用该层节点、返回值顺序从上到下、允许浮点误差

题目重述
--------

给定非空二叉树根节点 ``root``，计算树中每一层所有节点值的算术平均数，并按照从根层到最深层的顺序返回这些平均值。

同一深度的全部节点共同组成一层；缺失孩子不参与平均值计算。树中节点数位于 ``[1, 10^4]``，节点值位于 32 位有符号整数范围内。返回结果中每个数与正确答案的误差不超过 ``10^-5`` 即可接受，求和时需要避免整数溢出。

自建示例
--------

同一层同时包含正数和负数：

.. code-block:: text

   输入：root = [5,1,9,-3,3,7,11]
   输出：[5.0,5.0,4.5]
   解释：三层的节点值分别为 [5]、[1,9]、[-3,3,7,11]，平均值依次为 5、5 和 4.5。

只有一个节点：

.. code-block:: text

   输入：root = [-8]
   输出：[-8.0]
   解释：树只有根层，该层平均值就是根节点本身的值。
