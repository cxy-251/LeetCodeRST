0650. 2 Keys Keyboard
=====================

题目信息
--------

:题号: 0650
:难度: Medium
:主题: 字符数量、全选复制、粘贴、最少操作
:原题: `LeetCode 0650 <https://leetcode.com/problems/2-keys-keyboard/>`_
:重点: 初始只有一个 A、Copy All 必须复制当前全部字符、Paste 使用最近一次复制内容、目标是恰好得到 n 个 A

题目重述
--------

记事本初始只显示一个字符 ``'A'``。每次操作只能选择以下一种：``Copy All`` 复制屏幕上的全部字符；``Paste`` 把最近一次复制的内容追加到屏幕末尾。

给定整数 ``n``，返回恰好得到 ``n`` 个 ``'A'`` 所需的最少操作次数。不能只复制部分字符；在没有执行过复制时，粘贴没有可用的新内容。``n`` 位于 ``[1, 1000]``，初始的一个 ``'A'`` 不计作操作。

自建示例
--------

中途重新复制当前全部内容：

.. code-block:: text

   输入：n = 6
   输出：5
   解释：依次执行 Copy All、Paste、Paste 得到 3 个 A，再执行 Copy All、Paste 得到 6 个 A，共五次操作。

目标就是初始状态：

.. code-block:: text

   输入：n = 1
   输出：0
   解释：屏幕开始时已经有一个 A，不需要执行任何操作。
