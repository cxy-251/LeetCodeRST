0605. Can Place Flowers
=======================

题目信息
--------

:题号: 0605
:难度: Easy
:主题: 二进制数组、相邻限制、可行性判断
:原题: `LeetCode 0605 <https://leetcode.com/problems/can-place-flowers/>`_
:重点: 只能在空地种花、新花不能与已有或新种花朵相邻、原花坛已保证合法、只需判断能否至少种下 n 朵

题目重述
--------

给定只包含 ``0`` 和 ``1`` 的数组 ``flowerbed``，其中 ``0`` 表示空地，``1`` 表示已经种有花；相邻位置不能同时有花。再给定整数 ``n``，判断能否在不违反相邻限制的前提下新种至少 ``n`` 朵花。

数组初始状态保证不存在相邻的两个 ``1``。``flowerbed.length`` 位于 ``[1, 2 * 10^4]``，``n`` 位于 ``[0, flowerbed.length]``。数组首尾位置只需检查其唯一存在的相邻位置；当 ``n = 0`` 时无需种花即可返回 ``true``。

自建示例
--------

同时利用花坛两端：

.. code-block:: text

   输入：flowerbed = [0,0,1,0,0]，n = 2
   输出：true
   解释：可以在下标 0 和 4 种花，两朵新花都不与下标 2 的已有花相邻。

空位数量足够但无法同时使用：

.. code-block:: text

   输入：flowerbed = [1,0,0,0,0,1]，n = 2
   输出：false
   解释：中间四个空位中最多只能选择一个合法位置，无法种下两朵互不相邻且不靠近已有花的新花。
