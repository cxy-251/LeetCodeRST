0621. Task Scheduler
====================

题目信息
--------

:题号: 0621
:难度: Medium
:主题: 任务序列、冷却间隔、空闲时间、最短总时长
:原题: `LeetCode 0621 <https://leetcode.com/problems/task-scheduler/>`_
:重点: 每个任务恰好执行一次、相同字母任务之间至少间隔 n 个单位、不同任务可任意排序、必要时允许插入空闲单位

题目重述
--------

给定字符数组 ``tasks`` 和非负整数 ``n``。每个字符表示一个需要占用一个时间单位的 CPU 任务；所有任务都必须执行一次，执行顺序可以重新安排。

两个相同字母的任务之间必须至少经过 ``n`` 个完整时间单位，这些单位可以执行其他任务，也可以保持空闲。返回完成全部任务所需的最少时间单位数。``tasks.length`` 位于 ``[1, 10^4]``，任务只使用大写英文字母，``n`` 位于 ``[0, 100]``。

自建示例
--------

需要插入一个空闲单位：

.. code-block:: text

   输入：tasks = ["A","A","A","B","C","C"]，n = 2
   输出：7
   解释：一种最短安排为 A、C、B、A、C、idle、A；任意两个 A 之间都隔开至少两个单位，总时长为 7。

没有冷却限制：

.. code-block:: text

   输入：tasks = ["D","D","E"]，n = 0
   输出：3
   解释：相同任务之间无需留出间隔，三个任务连续执行即可完成。
