0682. Baseball Game
===================

题目信息
--------

:题号: 0682
:难度: Easy
:主题: 得分记录、撤销、引用前序成绩、最终总和
:原题: `LeetCode 0682 <https://leetcode.com/problems/baseball-game/>`_
:重点: 整数字符串新增成绩、C 删除最近有效成绩、D 和 + 只引用当前仍有效的记录、输入保证每项操作合法

题目重述
--------

给定操作数组 ``operations``，按顺序维护一份比赛得分记录。整数字符串表示新增该分数；``"C"`` 删除最近一条仍有效的分数；``"D"`` 新增最近有效分数的两倍；``"+"`` 新增最近两条有效分数之和。

执行全部操作后，返回当前有效得分的总和。被 ``C`` 删除的成绩不再参与后续 ``D`` 或 ``+`` 的引用。输入保证每个操作在当时都有足够的前序记录可用。操作数位于 ``[1, 1000]``，答案保证在 32 位有符号整数范围内。

自建示例
--------

新增负分并撤销最近结果：

.. code-block:: text

   输入：operations = ["5","-2","D","+","C"]
   输出：-1
   解释：有效记录依次变为 [5]、[5,-2]、[5,-2,-4]、[5,-2,-4,-6]，最后撤销 -6，剩余总和为 -1。

撤销后重新开始记录：

.. code-block:: text

   输入：operations = ["3","C","7"]
   输出：7
   解释：成绩 3 被删除，最后只有新加入的成绩 7 保持有效。
