0653. Two Sum IV - Input is a BST
=================================

题目信息
--------

:题号: 0653
:难度: Easy
:主题: 二叉搜索树、两个不同节点、目标和
:原题: `LeetCode 0653 <https://leetcode.com/problems/two-sum-iv-input-is-a-bst/>`_
:重点: 必须选择树中两个不同节点、比较的是节点值之和、即使目标是某值的两倍也需要树中确实存在两个节点

题目重述
--------

给定非空二叉搜索树根节点 ``root`` 和整数 ``k``，判断树中是否存在两个不同节点，使它们的节点值之和恰好等于 ``k``。

不能把同一个节点使用两次；若两个不同节点具有相同的值，它们仍可以共同组成答案。树中节点数位于 ``[1, 10^4]``，节点值位于 ``[-10^4, 10^4]``，``k`` 位于 ``[-10^5, 10^5]``。

自建示例
--------

存在多组可行节点：

.. code-block:: text

   输入：root = [5,3,8,2,4,7,9]，k = 11
   输出：true
   解释：节点 2 与 9 的值之和为 11，节点 3 与 8 也满足条件；存在任意一组即可返回 true。

目标值无法由两个节点得到：

.. code-block:: text

   输入：root = [6,2,10,1,4,8,12]，k = 20
   输出：false
   解释：虽然树中有节点值 10，但不能重复使用同一个节点，树中也没有第二个值为 10 的节点。
