0617. Merge Two Binary Trees
============================

题目信息
--------

:题号: 0617
:难度: Easy
:主题: 二叉树、对应位置、节点值相加、结构合并
:原题: `LeetCode 0617 <https://leetcode.com/problems/merge-two-binary-trees/>`_
:重点: 两棵树从根开始按相同位置重叠、双方都有节点时值相加、只有一方有节点时该子树保留

题目重述
--------

给定两棵二叉树的根节点 ``root1`` 和 ``root2``，把它们从根开始按相同结构位置重叠，返回合并后树的根节点。

若某个位置两棵树都存在节点，合并节点的值等于两节点值之和，并继续合并对应的左右子树；若只有一棵树在该位置存在节点，结果中保留这一节点及其子树；若双方都为空，结果也为空。两棵树合计节点数位于 ``[0, 2000]``，节点值位于 ``[-10^4, 10^4]``。

自建示例
--------

不同位置的子树同时保留：

.. code-block:: text

   输入：root1 = [2,1,4]，root2 = [3,null,5]
   输出：[5,1,9]
   解释：根节点相加得到 5；左侧只有第一棵树的节点 1；右侧两个节点相加得到 9。

其中一棵树为空：

.. code-block:: text

   输入：root1 = null，root2 = [7,6]
   输出：[7,6]
   解释：没有重叠节点需要相加，结果保留第二棵树的全部结构和节点值。
