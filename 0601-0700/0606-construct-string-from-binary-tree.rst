0606. Construct String from Binary Tree
=======================================

题目信息
--------

:题号: 0606
:难度: Medium
:主题: 二叉树、先序表示、括号结构、空孩子语义
:原题: `LeetCode 0606 <https://leetcode.com/problems/construct-string-from-binary-tree/>`_
:重点: 按根左右顺序生成字符串、通常省略空孩子括号、仅有右孩子时必须保留左侧空括号以维持唯一结构

题目重述
--------

给定非空二叉树的根节点 ``root``，按照先序顺序把整棵树转换成字符串。每个节点先写自身整数值；存在孩子时，左子树和右子树分别放在紧随节点值的括号中。

没有孩子的空括号通常省略；但当某个节点没有左孩子而存在右孩子时，必须先写 ``()`` 表示缺失的左孩子，再写右子树，确保字符串能够唯一还原原树。树中节点数位于 ``[1, 10^4]``，节点值位于 ``[-1000, 1000]``。

自建示例
--------

节点只有右孩子：

.. code-block:: text

   输入：root = [8,4,10,null,6]
   输出："8(4()(6))(10)"
   解释：节点 4 没有左孩子但有右孩子 6，因此必须保留 4 后面的空左括号。

可以省略末尾空孩子：

.. code-block:: text

   输入：root = [5,3,null,2]
   输出："5(3(2))"
   解释：节点 3 只有左孩子 2，右侧空括号可以省略；根节点 5 的空右子树也无需表示。
