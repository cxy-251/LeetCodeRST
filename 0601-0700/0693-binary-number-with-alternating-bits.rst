0693. Binary Number with Alternating Bits
=========================================

题目信息
--------

:题号: 0693
:难度: Easy
:主题: 正整数、标准二进制表示、相邻位交替
:原题: `LeetCode 0693 <https://leetcode.com/problems/binary-number-with-alternating-bits/>`_
:重点: 使用不含前导零的标准二进制表示、每一对相邻位都必须不同、只有一位的数也满足条件

题目重述
--------

给定正整数 ``n``，判断其标准二进制表示中的相邻位是否始终交替，即任意相邻两位中一位为 ``0``、另一位为 ``1``。

判断时不人为添加前导零。只要出现相邻的 ``00`` 或 ``11`` 就返回 ``false``；单个二进制位没有相邻冲突，因此返回 ``true``。``n`` 位于 ``[1, 2^31 - 1]``。

自建示例
--------

所有相邻位都不同：

.. code-block:: text

   输入：n = 10
   输出：true
   解释：10 的二进制表示是 1010，任意相邻两位都一零一一交替出现。

末尾出现相同位：

.. code-block:: text

   输入：n = 11
   输出：false
   解释：11 的二进制表示是 1011，最后两位都是 1，不满足交替条件。
