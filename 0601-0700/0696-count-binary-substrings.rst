0696. Count Binary Substrings
=============================

题目信息
--------

:题号: 0696
:难度: Easy
:主题: 二进制字符串、连续子串、两段等长分组、按位置计数
:原题: `LeetCode 0696 <https://leetcode.com/problems/count-binary-substrings/>`_
:重点: 子串中 0 和 1 数量必须相等、同类字符各自连续成一段、只能发生一次 0/1 切换、相同文本不同位置分别计数

题目重述
--------

给定二进制字符串 ``s``，统计满足以下条件的非空连续子串数量：子串中 ``0`` 和 ``1`` 的数量相等，并且所有 ``0`` 连续排列、所有 ``1`` 也连续排列。

因此合法子串只能形如若干个 ``0`` 后接同样数量的 ``1``，或若干个 ``1`` 后接同样数量的 ``0``，不能在内部多次切换字符。相同内容出现在不同起止位置时分别计数。``s.length`` 位于 ``[1, 10^5]``。

自建示例
--------

相邻分组长度不同：

.. code-block:: text

   输入：s = "001110"
   输出：3
   解释：前两个分组 00 和 111 贡献 "0011"、"01" 两个子串，后两个分组 111 和 0 贡献 "10" 一个子串。

字符串只有一种字符：

.. code-block:: text

   输入：s = "111"
   输出：0
   解释：不存在字符 0，因此任何子串都无法同时含有等量的 0 和 1。
