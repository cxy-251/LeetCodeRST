0645. Set Mismatch
==================

题目信息
--------

:题号: 0645
:难度: Easy
:主题: 1 到 n 集合、重复值、缺失值、固定返回顺序
:原题: `LeetCode 0645 <https://leetcode.com/problems/set-mismatch/>`_
:重点: 一个数被重复写入两次并导致另一个数缺失、其余数各出现一次、返回 [重复值, 缺失值]

题目重述
--------

长度为 ``n`` 的数组 ``nums`` 原本应包含整数 ``1`` 到 ``n`` 各一次，但其中一个数被错误地重复了一次，导致另一个数没有出现。

找出重复值和缺失值，并按 ``[重复值, 缺失值]`` 的顺序返回。``nums.length`` 位于 ``[2, 10^4]``，所有元素位于 ``[1, n]``；题目保证恰好存在一个出现两次的数和一个完全缺失的数。

自建示例
--------

缺失值位于重复值之后：

.. code-block:: text

   输入：nums = [1,2,2,4,5]
   输出：[2,3]
   解释：2 出现两次，而完整集合 1..5 中的 3 没有出现。

缺失值位于数组中间：

.. code-block:: text

   输入：nums = [3,1,3]
   输出：[3,2]
   解释：3 被重复写入，原本应该出现的 2 缺失；返回顺序不能交换。
