0659. Split Array into Consecutive Subsequences
===============================================

题目信息
--------

:题号: 0659
:难度: Medium
:主题: 有序数组、元素分组、连续递增子序列、最小长度
:原题: `LeetCode 0659 <https://leetcode.com/problems/split-array-into-consecutive-subsequences/>`_
:重点: 每个元素实例必须恰好使用一次、每条子序列相邻值递增 1、每条长度至少为 3、重复值可以分配给不同子序列

题目重述
--------

给定按非递减顺序排列的整数数组 ``nums``，判断能否把数组中的所有元素划分为一条或多条子序列，使每条子序列都由连续整数构成，并且长度至少为 ``3``。

每个数组位置必须恰好属于一条子序列；子序列内相邻元素的值必须恰好增加 ``1``。相同数值的多个出现是不同元素，可以被分配到不同子序列。``nums.length`` 位于 ``[1, 10^4]``，元素值位于 ``[-1000, 1000]``。

自建示例
--------

不同长度的两条子序列：

.. code-block:: text

   输入：nums = [2,3,4,4,5,6,7]
   输出：true
   解释：可以划分为 [2,3,4] 和 [4,5,6,7]，两条都连续且长度不少于 3。

存在无法安置的重复值：

.. code-block:: text

   输入：nums = [1,2,3,4,4,5]
   输出：false
   解释：无论怎样划分，其中一个值为 4 的元素都无法加入长度至少为 3 的连续子序列，同时覆盖其余所有元素。
