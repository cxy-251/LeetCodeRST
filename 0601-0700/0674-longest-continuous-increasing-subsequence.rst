0674. Longest Continuous Increasing Subsequence
===============================================

题目信息
--------

:题号: 0674
:难度: Easy
:主题: 数组、连续子数组、严格递增、最大长度
:原题: `LeetCode 0674 <https://leetcode.com/problems/longest-continuous-increasing-subsequence/>`_
:重点: 选择区间必须连续、每个后项严格大于前项、相等会中断当前区间、返回最长区间长度

题目重述
--------

给定整数数组 ``nums``，寻找其中最长的连续严格递增区间，并返回其长度。

连续意味着选择原数组中的一段相邻元素，不能跳过中间位置；严格递增要求区间内每个元素都大于前一个元素，相等或下降都会结束当前递增区间。``nums.length`` 位于 ``[1, 10^4]``，元素值位于 ``[-10^9, 10^9]``。

自建示例
--------

最长区间位于后半部分：

.. code-block:: text

   输入：nums = [2,3,1,2,3,4]
   输出：4
   解释：连续区间 [1,2,3,4] 严格递增，长度为 4；前面的 [2,3] 更短。

相等元素会中断递增：

.. code-block:: text

   输入：nums = [5,5,5]
   输出：1
   解释：任何相邻两个元素都不满足严格大于，因此最长连续递增区间只能包含一个元素。
