0661. Image Smoother
====================

题目信息
--------

:题号: 0661
:难度: Easy
:主题: 整数矩阵、八邻域、边界裁剪、向下取整平均值
:原题: `LeetCode 0661 <https://leetcode.com/problems/image-smoother/>`_
:重点: 每个输出格使用原矩阵中自身及最多八个邻居、越界位置不参与、平均值向下取整、所有格必须基于原始值计算

题目重述
--------

给定表示灰度图像的 ``m × n`` 整数矩阵 ``img``。对每个格子，收集原矩阵中该格子自身以及横、竖、对角方向相邻且仍在矩阵范围内的格子，计算这些值的算术平均数并向下取整。

返回由所有平滑结果组成的新矩阵。不同输出格的计算都必须使用原始 ``img``，不能使用已经得到的平滑值。``m``、``n`` 位于 ``[1, 200]``，每个像素值位于 ``[0, 255]``。

自建示例
--------

所有格共享同一邻域：

.. code-block:: text

   输入：img = [[1,2],[3,4]]
   输出：[[2,2],[2,2]]
   解释：每个格子的有效邻域都是全部四个格子，平均值为 2.5，向下取整得到 2。

单行矩阵的边界邻域：

.. code-block:: text

   输入：img = [[5,10,20]]
   输出：[[7,11,15]]
   解释：两端各平均两个有效格子，中间平均三个格子，结果分别为 7、11、15。
