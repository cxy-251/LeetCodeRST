0657. Robot Return to Origin
============================

题目信息
--------

:题号: 0657
:难度: Easy
:主题: 平面坐标、方向指令、最终位置
:原题: `LeetCode 0657 <https://leetcode.com/problems/robot-return-to-origin/>`_
:重点: 机器人从原点出发、每个字符移动一个单位、只比较执行全部指令后的最终位置、路径中途是否回到原点不影响结果

题目重述
--------

机器人从二维平面的原点 ``(0, 0)`` 出发。字符串 ``moves`` 由 ``'U'``、``'D'``、``'L'``、``'R'`` 组成，分别表示向上、下、左、右移动一个单位。

按顺序执行全部指令后，判断机器人是否恰好回到原点。只检查最终坐标；机器人可以在执行过程中多次经过原点。``moves.length`` 位于 ``[1, 2 * 10^4]``。

自建示例
--------

四个方向最终抵消：

.. code-block:: text

   输入：moves = "UURRDDLL"
   输出：true
   解释：向上、右、下、左各移动两个单位，最终横纵坐标都重新变为 0。

只抵消了一个坐标方向：

.. code-block:: text

   输入：moves = "UDR"
   输出：false
   解释：上下移动相互抵消，但最后仍向右移动一个单位，最终位置为 (1,0)。
