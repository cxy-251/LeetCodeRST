0643. Maximum Average Subarray I
================================

题目信息
--------

:题号: 0643
:难度: Easy
:主题: 数组、固定长度连续子数组、最大平均值
:原题: `LeetCode 0643 <https://leetcode.com/problems/maximum-average-subarray-i/>`_
:重点: 子数组必须连续且长度恰好为 k、比较所有合法窗口、返回最大算术平均值而不是最大总和

题目重述
--------

给定整数数组 ``nums`` 和整数 ``k``，在数组中选择长度恰好为 ``k`` 的连续子数组，返回这些子数组中能够得到的最大平均值。

``nums.length`` 位于 ``[1, 10^5]``，``k`` 位于 ``[1, nums.length]``，元素值位于 ``[-10^4, 10^4]``。答案与正确值的绝对误差或相对误差不超过 ``10^-5`` 即可接受；负数也正常参与平均值计算。

自建示例
--------

最大窗口位于数组末尾：

.. code-block:: text

   输入：nums = [4,-2,7,1,5]，k = 3
   输出：4.3333333333
   解释：三个窗口的和分别为 9、6、13，最大平均值来自 [7,1,5]，等于 13/3。

窗口必须覆盖整个数组：

.. code-block:: text

   输入：nums = [-3,5,1]，k = 3
   输出：1.0
   解释：只有整个数组这一段合法，其平均值为 (-3+5+1)/3=1。
