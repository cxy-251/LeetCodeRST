0700. Search in a Binary Search Tree
====================================

题目信息
--------

:题号: 0700
:难度: Easy
:主题: 二叉搜索树、目标值、原节点引用、子树返回
:原题: `LeetCode 0700 <https://leetcode.com/problems/search-in-a-binary-search-tree/>`_
:重点: 根据 BST 大小关系查找目标值、找到时返回树中原节点及其完整子树、未找到时返回空节点

题目重述
--------

给定一棵二叉搜索树的根节点 ``root`` 和整数 ``val``，在树中查找节点值等于 ``val`` 的节点。

若目标节点存在，返回树中该原节点的引用，也就是以该节点为根的完整子树；不能只返回节点值或新建一个同值节点。若不存在目标值，返回 ``null``。树中节点数位于 ``[1, 5000]``，节点值互不相同且位于 ``[1, 10^7]``，``val`` 也位于 ``[1, 10^7]``。

自建示例
--------

返回目标节点的完整子树：

.. code-block:: text

   输入：root = [8,3,10,1,6,9,14]，val = 3
   输出：[3,1,6]
   解释：值为 3 的原节点存在，返回它以及其左孩子 1、右孩子 6 组成的完整子树。

目标值不存在：

.. code-block:: text

   输入：root = [8,3,10,1,6,9,14]，val = 7
   输出：null
   解释：按二叉搜索树的值关系查找后，树中没有值为 7 的节点。
