0690. Employee Importance
=========================

题目信息
--------

:题号: 0690
:难度: Medium
:主题: 员工对象、直接与间接下属、递归汇总
:原题: `LeetCode 0690 <https://leetcode.com/problems/employee-importance/>`_
:重点: 每个员工编号唯一、总重要度包含本人及全部层级下属、subordinates 只列直接下属、给定 id 保证存在

题目重述
--------

给定员工对象数组 ``employees``。每个员工包含唯一整数 ``id``、整数 ``importance``，以及直接下属编号列表 ``subordinates``。再给定目标员工编号 ``id``。

返回该员工本人的重要度，加上其全部直接和间接下属的重要度总和。下属列表中的编号需要继续查找对应员工对象并递归包含其下属；不属于目标员工管理层级的员工不能计入。员工数量位于 ``[1, 2000]``，重要度位于 ``[-100, 100]``，目标编号保证存在。

自建示例
--------

包含多层间接下属：

.. code-block:: text

   输入：employees = [[1,5,[2,3]],[2,3,[]],[3,4,[4]],[4,2,[]]]，id = 1
   输出：14
   解释：员工 1 的层级包含本人、直接下属 2 和 3，以及员工 3 的下属 4，总重要度为 5+3+4+2=14。

查询叶子员工：

.. code-block:: text

   输入：employees = [[1,6,[2]],[2,-2,[]]]，id = 2
   输出：-2
   解释：员工 2 没有下属，因此结果只包含其本人的重要度 -2。
