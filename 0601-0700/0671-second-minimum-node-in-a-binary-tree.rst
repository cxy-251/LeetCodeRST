0671. Second Minimum Node In a Binary Tree
==========================================

题目信息
--------

:题号: 0671
:难度: Easy
:主题: 特殊二叉树、最小值、严格第二小、重复值
:原题: `LeetCode 0671 <https://leetcode.com/problems/second-minimum-node-in-a-binary-tree/>`_
:重点: 每个节点要么无孩子要么有两个孩子、内部节点值等于两个孩子值的较小者、第二小必须严格大于全树最小值

题目重述
--------

给定一棵非空特殊二叉树：每个节点要么没有孩子，要么同时具有左、右孩子；对于每个内部节点，其值等于两个孩子节点值中的较小值。

返回整棵树中严格大于最小节点值的最小数，也就是不同数值意义下的第二小值。若树中不存在更大的数，返回 ``-1``。树中节点数位于 ``[1, 25]``，节点值位于 ``[1, 2^31-1]``；由特殊性质可知根节点值就是全树最小值。

自建示例
--------

最小值出现多次：

.. code-block:: text

   输入：root = [2,2,5,null,null,5,7]
   输出：5
   解释：最小值 2 出现多次，但第二小必须是严格更大的不同数值，因此答案为 5。

全树只有一种数值：

.. code-block:: text

   输入：root = [3,3,3]
   输出：-1
   解释：没有任何节点值严格大于根节点值 3，因此不存在第二小值。
