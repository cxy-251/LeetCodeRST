0287. Find the Duplicate Number
===============================

题目信息
--------

:题号: 0287
:难度: Medium
:主题: 数组、重复值、只读输入、常数空间
:原题: `LeetCode 0287 <https://leetcode.com/problems/find-the-duplicate-number/>`_
:重点: 长度为 ``n+1`` 而取值只有 ``1..n``、唯一重复值可出现多次、不能修改数组

题目重述
--------

给定包含 ``n+1`` 个整数的数组 ``nums``，每个元素都位于 ``[1, n]``。题目保证只有一个不同的整数在数组中重复出现，但这个整数可能出现两次，也可能出现更多次。返回这个唯一的重复值。

``1 <= n <= 10^5``。答案值唯一，不要求返回重复位置或出现次数。必须把输入数组视为只读，不能通过排序、取负标记或交换元素来改变其内容；同时只允许使用常数级额外空间。题目的进阶要求整体运行时间不超过 ``O(n)``。

自建示例
--------

重复值出现两次：

.. code-block:: text

   输入：nums = [2, 5, 1, 4, 3, 5]
   输出：5
   解释：数组长度为 6，因此 n = 5，所有值都在 1..5 中；只有 5 重复出现。

同一个值出现多次：

.. code-block:: text

   输入：nums = [3, 1, 3, 4, 2, 3]
   输出：3
   解释：3 出现三次，其他出现过的值都没有重复；题目仍只要求返回重复值 3。
