0274. H-Index
=============

题目信息
--------

:题号: 0274
:难度: Medium
:主题: 数组、引用次数、阈值统计
:原题: `LeetCode 0274 <https://leetcode.com/problems/h-index/>`_
:重点: ``h`` 同时表示论文数量和最低引用阈值、返回最大可行值、输入数组未排序

题目重述
--------

给定整数数组 ``citations``，其中 ``citations[i]`` 表示研究者第 ``i`` 篇论文获得的引用次数。返回该研究者的 H 指数：最大的整数 ``h``，使得至少有 ``h`` 篇论文各自被引用不少于 ``h`` 次，并且其余论文各自被引用不多于 ``h`` 次。

论文数量位于 ``[1, 5000]``，每篇论文的引用次数位于 ``[0, 1000]``。输入顺序没有排序保证。答案一定在 ``[0, citations.length]`` 内；只有满足条件的最大 ``h`` 才是最终结果，而不是任意一个可行阈值。

自建示例
--------

最大可行阈值位于中间：

.. code-block:: text

   输入：citations = [10, 8, 5, 4, 3]
   输出：4
   解释：有四篇论文的引用次数至少为 4；若取 h = 5，则只有三篇论文达到至少 5 次，因此最大值是 4。

所有论文都没有引用：

.. code-block:: text

   输入：citations = [0, 0, 0]
   输出：0
   解释：不存在至少一篇引用次数不少于 1 的论文，所以只有 h = 0 满足定义。
