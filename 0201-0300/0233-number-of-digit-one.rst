0233. Number of Digit One
=========================

题目信息
--------

:题号: 0233
:难度: Hard
:主题: 数学、数位统计、动态规划
:原题: `LeetCode 0233 <https://leetcode.com/problems/number-of-digit-one/>`_
:教学重点: 高位当前位低位分解、位权贡献

题目重述
--------

给定非负整数 ``n``，接口为 ``int countDigitOne(int n)``。返回从 0 到 ``n`` 的所有十进制整数中数字 ``1`` 出现的总次数。``n`` 最多约 ``10^9``，答案适合 32 位整数；前导零不计为数字。

自建示例
--------

.. code-block:: text

   输入：20
   输出：12
   说明：个位贡献 2 次，十位贡献 10 次。
