0218. The Skyline Problem
=========================

题目信息
--------

:题号: 0218. 天际线问题
:难度: Hard
:主题: 扫描线、事件排序、多重集合、轮廓压缩
:原题: `LeetCode 0218 <https://leetcode.com/problems/the-skyline-problem/>`_
:重点: 建筑起止事件、同坐标批处理、当前最高高度、关键点去重

题目重述
--------

城市中的每座建筑由 ``[left, right, height]`` 表示，覆盖横坐标区间 ``left <= x < right``，高度为正整数，
建筑边与坐标轴平行。返回城市从左到右的外轮廓关键点 ``[x, height]``：在 ``x`` 处轮廓高度发生变化时输出当前高度，
最后必须回到 0；相邻关键点的高度不能相同。建筑可以重叠、包含或在端点接触，输出按坐标递增。

建筑数量最多 ``10^4``，每座建筑保证 ``left < right``。题目要求的是轮廓，不是每个横坐标的高度列表，因此连续保持相同高度的区间
必须压缩成一个起点，边界只接触而高度不变时不能产生多余关键点。

自建示例
--------

部分重叠：

.. code-block:: text

   buildings = [[2,9,10],[3,7,15],[5,12,12]]
   输出 = [[2,10],[3,15],[7,12],[12,0]]

``x=7`` 时高度 15 的建筑结束，但高度 12 的建筑仍然活动；``x=12`` 最后一座建筑结束，轮廓回到 0。

同坐标事件不能制造假拐点：``[[1,3,4],[3,5,4]]`` 的输出是 ``[[1,4],[5,0]]``。两座楼在 ``x=3`` 只发生接替，
右侧最高高度仍为 4，不能先因第一座结束输出 0、再因第二座开始输出 4。

从横坐标切片到扫描线
--------------------

直接收集所有不同的左右边界，把相邻边界切成小段，再为每一小段扫描全部建筑寻找最高高度。若有 ``n`` 座建筑和 ``2n`` 个边界，
一次查找就可能检查 ``n`` 座建筑，重复工作达到 ``O(n^2)``。

轮廓只可能在建筑开始或结束的横坐标改变，因此将每座建筑压缩为两个事件：在 ``left`` 加入高度，在 ``right`` 移除高度。
扫描线从左到右处理事件；处理完整个坐标的一组事件后，活动建筑集合正好描述从当前 ``x`` 到下一个事件坐标之间的高度。

活动高度的状态
--------------

维护 ``active`` 为活动建筑高度的多重集合，并放入高度 0 哨兵表示“没有建筑”。在每个坐标 ``x`` 处理完所有事件后，
集合保持以下不变量：

* ``active`` 包含且只包含覆盖右侧开区间 ``[x, next_x)`` 的建筑高度；
* ``*active.rbegin()`` 是该区间的轮廓高度；
* 同样高度的不同建筑各有一份记录，结束一座不能影响仍在活动的另一座；
* ``previous_height`` 是上一个已输出区间的最高高度。

若当前最高高度与 ``previous_height`` 不同，``x`` 才是关键点；输出后更新 ``previous_height``。按坐标成组处理事件是状态不变量
成立的前提，否则同一坐标内的中间状态没有对应的非零宽度区间。

C++ 实现
--------

.. code-block:: cpp

   class Solution {
   public:
       std::vector<std::vector<int>> getSkyline(
           std::vector<std::vector<int>>& buildings) {
           std::vector<std::pair<int, int>> events;
           events.reserve(buildings.size() * 2);
           for (const std::vector<int>& building : buildings) {
               events.push_back({building[0], -building[2]});
               events.push_back({building[1], building[2]});
           }
           std::sort(events.begin(), events.end());

           std::multiset<int> active{0};
           std::vector<std::vector<int>> answer;
           int previous_height = 0;
           std::size_t index = 0;

           while (index < events.size()) {
               const int x = events[index].first;
               while (index < events.size() && events[index].first == x) {
                   const int encoded_height = events[index].second;
                   if (encoded_height < 0) {
                       active.insert(-encoded_height);
                   } else {
                       auto position = active.find(encoded_height);
                       active.erase(position);
                   }
                   ++index;
               }

               const int current_height = *active.rbegin();
               if (current_height != previous_height) {
                   answer.push_back({x, current_height});
                   previous_height = current_height;
               }
           }
           return answer;
       }
   };

题解
----

事件编码与同坐标批处理
~~~~~~~~~~~~~~~~~~~~~~

负高度表示开始事件，正高度表示结束事件；绝对值仍是建筑高度。``std::sort`` 会把事件按横坐标排列，外层循环把相同 ``x``
的事件归为一组。开始事件排在结束事件前只是排序的次序细节，轮廓高度必须在整组事件完成后才读取，因此不会依赖组内的瞬时状态。

例如在 ``x=3``，第一座高度 4 的楼结束、第二座高度 4 的楼开始。若每处理一个事件就输出，活动集合会短暂变成 ``{0}``，
产生不存在的 ``[3,0]``；成组更新后集合仍是 ``{0,4}``，与前一高度相同，正确地不输出任何点。

为什么必须是多重集合
~~~~~~~~~~~~~~~~~~~~~~

普通 ``set`` 只能保存一个高度副本。若两座高度都为 10 的楼重叠，第一座结束时直接删除 10 会错误地把轮廓降下来；
``multiset`` 为每座活动建筑保存一份记录。结束事件用 ``find`` 得到一份具体迭代器再删除，保留同高建筑的其他副本。

状态走读
~~~~~~~~

对 ``[[2,9,10],[3,7,15],[5,12,12]]``，扫描状态可以压缩为：

.. list-table::
   :header-rows: 1

   * - 坐标
     - 本坐标事件
     - 处理后活动高度
     - 输出
   * - 2
     - 加入 10
     - ``{0,10}``
     - ``[2,10]``
   * - 3
     - 加入 15
     - ``{0,10,15}``
     - ``[3,15]``
   * - 5
     - 加入 12
     - ``{0,10,12,15}``
     - 无，最高仍为 15
   * - 7
     - 移除 15
     - ``{0,10,12}``
     - ``[7,12]``
   * - 9
     - 移除 10
     - ``{0,12}``
     - 无，最高仍为 12
   * - 12
     - 移除 12
     - ``{0}``
     - ``[12,0]``

``previous_height`` 的作用是把同一水平线的连续区间压成一个点；活动集合则保留改变未来高度所需的全部建筑。

代码分析与复杂度
~~~~~~~~~~~~~~~~

事件数组把每座建筑的两个边界变成一次排序对象，后续扫描不再重复检查建筑与横坐标的关系。内层循环只负责改变 ``active``，
外层循环负责读取完整状态和决定是否输出；两层职责分开，正好对应“先更新状态、后观察轮廓”的推导。

空输入时事件数组为空，返回空轮廓；高度 0 哨兵保证最后一座建筑移除后 ``rbegin`` 仍有效。输入建筑的 ``left < right`` 保证
每个结束事件此前已经有对应的开始事件，``active.find`` 可以找到要移除的高度。算法不需要枚举建筑相交类型，分离、包含、端点接触
都由事件集合统一处理。

``n`` 座建筑产生 ``2n`` 个事件，排序时间 ``O(n log n)``；每个事件对多重集合做一次 ``O(log n)`` 插入或删除，扫描总时间仍为
``O(n log n)``，事件数组和活动集合占 ``O(n)`` 额外空间。输出关键点另占结果空间。相同坐标、相同高度、完全包含和只在边界接触的建筑
都必须先完成整组事件再比较最高值，否则会把零宽度的瞬时状态写进答案。
