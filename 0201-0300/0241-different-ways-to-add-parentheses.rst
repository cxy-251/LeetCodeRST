0241. Different Ways to Add Parentheses
=======================================

题目信息
--------

:题号: 0241
:难度: Medium
:主题: 表达式、括号分组、结果枚举
:原题: `LeetCode 0241 <https://leetcode.com/problems/different-ways-to-add-parentheses/>`_
:重点: 所有分组方式、加减乘、重复结果允许、返回顺序

题目重述
--------

给定一个由非负十进制整数和二元运算符 ``+``、``-``、``*`` 组成的字符串 ``expression``，通过添加括号改变运算分组，计算所有可能分组方式得到的结果，并把这些整数全部返回。

不同括号结构即使得到相同数值，也应在结果中分别保留，因此返回数组可以包含重复值；结果顺序没有要求。表达式长度在 ``1..20`` 范围内，所有可能结果都保证适合 32 位有符号整数。

自建示例
--------

.. code-block:: text

   输入：expression = "3-1-1"
   输出：[1,3]
   解释：(3 - 1) - 1 = 1，而 3 - (1 - 1) = 3；两种括号方式都要返回。

.. code-block:: text

   输入：expression = "2*3+4"
   输出：[10,14]
   解释：(2 * 3) + 4 = 10，2 * (3 + 4) = 14。输出顺序可以交换。
