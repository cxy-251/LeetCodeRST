0230. Kth Smallest Element in a BST
===================================

题目信息
--------

:题号: 0230
:难度: Medium
:主题: 二叉搜索树、顺序统计、节点值
:原题: `LeetCode 0230 <https://leetcode.com/problems/kth-smallest-element-in-a-bst/>`_
:重点: BST 有序性、一基排名、合法 k、返回节点值

题目重述
--------

给定一棵二叉搜索树的根节点 ``root`` 和整数 ``k``，把树中全部节点值按从小到大排列，返回其中第 ``k`` 个值。这里 ``k`` 从 ``1`` 开始计数，因此 ``k = 1`` 表示最小值。

树的节点数在 ``1..10^4`` 范围内，输入保证满足二叉搜索树性质，并且 ``1 <= k <=`` 节点总数。函数返回整数值，不需要返回节点对象，也不应修改树结构。

自建示例
--------

.. code-block:: text

   输入：root = [8,4,12,2,6,10,14], k = 5
   输出：10
   解释：节点值升序为 [2,4,6,8,10,12,14]，第 5 个值是 10。

.. code-block:: text

   输入：root = [3], k = 1
   输出：3
   解释：树中只有一个节点，它同时是第 1 小的值。
