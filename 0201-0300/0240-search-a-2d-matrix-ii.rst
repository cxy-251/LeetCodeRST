0240. Search a 2D Matrix II
===========================

题目信息
--------

:题号: 0240
:难度: Medium
:主题: 矩阵、有序数据、目标查找
:原题: `LeetCode 0240 <https://leetcode.com/problems/search-a-2d-matrix-ii/>`_
:重点: 行内有序、列内有序、目标存在性、矩阵只读

题目重述
--------

给定 ``m x n`` 整数矩阵 ``matrix`` 和整数 ``target``。矩阵的每一行都从左到右按非递减顺序排列，每一列都从上到下按非递减顺序排列。判断矩阵中是否至少存在一个元素等于 ``target``；存在时返回 ``true``，否则返回 ``false``。

行数和列数均在 ``1..300`` 范围内，矩阵元素和目标值都可能为负数、零或正数。函数只需判断目标是否存在，不修改矩阵，也不需要返回目标位置。

自建示例
--------

.. code-block:: text

   输入：matrix = [[1,4,7],[2,5,9],[3,6,12]], target = 6
   输出：true
   解释：元素 6 位于第三行第二列，因此目标存在。

.. code-block:: text

   输入：matrix = [[1,4,7],[2,5,9],[3,6,12]], target = 8
   输出：false
   解释：矩阵所有行和列都保持有序，但没有任何格子的值等于 8。
