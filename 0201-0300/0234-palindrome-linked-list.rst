0234. Palindrome Linked List
============================

题目信息
--------

:题号: 0234
:难度: Easy
:主题: 单链表、回文序列、节点值
:原题: `LeetCode 0234 <https://leetcode.com/problems/palindrome-linked-list/>`_
:重点: 正反读取一致、比较节点值、奇偶长度、空后继

题目重述
--------

给定单链表的头节点 ``head``，判断从头到尾得到的节点值序列是否为回文。若该序列从左向右与从右向左完全相同，返回 ``true``；否则返回 ``false``。判断依据是节点值的顺序，不是节点对象本身的地址。

链表节点数在 ``1..10^5`` 范围内，每个节点值在 ``0..9`` 范围内。函数只需返回判断结果，不要求返回回文对应的节点或下标。

自建示例
--------

.. code-block:: text

   输入：head = [2,4,4,2]
   输出：true
   解释：节点值序列正向和反向都是 [2,4,4,2]。

.. code-block:: text

   输入：head = [1,2,1,3]
   输出：false
   解释：反向序列为 [3,1,2,1]，与原序列不同。
