0224. Basic Calculator
======================

题目信息
--------

:题号: 0224
:难度: Hard
:主题: 字符串、表达式、括号、加减运算
:原题: `LeetCode 0224 <https://leetcode.com/problems/basic-calculator/>`_
:重点: 多位整数、空格、括号嵌套、正负号

题目重述
--------

给定一个合法的算术表达式字符串 ``s``，计算并返回其整数结果。表达式由十进制非负整数、空格、加号 ``+``、减号 ``-``、左括号和右括号组成，不包含乘法或除法；括号可以嵌套。

表达式长度最多为 ``3 * 10^5``，计算结果保证适合 32 位有符号整数。需要按正常的括号与加减运算规则求值，不能调用直接计算整段表达式的内置求值函数。

自建示例
--------

.. code-block:: text

   输入：s = "18-(7-(2+1))"
   输出：14
   解释：先算 2 + 1 = 3，再得 7 - 3 = 4，最后 18 - 4 = 14。

.. code-block:: text

   输入：s = " 30 - (8 + 5) + 2 "
   输出：19
   解释：空格不影响运算；括号内为 13，因此结果是 30 - 13 + 2 = 19。
