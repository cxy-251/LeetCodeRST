0224. Basic Calculator
======================

题目信息
--------

:题号: 0224
:难度: Hard
:主题: 栈、递归、字符串、表达式解析
:原题: `LeetCode 0224 <https://leetcode.com/problems/basic-calculator/>`_
:教学重点: 括号上下文、一元符号、逐字符解析

题目重述
--------

给定合法算术表达式字符串 ``s``，接口为 ``int calculate(string s)``。表达式包含非负整数、空格、``+``、``-`` 与括号，可出现一元负号；不包含乘除。字符串长度最多约 ``3 * 10^5``，平台保证表达式合法且结果为 32 位整数。返回计算结果，不调用内置表达式求值器。

自建示例
--------

.. code-block:: text

   输入："7-(2-(3+1))"
   输出：9

   输入："-(5-8)"
   输出：3
