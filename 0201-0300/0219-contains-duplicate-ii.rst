0219. Contains Duplicate II
===========================

题目信息
--------

:题号: 0219
:难度: Easy
:主题: 数组、哈希表、滑动窗口
:原题: `LeetCode 0219 <https://leetcode.com/problems/contains-duplicate-ii/>`_
:重点: 不同下标、相等元素、下标距离上限、最近出现位置

题目重述
--------

给定整数数组 ``nums`` 和非负整数 ``k``，判断是否存在两个不同下标 ``i``、``j``，使得 ``nums[i] == nums[j]``，并且 ``|i - j| <= k``。只要存在一对满足条件就返回 ``true``；否则返回 ``false``。

数组长度在 ``1..10^5`` 范围内，元素可为负数、零或正数，``k`` 可以为 ``0``。函数只判断是否存在符合条件的下标对，不修改输入数组。

自建示例
--------

.. code-block:: text

   输入：nums = [8,3,1,8], k = 3
   输出：true
   解释：值 8 分别位于下标 0 和 3，两者距离为 3，没有超过 k。

.. code-block:: text

   输入：nums = [5,2,5], k = 1
   输出：false
   解释：两个 5 的下标距离为 2；虽然数值相同，但距离超过 k。
