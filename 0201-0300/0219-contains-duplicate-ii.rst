0219. Contains Duplicate II
===========================

题目信息
--------

:题号: 0219
:难度: Easy
:主题: 数组、哈希表、滑动窗口
:原题: `LeetCode 0219 <https://leetcode.com/problems/contains-duplicate-ii/>`_
:重点: 两个不同下标、相等元素、下标距离不超过 k、k 为零的边界

题目重述
--------

给定整数数组 ``nums`` 和非负整数 ``k``，判断是否存在两个不同的零基下标 ``i``、``j``，同时满足 ``nums[i] == nums[j]`` 和 ``|i-j| <= k``。存在至少一对时返回 ``true``，否则返回 ``false``。

数组长度范围为 ``[1, 10^5]``，元素位于 ``[-10^9, 10^9]``，``k`` 位于 ``[0, 10^5]``。当 ``k=0`` 时，不同下标之间不可能满足距离限制，因此结果一定为 ``false``。函数只返回判断结果，不修改数组。

自建示例
--------

距离恰好达到上限：

.. code-block:: text

   输入：nums = [6, 2, 9, 6], k = 3
   输出：true
   解释：值 6 位于下标 0 和 3，两个下标不同，距离恰好等于 k。

存在重复但距离过远：

.. code-block:: text

   输入：nums = [4, 1, 4, 8], k = 1
   输出：false
   解释：两个 4 的下标距离为 2，数组中没有其他重复值满足距离限制。

滑动窗口
--------

扫描到下标 ``i`` 时，能够与当前元素配对的历史下标只能位于
``[i-k, i-1]``；更早的元素距离已经超过 ``k``，不应继续留在候选集合中。
因此维护一个集合 ``window``，它保存当前下标之前、最近 ``k`` 个位置上的不同值：

.. code-block:: text

   for i = 0 .. n-1:
       若 nums[i] 已在 window 中，返回 true
       把 nums[i] 加入 window
       若 i >= k，移除 nums[i-k]
   返回 false

检查必须发生在移除 ``nums[i-k]`` 之前：当 ``i-k`` 存在时，距离恰好为 ``k``，仍然是合法配对。
加入当前值后再移除最旧值，则下一轮开始时集合恰好对应新的滑动窗口。``k=0`` 时每轮只会留下当前值，
不同下标不可能同时出现在窗口内，结果必为 ``false``。

正确性说明
----------

循环开始处理 ``i`` 前，保持 ``window`` 恰好包含下标
``max(0, i-k)`` 到 ``i-1`` 中出现过的不同值。

若 ``nums[i]`` 已在集合中，则存在窗口内的 ``j<i`` 使两值相等，且
``i-j<=k``，算法返回真是正确的。若不在集合中，把它加入不会漏掉任何以后的配对；
随后移除 ``nums[i-k]``（若存在），使下一轮仍保持不变量。若扫描结束都没有命中，
每个元素都没有与允许距离内的历史元素相等，因此不存在满足条件的下标对。

C++ 实现
--------

.. code-block:: cpp

   class Solution {
   public:
       bool containsNearbyDuplicate(std::vector<int>& nums, int k) {
           if (k <= 0) return false;

           std::unordered_set<int> window;
           for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
               if (window.count(nums[i]) != 0) return true;

               window.insert(nums[i]);
               if (i >= k) {
                   window.erase(nums[i - k]);
               }
           }
           return false;
       }
   };

代码分析
--------

``window`` 只保存值而不保存下标，是因为窗口中的每个位置都已经满足与当前下标的距离限制；
删除时仍用 ``nums[i-k]`` 精确移除最旧位置。重复值若在窗口内出现会立即返回，因而不需要统计频次。
哈希集合的查询、插入和删除平均为常数时间；每个数组元素至多加入和移除一次，平均时间复杂度为
``O(n)``，额外空间为 ``O(min(n,k))``。输入数组和其元素顺序均不被修改。
