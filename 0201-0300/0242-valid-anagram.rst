0242. Valid Anagram
===================

题目信息
--------

:题号: 0242
:难度: Easy
:主题: 字符串、字符频次、多重集合
:原题: `LeetCode 0242 <https://leetcode.com/problems/valid-anagram/>`_
:重点: 使用全部字符、频次完全相同、长度一致、小写字母

题目重述
--------

给定两个只包含小写英文字母的字符串 ``s`` 和 ``t``，判断 ``t`` 是否是 ``s`` 的字母异位词。字母异位词必须恰好使用 ``s`` 中的全部字符，每种字符的出现次数都与 ``s`` 完全相同，只允许重新排列顺序。

两个字符串长度均在 ``1..5 * 10^4`` 范围内。若长度不同，或任意字符的频次不同，就返回 ``false``；否则返回 ``true``。函数不修改输入字符串。

自建示例
--------

.. code-block:: text

   输入：s = "aabbc", t = "abcab"
   输出：true
   解释：两个字符串都包含两个 a、两个 b 和一个 c，只是排列顺序不同。

.. code-block:: text

   输入：s = "rat", t = "car"
   输出：false
   解释：s 包含字符 t，而 t 包含字符 c，字符频次集合并不相同。
