0214. Shortest Palindrome
=========================

题目信息
--------

:题号: 0214. 最短回文串
:难度: Hard
:主题: 字符串、回文前缀、前缀函数、KMP
:原题: `LeetCode 0214 <https://leetcode.com/problems/shortest-palindrome/>`_
:重点: 只能在开头添加、最长回文前缀、复用失配边界

题目重述
--------

给定字符串 ``s``，只能在它的开头添加任意字符，返回能够得到的最短回文串。原字符串中的字符顺序不能改变，新增部分必须放在
原串之前；若原串本身已经是回文，则不需要添加字符。字符串只含小写英文字母，长度最多为 ``5 * 10^4``。

自建示例
--------

``s = "aacecaaa"`` 的最长回文前缀是 ``"aacecaa"``，剩余后缀只有 ``"a"``，把它的逆序 ``"a"`` 放到前面后仍得到
``"aacecaaa"``。

``s = "abcd"`` 的回文前缀只有 ``"a"``。必须把剩余后缀 ``"bcd"`` 的逆序 ``"dcb"`` 放到开头，答案是
``"dcbabcd"``；若保留 ``"ab"``，它已经不是回文，任何只在开头添加的字符都无法修复原串内部的顺序。

``s = "aba"`` 已经是回文，答案仍为 ``"aba"``；这说明目标不是让添加字符数量至少为 1，而是使结果最短。

先确定必须保留的前缀
--------------------

因为只能在开头添加字符，原串中没有被镜像的部分只能是一个后缀。设保留的原串前缀为 ``s[0:p)``，那么最短构造必然是：

.. code-block:: text

   reverse(s[p..n)) + s

要让整个结果成为回文，保留的前缀必须本身是回文；并且 ``p`` 越大，需要添加的字符越短。因此问题被压缩为：找出 ``s`` 的最长回文前缀。

直接检查前缀的重复工作
----------------------

从 ``n`` 到 1 依次检查前缀是否回文，找到第一个成功者就能构造最短答案。检查长度为 ``p`` 的前缀要从两端向中间比较，
最坏每个候选都重新读取大量字符，时间为 ``O(n^2)``。即使把回文判断改为哈希，也要为每个候选维护或查询边界，容易引入碰撞处理，
没有消除“多个候选共享同一前缀比较”的本质重复。

把回文条件变成前后缀相等
----------------------

令 ``r = reverse(s)``，构造组合串 ``t = s + '#' + r``，其中 ``#`` 是不在小写字母集合中的分隔符。若 ``s`` 的前缀
``s[0:p)`` 是回文，那么它等于自身逆序；而 ``r`` 的前 ``p`` 个字符正好对应 ``s`` 的后缀逆序，所以这段前缀同时也是 ``t`` 的前缀和后缀。

反过来，跨过分隔符的匹配不可能成立，组合串的最长相等前后缀只能对应 ``s`` 的一个回文前缀。于是 ``t`` 的最长 border（既是前缀又是后缀）
长度就是要保留的 ``p``。KMP 前缀函数在扫描每个字符时保存当前最长 border；失配后跳到更短的已知 border，而不是从头重新比较，
把所有前缀候选的工作压缩为一次线性扫描。

前缀函数状态
------------

``lps[i]`` 表示 ``t[0..i]`` 的最长真前缀同时也是后缀的长度。处理 ``t[i]`` 时，令 ``length = lps[i-1]``：

* 若 ``t[i] == t[length]``，当前 border 可以延长，令 ``length++``；
* 若失配且 ``length > 0``，跳到 ``lps[length-1]``，因为更短的 border 是唯一仍可能接上当前字符的候选；
* 若失配且没有更短 border，``length`` 保持 0。

分隔符保证一个 border 不会同时跨越 ``s`` 和 ``r`` 的拼接位置。最后的 ``lps.back()`` 就是最长回文前缀长度。

C++ 实现
--------

.. code-block:: cpp

   class Solution {
   public:
       std::string shortestPalindrome(const std::string& s) {
           if (s.empty()) return s;

           std::string reversed = s;
           std::reverse(reversed.begin(), reversed.end());
           const std::string combined = s + '#' + reversed;
           std::vector<int> lps(combined.size(), 0);

           for (std::size_t i = 1; i < combined.size(); ++i) {
               int length = lps[i - 1];
               while (length > 0 && combined[i] != combined[length]) {
                   length = lps[length - 1];
               }
               if (combined[i] == combined[length]) ++length;
               lps[i] = length;
           }

           const int palindrome_prefix = lps.back();
           std::string answer = reversed.substr(0, s.size() - palindrome_prefix);
           answer += s;
           return answer;
       }
   };

题解
----

边界长度如何决定新增部分
~~~~~~~~~~~~~~~~~~~~~~~~

若 ``p`` 是最长回文前缀，后缀长度为 ``n-p``，必须添加的字符正好是该后缀的逆序。选择更短的回文前缀会增加至少一个新增字符，
选择更长的非回文前缀则无法使结果成为回文；因此最长回文前缀与最短答案是一一对应的。代码中的 ``reversed.substr`` 只截取未被保留的后缀，
不会重新排列原串。

状态走读
~~~~~~~~

对 ``s = "abcd"``，组合串 ``t = "abcd#dcba"`` 的关键前缀函数状态可概括为：

.. list-table::
   :header-rows: 1

   * - 扫描片段
     - 当前候选 border
     - 变化
   * - ``a``、``ab``、``abc``、``abcd``
     - 无真前后缀
     - ``lps`` 依次保持 0
   * - ``#``
     - 任何跨界候选失效
     - 仍为 0
   * - ``d``
     - 与首字符 ``a`` 不同
     - 仍为 0
   * - 最后的 ``a``
     - 与组合串首字符相等
     - ``lps.back() = 1``

保留 ``a``，新增 ``dcb``，得到 ``dcbabcd``。若 ``s`` 为 ``aacecaaa``，最后的 border 会延伸到 ``aacecaa``，
新增部分长度降为 1；若整串回文，border 长度等于 ``s.size()``，新增部分为空。

代码分析与方案取舍
~~~~~~~~~~~~~~~~~~

暴力前缀判断语义最直观但最坏二次；滚动哈希可以把一次判断降为常数期望时间，却需要处理碰撞或双哈希。KMP 前缀函数不依赖随机性，
用 ``lps[length-1]`` 跳过已经证明不可能的候选，主解选择它以得到严格 ``O(n)`` 的边界。

``length`` 失配时不能直接归零：较短 border 仍可能和当前字符接上；而 ``combined[i] == combined[length]`` 的判断必须在
``length`` 退回后重新执行。分隔符不属于输入字符域，避免 ``s`` 的前缀与 ``r`` 的后缀在拼接处伪匹配。

复杂度与边界
~~~~~~~~~~~~

反转、构造组合串和计算前缀函数都扫描 ``O(n)`` 个字符，时间复杂度为 ``O(n)``；反串、组合串和 ``lps`` 共同占用 ``O(n)`` 额外空间。
空串提前返回，单字符必为回文；小写字符集合不包含 ``#``，所以分隔符不会与输入发生歧义。
