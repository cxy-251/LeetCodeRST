0221. Maximal Square
====================

题目信息
--------

:题号: 0221
:难度: Medium
:主题: 矩阵、动态规划、正方形区域
:原题: `LeetCode 0221 <https://leetcode.com/problems/maximal-square/>`_
:重点: 全一正方形、返回面积、字符矩阵、空结果为零

题目重述
--------

给定一个只包含字符 ``'0'`` 和 ``'1'`` 的 ``m x n`` 矩阵 ``matrix``，找出其中面积最大的、全部由 ``'1'`` 组成的轴对齐正方形，并返回该正方形的面积。返回的是面积而不是边长，也不需要返回正方形的位置。

矩阵行列数均不超过 300。若矩阵中没有字符 ``'1'``，则不存在正面积的合法正方形，返回 ``0``。

自建示例
--------

.. code-block:: text

   输入：matrix = [["1","1","1","0"],
                    ["1","1","1","1"],
                    ["0","1","1","1"]]
   输出：4
   解释：矩阵中存在多个边长为 2 的全一正方形，但不存在边长为 3 的全一正方形，所以最大面积为 2 * 2 = 4。

.. code-block:: text

   输入：matrix = [["0","0"],["0","0"]]
   输出：0
   解释：矩阵中没有任何值为 '1' 的格子，因此没有合法正方形。
