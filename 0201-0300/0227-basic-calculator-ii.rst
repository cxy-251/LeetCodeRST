0227. Basic Calculator II
=========================

题目信息
--------

:题号: 0227
:难度: Medium
:主题: 字符串、表达式、运算优先级、整数除法
:原题: `LeetCode 0227 <https://leetcode.com/problems/basic-calculator-ii/>`_
:重点: 多位整数、乘除优先、从左结合、向零截断

题目重述
--------

给定一个合法的算术表达式字符串 ``s``，计算并返回其整数结果。表达式由非负十进制整数、空格以及运算符 ``+``、``-``、``*``、``/`` 组成，不包含括号。乘法和除法的优先级高于加法和减法，同级运算按从左到右的顺序执行。

整数除法向零截断。字符串长度最多为 ``3 * 10^5``，所有中间结果和最终答案保证适合 32 位有符号整数；不能调用直接计算整段表达式的内置求值函数。

自建示例
--------

.. code-block:: text

   输入：s = "14-3*4+8/3"
   输出：4
   解释：先计算 3 * 4 = 12 和 8 / 3 = 2，再计算 14 - 12 + 2 = 4；除法结果向零截断。

.. code-block:: text

   输入：s = " 20 / 3 * 2 + 1 "
   输出：13
   解释：同级乘除从左到右计算，20 / 3 = 6，6 * 2 = 12，最后加 1 得 13。
