0264. Ugly Number II
====================

题目信息
--------

:题号: 0264
:难度: Medium
:主题: 动态规划、堆、数学
:原题: `LeetCode 0264 <https://leetcode.com/problems/ugly-number-ii/>`_
:教学重点: 三路有序生成、去重、指针推进

题目重述
--------

给定整数 ``n``，接口为 ``int nthUglyNumber(int n)``。返回按升序排列的第 ``n`` 个丑数，丑数的质因子只包含 ``2``、``3``、``5``，且 ``1`` 是第一个。``1 <= n <= 1690``，答案适合 32 位整数。

自建示例
--------

.. code-block:: text

   输入：n=7
   输出：8
   说明：前七个为 1,2,3,4,5,6,8。
