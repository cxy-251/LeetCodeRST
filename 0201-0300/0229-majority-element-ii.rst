0229. Majority Element II
=========================

题目信息
--------

:题号: 0229
:难度: Medium
:主题: 数组、计数、多数元素
:原题: `LeetCode 0229 <https://leetcode.com/problems/majority-element-ii/>`_
:重点: 严格超过三分之一、不同结果、至多两个、返回顺序

题目重述
--------

给定整数数组 ``nums``，返回所有出现次数严格大于 ``floor(n / 3)`` 的不同元素，其中 ``n`` 是数组长度。结果中不能重复包含同一个值；满足条件的元素最多有两个。

数组长度在 ``1..5 * 10^4`` 范围内。若存在多个合法元素，返回顺序没有要求；若没有任何元素达到阈值，返回空数组。函数不需要修改输入数组。

自建示例
--------

.. code-block:: text

   输入：nums = [4,1,4,2,4,2,2]
   输出：[4,2]
   解释：数组长度为 7，floor(7 / 3) = 2；4 和 2 都出现 3 次，严格大于 2。输出为 [2,4] 也同样合法。

.. code-block:: text

   输入：nums = [1,2,3,4]
   输出：[]
   解释：阈值为 floor(4 / 3) = 1，每个元素都只出现一次，没有元素严格超过阈值。
