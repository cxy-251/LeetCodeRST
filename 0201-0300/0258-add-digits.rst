0258. Add Digits
================

题目信息
--------

:题号: 0258
:难度: Easy
:主题: 数学、数根、模拟
:原题: `LeetCode 0258 <https://leetcode.com/problems/add-digits/>`_
:教学重点: 重复数位和、数字根、零值边界

题目重述
--------

给定非负 32 位整数 ``num``，接口为 ``int addDigits(int num)``。反复把十进制各位相加，直到结果只剩一位，返回该数字。允许模拟，也可使用常数时间公式；``0`` 的结果仍为 ``0``。

自建示例
--------

.. code-block:: text

   输入：9998
   输出：8
   说明：9+9+9+8=35，3+5=8。
