0228. Summary Ranges
====================

题目信息
--------

:题号: 0228
:难度: Easy
:主题: 数组、连续区间、字符串格式
:原题: `LeetCode 0228 <https://leetcode.com/problems/summary-ranges/>`_
:重点: 严格递增、完整覆盖、单点格式、连续端点

题目重述
--------

给定一个严格递增且没有重复值的整数数组 ``nums``，把其中所有数字划分为若干个互不重叠的连续整数区间，并按原数组顺序返回这些区间的字符串表示。返回的区间必须恰好覆盖数组中的全部数字，不能包含数组中不存在的整数。

若一个区间只有单个整数 ``a``，表示为 ``"a"``；若区间从 ``a`` 连续到 ``b`` 且 ``a < b``，表示为 ``"a->b"``。数组可以为空，元素可能位于 32 位有符号整数边界。

自建示例
--------

.. code-block:: text

   输入：nums = [-3,-2,0,1,2,6]
   输出：["-3->-2","0->2","6"]
   解释：-3 与 -2 连续，0、1、2 构成另一段连续区间，6 与相邻数字不连续，所以单独表示。

.. code-block:: text

   输入：nums = []
   输出：[]
   解释：空数组没有需要表示的区间。
