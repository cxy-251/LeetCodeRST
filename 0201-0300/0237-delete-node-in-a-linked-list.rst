0237. Delete Node in a Linked List
=================================

题目信息
--------

:题号: 0237
:难度: Medium
:主题: 单链表、原地修改、受限接口
:原题: `LeetCode 0237 <https://leetcode.com/problems/delete-node-in-a-linked-list/>`_
:重点: 不提供头节点、待删节点非尾节点、节点值唯一、无返回值

题目重述
--------

给定单链表中的一个节点 ``node``，要求从链表中删除这个节点。函数只接收待删除节点本身，不会获得链表头节点；调用完成后，从原链表头开始遍历得到的序列中不再包含 ``node`` 原来的值，其余元素保持原有相对顺序。

输入链表至少包含两个节点，所有节点值互不相同。平台保证 ``node`` 确实属于该链表，并且不是尾节点，因此它一定存在后继节点。函数直接修改链表且没有返回值。

自建示例
--------

.. code-block:: text

   输入：原链表为 [4,7,9,2]，传入值为 9 的节点
   输出：链表变为 [4,7,2]
   解释：调用后值 9 从可遍历序列中消失，4、7、2 的相对顺序保持不变。

.. code-block:: text

   输入：原链表为 [5,1,8]，传入值为 1 的节点
   输出：链表变为 [5,8]
   解释：待删除节点位于链表中间且不是尾节点，删除后首尾节点仍按原顺序连接。
