0222. Count Complete Tree Nodes
==============================

题目信息
--------

:题号: 0222
:难度: Easy
:主题: 完全二叉树、节点计数、树结构
:原题: `LeetCode 0222 <https://leetcode.com/problems/count-complete-tree-nodes/>`_
:重点: 完全二叉树保证、节点身份、空树、节点总数

题目重述
--------

给定一棵完全二叉树的根节点 ``root``，返回树中节点的总数量。完全二叉树除最后一层外每一层都被填满，最后一层的节点从左向右连续出现。节点值是否重复不影响计数，每个实际节点都应计入一次。

树的节点数在 ``0..5 * 10^4`` 范围内；空树返回 ``0``。函数只统计节点，不应改变树的结构或节点值。

自建示例
--------

.. code-block:: text

   输入：root = [7,4,9,2,5,8]
   输出：6
   解释：层序表示中共有六个非空节点；最后一层的 2、5、8 从左侧连续填充，因此输入满足完全二叉树条件。

.. code-block:: text

   输入：root = []
   输出：0
   解释：空树不包含任何节点。
