0222. Count Complete Tree Nodes
==============================

题目信息
--------

:题号: 0222
:难度: Easy
:主题: 完全二叉树、二分查找、位运算
:原题: `LeetCode 0222 <https://leetcode.com/problems/count-complete-tree-nodes/>`_
:教学重点: 完全树结构、满树判定、末层定位

题目重述
--------

给定一棵完全二叉树的根节点 ``root``，接口为 ``int countNodes(TreeNode* root)``，返回节点总数。节点数最多约 ``5 * 10^4``；平台保证输入满足完全二叉树定义。不得按节点值去重，节点身份由指针确定，输入树不应被修改。

自建示例
--------

.. code-block:: text

   输入：层序 [1,2,3,4,5]
   输出：5
   说明：最后一层从左侧连续填充。

   输入：[]
   输出：0
