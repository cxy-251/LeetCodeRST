0300. Longest Increasing Subsequence
====================================

题目信息
--------

:题号: 0300
:难度: Medium
:主题: 数组、子序列、严格递增、长度优化
:原题: `LeetCode 0300 <https://leetcode.com/problems/longest-increasing-subsequence/>`_
:重点: 子序列可以跳过元素但不能改变原顺序、相等值不能延长、只返回最大长度

题目重述
--------

给定整数数组 ``nums``，返回其中最长严格递增子序列的长度。子序列由原数组删除任意数量的元素后得到，保留下来的元素必须继续保持原有下标顺序，但不要求在原数组中连续。

严格递增要求序列中每个后继元素都大于前一个元素，因此相等值不能作为一次增长。数组长度位于 ``[1, 2500]``，每个元素位于 ``[-10^4, 10^4]``。题目只要求返回长度，不需要恢复具体子序列；当存在多个同样长的答案时，它们都对应同一个返回值。进阶问题要求把时间复杂度优化到 ``O(n log n)``。

自建示例
--------

最优子序列需要跳过部分元素：

.. code-block:: text

   输入：nums = [3, 1, 2, 5, 4, 7]
   输出：4
   解释：例如 [1,2,4,7] 是长度为 4 的严格递增子序列；元素 4 虽位于 5 之后，仍可跳过 5 保持原下标顺序。

全部元素相等：

.. code-block:: text

   输入：nums = [2, 2, 2]
   输出：1
   解释：严格递增不允许相邻选中值相等，所以任何合法递增子序列最多只包含一个元素。
