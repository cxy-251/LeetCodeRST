0268. Missing Number
====================

题目信息
--------

:题号: 0268
:难度: Easy
:主题: 数组、位运算、数学、排序
:原题: `LeetCode 0268 <https://leetcode.com/problems/missing-number/>`_
:教学重点: 完整集合差、异或抵消、溢出安全

题目重述
--------

给定长度为 ``n`` 的数组 ``nums``，包含区间 ``[0,n]`` 中互不相同的 ``n`` 个数，接口为 ``int missingNumber(vector<int>& nums)``。返回唯一缺失值。``n`` 最多约 ``10^4``；返回单个整数，输入不要求排序，也无需修改。

自建示例
--------

.. code-block:: text

   输入：[4,2,1,0]
   输出：3

   输入：[0]
   输出：1
