0213. House Robber II
=====================

题目信息
--------

:题号: 0213. 打家劫舍 II
:难度: Medium
:主题: 动态规划、环形数组、滚动状态
:原题: `LeetCode 0213 <https://leetcode.com/problems/house-robber-ii/>`_
:重点: 首尾房屋相邻、相邻房屋不能同时选择、环拆线、单屋边界

题目重述
--------

有一圈房屋，``nums[i]`` 表示第 ``i`` 间房中的金额。选择一间房会取得其金额，但同一晚不能选择相邻的两间房；
因为房屋围成圆，第 0 间和最后一间也相邻。返回在不触发警报的前提下能取得的最大金额，不要求返回具体选择的房屋。

房屋数量位于 ``[1, 100]``，金额位于 ``[0, 1000]``。函数不修改输入；只有一间房时它没有另一间不同房屋与之冲突，答案就是该房屋金额。

自建示例
--------

首尾两个高金额不能同时取得：

.. code-block:: text

   nums = [8, 1, 1, 8]
   输出 = 9

不能选两端的 8；可以选下标 0 和 2，或下标 1 和 3，最大总额都是 9。把它当成直线并取两端会错误得到 16。

只有首尾冲突时的选择：``nums = [2,3,2]`` 的答案是 3。选择第 0 间和第 2 间会同时触发圆环的首尾约束，
因此只能选中间的 3，或者任选一个 2。

从子集枚举到线性前缀状态
------------------------

直接为每间房决定“抢或不抢”，再检查所有相邻对，最多要探索指数级的选择组合。在线性排列中，处理到下标 ``i`` 时，
合法方案只有两类：不抢第 ``i`` 间，最优值是前 ``i-1`` 间的结果；抢第 ``i`` 间，则第 ``i-1`` 间不能抢，
最优值是前 ``i-2`` 间的结果加 ``nums[i]``。因此有：

.. math::

   best[i] = \max(best[i-1], best[i-2] + nums[i])

这个递推把“是否与相邻房屋冲突”的检查压缩成两个前缀状态，不再枚举每一种组合。

环形边只需要一次二分
--------------------

线性递推还没有处理第 0 间与最后一间的额外冲突。任意合法方案必然属于以下两种互斥情况之一：

* 不抢第 0 间，此时可以在连续区间 ``[1, n-1]`` 上做线性 DP；
* 抢第 0 间，此时最后一间必不能抢，只需在 ``[0, n-2]`` 上做线性 DP。

这两个区间覆盖所有合法方案，且每个子问题已没有首尾相接的边。分别求最大值后取较大者，就把环形问题转化成两次同一个
线性问题，而不是枚举“首尾是否选择”之外的全部组合。

状态不变量与滚动压缩
--------------------

``robLinear(left, right)`` 扫描一个连续区间。处理下标 ``i`` 前，``previous_one`` 是 ``[left, i-1]`` 的最优值，
``previous_two`` 是 ``[left, i-2]`` 的最优值；因此当前值是 ``max(previous_one, previous_two + nums[i])``。
计算完成后先把旧的 ``previous_one`` 交给 ``previous_two``，再把当前值交给 ``previous_one``。

线性 DP 的完整数组只保存了已经不再需要的历史项。滚动两个变量删除了这部分空间，而不会删除决策所需的信息。

C++ 实现
--------

.. code-block:: cpp

   class Solution {
   private:
       static int robLinear(const std::vector<int>& nums, int left, int right) {
           int previous_two = 0;
           int previous_one = 0;
           for (int index = left; index <= right; ++index) {
               const int current = std::max(previous_one,
                                            previous_two + nums[index]);
               previous_two = previous_one;
               previous_one = current;
           }
           return previous_one;
       }

   public:
       int rob(std::vector<int>& nums) {
           const int count = static_cast<int>(nums.size());
           if (count == 1) return nums[0];
           return std::max(robLinear(nums, 0, count - 2),
                           robLinear(nums, 1, count - 1));
       }
   };

题解
----

两个环分支覆盖什么
~~~~~~~~~~~~~~~~~~

把合法方案按是否选择第 0 间分类。若选择它，最后一间必不选，方案完全落在 ``[0,n-2]``；若不选择它，最后一间可以选或不选，
方案完全落在 ``[1,n-1]``。任一合法方案恰好属于其中一个类别，两个线性子问题的最优值取最大就不会遗漏，也不会把两个类别的选择合并。

长度为 2 时，两个区间分别只含一个端点，正确表达两间房相邻且最多抢一间；长度为 1 时两个区间会重复同一房屋，
所以必须在公共入口先返回 ``nums[0]``。

状态走读
~~~~~~~~

对 ``nums=[2,3,2]``：

.. list-table::
   :header-rows: 1

   * - 子问题
     - 扫描值
     - ``(previous_two, previous_one)``
     - 结果
   * - ``[0,1]``
     - 2、3
     - ``(0,0) -> (0,2) -> (2,3)``
     - 3
   * - ``[1,2]``
     - 3、2
     - ``(0,0) -> (0,3) -> (3,3)``
     - 3

两种情况下都只选择一个 3。在线性状态中，当前值取“不抢当前”和“抢当前并跳过前一间”的最大值；环形冲突已经在区间端点处一次性处理。

代码分析与方案取舍
~~~~~~~~~~~~~~~~~~

完整线性 DP 表能保存每个前缀最优值，空间为 ``O(n)``；递推只依赖前两项，滚动变量把已经不再读取的历史状态删除到 ``O(1)``。
公共入口只调用两次 ``robLinear``，主函数不需要在每个房屋状态中额外记录“是否抢了第 0 间”。

金额非负使 0 作为空前缀最优值合法；``previous_two`` 和 ``previous_one`` 保存的是前缀最优金额，而不是最近两间房的金额，
这是代码理解中最容易混淆的地方。函数不修改数组，两个分支只读同一份输入。

复杂度与边界
~~~~~~~~~~~~

两个区间各扫描至多 ``n`` 间房，时间复杂度为 ``O(n)``；每个线性扫描只保留两个状态，额外空间为 ``O(1)``。全 0、单屋、两屋和首尾
均为最大值的情况分别由初值、单屋分支、单元素区间和环拆分处理。若只运行一次直线 DP，会把首尾同时选择的非法方案算进去，不能作为本题解法。
