0226. Invert Binary Tree
========================

题目信息
--------

:题号: 0226
:难度: Easy
:主题: 二叉树、深度优先搜索、广度优先搜索
:原题: `LeetCode 0226 <https://leetcode.com/problems/invert-binary-tree/>`_
:重点: 每个节点交换左右子树、返回根节点、空树、结构变化

题目重述
--------

给定二叉树根节点 ``root``，把树中每个节点的左子树和右子树互换，返回反转后的根节点。反转作用于整棵树，而不是只交换根节点的两个直接孩子。

树中节点数位于 ``[0, 100]``，节点值位于 ``[-100, 100]``。空树反转后仍返回空引用。题目返回的是完成结构交换后的树，节点值本身保持不变。

自建示例
--------

多层子树同时交换：

.. code-block:: text

   输入：root = [5, 3, 8, 1, 4, 7, null]
   输出：[5, 8, 3, null, 7, 4, 1]
   解释：根节点的左右子树互换；原节点 3 的孩子 1 和 4、原节点 8 的孩子 7 和空位置也分别互换。

空树：

.. code-block:: text

   输入：root = []
   输出：[]
   解释：没有节点需要交换，结果仍为空树。
