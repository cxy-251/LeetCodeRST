0226. Invert Binary Tree
========================

题目信息
--------

:题号: 0226
:难度: Easy
:主题: 二叉树、结构变换、递归、遍历
:原题: `LeetCode 0226 <https://leetcode.com/problems/invert-binary-tree/>`_
:重点: 每个节点左右交换、原节点复用、空树、返回根节点

题目重述
--------

给定二叉树根节点 ``root``，把树中每个节点的左子树与右子树互换，并返回变换后的根节点。操作作用于整棵树，而不仅是根节点的两个孩子；返回结果继续使用输入中的原节点，只改变孩子连接关系。

树最多包含 100 个节点。空树返回空引用，单节点树反转后仍是原来的单节点树。

自建示例
--------

.. code-block:: text

   输入：root = [2,1,4,null,null,3,5]
   输出：[2,4,1,5,3]
   解释：根节点的左右子树交换，原节点 4 的孩子 3 和 5 也交换为 5 和 3。

.. code-block:: text

   输入：root = [7]
   输出：[7]
   解释：单节点没有左右子树可以交换，因此结构不变。
