0292. Nim Game
==============

题目信息
--------

:题号: 0292
:难度: Easy
:主题: 轮流取石子、最优策略、胜负判断
:原题: `LeetCode 0292 <https://leetcode.com/problems/nim-game/>`_
:重点: 你先手、每回合必须拿 1 至 3 块、拿走最后一块者获胜、双方都按最优策略行动

题目重述
--------

桌上最初有 ``n`` 块石头。你和对手轮流行动，由你先手；每次行动必须从剩余石头中拿走 ``1``、``2`` 或 ``3`` 块，拿走最后一块石头的人获胜。判断在双方都采用最优策略时，你是否能够保证获胜。

``n`` 位于 ``[1, 2^31 - 1]``，因此游戏开始时至少有一块石头。函数只返回布尔结果：存在一种策略能让你无论对手如何最优应对都获胜时返回 ``true``，否则返回 ``false``；不需要输出具体的取石过程。
