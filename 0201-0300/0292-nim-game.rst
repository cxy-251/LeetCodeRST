0292. Nim Game
==============

题目信息
--------

:题号: 0292
:难度: Easy
:主题: 数学、博弈论、脑筋急转弯
:原题: `LeetCode 0292 <https://leetcode.com/problems/nim-game/>`_
:教学重点: 必败状态、模四分类、最优策略

题目重述
--------

桌上有 ``n`` 块石头，你与对手轮流拿走 1 到 3 块，你先手，拿走最后一块者获胜。接口为 ``bool canWinNim(int n)``，判断双方都采用最优策略时你是否必胜。``n`` 为正 32 位整数，只返回布尔值。

自建示例
--------

.. code-block:: text

   输入：n=8
   输出：false

   输入：n=10
   输出：true
