0263. Ugly Number
=================

题目信息
--------

:题号: 0263
:难度: Easy
:主题: 数学、质因数、整除
:原题: `LeetCode 0263 <https://leetcode.com/problems/ugly-number/>`_
:重点: 只允许质因数 2、3、5、输入必须为正数、``1`` 没有质因数但仍视为丑数

题目重述
--------

给定一个 32 位有符号整数 ``n``，判断它是否为丑数。丑数必须是正整数，并且它的全部质因数只能来自 ``2``、``3`` 和 ``5``；只要还含有其他质因数，就不是丑数。

``n`` 位于 ``[-2^31, 2^31 - 1]``。``1`` 没有质因数，按照题目定义仍属于丑数；``0`` 和所有负数都不属于丑数。函数只返回布尔结果，不需要给出质因数分解。

自建示例
--------

只含允许的质因数：

.. code-block:: text

   输入：n = 45
   输出：true
   解释：45 = 3 × 3 × 5，所有质因数都属于 2、3、5。

混入其他质因数：

.. code-block:: text

   输入：n = 14
   输出：false
   解释：14 = 2 × 7，其中质因数 7 不在允许集合中。

定义边界：

.. code-block:: text

   输入：n = 1
   输出：true
   解释：题目明确把 1 视为丑数，尽管它没有质因数。
