0263. Ugly Number
=================

题目信息
--------

:题号: 0263
:难度: Easy
:主题: 数学、质因数
:原题: `LeetCode 0263 <https://leetcode.com/problems/ugly-number/>`_
:教学重点: 反复除去允许质因子、非正数边界

题目重述
--------

给定 32 位有符号整数 ``n``，接口为 ``bool isUgly(int n)``。若 ``n`` 为正数且质因子只包含 ``2``、``3``、``5``，返回 ``true``；``1`` 视为丑数，非正数不是丑数。

自建示例
--------

.. code-block:: text

   输入：45
   输出：true

   输入：14
   输出：false
