0239. Sliding Window Maximum
============================

题目信息
--------

:题号: 0239
:难度: Hard
:主题: 数组、滑动窗口、单调队列
:原题: `LeetCode 0239 <https://leetcode.com/problems/sliding-window-maximum/>`_
:重点: 固定长度连续窗口、每次右移一格、按窗口起点返回最大值、重复最大值

题目重述
--------

给定整数数组 ``nums`` 和窗口长度 ``k``。一个长度恰好为 ``k`` 的连续窗口从数组最左端开始，每次向右移动一个位置，直到覆盖数组最右端。返回每个窗口中的最大元素，结果顺序必须与窗口出现顺序一致。

数组长度位于 ``[1, 10^5]``，元素位于 ``[-10^4, 10^4]``，并满足 ``1 <= k <= nums.length``。结果数组长度固定为 ``nums.length-k+1``。不同位置可以拥有相同最大值，每个窗口都必须单独产生一个结果；函数无需修改输入数组。

自建示例
--------

最大值离开窗口后发生变化：

.. code-block:: text

   输入：nums = [2, 9, 3, 1, 7, 6]，k = 3
   输出：[9, 9, 7, 7]
   解释：四个窗口依次为 [2,9,3]、[9,3,1]、[3,1,7]、[1,7,6]，最大值分别为 9、9、7、7。

窗口长度为 1：

.. code-block:: text

   输入：nums = [-2, 4, 0]，k = 1
   输出：[-2, 4, 0]
   解释：每个窗口只包含一个元素，所以结果与原数组相同。
