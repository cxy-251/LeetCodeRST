0239. Sliding Window Maximum
============================

题目信息
--------

:题号: 0239
:难度: Hard
:主题: 数组、滑动窗口、区间最大值
:原题: `LeetCode 0239 <https://leetcode.com/problems/sliding-window-maximum/>`_
:重点: 固定窗口长度、逐格右移、窗口内最大值、输出顺序

题目重述
--------

给定整数数组 ``nums`` 和整数 ``k``，一个长度恰好为 ``k`` 的窗口最初覆盖数组前 ``k`` 个元素，随后每次向右移动一个位置，直到覆盖数组末尾。返回每个窗口中的最大元素，结果顺序与窗口起点从左到右的顺序一致。

数组长度在 ``1..10^5`` 范围内，并且 ``1 <= k <= nums.length``。结果长度为 ``nums.length - k + 1``；函数只读取输入数组，不需要修改元素。

自建示例
--------

.. code-block:: text

   输入：nums = [4,2,12,3,8], k = 3
   输出：[12,12,12]
   解释：三个窗口分别是 [4,2,12]、[2,12,3]、[12,3,8]，它们的最大值都为 12。

.. code-block:: text

   输入：nums = [5,1], k = 1
   输出：[5,1]
   解释：窗口长度为 1 时，每个窗口只包含当前位置的元素，所以输出与输入相同。
