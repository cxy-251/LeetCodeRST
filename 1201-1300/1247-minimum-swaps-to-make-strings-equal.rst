1247. Minimum Swaps to Make Strings Equal
=========================================

题目信息
--------

:题号: 1247
:难度: Medium
:主题: 字符串、计数、交换
:原题: `LeetCode 1247 <https://leetcode.com/problems/minimum-swaps-to-make-strings-equal/>`_
:重点: 每次从两个字符串中各选一个位置并交换字符；只需统计 ``xy`` 与 ``yx`` 两类不匹配位置

题目重述
--------

给定长度相同、只包含 ``x`` 和 ``y`` 的字符串 ``s1`` 与 ``s2``。一次操作可以选择 ``s1`` 中的一个字符和 ``s2`` 中的一个字符，并交换它们。

请返回使两个字符串完全相等所需的最少交换次数。若无论怎样交换都无法相等，返回 ``-1``。

``1 <= s1.length == s2.length <= 1000``，两个字符串只包含 ``x`` 和 ``y``。

自建示例
--------

两类不匹配都为偶数时可以分别配对：

.. code-block:: text

   输入：s1 = "xxyy", s2 = "yyxx"
   输出：2
   解释：存在两个 xy 型和两个 yx 型不匹配位置，每一对同类型不匹配可用一次交换修复。

不匹配字符总数为奇数时无解：

.. code-block:: text

   输入：s1 = "x", s2 = "y"
   输出：-1
   解释：两个字符串合计只有一个 x 和一个 y，任何跨字符串交换只会互换二者，无法使对应位置相同。
