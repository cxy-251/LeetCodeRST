1248. Count Number of Nice Subarrays
====================================

题目信息
--------

:题号: 1248
:难度: Medium
:主题: 数组、连续子数组、前缀计数、滑动窗口
:原题: `LeetCode 1248 <https://leetcode.com/problems/count-number-of-nice-subarrays/>`_
:重点: 好子数组必须连续且恰好包含 ``k`` 个奇数；不同起止下标分别计数

题目重述
--------

给定正整数数组 ``nums`` 和整数 ``k``。若一个连续非空子数组中恰好包含 ``k`` 个奇数，则称它为好子数组。

请统计 ``nums`` 中好子数组的总数量。内容相同但边界位置不同的子数组需要分别计数。

``1 <= nums.length <= 5 * 10^4``，``1 <= nums[i] <= 10^5``，``1 <= k <= nums.length``。

自建示例
--------

首尾偶数会产生多种边界选择：

.. code-block:: text

   输入：nums = [2,1,2,1,2], k = 2
   输出：4
   解释：两个奇数都必须包含；起点可选下标 0 或 1，终点可选下标 3 或 4，共四个子数组。

数组中奇数不足时答案为零：

.. code-block:: text

   输入：nums = [2,4,6], k = 1
   输出：0
   解释：任意连续子数组都不包含奇数。
