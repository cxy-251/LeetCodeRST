1223. Dice Roll Simulation
==========================

题目信息
--------

:题号: 1223
:难度: Hard
:主题: 动态规划、连续次数限制、计数
:原题: `LeetCode 1223 <https://leetcode.com/problems/dice-roll-simulation/>`_
:重点: 第 ``i`` 个点数最多连续出现 ``rollMax[i]`` 次；统计长度为 ``n`` 的合法掷骰序列并取模

题目重述
--------

掷一个六面骰子 ``n`` 次。数组 ``rollMax`` 长度为 ``6``，其中 ``rollMax[i]`` 表示点数 ``i + 1`` 最多允许连续出现多少次。

请统计满足所有连续次数限制的不同点数序列数量，并返回结果对 ``10^9 + 7`` 取模后的值。

``1 <= n <= 5000``，``rollMax.length == 6``，``1 <= rollMax[i] <= 15``。

自建示例
--------

所有点数都不能连续重复：

.. code-block:: text

   输入：n = 3, rollMax = [1,1,1,1,1,1]
   输出：150
   解释：第一次有 6 种选择，之后每次都不能与前一次相同，各有 5 种选择，共 6 * 5 * 5 = 150。

只掷一次时限制不会触发：

.. code-block:: text

   输入：n = 1, rollMax = [1,2,3,4,5,6]
   输出：6
   解释：六个点数都可以作为唯一一次结果。
