1240. Tiling a Rectangle with the Fewest Squares
================================================

题目信息
--------

:题号: 1240
:难度: Hard
:主题: 回溯、状态压缩、矩形铺砌
:原题: `LeetCode 1240 <https://leetcode.com/problems/tiling-a-rectangle-with-the-fewest-squares/>`_
:重点: 使用边平行于矩形边界、边长为正整数的正方形无重叠铺满 ``n x m`` 矩形，并最小化正方形数量

题目重述
--------

给定矩形的整数边长 ``n`` 和 ``m``。可以使用任意数量、任意整数边长的正方形，每个正方形必须完全位于矩形内，正方形之间不能重叠，所有正方形的并集必须恰好覆盖整个矩形。

请返回完成铺砌所需正方形的最少数量。

``1 <= n, m <= 13``。
