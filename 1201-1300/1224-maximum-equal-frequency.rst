1224. Maximum Equal Frequency
=============================

题目信息
--------

:题号: 1224
:难度: Hard
:主题: 数组、前缀、频次统计
:原题: `LeetCode 1224 <https://leetcode.com/problems/maximum-equal-frequency/>`_
:重点: 对某个前缀必须恰好删除一个元素，删除后所有仍出现的不同数值频次相同；求最长合法前缀

题目重述
--------

给定正整数数组 ``nums``。对于前缀 ``nums[0..i]``，允许从该前缀中删除恰好一个元素实例。

若删除后所有仍保留的不同数值都出现相同次数，则该前缀有效。请返回有效前缀能够达到的最大长度。

``1 <= nums.length <= 10^5``，``1 <= nums[i] <= 10^5``。

自建示例
--------

最长合法前缀可能不是整个数组：

.. code-block:: text

   输入：nums = [1,1,2,2,3,3,3,4,4,4]
   输出：9
   解释：前九项频次为 2、2、3、2，删除一个 3 后都变为 2；加入最后一个 4 后频次为 2、2、3、3，无法只删一个元素使其相等。

删除最高频值的一个实例即可统一频次：

.. code-block:: text

   输入：nums = [4,4,4,5,5]
   输出：5
   解释：删除一个 4 后，4 和 5 都出现两次。
