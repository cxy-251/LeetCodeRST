1221. Split a String in Balanced Strings
========================================

题目信息
--------

:题号: 1221
:难度: Easy
:主题: 字符串、贪心、计数
:原题: `LeetCode 1221 <https://leetcode.com/problems/split-a-string-in-balanced-strings/>`_
:重点: 平衡字符串中 ``L`` 与 ``R`` 数量相等；必须把整个输入划分为连续非空片段并最大化片段数

题目重述
--------

给定只包含 ``L`` 和 ``R`` 的平衡字符串 ``s``，其中两种字符总数相同。需要按原顺序把整个字符串切分为若干连续且非空的子串，使每个子串中的 ``L`` 和 ``R`` 数量也相等。

请返回能够得到的最大平衡子串数量。

``2 <= s.length <= 1000``，``s`` 只包含 ``L`` 和 ``R``，并且整体保证平衡。

自建示例
--------

遇到计数重新平衡时立即切分：

.. code-block:: text

   输入：s = "LRLRLLRR"
   输出：3
   解释：可以切分为 "LR"、"LR" 和 "LLRR"，三个片段都平衡。

无法提前平衡时只能形成一个片段：

.. code-block:: text

   输入：s = "LLRR"
   输出：1
   解释：任意真前缀的 L 与 R 数量都不同，只能保留整个字符串。
