1226. The Dining Philosophers
=============================

题目信息
--------

:题号: 1226
:难度: Medium
:主题: 并发、互斥锁、死锁避免、资源协调
:原题: `LeetCode 1226 <https://leetcode.com/problems/the-dining-philosophers/>`_
:重点: 五名哲学家共享五把叉子；每次进餐必须独占左右两把叉子，并按回调要求拿叉、进餐和放叉，同时避免死锁

题目重述
--------

五名哲学家围坐在圆桌旁，编号为 ``0`` 到 ``4``，相邻两人共享一把叉子。实现 ``wantsToEat`` 方法；当编号为 ``philosopher`` 的线程请求进餐时，需要安全调用给定的拿左叉、拿右叉、进餐、放左叉和放右叉回调。

任意时刻同一把叉子不能被两名哲学家同时持有。实现必须保证并发调用不会死锁，并使每次请求最终都能完成一次完整进餐。

哲学家编号始终位于 ``[0,4]``，测试会并发发起多次进餐请求。

自建示例
--------

单个哲学家独占两把叉子时按完整顺序执行：

.. code-block:: text

   输入：philosopher = 2，左右叉当前都空闲
   输出：pickLeftFork -> pickRightFork -> eat -> putLeftFork -> putRightFork
   解释：进餐前必须同时获得两把相邻叉子，结束后释放两把叉子。

相邻请求同时到达时不能共享叉子：

.. code-block:: text

   输入：philosopher = 0 与 philosopher = 1 并发请求
   输出：任意无死锁且不重叠占用共享叉子的合法执行顺序
   解释：两次请求可以先后完成，或者在不冲突的阶段交错，但共享叉子不能同时被两人持有。
