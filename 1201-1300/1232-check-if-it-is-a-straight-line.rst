1232. Check If It Is a Straight Line
====================================

题目信息
--------

:题号: 1232
:难度: Easy
:主题: 平面几何、共线判断、叉积
:原题: `LeetCode 1232 <https://leetcode.com/problems/check-if-it-is-a-straight-line/>`_
:重点: 所有点必须与前两个点确定的直线共线；应避免直接比较浮点斜率

题目重述
--------

给定平面上若干互不相同的点 ``coordinates[i] = [x_i, y_i]``。请判断这些点是否全部位于同一条无限直线上。

若所有点共线返回 ``true``，只要存在一个点偏离由其他点确定的直线就返回 ``false``。竖直线和水平线都属于合法直线。

``2 <= coordinates.length <= 1000``，``-10^4 <= x_i, y_i <= 10^4``，所有坐标互不相同。

自建示例
--------

竖直方向的点同样可以共线：

.. code-block:: text

   输入：coordinates = [[2,1],[2,4],[2,-3]]
   输出：true
   解释：所有点的横坐标都为 2，因此位于直线 x = 2 上。

方向比例不一致时不共线：

.. code-block:: text

   输入：coordinates = [[0,0],[2,2],[3,4]]
   输出：false
   解释：前两点方向为 (2,2)，第三点相对原点方向为 (3,4)，二者不成比例。
