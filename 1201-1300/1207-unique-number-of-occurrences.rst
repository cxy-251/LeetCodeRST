1207. Unique Number of Occurrences
==================================

题目信息
--------

:题号: 1207
:难度: Easy
:主题: 数组、频次统计、哈希集合
:原题: `LeetCode 1207 <https://leetcode.com/problems/unique-number-of-occurrences/>`_
:重点: 统计每个不同整数的出现次数，并判断这些次数是否两两不同

题目重述
--------

给定整数数组 ``arr``。先统计数组中每个不同数值的出现次数，再判断是否存在两个不同数值拥有相同的出现次数。

若所有不同数值对应的频次两两不同，返回 ``true``；只要有任意两个不同数值的频次相同，就返回 ``false``。

``1 <= arr.length <= 1000``，``-1000 <= arr[i] <= 1000``。

自建示例
--------

所有频次互不相同：

.. code-block:: text

   输入：arr = [4,4,2,2,2,9]
   输出：true
   解释：4、2、9 的出现次数分别为 2、3、1，三个频次各不相同。

两个数值出现次数相同：

.. code-block:: text

   输入：arr = [1,1,2,2]
   输出：false
   解释：1 和 2 都出现两次，因此频次不唯一。
