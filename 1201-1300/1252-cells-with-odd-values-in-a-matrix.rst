1252. Cells with Odd Values in a Matrix
=======================================

题目信息
--------

:题号: 1252
:难度: Easy
:主题: 矩阵、行列增量、奇偶性
:原题: `LeetCode 1252 <https://leetcode.com/problems/cells-with-odd-values-in-a-matrix/>`_
:重点: 每个操作同时把指定整行和整列所有元素加一，交叉格会加二；返回最终奇数格数量

题目重述
--------

创建一个初始全为 ``0`` 的 ``m x n`` 整数矩阵。对于 ``indices`` 中每个 ``[r, c]``，把第 ``r`` 行所有元素加一，再把第 ``c`` 列所有元素加一。

按顺序完成全部操作后，请返回矩阵中值为奇数的格子数量。

``1 <= m, n <= 50``，``1 <= indices.length <= 100``，每个行列下标都位于矩阵范围内。

   输入：m = 2, n = 2, indices = [[0,0]]
   输出：2
   解释：最终矩阵为 [[2,1],[1,0]]，其中两个格子的值为奇数。

相同操作执行两次会恢复全部偶数：

   输入：m = 2, n = 3, indices = [[1,1],[1,1]]
   输出：0
   解释：被影响的行和列都累计增加两次，所有格子的最终值都是偶数。
