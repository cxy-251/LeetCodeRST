1233. Remove Sub-Folders from the Filesystem
============================================

题目信息
--------

:题号: 1233
:难度: Medium
:主题: 字符串、排序、目录路径
:原题: `LeetCode 1233 <https://leetcode.com/problems/remove-sub-folders-from-the-filesystem/>`_
:重点: 路径只有在父路径后紧接 ``/`` 和至少一个目录名时才是子文件夹；相同文本前缀不一定构成父子关系

题目重述
--------

给定互不相同的绝对目录路径数组 ``folder``。若路径 ``b`` 可以写成 ``a + "/" + name``，其中 ``name`` 非空且可以继续包含多级目录，则 ``b`` 是 ``a`` 的子文件夹。

请删除所有存在父文件夹的路径，只返回最外层文件夹。返回顺序不限。

``1 <= folder.length <= 4 * 10^4``，每条路径长度在 ``[2,100]`` 范围内，由小写英文字母和 ``/`` 组成，并以 ``/`` 开头。

自建示例
--------

文本前缀相同不代表目录父子关系：

.. code-block:: text

   输入：folder = ["/a","/a/b","/ab","/ab/c","/x"]
   输出：["/a","/ab","/x"]
   解释：/a/b 是 /a 的子目录，/ab/c 是 /ab 的子目录；/ab 不是 /a 的子目录，因为 a 后没有目录分隔符。

多层嵌套只保留最外层目录：

.. code-block:: text

   输入：folder = ["/p","/p/q","/p/q/r"]
   输出：["/p"]
   解释：后两条路径都位于 /p 之下。
