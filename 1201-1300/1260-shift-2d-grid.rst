1260. Shift 2D Grid
===================

题目信息
--------

:题号: 1260
:难度: Easy
:主题: 矩阵、循环位移、下标映射
:原题: `LeetCode 1260 <https://leetcode.com/problems/shift-2d-grid/>`_
:重点: 每次把所有元素按行优先顺序向后移动一位，行末移到下一行开头，右下角移到左上角

题目重述
--------

给定 ``m x n`` 矩阵 ``grid`` 和整数 ``k``。一次移动把每个元素移到行优先顺序中的下一个位置：非行末元素向右，行末元素移到下一行第一列，右下角元素移到左上角。

连续执行 ``k`` 次后，返回得到的矩阵。

``1 <= grid.length, grid[i].length <= 50``，``-1000 <= grid[i][j] <= 1000``，``0 <= k <= 100``。

自建示例
--------

跨行循环移动两个位置：

.. code-block:: text

   输入：grid = [[1,2,3],[4,5,6]], k = 2
   输出：[[5,6,1],[2,3,4]]
   解释：按行展开为 [1,2,3,4,5,6]，整体向右循环移动两位后为 [5,6,1,2,3,4]。

移动次数是元素总数的倍数时矩阵不变：

.. code-block:: text

   输入：grid = [[7,8]], k = 4
   输出：[[7,8]]
   解释：矩阵共有两个元素，循环移动四次等价于不移动。
