1222. Queens That Can Attack the King
=====================================

题目信息
--------

:题号: 1222
:难度: Medium
:主题: 棋盘、八方向扫描、阻挡关系
:原题: `LeetCode 1222 <https://leetcode.com/problems/queens-that-can-attack-the-king/>`_
:重点: 皇后沿行、列和对角线攻击；每个方向只有离国王最近且未被其他皇后阻挡的皇后能够攻击

题目重述
--------

在固定的 ``8 x 8`` 国际象棋棋盘上，数组 ``queens`` 给出若干皇后坐标，``king`` 给出国王坐标。所有棋子位置互不相同。

皇后可以沿水平、竖直和两条对角线方向攻击。若同一方向上存在多名皇后，靠近国王的皇后会阻挡后面的皇后。请返回所有能够直接攻击国王的皇后坐标，返回顺序不限。

``1 <= queens.length <= 63``，所有坐标分量均在 ``[0,7]`` 范围内。

自建示例
--------

每个方向只保留最近的皇后：

.. code-block:: text

   输入：queens = [[3,0],[3,2],[0,3],[2,3],[6,6],[5,5]], king = [3,3]
   输出：[[3,2],[2,3],[5,5]]
   解释：三名返回的皇后分别从左、上和右下方向攻击；更远的同方向皇后被阻挡。

没有皇后与国王共线时返回空数组：

.. code-block:: text

   输入：queens = [[1,2],[2,1]], king = [0,0]
   输出：[]
   解释：两名皇后都不与国王处于同一行、同一列或同一对角线。
