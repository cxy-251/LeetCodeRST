1275. Find Winner on a Tic Tac Toe Game
=======================================

题目信息
--------

:题号: 1275
:难度: Easy
:主题: 井字棋、状态模拟、胜负判断
:原题: `LeetCode 1275 <https://leetcode.com/problems/find-winner-on-a-tic-tac-toe-game/>`_
:重点: 两名玩家按给定顺序交替落子，A 先手使用 ``X``，B 使用 ``O``；根据最终状态返回胜者、平局或未结束

题目重述
--------

在 ``3 x 3`` 棋盘上进行井字棋。数组 ``moves`` 按时间顺序给出每次落子的坐标，玩家 A 先手，之后 A 与 B 交替行动。所有落子位置互不重复且合法。

若某位玩家在任意行、列或对角线上占据三个格子，返回 ``"A"`` 或 ``"B"``。若九格全部填满仍无人获胜，返回 ``"Draw"``；否则返回 ``"Pending"``。

``1 <= moves.length <= 9``，每个坐标分量位于 ``[0,2]``，题目保证游戏过程合法且胜出后不会继续落子。

自建示例
--------

先手通过主对角线获胜：

.. code-block:: text

   输入：moves = [[0,0],[0,1],[1,1],[0,2],[2,2]]
   输出："A"
   解释：A 最终占据 (0,0)、(1,1)、(2,2)，形成主对角线。

只进行一步时游戏尚未结束：

.. code-block:: text

   输入：moves = [[1,1]]
   输出："Pending"
   解释：棋盘未满，也没有任何三连线。
