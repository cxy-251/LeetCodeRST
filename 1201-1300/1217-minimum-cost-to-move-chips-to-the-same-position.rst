1217. Minimum Cost to Move Chips to The Same Position
=====================================================

题目信息
--------

:题号: 1217
:难度: Easy
:主题: 数组、奇偶性、最小代价
:原题: `LeetCode 1217 <https://leetcode.com/problems/minimum-cost-to-move-chips-to-the-same-position/>`_
:重点: 每次移动两个位置成本为 ``0``，移动一个位置成本为 ``1``；最终只需比较奇数位置和偶数位置的筹码数量

题目重述
--------

数轴上有若干筹码，``position[i]`` 表示第 ``i`` 个筹码的位置。一次操作可以把任意筹码移动 ``2`` 个单位，成本为 ``0``；或者移动 ``1`` 个单位，成本为 ``1``，方向不限。

可以执行任意次数操作，请把所有筹码移动到同一个整数位置，并返回所需的最小总成本。

``1 <= position.length <= 100``，``1 <= position[i] <= 10^9``。

自建示例
--------

只需把较少的奇偶组跨越一次：

.. code-block:: text

   输入：position = [1,3,5,8]
   输出：1
   解释：前三个筹码可以免费移动到任意奇数位置；位置 8 的筹码跨到奇数位置需要一次成本为 1 的移动。

所有筹码位置奇偶性相同时成本为零：

.. code-block:: text

   输入：position = [2,4,6]
   输出：0
   解释：三个位置都是偶数，可以只使用每次移动两个单位的免费操作把它们集中。
