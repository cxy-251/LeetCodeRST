1254. Number of Closed Islands
==============================

题目信息
--------

:题号: 1254
:难度: Medium
:主题: 网格、连通分量、深度优先搜索
:原题: `LeetCode 1254 <https://leetcode.com/problems/number-of-closed-islands/>`_
:重点: ``0`` 表示陆地、``1`` 表示水；闭合岛屿是未接触矩阵边界、完全被水包围的四向陆地连通分量

题目重述
--------

给定只包含 ``0`` 和 ``1`` 的矩阵 ``grid``，其中 ``0`` 表示陆地，``1`` 表示水。上下左右相邻的陆地格属于同一个岛屿。

若一个岛屿的所有陆地格都不位于矩阵边界，并且该连通分量四周由水包围，则它是闭合岛屿。请返回闭合岛屿的数量。

``1 <= grid.length, grid[i].length <= 100``，每个元素为 ``0`` 或 ``1``。

自建示例
--------

完全位于内部的陆地分量被计数：

.. code-block:: text

   输入：grid = [[1,1,1,1],[1,0,0,1],[1,1,0,1],[1,1,1,1]]
   输出：1
   解释：三个相连的陆地格不接触边界，并被水完全包围。

接触边界的陆地不闭合：

.. code-block:: text

   输入：grid = [[0,1],[0,1]]
   输出：0
   解释：唯一陆地分量包含左边界上的格子，因此不是闭合岛屿。
