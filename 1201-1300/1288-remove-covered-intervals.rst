1288. Remove Covered Intervals
==============================

题目信息
--------

:题号: 1288
:难度: Medium
:主题: 区间、排序、覆盖关系
:原题: `LeetCode 1288 <https://leetcode.com/problems/remove-covered-intervals/>`_
:重点: 若 ``c <= a`` 且 ``b <= d``，则区间 ``[a,b)`` 被 ``[c,d)`` 覆盖；删除所有被其他区间覆盖的区间并返回剩余数量

题目重述
--------

给定互不相同的半开区间数组 ``intervals``。若存在另一区间 ``[c,d)``，使 ``c <= a`` 且 ``b <= d``，则区间 ``[a,b)`` 被它覆盖。

删除所有被其他区间覆盖的区间，并返回最终剩余区间数量。

``1 <= intervals.length <= 1000``，``0 <= start_i < end_i <= 10^5``，所有区间互不相同。

自建示例
--------

只删除完全包含在另一段中的区间：

.. code-block:: text

   输入：intervals = [[1,5],[2,3],[4,8]]
   输出：2
   解释：[2,3) 被 [1,5) 覆盖；[1,5) 与 [4,8) 互不覆盖。

仅在端点相接不构成覆盖：

.. code-block:: text

   输入：intervals = [[1,2],[2,3]]
   输出：2
   解释：两个半开区间只在端点相接，任何一个都不包含另一个。
