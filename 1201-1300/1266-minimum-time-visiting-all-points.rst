1266. Minimum Time Visiting All Points
======================================

题目信息
--------

:题号: 1266
:难度: Easy
:主题: 平面坐标、切比雪夫距离、路径
:原题: `LeetCode 1266 <https://leetcode.com/problems/minimum-time-visiting-all-points/>`_
:重点: 每秒横纵坐标各最多改变 ``1``，因此相邻两点最短时间为横纵坐标差绝对值的较大者；必须按输入顺序访问

题目重述
--------

给定平面点数组 ``points``，需要从第一个点出发，并按数组顺序依次访问后续每个点。每秒可以水平移动一个单位、竖直移动一个单位，或者同时在两个方向各移动一个单位。

请返回访问全部点所需的最少总时间。

``1 <= points.length <= 100``，``-1000 <= points[i][0], points[i][1] <= 1000``。

自建示例
--------

对角移动可以同时缩小两个坐标差：

.. code-block:: text

   输入：points = [[0,0],[3,1],[1,4]]
   输出：6
   解释：前两点最短需要 max(3,1)=3 秒，后两点需要 max(2,3)=3 秒，总计 6 秒。

只有一个点时无需移动：

.. code-block:: text

   输入：points = [[5,-2]]
   输出：0
   解释：起点已经是唯一需要访问的点。
