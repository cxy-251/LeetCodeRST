1238. Circular Permutation in Binary Representation
===================================================

题目信息
--------

:题号: 1238
:难度: Medium
:主题: 格雷码、位运算、循环排列
:原题: `LeetCode 1238 <https://leetcode.com/problems/circular-permutation-in-binary-representation/>`_
:重点: 排列必须包含 ``0`` 到 ``2^n - 1`` 恰好一次，从 ``start`` 开始，任意相邻项以及首尾之间都只相差一个二进制位

题目重述
--------

给定整数 ``n`` 和 ``start``。请返回一个长度为 ``2^n`` 的排列，包含范围 ``[0, 2^n - 1]`` 中每个整数恰好一次，且第一项必须等于 ``start``。

把每个整数写成 ``n`` 位二进制后，排列中任意相邻两项必须恰好有一位不同；最后一项与第一项也必须满足同样条件。任意合法排列均可返回。

``1 <= n <= 16``，``0 <= start < 2^n``。
