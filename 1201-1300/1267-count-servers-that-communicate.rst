1267. Count Servers that Communicate
====================================

题目信息
--------

:题号: 1267
:难度: Medium
:主题: 矩阵、行列计数、服务器通信
:原题: `LeetCode 1267 <https://leetcode.com/problems/count-servers-that-communicate/>`_
:重点: 值为 ``1`` 的服务器只要同行或同列存在另一台服务器即可通信；返回能够通信的服务器数量

题目重述
--------

给定二进制矩阵 ``grid``，``grid[i][j] == 1`` 表示该格有一台服务器，``0`` 表示空格。

若一台服务器所在的同一行或同一列中还存在至少一台其他服务器，则它能够与其他服务器通信。请返回所有能够通信的服务器数量；孤立服务器不计入答案。

``1 <= grid.length, grid[i].length <= 250``，每个元素为 ``0`` 或 ``1``。

自建示例
--------

不同服务器可以分别通过行和列通信：

.. code-block:: text

   输入：grid = [[1,0,1],[0,1,0],[0,1,0]]
   输出：4
   解释：第一行的两台服务器互相通信，第二列的两台服务器互相通信，四台都应计数。

唯一服务器无法通信：

.. code-block:: text

   输入：grid = [[1,0],[0,0]]
   输出：0
   解释：该服务器所在行和列都没有其他服务器。
