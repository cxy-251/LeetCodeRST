1234. Replace the Substring for Balanced String
===============================================

题目信息
--------

:题号: 1234
:难度: Medium
:主题: 字符串、滑动窗口、频次平衡
:原题: `LeetCode 1234 <https://leetcode.com/problems/replace-the-substring-for-balanced-string/>`_
:重点: 字符串长度是 ``4`` 的倍数；可把一个连续子串替换为任意同长度字符串，使 ``QWER`` 各出现 ``n/4`` 次

题目重述
--------

给定只包含 ``Q``、``W``、``E``、``R`` 的字符串 ``s``，其长度 ``n`` 是 ``4`` 的倍数。若四种字符都恰好出现 ``n / 4`` 次，则字符串平衡。

可以选择一个连续子串，并将它替换为任意同长度字符串。请返回使整个字符串平衡所需替换子串的最小长度；原字符串已平衡时返回 ``0``。

``4 <= s.length <= 10^5``，``s.length`` 是 ``4`` 的倍数。

自建示例
--------

替换两个过量字符即可补齐缺少字符：

.. code-block:: text

   输入：s = "QQQQWERR"
   输出：2
   解释：目标频次均为 2；把任意连续的 "QQ" 替换为 "WE" 后四种字符都出现两次。

原字符串已经平衡：

.. code-block:: text

   输入：s = "QQWWEERR"
   输出：0
   解释：Q、W、E、R 各出现两次，无需替换。
