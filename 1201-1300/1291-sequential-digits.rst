1291. Sequential Digits
=======================

题目信息
--------

:题号: 1291
:难度: Medium
:主题: 数字生成、枚举、排序
:原题: `LeetCode 1291 <https://leetcode.com/problems/sequential-digits/>`_
:重点: 顺次数的每一位都比前一位恰好大 ``1``；返回闭区间 ``[low, high]`` 内全部顺次数并按升序排列

题目重述
--------

若一个正整数的十进制数位从左到右依次递增，并且每一位都比前一位恰好大 ``1``，则称它为顺次数。

给定整数 ``low`` 和 ``high``，请返回闭区间 ``[low, high]`` 中所有顺次数，并按数值升序排列。

``10 <= low <= high <= 10^9``。

自建示例
--------

区间可以包含不同位数的顺次数：

.. code-block:: text

   输入：low = 50, high = 500
   输出：[56,67,78,89,123,234,345,456]
   解释：这些数的相邻十进制数位都依次增加一，并且全部位于给定区间。

区间内没有顺次数时返回空数组：

.. code-block:: text

   输入：low = 1000, high = 1100
   输出：[]
   解释：最接近的四位顺次数 1234 已超过上界。
