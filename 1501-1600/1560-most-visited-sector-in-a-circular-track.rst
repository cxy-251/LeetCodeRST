1560. Most Visited Sector in a Circular Track
=============================================

题目信息
--------

:题号: 1560
:难度: Easy
:主题: 数组、环形轨道、模拟
:原题: `LeetCode 1560 <https://leetcode.com/problems/most-visited-sector-in-a-circular-track/>`_
:重点: 运动始终按编号递增方向绕圈；访问次数最多的扇区只由起点和最终终点之间的顺时针区间决定

题目重述
--------

圆形赛道分为编号 ``1`` 到 ``n`` 的扇区。数组 ``rounds`` 给出每一轮的起点和下一轮终点，运动员始终按 ``1,2,...,n,1`` 的方向前进。

起始扇区以及经过和到达的每个扇区都计为一次访问。请返回访问次数最多的所有扇区编号，并按升序排列。

``2 <= n <= 100``，``2 <= rounds.length <= 100``，每个编号位于 ``[1,n]``。

自建示例
--------

不绕过编号末端时起点到终点都访问一次：

.. code-block:: text

   输入：n = 4, rounds = [1,3]
   输出：[1,2,3]
   解释：运动员依次访问扇区 1、2、3。

绕完整个编号边界时所有扇区访问次数相同：

.. code-block:: text

   输入：n = 4, rounds = [3,2]
   输出：[1,2,3,4]
   解释：路径为 3 -> 4 -> 1 -> 2，每个扇区各访问一次。
