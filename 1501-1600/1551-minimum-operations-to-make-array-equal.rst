1551. Minimum Operations to Make Array Equal
============================================

题目信息
--------

:题号: 1551
:难度: Medium
:主题: 数学、等差数列、最小操作数
:原题: `LeetCode 1551 <https://leetcode.com/problems/minimum-operations-to-make-array-equal/>`_
:重点: 初始数组第 ``i`` 项为 ``2i+1``；每次把一个元素加一、另一个元素减一，求全部相等的最少次数

题目重述
--------

给定整数 ``n``，构造长度为 ``n`` 的数组 ``arr``，其中 ``arr[i] = 2 * i + 1``。

一次操作选择两个不同下标，把一个元素增加 ``1``，另一个元素减少 ``1``。请返回使数组所有元素相等所需的最少操作次数。

``1 <= n <= 10^4``。

--------

   输入：n = 4
   输出：4
   解释：初始数组为 [1,3,5,7]，把两端差值向中间转移共需 3+1=4 次。

   输出：0
