1572. Matrix Diagonal Sum
=========================

题目信息
--------

:题号: 1572
:难度: Easy
:主题: 矩阵、对角线、模拟
:原题: `LeetCode 1572 <https://leetcode.com/problems/matrix-diagonal-sum/>`_
:重点: 计算主对角线与副对角线元素和；奇数阶矩阵中心格同时属于两条对角线，只能计一次

题目重述
--------

给定 ``n x n`` 整数矩阵 ``mat``。主对角线由满足行列下标相等的格子组成，副对角线由满足 ``i + j = n - 1`` 的格子组成。

请返回两条对角线上所有元素的总和。若一个格子同时属于两条对角线，只计入一次。

``1 <= n <= 100``，``1 <= mat[i][j] <= 100``。

自建示例
--------

奇数阶矩阵中心元素不能重复计数：

.. code-block:: text

   输入：mat = [[1,2,3],[4,5,6],[7,8,9]]
   输出：25
   解释：两条对角线之和为 15+15，再减去重复的中心值 5。

单元素矩阵的唯一格子只计一次：

.. code-block:: text

   输入：mat = [[4]]
   输出：4
   解释：该格同时属于两条对角线。
