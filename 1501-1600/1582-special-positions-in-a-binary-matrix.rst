1582. Special Positions in a Binary Matrix
==========================================

题目信息
--------

:题号: 1582
:难度: Easy
:主题: 二进制矩阵、行列计数
:原题: `LeetCode 1582 <https://leetcode.com/problems/special-positions-in-a-binary-matrix/>`_
:重点: 特殊位置必须为 ``1``，且所在整行和整列都没有其他 ``1``

题目重述
--------

给定二进制矩阵 ``mat``。若格子 ``(i,j)`` 的值为 ``1``，并且第 ``i`` 行与第 ``j`` 列中的其他格子全部为 ``0``，则该位置是特殊位置。

请返回矩阵中特殊位置的数量。

``1 <= mat.length, mat[i].length <= 100``，每个元素为 ``0`` 或 ``1``。

自建示例
--------

列中出现多个一会使对应位置都不特殊：

.. code-block:: text

   输入：mat = [[1,0,0],[0,0,1],[1,0,0]]
   输出：1
   解释：位置 (1,2) 的行列中没有其他一；第一列有两个一。

全零矩阵没有特殊位置：

.. code-block:: text

   输入：mat = [[0,0]]
   输出：0
   解释：特殊位置首先必须取值为一。
