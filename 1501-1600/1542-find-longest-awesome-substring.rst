1542. Find Longest Awesome Substring
====================================

题目信息
--------

:题号: 1542
:难度: Hard
:主题: 字符串、前缀状态、位掩码、回文排列
:原题: `LeetCode 1542 <https://leetcode.com/problems/find-longest-awesome-substring/>`_
:重点: 子串字符可任意重排；能组成回文串当且仅当最多一种数字的出现次数为奇数

题目重述
--------

给定只包含数字字符 ``0`` 到 ``9`` 的字符串 ``s``。若一个连续子串中的字符可以重新排列成回文串，则称它为超赞子串。

请返回 ``s`` 中最长超赞子串的长度。重新排列只用于判断，不改变子串必须连续的要求。

``1 <= s.length <= 10^5``。

自建示例
--------

整个字符串只有一种数字出现奇数次时全部可用：

.. code-block:: text

   输入：s = "11223"
   输出：5
   解释：1 和 2 各出现两次，3 出现一次，全部字符可重排为回文串。

所有数字互不相同时最长长度为一：

.. code-block:: text

   输入：s = "123"
   输出：1
   解释：任意长度大于一的子串都会有至少两个奇数频次。
