1592. Rearrange Spaces Between Words
====================================

题目信息
--------

:题号: 1592
:难度: Easy
:主题: 字符串、计数、格式化
:原题: `LeetCode 1592 <https://leetcode.com/problems/rearrange-spaces-between-words/>`_
:重点: 保留原单词顺序和空格总数；词间空格尽量平均，不能平均分配的剩余空格全部放在末尾

题目重述
--------

给定由小写单词和空格组成的字符串 ``text``。重新排列其中所有空格，同时保持单词内容和相对顺序不变。

若有多个单词，使每对相邻单词之间的空格数相同且尽可能多，剩余空格放在字符串末尾。若只有一个单词，全部空格都放在它后面。返回结果字符串。

``1 <= text.length <= 100``，字符串至少包含一个单词。

自建示例
--------

空格可以在多个词间恰好平均分配：

.. code-block:: text

   输入：text = "  a b  c "
   输出："a   b   c"
   解释：共有六个空格和两个词间间隙，每处放三个空格。

只有一个单词时全部空格移到末尾：

.. code-block:: text

   输入：text = "  word "
   输出："word   "
   解释：三个空格全部放在唯一单词之后。
