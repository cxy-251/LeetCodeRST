1550. Three Consecutive Odds
============================

题目信息
--------

:题号: 1550
:难度: Easy
:主题: 数组、连续段、奇偶性
:原题: `LeetCode 1550 <https://leetcode.com/problems/three-consecutive-odds/>`_
:重点: 判断数组中是否存在连续三个位置，其元素全部为奇数

题目重述
--------

给定整数数组 ``arr``。请判断是否存在某个长度恰好为三的连续子数组，其中三个元素都是奇数。

若存在返回 ``true``，否则返回 ``false``。

``1 <= arr.length <= 1000``，``1 <= arr[i] <= 1000``。

自建示例
--------

连续三个奇数可以位于数组中间：

.. code-block:: text

   输入：arr = [2,3,5,7,4]
   输出：true
   解释：连续元素 3、5、7 都是奇数。

奇数数量足够但不连续时仍返回假：

.. code-block:: text

   输入：arr = [1,2,3,5]
   输出：false
   解释：偶数 2 打断了连续段，末尾只有两个连续奇数。
