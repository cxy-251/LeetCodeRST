1513. Number of Substrings With Only 1s
=======================================

题目信息
--------

:题号: 1513
:难度: Medium
:主题: 字符串、连续段、计数
:原题: `LeetCode 1513 <https://leetcode.com/problems/number-of-substrings-with-only-1s/>`_
:重点: 统计全部字符均为 ``1`` 的非空连续子串；长度为 ``L`` 的连续一段贡献 ``L(L+1)/2``

题目重述
--------

给定二进制字符串 ``s``。请统计其中所有只由字符 ``1`` 组成的非空连续子串数量。

不同起止位置的子串分别计数，即使内容相同。答案可能很大，返回结果对 ``10^9 + 7`` 取模后的值。

``1 <= s.length <= 10^5``，``s`` 只包含 ``0`` 和 ``1``。

自建示例
--------

不同连续一段的贡献需要相加：

.. code-block:: text

   输入：s = "11011"
   输出：6
   解释：两个长度为 2 的连续一段各贡献 3 个子串，总计 6。

字符串中没有一时答案为零：

.. code-block:: text

   输入：s = "0"
   输出：0
   解释：唯一非空子串包含字符 0。
