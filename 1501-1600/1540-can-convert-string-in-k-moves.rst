1540. Can Convert String in K Moves
===================================

题目信息
--------

:题号: 1540
:难度: Medium
:主题: 字符串、计数、模运算、调度
:原题: `LeetCode 1540 <https://leetcode.com/problems/can-convert-string-in-k-moves/>`_
:重点: 第 ``i`` 次操作可把一个字符循环后移 ``i`` 位，且每个操作编号只能使用一次；相同位移需求需间隔 ``26`` 调度

题目重述
--------

给定两个小写字符串 ``s``、``t`` 和非负整数 ``k``。在第 ``i`` 次操作中，可以选择 ``s`` 的一个位置，把该字符在字母表中循环后移 ``i`` 位；也可以跳过该次操作。每个 ``i`` 只能使用一次，``1 <= i <= k``。

请判断能否在至多 ``k`` 次编号操作后把 ``s`` 变成 ``t``。两个字符串长度不同时直接返回 ``false``。

``1 <= s.length, t.length <= 10^5``，``0 <= k <= 10^9``。

自建示例
--------

相同位移需求需要使用相差二十六的操作编号：

.. code-block:: text

   输入：s = "abc", t = "bcd", k = 53
   输出：true
   解释：三个位置都需后移一位，可分别使用操作 1、27、53。

最大操作编号不足以安排全部重复位移时失败：

.. code-block:: text

   输入：s = "abc", t = "bcd", k = 52
   输出：false
   解释：第三个后移一位的需求最早需要操作 53。
