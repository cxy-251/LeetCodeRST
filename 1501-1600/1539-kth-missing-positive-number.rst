1539. Kth Missing Positive Number
================================

题目信息
--------

:题号: 1539
:难度: Easy
:主题: 有序数组、二分查找、缺失数
:原题: `LeetCode 1539 <https://leetcode.com/problems/kth-missing-positive-number/>`_
:重点: 数组严格递增且只含正整数；按正整数自然顺序统计未出现的第 ``k`` 个

题目重述
--------

给定严格递增的正整数数组 ``arr`` 和正整数 ``k``。从正整数 ``1`` 开始依次检查，数组中没有出现的数构成缺失序列。

请返回这个缺失序列中的第 ``k`` 个正整数。

``1 <= arr.length <= 1000``，``1 <= arr[i], k <= 1000``。

自建示例
--------

缺失序列可以跨过数组末尾：

.. code-block:: text

   输入：arr = [2,3,4], k = 2
   输出：5
   解释：缺失正整数依次为 1、5、6……，第二个是 5。

数组从一开始连续时首个缺失数位于末尾之后：

.. code-block:: text

   输入：arr = [1,2,3], k = 1
   输出：4
   解释：1、2、3 均存在，首个缺失正整数为 4。
