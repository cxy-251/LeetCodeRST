1512. Number of Good Pairs
==========================

题目信息
--------

:题号: 1512
:难度: Easy
:主题: 数组、计数、组合
:原题: `LeetCode 1512 <https://leetcode.com/problems/number-of-good-pairs/>`_
:重点: 好数对要求 ``i < j`` 且 ``nums[i] == nums[j]``；相同数值出现 ``c`` 次会贡献 ``c(c-1)/2`` 对

题目重述
--------

给定整数数组 ``nums``。若下标对 ``(i,j)`` 满足 ``i < j`` 且两个位置的数值相等，则称它为好数对。

请返回数组中好数对的总数量。相同的两个数值实例只按它们的下标组合计数一次。

``1 <= nums.length <= 100``，``1 <= nums[i] <= 100``。

自建示例
--------

同一数值出现三次会形成三个下标对：

.. code-block:: text

   输入：nums = [1,2,1,1]
   输出：3
   解释：值为 1 的位置为 0、2、3，对应 (0,2)、(0,3)、(2,3)。

所有元素互不相同时没有好数对：

.. code-block:: text

   输入：nums = [3,4,5]
   输出：0
   解释：不存在数值相等的两个不同位置。
