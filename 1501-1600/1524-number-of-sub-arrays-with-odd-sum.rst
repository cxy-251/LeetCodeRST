1524. Number of Sub-arrays With Odd Sum
=======================================

题目信息
--------

:题号: 1524
:难度: Medium
:主题: 数组、前缀和、奇偶性、计数
:原题: `LeetCode 1524 <https://leetcode.com/problems/number-of-sub-arrays-with-odd-sum/>`_
:重点: 统计元素和为奇数的非空连续子数组；答案对 ``10^9 + 7`` 取模

题目重述
--------

给定整数数组 ``arr``。请统计其中元素和为奇数的非空连续子数组数量。

不同起止下标的子数组分别计数。由于答案可能很大，返回结果对 ``10^9 + 7`` 取模后的值。

``1 <= arr.length <= 10^5``，``1 <= arr[i] <= 100``。

自建示例
--------

奇偶前缀组合会产生多个奇数和子数组：

.. code-block:: text

   输入：arr = [1,2,1]
   输出：4
   解释：合法子数组为两个单独的 1、[1,2] 和 [2,1]。

所有元素为偶数时答案为零：

.. code-block:: text

   输入：arr = [2,4]
   输出：0
   解释：任意连续子数组的和都为偶数。
