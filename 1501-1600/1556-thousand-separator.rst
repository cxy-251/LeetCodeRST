1556. Thousand Separator
========================

题目信息
--------

:题号: 1556
:难度: Easy
:主题: 整数、字符串、格式化
:原题: `LeetCode 1556 <https://leetcode.com/problems/thousand-separator/>`_
:重点: 从右向左每三个十进制数字插入一个句点，最高位组前不添加分隔符

题目重述
--------

给定非负整数 ``n``。请把它写成十进制字符串，并从右向左每三个数字使用句点 ``.`` 分隔。

返回格式化后的字符串。数值零应返回 ``"0"``。

``0 <= n <= 2^31 - 1``。

自建示例
--------

多个千位组都需要分隔：

.. code-block:: text

   输入：n = 1234567
   输出："1.234.567"
   解释：从右侧开始每三个数字组成一组。

零不需要任何分隔符：

.. code-block:: text

   输入：n = 0
   输出："0"
   解释：十进制表示只有一个数字。
