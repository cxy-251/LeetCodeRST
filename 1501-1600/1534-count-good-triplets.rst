1534. Count Good Triplets
=========================

题目信息
--------

:题号: 1534
:难度: Easy
:主题: 数组、枚举、三元组
:原题: `LeetCode 1534 <https://leetcode.com/problems/count-good-triplets/>`_
:重点: 三元组必须满足 ``i < j < k``，并同时满足三组绝对差上限

题目重述
--------

给定整数数组 ``arr`` 和三个非负整数 ``a``、``b``、``c``。下标三元组 ``(i,j,k)`` 只有在 ``i < j < k``，且 ``|arr[i]-arr[j]| <= a``、``|arr[j]-arr[k]| <= b``、``|arr[i]-arr[k]| <= c`` 时才是好三元组。

请返回数组中好三元组的总数量。

``3 <= arr.length <= 100``，``0 <= arr[i], a, b, c <= 1000``。

自建示例
--------

唯一三元组同时满足全部限制：

.. code-block:: text

   输入：arr = [1,2,3], a = 1, b = 2, c = 2
   输出：1
   解释：下标 (0,1,2) 的三组差分别为 1、1、2。

任一差值超限都会使三元组无效：

.. code-block:: text

   输入：arr = [1,5,9], a = 2, b = 10, c = 10
   输出：0
   解释：前两个元素之差为 4，超过 a。
