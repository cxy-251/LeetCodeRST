1525. Number of Good Ways to Split a String
===========================================

题目信息
--------

:题号: 1525
:难度: Medium
:主题: 字符串、前后缀、不同字符计数
:原题: `LeetCode 1525 <https://leetcode.com/problems/number-of-good-ways-to-split-a-string/>`_
:重点: 把字符串切成两个非空连续部分；左右部分包含的不同字符数量相等时切分有效

题目重述
--------

给定小写字符串 ``s``。在任意相邻字符之间切分一次，得到非空前缀 ``s_left`` 和非空后缀 ``s_right``。

若两部分中不同字符的数量相同，则该切分为好切分。请返回好切分的总数量。

``2 <= s.length <= 10^5``，``s`` 只包含小写英文字母。

自建示例
--------

只有中间切分满足不同字符数相等：

.. code-block:: text

   输入：s = "abca"
   输出：1
   解释：切成 "ab" 与 "ca" 时两侧各有两个不同字符，其余切分不满足。

所有字符相同时每个切分都有效：

.. code-block:: text

   输入：s = "aaaa"
   输出：3
   解释：三个切分位置的左右部分都只包含字符 a。
