1598. Crawler Log Folder
========================

题目信息
--------

:题号: 1598
:难度: Easy
:主题: 字符串、栈、路径模拟
:原题: `LeetCode 1598 <https://leetcode.com/problems/crawler-log-folder/>`_
:重点: ``x/`` 进入子目录，``../`` 返回父目录但根目录不能再上移，``./`` 保持原目录；返回回到根目录的最少操作数

题目重述
--------

文件系统浏览器初始位于主目录。依次执行 ``logs`` 中的操作：``"../"`` 返回父目录；``"./"`` 保持当前目录；其他形如 ``"name/"`` 的字符串进入一个子目录。

在主目录执行 ``"../"`` 仍停留在主目录。完成全部日志后，请返回回到主目录所需的最少操作次数。

``1 <= logs.length <= 10^3``，目录名只包含小写英文字母和数字。

自建示例
--------

返回父目录后还可以再次进入新子目录：

.. code-block:: text

   输入：logs = ["d1/","d2/","../","d3/"]
   输出：2
   解释：最终路径深度为二，需要连续返回两次。

在根目录上移和停留都不会增加深度：

.. code-block:: text

   输入：logs = ["../","./"]
   输出：0
   解释：浏览器始终位于主目录。
