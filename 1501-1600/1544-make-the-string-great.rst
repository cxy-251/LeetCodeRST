1544. Make The String Great
===========================

题目信息
--------

:题号: 1544
:难度: Easy
:主题: 字符串、栈、相邻消除
:原题: `LeetCode 1544 <https://leetcode.com/problems/make-the-string-great/>`_
:重点: 相邻字符若为同一英文字母的大小写形式，就可同时删除；反复删除直到不存在坏相邻对

题目重述
--------

给定由大小写英文字母组成的字符串 ``s``。若两个相邻字符代表同一个字母且大小写相反，例如 ``aA`` 或 ``Bb``，则可以把这两个字符同时删除。

反复执行任意合法删除，直到字符串中不存在这样的相邻对。请返回最终字符串；题目保证最终结果唯一。

``1 <= s.length <= 100``。

自建示例
--------

一次删除后可以继续删除新形成的相邻对：

.. code-block:: text

   输入：s = "aAbBc"
   输出："c"
   解释：先后删除 aA 和 bB，最终只剩 c。

没有坏相邻对时字符串保持不变：

.. code-block:: text

   输入：s = "abc"
   输出："abc"
   解释：任意相邻字符都不是同一字母的相反大小写。
