1588. Sum of All Odd Length Subarrays
=====================================

题目信息
--------

:题号: 1588
:难度: Easy
:主题: 数组、连续子数组、贡献计数
:原题: `LeetCode 1588 <https://leetcode.com/problems/sum-of-all-odd-length-subarrays/>`_
:重点: 枚举所有长度为奇数的连续子数组，并把每个子数组的元素和再次累加

题目重述
--------

给定正整数数组 ``arr``。考虑所有长度为奇数的非空连续子数组。

请先计算每个这样的子数组元素和，再返回这些和的总和。不同边界的子数组分别计数。

``1 <= arr.length <= 100``，``1 <= arr[i] <= 1000``。

自建示例
--------

长度一和长度三的子数组都需计入：

.. code-block:: text

   输入：arr = [1,2,3]
   输出：12
   解释：三个长度一子数组之和为 6，整个长度三子数组之和也为 6。

单元素数组只有一个奇数长度子数组：

.. code-block:: text

   输入：arr = [5]
   输出：5
   解释：唯一子数组就是 [5]。
