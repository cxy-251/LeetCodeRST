1535. Find the Winner of an Array Game
======================================

题目信息
--------

:题号: 1535
:难度: Medium
:主题: 数组、模拟、最大值
:原题: `LeetCode 1535 <https://leetcode.com/problems/find-the-winner-of-an-array-game/>`_
:重点: 每轮比较数组前两个数，较大者留在首位，较小者移到末尾；连续获胜 ``k`` 轮者结束游戏

题目重述
--------

给定由互不相同正整数组成的数组 ``arr`` 和正整数 ``k``。每轮比较数组前两个元素，较大者留在数组首位，较小者移动到数组末尾。

某个数连续赢得 ``k`` 轮时，游戏立即结束。请返回获胜的数值。

``2 <= arr.length <= 10^5``，``1 <= k <= 10^9``，数组元素互不相同。

自建示例
--------

   输入：arr = [3,1,2], k = 2
   输出：3
   解释：3 先后击败 1 和 2，连续获胜两轮。

   输入：arr = [1,5,2], k = 1
   输出：5
   解释：首轮比较 1 与 5，5 获胜后游戏结束。
