# 目录职责

`packages/` 存放可复用库、共享类型、模板引擎、内容管线与特效模块。

# 允许内容

- 可复用包目录
- 每个包自己的 `README.md`
- 共享逻辑与类型

# 禁止内容

- 直接可运行应用
- 一次性脚本入口
- 只属于某个应用的页面层状态

# 修改前必须阅读

- `../README.md`
- `../PROJECT_MAP.md`
- `../AGENTS.md`

# 命名规则

- 包目录采用语义化名称，如 `atomic-ui`、`content-pipeline`
- 每个包必须包含自己的 `README.md`

# 边界说明

应用在 `apps/`，脚本在 `tools/`，服务在 `services/`。
凡是需要跨应用或跨脚本复用的能力，优先落在这里。

# Codex 规则

- 修改本目录文件前必须阅读本 README。
- 不允许把应用层页面逻辑顺手塞进包目录。
- 如需新增包，先补该包目录 `README.md`。
