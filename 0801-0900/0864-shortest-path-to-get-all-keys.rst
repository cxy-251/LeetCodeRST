0864. Shortest Path to Get All Keys
========================================================================================================================

题目信息
--------

:题号: 0864
:难度: Hard
:主题: 网格、钥匙与锁、最短路径
:原题: `LeetCode 0864 <https://leetcode.com/problems/shortest-path-to-get-all-keys/>`_
:重点: 移动状态包含当前位置和已持有钥匙集合；钥匙取得后永久保留，对应大写锁只有持有同字母钥匙时才能进入

题目重述
--------

给定字符网格 ``grid``。字符 ``@`` 是唯一的起点，``.`` 是空地，``#`` 是不可进入的墙，小写字母 ``a`` 至 ``f`` 表示钥匙，大写字母 ``A`` 至 ``F`` 表示对应的锁。

每一步可以向上、下、左、右移动一格，不能越界或穿过墙。进入钥匙格后会永久获得该钥匙；只有已经持有对应小写钥匙时，才能进入相应的大写锁格。请返回从起点收集网格中全部钥匙所需的最少步数；若无法收集齐，返回 ``-1``。

网格行列数均在 ``[1, 30]`` 范围内，恰有一个起点，并包含 ``1`` 至 ``6`` 把互不相同的钥匙；每把钥匙及其对应锁在网格中至多出现一次。

自建示例
--------

取得钥匙后穿过对应锁：

.. code-block:: text

   输入：grid = ["@.a","..A","b.."]
   输出：6
   解释：可以先向右两步取得 a，再向下穿过锁 A，沿底行向左两步取得 b，共移动 6 步；也可以先取得 b，再返回上方取得 a，最短步数相同。

钥匙不可达：

.. code-block:: text

   输入：grid = ["@#a","###","b.."]
   输出：-1
   解释：墙把起点与两把钥匙完全隔开，无法收集全部钥匙。
