0896. Monotonic Array
========================================================================================================================

题目信息
--------

:题号: 0896
:难度: Easy
:主题: 数组、单调性、相邻比较
:原题: `LeetCode 0896 <https://leetcode.com/problems/monotonic-array/>`_
:重点: 整个数组只需满足非递减或非递增其中一种，允许相邻元素相等

题目重述
--------

给定整数数组 ``nums``。若对所有合法下标 ``i < j`` 都有 ``nums[i] <= nums[j]``，则数组单调非递减；若对所有 ``i < j`` 都有 ``nums[i] >= nums[j]``，则数组单调非递增。

请判断 ``nums`` 是否至少满足上述一种单调性。相邻或非相邻元素可以相等；长度为 ``1`` 的数组同时满足两种定义。

``1 <= nums.length <= 10^5``，``-10^5 <= nums[i] <= 10^5``。

自建示例
--------

允许出现相等元素：

.. code-block:: text

   输入：nums = [3,3,2,1]
   输出：true
   解释：数组从左到右从未增大，满足单调非递增。

方向发生改变：

.. code-block:: text

   输入：nums = [1,3,2]
   输出：false
   解释：先从 1 增加到 3，随后又减小到 2，既不非递减也不非递增。
