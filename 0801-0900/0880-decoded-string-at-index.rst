0880. Decoded String at Index
========================================================================================================================

题目信息
--------

:题号: 0880
:难度: Medium
:主题: 编码字符串、重复展开、第 k 个字符
:原题: `LeetCode 0880 <https://leetcode.com/problems/decoded-string-at-index/>`_
:重点: 字母追加到当前解码串末尾，数字 d 把当前完整解码串重复 d 次；k 从 1 开始且只需返回对应单个字母

题目重述
--------

给定编码字符串 ``s``。从空字符串开始按顺序读取：

* 遇到小写字母时，把该字母追加到当前解码字符串末尾；
* 遇到数字 ``d``（范围 ``2`` 至 ``9``）时，把当前整个解码字符串重复 ``d`` 次，也就是用 ``d`` 份当前内容连接形成新字符串。

给定从 ``1`` 开始的下标 ``k``，请返回完整解码字符串的第 ``k`` 个字符。输入保证该位置存在；解码结果可能极长，但返回值只是一个字符。

``2 <= s.length <= 100``，``s`` 由小写英文字母和数字 ``2`` 至 ``9`` 组成并以字母开头；``1 <= k <= 10^9``，完整解码长度小于 ``2^63``。

自建示例
--------

数字重复此前的全部内容：

.. code-block:: text

   输入：s = "ab3c2", k = 8
   输出："a"
   解释：ab3 解码为 ababab，追加 c 得到 abababc，再整体重复两次得到 abababcabababc；第 8 个字符是第二份内容的首字符 a。
