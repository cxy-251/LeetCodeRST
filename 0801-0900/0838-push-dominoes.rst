0838. Push Dominoes
========================================================================================================================

题目信息
--------

:题号: 0838
:难度: Medium
:主题: 字符串、同时传播、受力平衡
:原题: `LeetCode 0838 <https://leetcode.com/problems/push-dominoes/>`_
:重点: 所有倒下过程同时发生；直立骨牌若在同一时刻受到大小相同、方向相反的力会保持直立

题目重述
--------

给定字符串 ``dominoes``，其中 ``L`` 表示初始向左倒下的骨牌，``R`` 表示初始向右倒下的骨牌，``.`` 表示直立骨牌。每秒，正在向左倒的骨牌会推动紧邻左侧的直立骨牌，正在向右倒的骨牌会推动紧邻右侧的直立骨牌。

所有作用同时发生。若一块直立骨牌在同一时刻同时受到向左和向右的力，两股力抵消，它保持直立；已倒下或正在倒下的骨牌不会改变方向。请返回系统稳定后的状态字符串。

``1 <= dominoes.length <= 10^5``，字符串只包含 ``L``、``R`` 和 ``.``。

自建示例
--------

中点同时受力保持直立：

.. code-block:: text

   输入：dominoes = "R...L"
   输出："RR.LL"
   解释：两端的力向中间传播，靠近两端的骨牌分别倒向右和左；正中骨牌同时受到相反方向的力，因此保持直立。

相反方向向外传播：

.. code-block:: text

   输入：dominoes = "L...R"
   输出："L...R"
   解释：左端向左、右端向右，二者都不会推动中间骨牌，状态不变。
