0866. Prime Palindrome
========================================================================================================================

题目信息
--------

:题号: 0866
:难度: Medium
:主题: 整数、质数、回文数
:原题: `LeetCode 0866 <https://leetcode.com/problems/prime-palindrome/>`_
:重点: 返回不小于 n 的最小整数，同时必须是质数且十进制表示正反读取相同

题目重述
--------

给定整数 ``n``。一个整数是质回文数，当且仅当它大于 ``1``、只有 ``1`` 和自身两个正因数，并且它的十进制数字从左向右和从右向左读取完全相同。

请返回满足 ``x >= n`` 的最小质回文数 ``x``。题目保证答案存在，并且位于 ``[2, 2 * 10^8]`` 范围内。

``1 <= n <= 10^8``。

自建示例
--------

跨过一系列合数回文：

.. code-block:: text

   输入：n = 31
   输出：101
   解释：不小于 31 且小于 101 的两位回文数 33、44、55、66、77、88、99 都是合数，因此 101 是第一个符合条件的质回文数。

输入小于最小质数：

.. code-block:: text

   输入：n = 1
   输出：2
   解释：n 达到题目允许的最小值。数字 1 不是质数，2 既是质数也是单数字回文，因此是最小答案。
