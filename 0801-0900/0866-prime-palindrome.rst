0866. Prime Palindrome
========================================================================================================================

题目信息
--------

:题号: 0866
:难度: Medium
:主题: 整数、质数、回文数
:原题: `LeetCode 0866 <https://leetcode.com/problems/prime-palindrome/>`_
:重点: 返回不小于 n 的最小整数，同时必须是质数且十进制表示正反读取相同

题目重述
--------

给定整数 ``n``。一个整数是质回文数，当且仅当它大于 ``1``、只有 ``1`` 和自身两个正因数，并且它的十进制数字从左向右和从右向左读取完全相同。

请返回满足 ``x >= n`` 的最小质回文数 ``x``。题目保证答案存在，并且小于 ``2 * 10^8``。

``1 <= n <= 10^8``。

自建示例
--------

跨过一系列合数回文：

.. code-block:: text

   输入：n = 13
   输出：101
   解释：13 之后的两位回文数 22、33、44、55、66、77、88、99 都不是质数，101 是第一个同时满足质数和回文条件的数。
