0859. Buddy Strings
========================================================================================================================

题目信息
--------

:题号: 0859
:难度: Easy
:主题: 字符串、一次交换、重复字符
:原题: `LeetCode 0859 <https://leetcode.com/problems/buddy-strings/>`_
:重点: 必须在 s 中交换两个不同下标且恰好执行一次；当 s 已等于 goal 时，只有存在重复字符才能交换后保持不变

题目重述
--------

给定字符串 ``s`` 和 ``goal``。必须在 ``s`` 中选择两个不同下标 ``i`` 和 ``j``，交换这两个位置的字符，且只能执行这一次交换。

请判断交换后能否使 ``s`` 与 ``goal`` 完全相同。若两个字符串原本相同，仍必须执行交换，因此只有 ``s`` 中存在至少两个相同字符时才可能保持结果不变；若长度不同则不可能成功。

``1 <= s.length, goal.length <= 2 * 10^4``，两个字符串只包含小写英文字母。

自建示例
--------

交换两个不同字符得到目标：

.. code-block:: text

   输入：s = "abcd", goal = "abdc"
   输出：true
   解释：交换 s 中下标 2 和 3 的字符 c、d 后得到 "abdc"，恰好等于 goal。

相同字符串依靠重复字符完成交换：

.. code-block:: text

   输入：s = "aab", goal = "aab"
   输出：true
   解释：交换两个值都为 a 的不同下标后字符串不变，满足恰好一次交换。

相同但没有重复字符：

.. code-block:: text

   输入：s = "ab", goal = "ab"
   输出：false
   解释：唯一可交换的两个位置会得到 ba，无法在执行一次交换后仍等于目标。
