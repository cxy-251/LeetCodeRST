0849. Maximize Distance to Closest Person
========================================================================================================================

题目信息
--------

:题号: 0849
:难度: Medium
:主题: 数组、座位距离、最近占用位置
:原题: `LeetCode 0849 <https://leetcode.com/problems/maximize-distance-to-closest-person/>`_
:重点: 只能选择一个空座位，得分是到最近已坐人员的下标距离；目标是最大化这个最小距离

题目重述
--------

一排座位用二进制数组 ``seats`` 表示，``1`` 表示该位置已经有人，``0`` 表示空座位。Alex 必须选择一个值为 ``0`` 的位置坐下。

若选择下标 ``i``，他与最近人员的距离是 ``|i - j|`` 在所有满足 ``seats[j] == 1`` 的下标中的最小值。请返回选择最佳空座位后能够取得的最大距离。

``2 <= seats.length <= 2 * 10^4``，数组中至少有一个 ``0`` 和一个 ``1``。

自建示例
--------

最佳位置位于两名人员之间：

.. code-block:: text

   输入：seats = [1,0,0,0,1,0]
   输出：2
   解释：选择下标 2 时，到下标 0 和 4 的人员距离都为 2，最近距离为 2；其他空座位的最近距离不超过 2。

最佳位置位于队列末端：

.. code-block:: text

   输入：seats = [1,0,0,0]
   输出：3
   解释：选择最后一个下标 3 时，到唯一已坐人员下标 0 的距离为 3；其他空座位距离更小，因此最大距离为 3。
