0844. Backspace String Compare
========================================================================================================================

题目信息
--------

:题号: 0844
:难度: Easy
:主题: 字符串、退格处理、结果比较
:原题: `LeetCode 0844 <https://leetcode.com/problems/backspace-string-compare/>`_
:重点: 字符 # 删除当前文本的最后一个字符；文本为空时退格不产生效果，比较的是处理后的最终字符串

题目重述
--------

给定字符串 ``s`` 和 ``t``，其中小写字母表示输入字符，``#`` 表示一次退格操作。按从左到右的顺序处理每个字符串：遇到 ``#`` 时删除当前结果中的最后一个字符；若当前结果为空，则该退格不做任何事。

请判断两个字符串经过全部退格操作后得到的最终文本是否完全相同，并返回布尔值。

``1 <= s.length, t.length <= 200``，两个字符串只包含小写英文字母和字符 ``#``。

自建示例
--------

开头的退格作用于空文本：

.. code-block:: text

   输入：s = "ab##c", t = "#c"
   输出：true
   解释：s 中 ab 被两个退格全部删除后剩下 c；t 开头的退格无效果，最终也只剩 c。
