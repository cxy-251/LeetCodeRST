0830. Positions of Large Groups
========================================================================================================================

题目信息
--------

:题号: 0830
:难度: Easy
:主题: 字符串、连续字符组、下标区间
:原题: `LeetCode 0830 <https://leetcode.com/problems/positions-of-large-groups/>`_
:重点: 大组必须由至少三个连续相同字符组成；返回每组从 0 开始的闭区间，并按起始下标升序排列

题目重述
--------

给定字符串 ``s``。一组字符是指一段最大化的连续相同字符区间，也就是该区间无法再向左或向右扩展同一字符。若一组的长度至少为 ``3``，则称为大组。

请返回所有大组的下标区间 ``[start, end]``，其中两个下标都从 ``0`` 开始且包含在组内。结果按照 ``start`` 从小到大排列。

``1 <= s.length <= 1000``，``s`` 只包含小写英文字母。

自建示例
--------

首尾都存在大组：

.. code-block:: text

   输入：s = "aaabccdddd"
   输出：[[0,2],[6,9]]
   解释：开头三个 a 的闭区间为 [0,2]，结尾四个 d 的闭区间为 [6,9]；单个 b 和两个 c 都不足三个字符。

不存在大组：

.. code-block:: text

   输入：s = "abbc"
   输出：[]
   解释：各连续字符组分别是 "a"、"bb" 和 "c"，长度都小于 3，因此结果为空数组。
