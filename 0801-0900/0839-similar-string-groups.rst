0839. Similar String Groups
========================================================================================================================

题目信息
--------

:题号: 0839
:难度: Hard
:主题: 字符串、交换关系、连通分组
:原题: `LeetCode 0839 <https://leetcode.com/problems/similar-string-groups/>`_
:重点: 两字符串相同或可通过交换其中一个字符串的两个位置变成相同即直接相似；分组按相似关系的传递连通性确定

题目重述
--------

给定字符串数组 ``strs``，所有字符串长度相同，并且彼此都是字母异位词。若两个字符串完全相同，或者能在其中一个字符串中选择两个不同位置交换字符后得到另一个字符串，则它们直接相似。

把每个字符串实例视为一个节点，直接相似的两个实例之间相连。即使两个字符串不直接相似，只要能通过一系列直接相似的字符串相互到达，它们也属于同一组。请返回最终的连通组数量。

``1 <= strs.length <= 300``，每个字符串长度在 ``[1, 300]`` 范围内，只包含小写英文字母；所有字符串互为字母异位词。

自建示例
--------

同一字母集合形成两个相似组：

.. code-block:: text

   输入：strs = ["abcd","cbad","adcb","acbd"]
   输出：2
   解释：abcd 可交换偶数下标 0、2 得到 cbad，也可交换奇数下标 1、3 得到 adcb，因此前三个字符串连通；acbd 与前三者都不能通过一次交换直接相似，也没有中间字符串把它们连接起来，所以单独成组。
