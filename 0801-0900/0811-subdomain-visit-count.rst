0811. Subdomain Visit Count
========================================================================================================================

题目信息
--------

:题号: 0811
:难度: Medium
:主题: 字符串、域名层级、频次汇总
:原题: `LeetCode 0811 <https://leetcode.com/problems/subdomain-visit-count/>`_
:重点: 访问一个完整域名时，其所有按点号截取的父域名都获得同样的访问次数；结果顺序不限

题目重述
--------

给定若干计数域名字符串 ``cpdomains``。每项格式为 ``"次数 域名"``，表示该完整域名被访问了指定次数。访问一个域名也同时视为访问它的每一级父域名：例如访问 ``a.b.com``，会同时计入 ``a.b.com``、``b.com`` 和 ``com``。

请汇总所有完整域名及其父域名的总访问次数，并以相同的 ``"次数 域名"`` 格式返回。每个域名只需在结果中出现一次，结果顺序不限。

``1 <= cpdomains.length <= 100``；每项中的访问次数在 ``[1, 10^4]`` 范围内，域名由小写字母和点号组成，整体长度不超过 100。

自建示例
--------

不同完整域名共享父域名：

.. code-block:: text

   输入：cpdomains = ["40 api.example.com","60 shop.example.com"]
   输出：["40 api.example.com","60 shop.example.com","100 example.com","100 com"]
   解释：两个完整域名都属于 example.com 和 com，因此这两个父域名各累计 100 次；结果顺序可以不同。
