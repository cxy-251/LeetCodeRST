0821. Shortest Distance to a Character
========================================================================================================================

题目信息
--------

:题号: 0821
:难度: Easy
:主题: 字符串、下标距离、最近出现位置
:原题: `LeetCode 0821 <https://leetcode.com/problems/shortest-distance-to-a-character/>`_
:重点: 对每个下标分别寻找任意一个字符 c 的最近出现位置，距离按下标差的绝对值计算

题目重述
--------

给定字符串 ``s`` 和字符 ``c``，题目保证 ``c`` 至少在 ``s`` 中出现一次。对于每个下标 ``i``，计算它到某个满足 ``s[j] == c`` 的下标 ``j`` 的最小距离 ``|i - j|``。

请返回长度与 ``s`` 相同的整数数组，其中第 ``i`` 项就是上述最短距离。字符串下标从 ``0`` 开始，多个相同字符位置中只取距离最近者。

``1 <= s.length <= 10^4``，``s`` 和 ``c`` 均只包含小写英文字母。

自建示例
--------

目标字符多次出现：

.. code-block:: text

   输入：s = "abcaad", c = "a"
   输出：[0,1,1,0,0,1]
   解释：a 出现在下标 0、3、4；每个位置到这三个下标中最近者的距离依次为 0、1、1、0、0、1。
