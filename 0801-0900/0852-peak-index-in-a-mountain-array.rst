0852. Peak Index in a Mountain Array
========================================================================================================================

题目信息
--------

:题号: 0852
:难度: Medium
:主题: 数组、山脉数组、峰顶下标
:原题: `LeetCode 0852 <https://leetcode.com/problems/peak-index-in-a-mountain-array/>`_
:重点: 输入保证先严格递增后严格递减，因此峰顶唯一且不在数组两端；返回从 0 开始的峰顶下标

题目重述
--------

给定一个山脉数组 ``arr``。存在唯一的下标 ``i``，满足 ``0 < i < arr.length - 1``，数组从开头到 ``i`` 严格递增，并从 ``i`` 到末尾严格递减。

请返回这个唯一峰顶元素的下标 ``i``。输入已经保证满足山脉数组定义，不需要处理不存在峰顶或含平台的情况。

``3 <= arr.length <= 10^5``，``0 <= arr[i] <= 10^6``。

自建示例
--------

峰顶位于中间：

.. code-block:: text

   输入：arr = [0,2,5,3,1]
   输出：2
   解释：下标 2 的值 5 左侧严格递增，右侧严格递减，因此它是唯一峰顶。
