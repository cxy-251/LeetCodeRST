0883. Projection Area of 3D Shapes
========================================================================================================================

题目信息
--------

:题号: 0883
:难度: Easy
:主题: 三维方块、正投影、矩阵
:原题: `LeetCode 0883 <https://leetcode.com/problems/projection-area-of-3d-shapes/>`_
:重点: 顶视图面积等于非零格数，两个侧视图分别取每行和每列的最大高度；返回三幅投影面积之和

题目重述
--------

给定一个 ``n x n`` 矩阵 ``grid``，``grid[i][j]`` 表示在平面格子 ``(i, j)`` 上竖直堆放的单位立方体数量。由这些立方体组成三维形体。

分别从顶部、前方和侧方进行正投影。顶部投影中，每个高度大于零的格子贡献一个单位面积；另外两个方向中，同一直线上的立方体会互相遮挡，只由该行或该列的最大高度决定投影面积。请返回三幅投影面积之和。

``1 <= n <= 50``，``0 <= grid[i][j] <= 50``。

自建示例
--------

空格不贡献顶视图面积：

.. code-block:: text

   输入：grid = [[1,2],[3,0]]
   输出：13
   解释：顶视图有三个非零格，面积为 3；两行最大高度之和为 2 + 3 = 5，两列最大高度之和为 3 + 2 = 5，总面积为 3 + 5 + 5 = 13。

单格中没有立方体：

.. code-block:: text

   输入：grid = [[0]]
   输出：0
   解释：矩阵尺寸达到允许的最小值，唯一格子的高度为 0。三个方向都看不到任何单位面积，因此投影面积总和为 0。
