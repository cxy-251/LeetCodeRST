0900. RLE Iterator
========================================================================================================================

题目信息
--------

:题号: 0900
:难度: Medium
:主题: 设计题、游程编码、顺序消耗
:原题: `LeetCode 0900 <https://leetcode.com/problems/rle-iterator/>`_
:重点: 编码按“数量、数值”成对表示序列；next(n) 按顺序消耗 n 个元素并返回最后一个，被请求数量不足时消耗全部剩余元素并返回 -1

题目重述
--------

实现 ``RLEIterator`` 类。构造函数接收偶数长度数组 ``encoding``，每对 ``encoding[2 * i]`` 和 ``encoding[2 * i + 1]`` 表示后一个数值连续出现前一个数量的次数；数量可以为 ``0``。对象需要在多次调用之间保存尚未被消耗的序列状态。

``next(n)``：从当前剩余序列开头按顺序消耗 ``n`` 个元素。若剩余元素至少有 ``n`` 个，返回本次消耗的第 ``n`` 个、也就是最后一个元素的值；若不足 ``n`` 个，则把所有剩余元素全部消耗，并返回 ``-1``。已经消耗的元素不会在后续调用中再次出现。

``2 <= encoding.length <= 1000`` 且长度为偶数，``0 <= encoding[i] <= 10^9``；``next`` 调用次数不超过 ``1000``，每次满足 ``1 <= n <= 10^9``。

自建示例
--------

失败调用也会耗尽剩余元素：

.. code-block:: text

   输入：
   ["RLEIterator","next","next","next"]
   [[[3,8,0,9,2,5]],[2],[2],[2]]
   输出：[null,8,5,-1]
   解释：编码表示 [8,8,8,5,5]。第一次消耗两个 8 并返回 8；第二次消耗剩余的 8 和第一个 5，返回 5；最后只剩一个 5，不足以消耗两个，因此耗尽它并返回 -1。
