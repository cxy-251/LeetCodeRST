0868. Binary Gap
========================================================================================================================

题目信息
--------

:题号: 0868
:难度: Easy
:主题: 整数、二进制、位间距
:原题: `LeetCode 0868 <https://leetcode.com/problems/binary-gap/>`_
:重点: 只比较二进制表示中相邻出现的两个 1，距离按它们位下标之差计算；不足两个 1 时返回 0

题目重述
--------

给定正整数 ``n``，写出它不含前导零的二进制表示。对于其中任意两个连续出现的 ``1``，也就是它们之间没有其他 ``1``，定义距离为两个位位置的差。

请返回所有相邻 ``1`` 之间的最大距离。若二进制表示中少于两个 ``1``，返回 ``0``。

``1 <= n <= 10^9``。

自建示例
--------

不同相邻一位对具有不同距离：

.. code-block:: text

   输入：n = 41
   输出：3
   解释：41 的二进制表示为 101001，三个 1 的位位置从高到低相差 2 和 3，因此最大二进制间距为 3。

二进制中只有一个一：

.. code-block:: text

   输入：n = 16
   输出：0
   解释：16 的二进制表示为 10000，只包含一个 1，没有相邻的一位对，因此返回 0。
