0868. Binary Gap
========================================================================================================================

题目信息
--------

:题号: 0868
:难度: Easy
:主题: 整数、二进制、位间距
:原题: `LeetCode 0868 <https://leetcode.com/problems/binary-gap/>`_
:重点: 只比较二进制表示中相邻出现的两个 1，距离按它们位下标之差计算；不足两个 1 时返回 0

题目重述
--------

给定正整数 ``n``，写出它不含前导零的二进制表示。对于其中任意两个连续出现的 ``1``，也就是它们之间没有其他 ``1``，定义距离为两个位位置的差。

请返回所有相邻 ``1`` 之间的最大距离。若二进制表示中少于两个 ``1``，返回 ``0``。

``1 <= n <= 10^9``。

自建示例
--------

不同相邻一位对具有不同距离：

.. code-block:: text

   输入：n = 22
   输出：2
   解释：22 的二进制表示为 10110，其中相邻的 1 之间距离分别为 2 和 1，最大值为 2。
