0805. Split Array With Same Average
========================================================================================================================

题目信息
--------

:题号: 0805
:难度: Hard
:主题: 数组、非空划分、平均值
:原题: `LeetCode 0805 <https://leetcode.com/problems/split-array-with-same-average/>`_
:重点: 需要把全部元素按下标分成两个非空部分，元素不能遗漏或重复；判断两部分算术平均值是否相等

题目重述
--------

给定整数数组 ``nums``。请判断能否把数组中的全部元素划分为两个非空数组 ``A`` 和 ``B``，使每个原元素恰好属于其中一个部分，并且 ``A`` 与 ``B`` 的算术平均值相同。

划分依据是元素所在位置，因此数组中相同数值的多个实例仍是不同元素；两个部分不要求保持原数组中的连续性或顺序。若存在至少一种合法划分，返回 ``true``，否则返回 ``false``。

``1 <= nums.length <= 30``，``0 <= nums[i] <= 10^4``。

自建示例
--------

可以按交叉位置划分：

.. code-block:: text

   输入：nums = [1,2,5,6]
   输出：true
   解释：可分为 [1,6] 与 [2,5]，两部分平均值都为 3.5。

不存在相同平均值的非空划分：

.. code-block:: text

   输入：nums = [1,2,4]
   输出：false
   解释：任取一个或两个元素组成一部分，都无法使它与剩余元素的平均值相等。
