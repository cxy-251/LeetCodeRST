0867. Transpose Matrix
========================================================================================================================

题目信息
--------

:题号: 0867
:难度: Easy
:主题: 矩阵、行列交换、转置
:原题: `LeetCode 0867 <https://leetcode.com/problems/transpose-matrix/>`_
:重点: 原矩阵第 i 行第 j 列的元素移动到结果第 j 行第 i 列；m×n 矩阵转置后尺寸为 n×m

题目重述
--------

给定一个 ``m x n`` 整数矩阵 ``matrix``。矩阵转置是把每个元素 ``matrix[i][j]`` 放到结果矩阵的 ``answer[j][i]`` 位置，相当于交换行下标和列下标。

请返回转置后的 ``n x m`` 矩阵。输入不要求是方阵，原矩阵的所有元素都必须保留一次。

``m == matrix.length``，``n == matrix[i].length``，``1 <= m, n <= 1000``，``1 <= m * n <= 10^5``，``-10^9 <= matrix[i][j] <= 10^9``。

自建示例
--------

三行两列矩阵转置后交换尺寸：

.. code-block:: text

   输入：matrix = [[-1,0],[2,3],[4,5]]
   输出：[[-1,2,4],[0,3,5]]
   解释：原矩阵第一列 -1、2、4 成为结果第一行，第二列 0、3、5 成为结果第二行，尺寸从 3×2 变为 2×3。

单行矩阵转置为单列：

.. code-block:: text

   输入：matrix = [[7,-2,9]]
   输出：[[7],[-2],[9]]
   解释：矩阵只有一行，转置后每个原列元素各自成为一行，结果尺寸为 3×1。
