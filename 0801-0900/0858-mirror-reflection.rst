0858. Mirror Reflection
========================================================================================================================

:重点: 光线从左下角向右墙上距底 q 的位置射出并按镜面规律反射；返回首先命中的三个非起点角落接收器编号

题目重述
--------

一个边长为 ``p`` 的正方形房间四壁均为镜面。光线从左下角出发，第一次到达右墙时，落点距右下角竖直距离为 ``q``。之后光线按照入射角等于反射角的规律在墙面间反射。

除起点外，三个角落各有一个接收器：右下角编号 ``0``，右上角编号 ``1``，左上角编号 ``2``。题目保证光线最终会到达其中一个接收器。请返回它首先命中的接收器编号。

``1 <= q <= p <= 1000``。

自建示例
--------

光线最终到达左上角：

.. code-block:: text

   输入：p = 6, q = 4
   输出：2
   解释：把反射路径展开后，光线首次到达角点时水平方向跨过 3 个房间宽度，竖直方向跨过 2 个房间高度。折回原房间后，奇数次水平跨越对应左侧，偶数次竖直跨越对应上侧，因此命中左上角接收器 2。

光线最终到达右下角：

.. code-block:: text

   输入：p = 3, q = 2
   输出：0
   解释：展开反射路径后，光线首次到达角点时水平方向跨过 3 个房间宽度、竖直方向跨过 2 个房间高度；折回原房间后对应右下角接收器 0。
