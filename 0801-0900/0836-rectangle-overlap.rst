0836. Rectangle Overlap
========================================================================================================================

题目信息
--------

:题号: 0836
:难度: Easy
:主题: 几何、轴对齐矩形、正面积交集
:原题: `LeetCode 0836 <https://leetcode.com/problems/rectangle-overlap/>`_
:重点: 只有交集面积严格大于零才算重叠；仅接触边或角不算重叠

题目重述
--------

两个矩形都与坐标轴平行。数组 ``rec = [x1, y1, x2, y2]`` 表示矩形左下角为 ``(x1, y1)``、右上角为 ``(x2, y2)``，并保证矩形宽和高都为正。

给定 ``rec1`` 和 ``rec2``，请判断两个矩形的交集是否具有严格为正的面积。若它们只在一条边或一个顶点上接触，交集面积为零，应返回 ``false``。

所有坐标均在 ``[-10^9, 10^9]`` 范围内，并满足 ``x1 < x2``、``y1 < y2``。

自建示例
--------

只共享边界不算重叠：

.. code-block:: text

   输入：rec1 = [0,0,2,2], rec2 = [2,0,4,2]
   输出：false
   解释：两个矩形只在直线 x = 2 上接触，交集宽度为 0，因此没有正面积交集。

存在正面积交集：

.. code-block:: text

   输入：rec1 = [-1,-1,3,2], rec2 = [1,0,4,4]
   输出：true
   解释：交集为 [1,0,3,2]，宽和高都大于 0。
