0897. Increasing Order Search Tree
========================================================================================================================

题目信息
--------

:题号: 0897
:难度: Easy
:主题: 二叉搜索树、节点重排、递增链
:原题: `LeetCode 0897 <https://leetcode.com/problems/increasing-order-search-tree/>`_
:重点: 使用原树全部节点重新连接，最小值节点成为根；每个节点左孩子必须为空，只能通过右孩子按值严格递增

题目重述
--------

给定一棵节点值互不相同的二叉搜索树 ``root``。重新排列树中的全部原节点，使结果树的根节点是原树中值最小的节点，并且每个节点都没有左孩子，只有可能存在一个右孩子。

沿结果树的右孩子链读取时，节点值必须严格递增，并且原树中的每个节点恰好出现一次。请返回重排后树的根节点。

树中节点数在 ``[1, 100]`` 范围内，``0 <= Node.val <= 1000``，所有节点值互不相同。

自建示例
--------

所有节点被连接成递增右链：

.. code-block:: text

   输入：root = [5,3,6,2,4,null,8]
   输出：[2,null,3,null,4,null,5,null,6,null,8]
   解释：原树节点值按升序为 2、3、4、5、6、8；值 2 的节点成为根，其余节点依次作为右孩子，所有左孩子都为空。
