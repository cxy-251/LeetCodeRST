0874. Walking Robot Simulation
========================================================================================================================

题目信息
--------

:题号: 0874
:难度: Medium
:主题: 坐标模拟、方向旋转、障碍物
:原题: `LeetCode 0874 <https://leetcode.com/problems/walking-robot-simulation/>`_
:重点: 机器人初始朝北并按命令顺序逐单位移动；下一格有障碍时该前进命令不能继续，返回过程中到原点平方距离的最大值

题目重述
--------

机器人初始位于坐标 ``(0, 0)``，面向北方。按顺序执行数组 ``commands``：

* ``-2`` 表示原地向左转 90 度；
* ``-1`` 表示原地向右转 90 度；
* ``1`` 至 ``9`` 表示沿当前方向前进对应单位数，每次移动一格。

数组 ``obstacles`` 给出不可进入的障碍坐标。执行前进命令时，若下一格是障碍，机器人停在当前格并结束该条前进命令，再继续处理下一条命令。请返回整个过程中机器人到原点的欧氏距离平方 ``x^2 + y^2`` 的最大值。

``1 <= commands.length <= 10^4``，障碍数不超过 ``10^4``；障碍坐标在 ``[-3 * 10^4, 3 * 10^4]`` 范围内且互不相同，原点不是障碍。

自建示例
--------

障碍中断一条前进命令：

.. code-block:: text

   输入：commands = [4,-1,4], obstacles = [[2,4]]
   输出：17
   解释：机器人先到 (0,4)，右转后向东移动到 (1,4)；下一格 (2,4) 是障碍，因此停下。最大平方距离为 1^2 + 4^2 = 17。
