0874. Walking Robot Simulation
========================================================================================================================

题目信息
--------

:题号: 0874
:难度: Medium
:主题: 坐标模拟、方向旋转、障碍物
:原题: `LeetCode 0874 <https://leetcode.com/problems/walking-robot-simulation/>`_
:重点: 机器人初始朝北并按命令顺序逐单位移动；下一格有障碍时结束当前前进命令，返回过程中到原点平方距离的最大值

题目重述
--------

机器人初始位于坐标 ``(0, 0)``，面向北方。按顺序执行数组 ``commands``：

* ``-2`` 表示原地向左转 90 度；
* ``-1`` 表示原地向右转 90 度；
* ``1`` 至 ``9`` 表示沿当前方向前进对应单位数，每次移动一格。

数组 ``obstacles`` 给出不可进入的障碍坐标。执行前进命令时，若下一格是障碍，机器人停在当前格并结束该条前进命令，再继续处理下一条命令。障碍可以位于原点：机器人开始时不受它影响，但离开原点后不能再次进入该格。请返回整个过程中机器人到原点的欧氏距离平方 ``x^2 + y^2`` 的最大值。

``1 <= commands.length <= 10^4``，障碍数不超过 ``10^4``；障碍坐标在 ``[-3 * 10^4, 3 * 10^4]`` 范围内且互不相同，答案保证小于 ``2^31``。

自建示例
--------

不同障碍分别中断两条前进命令：

.. code-block:: text

   输入：commands = [3,-1,2,-2,4], obstacles = [[2,3],[1,5]]
   输出：17
   解释：机器人先向北到 (0,3)，右转后向东只能走到 (1,3)，因为下一格 (2,3) 有障碍；再左转朝北，只能走到 (1,4)，下一格 (1,5) 又被阻挡。过程中最大平方距离为 1^2 + 4^2 = 17。

原点障碍只阻止机器人返回：

.. code-block:: text

   输入：commands = [2,-1,-1,3], obstacles = [[0,0]]
   输出：4
   解释：机器人起步时可以从原点向北走到 (0,2)。连续两次右转后朝南前进，先到 (0,1)，但下一格原点是障碍，无法返回。最远位置 (0,2) 的平方距离为 4。
