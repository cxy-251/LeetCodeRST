0833. Find And Replace in String
========================================================================================================================

题目信息
--------

:题号: 0833
:难度: Medium
:主题: 字符串、区间匹配、同时替换
:原题: `LeetCode 0833 <https://leetcode.com/problems/find-and-replace-in-string/>`_
:重点: 所有匹配都基于原字符串同时判断；只有 source 在指定原下标处完整匹配时才替换，成功替换区间保证不重叠

题目重述
--------

给定字符串 ``s``，以及长度相同的数组 ``indices``、``sources`` 和 ``targets``。第 ``i`` 项表示尝试从原字符串下标 ``indices[i]`` 开始匹配 ``sources[i]``：若该位置起的连续字符与 ``sources[i]`` 完全相同，就用 ``targets[i]`` 替换它；否则忽略该项。

所有替换必须视为同时发生，匹配位置均相对于未修改的原字符串，不能让较早替换改变后续下标或匹配内容。题目保证所有成功匹配的源区间互不重叠。请返回替换后的字符串。

``1 <= s.length <= 1000``，替换项数在 ``[1, 100]`` 范围内；下标合法且互不相同，``sources[i]`` 和 ``targets[i]`` 长度在 ``[1, 50]`` 范围内，相关字符串只包含小写英文字母。

自建示例
--------

两个替换基于原字符串同时生效：

.. code-block:: text

   输入：s = "abcdxyz", indices = [0,4], sources = ["ab","xy"], targets = ["pq","mn"]
   输出："pqcdmnz"
   解释：原字符串下标 0 处匹配 ab，下标 4 处匹配 xy，两个区间不重叠，因此同时替换。

不匹配的操作被忽略：

.. code-block:: text

   输入：s = "hello", indices = [1], sources = ["all"], targets = ["ipp"]
   输出："hello"
   解释：从下标 1 开始的子串不是 all，因此不执行替换。
