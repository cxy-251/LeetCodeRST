0853. Car Fleet
========================================================================================================================

题目信息
--------

:题号: 0853
:难度: Medium
:主题: 车辆运动、追赶、车队计数
:原题: `LeetCode 0853 <https://leetcode.com/problems/car-fleet/>`_
:重点: 车辆不能超车；后车追上前车后以较慢速度共同前进，同一时刻在目标处相遇也算一个车队

题目重述
--------

有 ``n`` 辆车沿同一直线向位置 ``target`` 行驶。``position[i]`` 和 ``speed[i]`` 分别表示第 ``i`` 辆车的初始位置和恒定速度，所有初始位置互不相同且都小于目标。

车辆不能超车。若一辆较快的后车在到达目标前追上前车，它们从此组成一个车队，并以车队中较慢的速度继续行驶；多个车或车队可以继续合并。若车辆恰好在目标位置同时相遇，也视为同一车队。请返回到达目标的车队数量。

``1 <= n <= 10^5``，``0 <= position[i] < target <= 10^6``，``1 <= speed[i] <= 10^6``，初始位置互不相同。
