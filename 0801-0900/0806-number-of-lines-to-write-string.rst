0806. Number of Lines To Write String
========================================================================================================================

题目信息
--------

:题号: 0806
:难度: Easy
:主题: 字符串、逐行排版、宽度累计
:原题: `LeetCode 0806 <https://leetcode.com/problems/number-of-lines-to-write-string/>`_
:重点: 字符必须按原顺序书写，每行最多容纳 100 个宽度单位；返回总行数和最后一行已使用宽度

题目重述
--------

数组 ``widths`` 给出小写字母 ``a`` 至 ``z`` 各自在纸面上占用的宽度。给定只含小写字母的字符串 ``s``，按字符原顺序从第一行开始书写，每行最多使用 100 个宽度单位。

若下一个字符会使当前行总宽度超过 100，就必须换到新的一行书写该字符；恰好达到 100 不需要提前换行。请返回长度为 2 的数组：第一项是使用的总行数，第二项是最后一行实际使用的宽度。

``widths`` 恰好包含 26 个整数，每个宽度在 ``[2, 10]`` 范围内；``1 <= s.length <= 1000``，且 ``s`` 只包含小写英文字母。

自建示例
--------

恰好写满一行后换行：

.. code-block:: text

   输入：widths = [10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10,10], s = "abcdefghijk"
   输出：[2,10]
   解释：前 10 个字符总宽度为 100，写满第一行；最后一个字符写在第二行，占用 10 个宽度单位。

字符串只有一个字符：

.. code-block:: text

   输入：widths = [2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2,2], s = "z"
   输出：[1,2]
   解释：字符串长度达到题目允许的最小值，只需使用一行；字母 z 的宽度为 2，所以最后一行宽度为 2。
