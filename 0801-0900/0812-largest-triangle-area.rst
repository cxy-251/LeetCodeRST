0812. Largest Triangle Area
========================================================================================================================

题目信息
--------

:题号: 0812
:难度: Easy
:主题: 几何、平面点、三角形面积
:原题: `LeetCode 0812 <https://leetcode.com/problems/largest-triangle-area/>`_
:重点: 从不同输入点中任选三个作为顶点，返回能够形成的最大三角形面积；共线三点面积为零

题目重述
--------

给定二维平面上一组互不相同的点 ``points``，其中 ``points[i] = [x_i, y_i]``。从这些点中选择三个不同的点作为三角形顶点，计算其面积。

请返回所有选择中能够得到的最大面积。若三个点共线，它们形成的面积为 ``0``。答案与真实值的误差在 ``10^-5`` 以内即可接受。

``3 <= points.length <= 50``，每个坐标均在 ``[-50, 50]`` 范围内，所有点互不相同。

自建示例
--------

最大面积来自直角三角形：

.. code-block:: text

   输入：points = [[0,0],[4,0],[0,3],[1,1]]
   输出：6.0
   解释：选择 (0,0)、(4,0) 和 (0,3)，底为 4、高为 3，面积为 4 * 3 / 2 = 6；其他三点组合面积更小。
