0845. Longest Mountain in Array
========================================================================================================================

题目信息
--------

:题号: 0845
:难度: Medium
:主题: 数组、连续子数组、严格单调
:原题: `LeetCode 0845 <https://leetcode.com/problems/longest-mountain-in-array/>`_
:重点: 山脉必须是长度至少 3 的连续子数组，并存在内部峰顶；峰顶左侧严格递增、右侧严格递减，不能出现相等元素

题目重述
--------

给定整数数组 ``arr``。一个连续子数组是山脉，当且仅当它的长度至少为 ``3``，并存在一个既不是首项也不是末项的峰顶，使峰顶之前的元素严格递增，峰顶之后的元素严格递减。

请返回数组中最长山脉子数组的长度。山脉不能包含平台，相邻元素相等会中断严格递增或严格递减；若不存在山脉，返回 ``0``。

``1 <= arr.length <= 10^4``，``0 <= arr[i] <= 10^4``。

自建示例
--------

两个山脉中选择较长者：

.. code-block:: text

   输入：arr = [1,2,3,2,1,2,1]
   输出：5
   解释：子数组 [1,2,3,2,1] 是长度 5 的山脉；末尾 [1,2,1] 长度为 3，因此最长长度为 5。
