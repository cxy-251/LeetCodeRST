0846. Hand of Straights
========================================================================================================================

题目信息
--------

:题号: 0846
:难度: Medium
:主题: 多重集合、连续整数、分组
:原题: `LeetCode 0846 <https://leetcode.com/problems/hand-of-straights/>`_
:重点: 必须使用每张牌恰好一次，分成若干个大小正好为 groupSize 的组；每组数值按 1 连续，重复牌按实例分别使用

题目重述
--------

给定整数数组 ``hand``，每个元素表示一张牌的点数，以及整数 ``groupSize``。请判断能否把所有牌划分成若干组，使每组恰好包含 ``groupSize`` 张牌，并且组内牌的点数可以排列成连续整数，相邻点数之差均为 ``1``。

每张输入牌必须恰好属于一个组；相同点数的多张牌是不同实例，可以分别放入不同组。若牌总数无法被 ``groupSize`` 整除或不存在合法划分，返回 ``false``。

``1 <= hand.length <= 10^4``，``0 <= hand[i] <= 10^9``，``1 <= groupSize <= hand.length``。

自建示例
--------

重复点数分别用于两个连续组：

.. code-block:: text

   输入：hand = [1,2,2,3,3,4], groupSize = 3
   输出：true
   解释：可以分为 [1,2,3] 和 [2,3,4]，所有六张牌恰好使用一次。

缺少连续点数：

.. code-block:: text

   输入：hand = [1,2,4,5], groupSize = 2
   输出：true
   解释：可以分为 [1,2] 和 [4,5]；不同组之间不要求连续。
