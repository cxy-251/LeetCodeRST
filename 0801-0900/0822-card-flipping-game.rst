0822. Card Flipping Game
========================================================================================================================

题目信息
--------

:题号: 0822
:难度: Medium
:主题: 数组、双面卡片、候选值排除
:原题: `LeetCode 0822 <https://leetcode.com/problems/card-flipping-game/>`_
:重点: 可任意翻转卡片；好数字最终必须朝下出现在至少一张卡片上，同时不能朝上出现在任何卡片上

题目重述
--------

桌上有 ``n`` 张双面卡片，``fronts[i]`` 和 ``backs[i]`` 分别表示第 ``i`` 张卡片初始朝上和朝下的数字。可以翻转任意数量的卡片，也可以一张都不翻。

完成翻转后，若某个正整数出现在至少一张卡片朝下的一面，并且没有出现在任何卡片朝上的一面，则它是好数字。请返回通过某种翻转方式能够得到的最小好数字；若不存在好数字，返回 ``0``。

``n == fronts.length == backs.length``，``1 <= n <= 1000``，所有数字均在 ``[1, 2000]`` 范围内。

自建示例
--------

避开两面相同的禁止数字：

.. code-block:: text

   输入：fronts = [1,2], backs = [1,3]
   输出：2
   解释：第一张卡片两面都是 1，因此无论怎样翻转，数字 1 都会朝上出现在某张卡片上，不能成为好数字。翻转第二张卡片后，2 朝下而所有朝上的数字为 1 和 3，因此最小好数字是 2。

没有任何候选值：

.. code-block:: text

   输入：fronts = [4,4], backs = [4,4]
   输出：0
   解释：每张卡片两面都是 4，无论怎样翻转，4 都会同时出现在朝上面，不能成为好数字；又没有其他数字，因此返回 0。
