0822. Card Flipping Game
========================================================================================================================

题目信息
--------

:题号: 0822
:难度: Medium
:主题: 数组、双面卡片、候选值排除
:原题: `LeetCode 0822 <https://leetcode.com/problems/card-flipping-game/>`_
:重点: 可任意翻转卡片；目标数字最终必须出现在至少一张正面，同时不能出现在任何一张背面

题目重述
--------

桌上有 ``n`` 张双面卡片，``fronts[i]`` 和 ``backs[i]`` 分别表示第 ``i`` 张卡片当前正面和背面的数字。可以选择任意张卡片翻面，每张至多翻一次。

翻面完成后，若某个正整数出现在至少一张卡片的正面，并且没有出现在任何卡片的背面，则它是一个好数字。请返回能够得到的最小好数字；若无论怎样翻面都不存在好数字，返回 ``0``。

``fronts.length == backs.length``，长度在 ``[1, 1000]`` 范围内，所有数字均在 ``[1, 2000]`` 范围内。

自建示例
--------

同一张卡片两面相同的数字无法成为好数字：

.. code-block:: text

   输入：fronts = [1,2], backs = [1,3]
   输出：2
   解释：数字 1 同时写在第一张卡片两面，无论是否翻转都会出现在背面；数字 2 已在正面且所有背面均没有 2，因此最小好数字是 2。

没有任何候选值：

.. code-block:: text

   输入：fronts = [4,4], backs = [4,4]
   输出：0
   解释：唯一出现的数字 4 在每张卡片两面都相同，不可能从所有背面消失。
