0872. Leaf-Similar Trees
========================================================================================================================

题目信息
--------

:题号: 0872
:难度: Easy
:主题: 二叉树、叶节点序列、顺序比较
:原题: `LeetCode 0872 <https://leetcode.com/problems/leaf-similar-trees/>`_
:重点: 叶节点是没有左右孩子的节点；分别从左到右读取两棵树的叶值序列，只有长度和值顺序都相同才相似

题目重述
--------

给定两棵二叉树 ``root1`` 和 ``root2``。叶节点是没有左孩子也没有右孩子的节点。按照从树的最左叶节点到最右叶节点的顺序，依次记录所有叶节点的值，得到该树的叶值序列。

若两棵树的叶值序列长度相同，并且每个位置的值都相同，则称它们叶相似。请返回两棵树是否叶相似。内部节点的值和结构可以不同，只比较叶节点序列。

每棵树的节点数在 ``[1, 200]`` 范围内，节点值在 ``[0, 200]`` 范围内。

自建示例
--------

内部根值不同但叶序列相同：

.. code-block:: text

   输入：root1 = [1,2,3], root2 = [9,2,3]
   输出：true
   解释：两棵树从左到右的叶节点值都为 [2,3]，根节点值不同不影响叶相似性。
