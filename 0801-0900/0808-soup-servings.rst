题目重述
--------

最初有 ``n`` 毫升 A 汤和 ``n`` 毫升 B 汤。每一轮从以下四种供应方式中等概率选择一种：

* 供应 100 毫升 A、0 毫升 B；
* 供应 75 毫升 A、25 毫升 B；
* 供应 50 毫升 A、50 毫升 B；
* 供应 25 毫升 A、75 毫升 B。

若某种汤剩余量不足本次需要供应的数量，就供应其全部剩余量。重复操作，直到 A 或 B 至少有一种为空。请返回“A 比 B 先空”的概率，加上“A 与 B 在同一轮同时为空”的概率的一半。答案与真实值的误差在 ``10^-5`` 以内即可接受。

``0 <= n <= 10^9``。

自建示例
--------

一次操作后停止：

.. code-block:: text

   输入：n = 25
   输出：0.625
   解释：第一种操作使 A 先空，贡献 1；其余三种操作都使 A、B 同时空，分别贡献 0.5。四种操作等概率，因此结果为 (1 + 0.5 + 0.5 + 0.5) / 4 = 0.625。

初始时两种汤都为空：

.. code-block:: text

   输入：n = 0
   输出：0.5
   解释：A 与 B 一开始同时为空，因此只计同时为空概率的一半。
