0829. Consecutive Numbers Sum
========================================================================================================================

题目信息
--------

:题号: 0829
:难度: Hard
:主题: 整数、连续正数、表示数量
:原题: `LeetCode 0829 <https://leetcode.com/problems/consecutive-numbers-sum/>`_
:重点: 每种表示由一个或多个连续正整数构成；起始值和项数不同即为不同方式，单独的 n 本身也算一种

题目重述
--------

给定正整数 ``n``。统计有多少种方式可以把 ``n`` 表示为一个或多个连续正整数之和。

每种方式中的所有项必须严格连续且都大于 ``0``。不同的起始正整数或不同的项数视为不同表示；只使用一个数 ``n`` 本身也属于合法方式。请返回表示方式总数。

``1 <= n <= 10^9``。

自建示例
--------

同时存在奇数项和偶数项表示：

.. code-block:: text

   输入：n = 21
   输出：4
   解释：四种表示分别是 21、10 + 11、6 + 7 + 8、1 + 2 + 3 + 4 + 5 + 6。
