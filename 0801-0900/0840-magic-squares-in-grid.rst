0840. Magic Squares In Grid
========================================================================================================================

题目信息
--------

:题号: 0840
:难度: Medium
:主题: 矩阵、3×3 子网格、幻方
:原题: `LeetCode 0840 <https://leetcode.com/problems/magic-squares-in-grid/>`_
:重点: 每个候选 3×3 子网格必须恰好使用数字 1 至 9 各一次，且三行、三列和两条对角线的和全部相等

题目重述
--------

给定整数矩阵 ``grid``。一个 ``3 x 3`` 子网格是幻方，当且仅当其中九个位置恰好包含数字 ``1`` 至 ``9`` 各一次，并且它的三行、三列以及两条主对角线的元素和全部相同。

请返回 ``grid`` 中满足条件的 ``3 x 3`` 连续子网格数量。不同左上角位置对应不同子网格；原矩阵中的元素可以超出 ``1`` 至 ``9``，但含有这些值的候选子网格不能成为幻方。

``1 <= grid.length, grid[0].length <= 10``，``0 <= grid[i][j] <= 15``。

自建示例
--------

整个矩阵构成一个幻方：

.. code-block:: text

   输入：grid = [[4,3,8],[9,5,1],[2,7,6]]
   输出：1
   解释：九个数字恰好是 1 至 9，三行、三列和两条对角线的和都为 15，因此唯一的 3×3 子网格是幻方。
