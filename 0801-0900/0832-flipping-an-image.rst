0832. Flipping an Image
========================================================================================================================

题目信息
--------

:题号: 0832
:难度: Easy
:主题: 矩阵、水平翻转、二进制取反
:原题: `LeetCode 0832 <https://leetcode.com/problems/flipping-an-image/>`_
:重点: 对每一行先反转左右顺序，再把每个 0 变为 1、每个 1 变为 0

题目重述
--------

给定一个 ``n x n`` 二进制矩阵 ``image``。先水平翻转图像，也就是把每一行的元素顺序反转；然后反转图像中的每个值，把 ``0`` 改为 ``1``，把 ``1`` 改为 ``0``。

请返回依次完成这两步操作后的矩阵。两步作用于所有行和全部格子，不能只选择部分位置。

``1 <= n <= 20``，矩阵元素只可能为 ``0`` 或 ``1``。

自建示例
--------

两行分别翻转并取反：

.. code-block:: text

   输入：image = [[1,0],[0,0]]
   输出：[[1,0],[1,1]]
   解释：水平翻转后得到 [[0,1],[0,0]]，再逐位取反得到 [[1,0],[1,1]]。
