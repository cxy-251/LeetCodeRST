0804. Unique Morse Code Words
========================================================================================================================

题目信息
--------

:题号: 0804
:难度: Easy
:主题: 字符串、字符映射、去重
:原题: `LeetCode 0804 <https://leetcode.com/problems/unique-morse-code-words/>`_
:重点: 单词的变换结果由各字母对应的摩尔斯编码按原顺序直接拼接，返回不同变换字符串的数量

题目重述
--------

小写英文字母 ``a`` 至 ``z`` 各自对应一个固定的摩尔斯编码。给定字符串数组 ``words``，把每个单词中的字母依次替换为其摩尔斯编码，并将这些编码直接连接成该单词的变换结果。

请返回所有单词产生了多少种不同的变换结果。输入中相同单词或不同单词可以得到相同结果，统计时只计一次。

``1 <= words.length <= 100``，每个单词长度在 ``[1, 12]`` 范围内，且只包含小写英文字母。

自建示例
--------

重复单词只贡献一种结果：

.. code-block:: text

   输入：words = ["ace","bdf","ace"]
   输出：2
   解释：两个 "ace" 的摩尔斯拼接结果相同；"bdf" 产生另一种结果，因此共有两种不同变换。
