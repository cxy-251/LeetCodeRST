0816. Ambiguous Coordinates
========================================================================================================================

题目信息
--------

:题号: 0816
:难度: Medium
:主题: 字符串、坐标格式、枚举
:原题: `LeetCode 0816 <https://leetcode.com/problems/ambiguous-coordinates/>`_
:重点: 需在数字串中加入一个逗号，并可在两侧各加入至多一个小数点；整数不能有多余前导零，小数不能有末尾零

题目重述
--------

给定一个形如 ``"(digits)"`` 的字符串 ``s``。原字符串由某个二维坐标删除逗号、空格和小数点后得到。请在内部数字串中选择一个位置加入逗号，把它分成两个非空部分，并在每一部分中选择是否加入一个小数点，从而恢复所有可能的坐标。

一个数的表示必须合法：整数部分除数字 ``0`` 本身外不能以 ``0`` 开头；含小数点时，小数部分不能为空且不能以 ``0`` 结尾。结果格式为 ``"(x, y)"``，合法结果可按任意顺序返回。

``4 <= s.length <= 12``，首尾字符分别为左右括号，内部只包含数字。

自建示例
--------

前导零限制排除其他写法：

.. code-block:: text

   输入：s = "(004)"
   输出：["(0, 0.4)"]
   解释：逗号只能放在第一个 0 后，右侧 "04" 只能写成 0.4；"00"、"04" 作为整数含多余前导零，而 0.0 含末尾零，均不合法。

内部数字串达到最短长度：

.. code-block:: text

   输入：s = "(12)"
   输出：["(1, 2)"]
   解释：字符串长度达到题目允许的最小值，内部只有两个数字。逗号只能放在它们之间，两侧都只有一位，无法再插入小数点，因此只有这一种坐标。
