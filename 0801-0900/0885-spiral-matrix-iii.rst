0885. Spiral Matrix III
========================================================================================================================

题目信息
--------

:题号: 0885
:难度: Medium
:主题: 矩阵、螺旋行走、坐标顺序
:原题: `LeetCode 0885 <https://leetcode.com/problems/spiral-matrix-iii/>`_
:重点: 从给定格开始朝东行走并按顺时针方向扩展螺旋；路径可以暂时离开网格，只记录进入网格的坐标

题目重述
--------

给定 ``rows x cols`` 的网格和起始坐标 ``(rStart, cStart)``。从起点开始面向东，沿顺时针螺旋行走：依次向东、向南、向西、向北，每走完两个方向后把该方向段的长度增加 ``1``，因此各段长度依次为 ``1, 1, 2, 2, 3, 3, ...``。

行走路径可以暂时超出网格边界，并在之后重新进入。请按实际访问顺序返回网格内全部 ``rows * cols`` 个坐标，起始格是结果中的第一项；网格外的坐标不记录，但行走过程不能跳过。

``1 <= rows, cols <= 100``，``1 <= rows * cols <= 10^4``，起点保证位于网格内。

自建示例
--------

单行网格中路径会暂时越界：

.. code-block:: text

   输入：rows = 1, cols = 4, rStart = 0, cStart = 1
   输出：[[0,1],[0,2],[0,0],[0,3]]
   解释：从 (0,1) 向东访问 (0,2)，随后向南和向西的部分路径位于网格外，重新进入时先访问 (0,0)，之后继续扩大的螺旋最终访问 (0,3)。
