0819. Most Common Word
========================================================================================================================

题目信息
--------

:题号: 0819
:难度: Easy
:主题: 字符串、词频统计、大小写归一化
:原题: `LeetCode 0819 <https://leetcode.com/problems/most-common-word/>`_
:重点: 单词比较不区分大小写，标点用于分隔而不属于单词；排除禁用词后答案保证唯一

题目重述
--------

给定一段文本 ``paragraph`` 和禁用词数组 ``banned``。文本中的单词由英文字母组成，字母以外的空格或标点 ``!?',;.`` 用作分隔。统计时不区分大小写，并把结果转换为小写形式。

请返回出现次数最多且不在 ``banned`` 中的单词。禁用词均以小写给出，题目保证至少存在一个非禁用词，并且最终答案唯一。

``1 <= paragraph.length <= 1000``，文本只包含英文字母、空格和规定的标点；``0 <= banned.length <= 100``，每个禁用词长度在 ``[1, 10]`` 范围内且只含小写英文字母。

自建示例
--------

忽略大小写和多种标点：

.. code-block:: text

   输入：paragraph = "Tea, tea! Coffee; tea? coffee.", banned = ["tea"]
   输出："coffee"
   解释：统一为小写并排除 tea 后，coffee 出现两次，是唯一出现最多的非禁用词。

禁用词数组为空：

.. code-block:: text

   输入：paragraph = "Alpha", banned = []
   输出："alpha"
   解释：banned 长度达到题目允许的最小值 0。文本只有一个单词，转为小写后为 alpha，因此它是唯一且出现次数最多的非禁用词。
