0848. Shifting Letters
========================================================================================================================

题目信息
--------

:题号: 0848
:难度: Medium
:主题: 字符串、前缀操作、循环字母
:原题: `LeetCode 0848 <https://leetcode.com/problems/shifting-letters/>`_
:重点: 第 i 项操作把前 i+1 个字符都向后移动 shifts[i] 次；多次操作效果累积，字母 z 的下一个字符是 a

题目重述
--------

给定小写字符串 ``s`` 和等长整数数组 ``shifts``。把一个字母向后移动一次，表示在字母表中变为下一个字母，且 ``z`` 的下一个字母是 ``a``。

对于每个下标 ``i``，需要把字符串前 ``i + 1`` 个字符分别向后移动 ``shifts[i]`` 次。所有操作依次累积作用于同一字符串。请返回完成全部移动后的结果字符串。

``1 <= s.length == shifts.length <= 10^5``，``s`` 只包含小写英文字母，``0 <= shifts[i] <= 10^9``。

自建示例
--------

大于一轮字母表的移动次数需要累积取模：

.. code-block:: text

   输入：s = "mzzb", shifts = [0,27,1,52]
   输出："obab"
   解释：四个位置累计移动次数分别为 80、80、53、52，按 26 取模后为 2、2、1、0。因此 m 变为 o，第一个 z 变为 b，第二个 z 变为 a，末尾 b 保持不变。

单字符跨过字母表末尾：

.. code-block:: text

   输入：s = "z", shifts = [1]
   输出："a"
   解释：字符串和 shifts 都达到允许的最小长度。字母 z 向后移动一次时按循环规则变为 a。
