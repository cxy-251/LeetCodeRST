0869. Reordered Power of 2
========================================================================================================================

题目信息
--------

:题号: 0869
:难度: Medium
:主题: 整数、数字重排、二的幂
:原题: `LeetCode 0869 <https://leetcode.com/problems/reordered-power-of-2/>`_
:重点: 必须使用 n 的全部十进制数字且各用一次，重排结果不能有前导零；判断是否存在某个排列为二的整数幂

题目重述
--------

给定正整数 ``n``。可以任意重排其十进制数字，包括保持原顺序；每个数字实例必须恰好使用一次，并且重排后的整数最高位不能为 ``0``。

请判断是否存在一种合法重排，使得到的正整数等于 ``2^k``，其中 ``k`` 是某个非负整数。

``1 <= n <= 10^9``。

自建示例
--------

交换数字后成为二的幂：

.. code-block:: text

   输入：n = 46
   输出：true
   解释：把数字重排为 64，而 64 = 2^6。

无需改变原有顺序：

.. code-block:: text

   输入：n = 128
   输出：true
   解释：题目允许保留原顺序，128 本身就是 2^7，因此存在合法排列。

所有合法排列都不是二的幂：

.. code-block:: text

   输入：n = 24
   输出：false
   解释：不含前导零的排列只有 24 和 42，二者都不是二的幂，因此返回 false。
