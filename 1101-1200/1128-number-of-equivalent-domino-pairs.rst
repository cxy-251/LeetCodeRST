1128. Number of Equivalent Domino Pairs
=======================================

题目信息
--------

:题号: 1128
:难度: Easy
:主题: 数组、哈希计数、多米诺骨牌
:原题: `LeetCode 1128 <https://leetcode.com/problems/number-of-equivalent-domino-pairs/>`_
:重点: 骨牌允许旋转，因此 ``[a,b]`` 与 ``[b,a]`` 等价；统计满足 ``i < j`` 的下标对数量

题目重述
--------

给定骨牌数组 ``dominoes``，其中每块骨牌由两个数字 ``[a,b]`` 表示。若两块骨牌数字顺序相同，或者将其中一块旋转后数字顺序相同，则它们等价。

请统计下标对 ``(i,j)`` 的数量，使 ``0 <= i < j < dominoes.length`` 且两块骨牌等价。相同骨牌出现多次时，不同下标组合分别计数。

``1 <= dominoes.length <= 4 * 10^4``，每块骨牌长度为 ``2``，数字在 ``[1,9]`` 范围内。

自建示例
--------

三个等价实例形成三个下标对：

.. code-block:: text

   输入：dominoes = [[2,3],[3,2],[2,3],[4,4]]
   输出：3
   解释：前三块骨牌两两等价，共有 C(3,2) = 3 个下标对；[4,4] 没有等价伙伴。

没有等价骨牌：

.. code-block:: text

   输入：dominoes = [[1,2],[1,3]]
   输出：0
   解释：旋转后分别为 [2,1] 和 [3,1]，两块骨牌仍不相同。
