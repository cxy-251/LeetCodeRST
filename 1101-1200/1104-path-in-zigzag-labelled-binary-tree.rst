1104. Path In Zigzag Labelled Binary Tree
=========================================

题目信息
--------

:题号: 1104
:难度: Medium
:主题: 二叉树、层序编号、镜像标签
:原题: `LeetCode 1104 <https://leetcode.com/problems/path-in-zigzag-labelled-binary-tree/>`_
:重点: 奇数层从左向右编号，偶数层从右向左编号；返回根节点到指定标签节点的完整路径

题目重述
--------

在一棵无限满二叉树中，节点按层依次使用正整数编号。第 ``1、3、5、...`` 层从左向右递增编号，第 ``2、4、6、...`` 层从右向左递增编号。

给定节点标签 ``label``，请返回从根节点标签 ``1`` 到该节点的路径，路径中标签按从根到目标的顺序排列。

``1 <= label <= 10^6``。

自建示例
--------

目标位于反向编号层：

.. code-block:: text

   输入：label = 11
   输出：[1,2,6,11]
   解释：标签 11 位于第 4 层；沿父节点向上依次得到 6、2、1，因此根到目标的路径为 [1,2,6,11]。

目标就是根节点：

.. code-block:: text

   输入：label = 1
   输出：[1]
   解释：根节点到自身的路径只包含标签 1。
