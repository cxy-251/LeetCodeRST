1162. As Far from Land as Possible
==================================

题目信息
--------

:题号: 1162
:难度: Medium
:主题: 二进制网格、多源广度优先搜索、曼哈顿距离
:原题: `LeetCode 1162 <https://leetcode.com/problems/as-far-from-land-as-possible/>`_
:重点: 对每个海洋格寻找最近陆地的曼哈顿距离，再取其中最大值；全为陆地或全为海洋时返回 ``-1``

题目重述
--------

给定 ``n x n`` 二进制矩阵 ``grid``，``1`` 表示陆地，``0`` 表示海洋。两个格子的距离定义为曼哈顿距离 ``|x1-x2| + |y1-y2|``。

对于每个海洋格，计算它到最近陆地格的距离。请返回这些最近距离中的最大值；若矩阵没有海洋格，或者没有任何陆地格，返回 ``-1``。

``1 <= n <= 100``，``grid`` 为 ``n x n`` 矩阵，每个格子为 ``0`` 或 ``1``。

自建示例
--------

两块对角陆地共同限制最远距离：

.. code-block:: text

   输入：grid = [[1,0,0],[0,0,0],[0,0,1]]
   输出：2
   解释：中心格及另外两个角附近海洋格到最近陆地的最大距离为 2。

矩阵全部为海洋：

.. code-block:: text

   输入：grid = [[0,0],[0,0]]
   输出：-1
   解释：不存在陆地格，无法为海洋格定义到最近陆地的距离。
