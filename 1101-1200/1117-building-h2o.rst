1117. Building H2O
==================

题目信息
--------

:题号: 1117
:难度: Medium
:主题: 并发、屏障同步、线程分组
:原题: `LeetCode 1117 <https://leetcode.com/problems/building-h2o/>`_
:重点: 每三个连续释放的线程必须恰好包含两个氢线程和一个氧线程；一组分子完成前不能释放下一组线程

题目重述
--------

输入包含氢线程 ``H`` 和氧线程 ``O``。氢线程调用 ``hydrogen(releaseHydrogen)``，氧线程调用 ``oxygen(releaseOxygen)``。每次回调分别输出对应字符。

请实现同步屏障，使线程按完整水分子分组通过：把最终输出每三个字符分成一组时，每组必须恰好有两个 ``H`` 和一个 ``O``；当前组三个线程全部通过后，下一组才能开始。组内字符顺序不限。

输入长度为 ``3n``，``1 <= n <= 20``，其中恰有 ``2n`` 个 ``H`` 和 ``n`` 个 ``O``。

自建示例
--------

三个水分子按完整三线程组释放：

.. code-block:: text

   输入：water = "OHHHOHHHO"
   输出："HHOHHOHHO"
   解释：输出可分成三组 HHO，每组都含两个氢线程和一个氧线程。

输入线程到达顺序与输出组内顺序可以不同：

.. code-block:: text

   输入：water = "HOHHHO"
   输出："OHHHHO"
   解释：输出分成 OHH 和 HHO 两组，两组都能形成一个完整水分子；其他满足分组条件的顺序也合法。
