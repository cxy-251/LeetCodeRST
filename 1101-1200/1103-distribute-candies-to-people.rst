1103. Distribute Candies to People
==================================

题目信息
--------

:题号: 1103
:难度: Easy
:主题: 数学、模拟、循环分配
:原题: `LeetCode 1103 <https://leetcode.com/problems/distribute-candies-to-people/>`_
:重点: 按 ``1, 2, 3, ...`` 的赠送量循环经过所有人；最后一次糖果不足时把剩余糖果全部给当前人

题目重述
--------

给定糖果总数 ``candies`` 和人数 ``num_people``。从第一个人开始，第一次给 ``1`` 颗，第二次给 ``2`` 颗，此后每次比上一次多给一颗；走到最后一个人后重新从第一个人继续。

当剩余糖果少于本次计划赠送量时，把剩余糖果全部给当前人并结束。请返回长度为 ``num_people`` 的数组，表示每个人最终得到的糖果数。

``1 <= candies <= 10^9``，``1 <= num_people <= 1000``。

自建示例
--------

最后一次赠送量被剩余糖果截断：

.. code-block:: text

   输入：candies = 8, num_people = 3
   输出：[3,2,3]
   解释：前三次分别赠送 1、2、3 颗；随后轮到第一个人时只剩 2 颗，因此最终分配为 [1+2,2,3]。

糖果数少于人数：

.. code-block:: text

   输入：candies = 2, num_people = 5
   输出：[1,1,0,0,0]
   解释：第一个人得到 1 颗，第二次计划给 2 颗但只剩 1 颗，因此第二个人得到剩余糖果，后面的人得到 0 颗。
