1200. Minimum Absolute Difference
=================================

题目信息
--------

:题号: 1200
:难度: Easy
:主题: 数组、排序、相邻差值
:原题: `LeetCode 1200 <https://leetcode.com/problems/minimum-absolute-difference/>`_
:重点: 数组元素互不相同；返回所有绝对差达到全局最小值的数值对，每对较小值在前，结果按第一项升序排列

题目重述
--------

给定元素互不相同的整数数组 ``arr``。从中选择两个不同元素 ``a`` 和 ``b``，计算绝对差 ``|a-b|``。

找出所有绝对差等于全局最小值的数值对。每个结果对写成 ``[较小值, 较大值]``，并按第一项从小到大返回。

``2 <= arr.length <= 10^5``，``-10^6 <= arr[i] <= 10^6``，所有元素互不相同。

自建示例
--------

多个相邻数对具有相同最小差：

.. code-block:: text

   输入：arr = [8,1,5,3]
   输出：[[1,3],[3,5]]
   解释：排序后为 [1,3,5,8]，相邻差分别为 2、2、3，因此前两个数对都达到最小差 2。

数组只有两个元素：

.. code-block:: text

   输入：arr = [-2,4]
   输出：[[-2,4]]
   解释：唯一可选数对自然具有最小绝对差。
