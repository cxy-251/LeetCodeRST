1108. Defanging an IP Address
=============================

题目信息
--------

:题号: 1108
:难度: Easy
:主题: 字符串、字符替换、IPv4 地址
:原题: `LeetCode 1108 <https://leetcode.com/problems/defanging-an-ip-address/>`_
:重点: 把地址中的每个句点 ``.`` 独立替换为 ``[.]``，其他字符和顺序保持不变

题目重述
--------

给定一个有效 IPv4 地址字符串 ``address``。请把其中每个分隔数字段的句点字符 ``.`` 替换为字符串 ``[.]``，并返回替换后的地址。

地址中的数字不做修改，也不需要验证输入格式。

``address`` 是有效 IPv4 地址。

自建示例
--------

替换三个分隔点：

.. code-block:: text

   输入：address = "255.100.50.0"
   输出："255[.]100[.]50[.]0"
   解释：三个句点均被替换为 [.]，数字段保持原样。

全零地址同样逐点替换：

.. code-block:: text

   输入：address = "0.0.0.0"
   输出："0[.]0[.]0[.]0"
   解释：每个句点都需要替换，不因数字段相同而合并。
