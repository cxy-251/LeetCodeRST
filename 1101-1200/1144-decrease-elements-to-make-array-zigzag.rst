1144. Decrease Elements To Make Array Zigzag
============================================

题目信息
--------

:题号: 1144
:难度: Medium
:主题: 数组、贪心、锯齿序列
:原题: `LeetCode 1144 <https://leetcode.com/problems/decrease-elements-to-make-array-zigzag/>`_
:重点: 一次操作只能把一个元素减一；目标可以选择偶数下标全部为谷底，或奇数下标全部为谷底

题目重述
--------

给定整数数组 ``nums``。一次操作可以选择任意下标，把该元素减小 ``1``。操作可以重复执行，但不能增加元素。

若数组满足以下任一模式，则称为锯齿数组：所有偶数下标元素都严格小于其相邻元素；或者所有奇数下标元素都严格小于其相邻元素。请返回把数组变成任一锯齿模式所需的最少操作次数。

``1 <= nums.length <= 1000``，``1 <= nums[i] <= 1000``。

自建示例
--------

降低中间元素即可形成谷底：

.. code-block:: text

   输入：nums = [5,5,5]
   输出：1
   解释：把下标 1 的值减为 4 后得到 [5,4,5]，奇数下标元素严格小于两侧，只需一次操作。

单元素数组天然满足条件：

.. code-block:: text

   输入：nums = [8]
   输出：0
   解释：唯一元素没有相邻元素，两种锯齿模式的比较条件都自然成立。
