1131. Maximum of Absolute Value Expression
==========================================

题目信息
--------

:题号: 1131
:难度: Medium
:主题: 数组、绝对值、极值
:原题: `LeetCode 1131 <https://leetcode.com/problems/maximum-of-absolute-value-expression/>`_
:重点: 在所有下标 ``i``、``j`` 中最大化两个数组值差的绝对值之和，再加下标距离

题目重述
--------

给定长度相同的整数数组 ``arr1`` 和 ``arr2``。对于任意下标 ``i`` 和 ``j``，表达式值为
``|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|``。

请返回所有合法下标组合中的最大表达式值。允许 ``i == j``，但此时表达式值为 ``0``。

``2 <= arr1.length == arr2.length <= 4 * 10^4``，``-10^6 <= arr1[i], arr2[i] <= 10^6``。

自建示例
--------

两个数组的差与下标距离同时贡献：

.. code-block:: text

   输入：arr1 = [1,3], arr2 = [2,-1]
   输出：6
   解释：选择下标 0 和 1，表达式为 |1-3| + |2-(-1)| + |0-1| = 2 + 3 + 1 = 6。

数组值完全相同时仍有下标距离：

.. code-block:: text

   输入：arr1 = [5,5], arr2 = [-2,-2]
   输出：1
   解释：两个数值差都为 0，选择不同下标后只剩 |0-1| = 1。
