1124. Longest Well-Performing Interval
======================================

题目信息
--------

:题号: 1124
:难度: Medium
:主题: 数组、连续区间、前缀和
:原题: `LeetCode 1124 <https://leetcode.com/problems/longest-well-performing-interval/>`_
:重点: 工作时长严格大于 ``8`` 才是劳累日；区间内劳累日数量必须严格多于非劳累日

题目重述
--------

给定数组 ``hours``，其中 ``hours[i]`` 表示第 ``i`` 天的工作时长。工作时长严格大于 ``8`` 小时的日期称为劳累日，其余日期称为非劳累日。

若一个非空连续区间中的劳累日数量严格大于非劳累日数量，则它是表现良好区间。请返回最长表现良好区间的长度；若不存在，返回 ``0``。

``1 <= hours.length <= 10^4``，``0 <= hours[i] <= 16``。

自建示例
--------

整个数组中劳累日占多数：

.. code-block:: text

   输入：hours = [9,6,9,6,9]
   输出：5
   解释：共有三个劳累日和两个非劳累日，因此整个长度为 5 的数组就是表现良好区间。

八小时不属于劳累日：

.. code-block:: text

   输入：hours = [8,8]
   输出：0
   解释：两个日期都不是严格大于 8 小时，任何非空区间都没有更多劳累日。
