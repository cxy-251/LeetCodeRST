1106. Parsing A Boolean Expression
==================================

题目信息
--------

:题号: 1106
:难度: Hard
:主题: 字符串解析、递归表达式、布尔运算
:原题: `LeetCode 1106 <https://leetcode.com/problems/parsing-a-boolean-expression/>`_
:重点: ``!`` 接收一个子表达式，``&`` 和 ``|`` 接收一个或多个逗号分隔子表达式；输入保证是合法表达式

题目重述
--------

给定合法布尔表达式 ``expression``。字符 ``t`` 和 ``f`` 分别表示真和假；``!(expr)`` 表示逻辑非；``&(expr1,expr2,...)`` 表示所有子表达式的逻辑与；``|(expr1,expr2,...)`` 表示所有子表达式的逻辑或。

运算可以任意嵌套。请计算整个表达式的布尔值并返回 ``true`` 或 ``false``。

``1 <= expression.length <= 2 * 10^4``；表达式只含 ``(``、``)``、``&``、``|``、``!``、``t``、``f`` 和 ``,``，并保证语法合法。

自建示例
--------

嵌套与、或和非运算：

.. code-block:: text

   输入：expression = "|(&(t,t),!(t))"
   输出：true
   解释：&(t,t) 为真，!(t) 为假；真与假进行逻辑或后结果为真。

表达式可以只是一个常量：

.. code-block:: text

   输入：expression = "f"
   输出：false
   解释：单个 f 本身就是合法表达式，表示布尔值假。
