1171. Remove Zero Sum Consecutive Nodes from Linked List
========================================================

题目信息
--------

:题号: 1171
:难度: Medium
:主题: 链表、前缀和、连续区间删除
:原题: `LeetCode 1171 <https://leetcode.com/problems/remove-zero-sum-consecutive-nodes-from-linked-list/>`_
:重点: 可反复删除任意元素和为 ``0`` 的非空连续节点段，直到不存在此类节点段，并返回剩余链表

题目重述
--------

给定单链表 ``head``。若一段连续且非空的节点值之和为 ``0``，可以把这一整段节点从链表中删除。

重复进行删除，直到链表中不再存在和为 ``0`` 的连续节点段。请返回最终链表的头节点；若全部节点都被删除，返回 ``null``。

链表节点数在 ``[1,1000]`` 范围内，``-1000 <= Node.val <= 1000``。

自建示例
--------

两段零和区间都被移除：

.. code-block:: text

   输入：head = [2,-2,3,-1,-2,4]
   输出：[4]
   解释：前两个节点之和为 0，中间的 3、-1、-2 之和也为 0，删除后只剩节点 4。

整个链表的和为零：

.. code-block:: text

   输入：head = [5,-5]
   输出：[]
   解释：两个连续节点之和为 0，删除后链表为空。
