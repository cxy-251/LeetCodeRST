1122. Relative Sort Array
=========================

题目信息
--------

:题号: 1122
:难度: Easy
:主题: 数组、相对排序、计数
:原题: `LeetCode 1122 <https://leetcode.com/problems/relative-sort-array/>`_
:重点: ``arr2`` 中元素互不相同且都出现在 ``arr1``；这些值按 ``arr2`` 顺序排列，其余值放在末尾升序排列

题目重述
--------

给定数组 ``arr1`` 和 ``arr2``。``arr2`` 中的元素互不相同，并且每个元素都至少在 ``arr1`` 中出现一次。

请重新排列 ``arr1``：所有出现在 ``arr2`` 中的值按照它们在 ``arr2`` 中的先后顺序集中排列，每个值保留在 ``arr1`` 中的全部出现次数；不在 ``arr2`` 中的元素放到结果末尾，并按升序排列。

``1 <= arr1.length, arr2.length <= 1000``，``0 <= arr1[i], arr2[i] <= 1000``。

自建示例
--------

指定值保留全部重复次数：

.. code-block:: text

   输入：arr1 = [5,3,5,2,4,3,1], arr2 = [3,5]
   输出：[3,3,5,5,1,2,4]
   解释：3 和 5 按 arr2 顺序排列；剩余的 2、4、1 升序成为 1、2、4。

只有一个相对排序值：

.. code-block:: text

   输入：arr1 = [2,1], arr2 = [2]
   输出：[2,1]
   解释：值 2 位于最前，其余值 1 放在末尾。
