1137. N-th Tribonacci Number
============================

题目信息
--------

:题号: 1137
:难度: Easy
:主题: 数学、递推、动态规划
:原题: `LeetCode 1137 <https://leetcode.com/problems/n-th-tribonacci-number/>`_
:重点: 初值为 ``T0=0``、``T1=T2=1``，后续每项等于前三项之和

题目重述
--------

定义泰波那契数列：``T0 = 0``，``T1 = 1``，``T2 = 1``；对于 ``n >= 0``，有 ``T(n+3) = Tn + T(n+1) + T(n+2)``。

给定整数 ``n``，请返回 ``Tn``。题目保证答案不超过 32 位有符号整数上限。

``0 <= n <= 37``。

自建示例
--------

递推到第五项：

.. code-block:: text

   输入：n = 5
   输出：7
   解释：T3 = 2，T4 = 4，T5 = 1 + 2 + 4 = 7。

返回初始项：

.. code-block:: text

   输入：n = 0
   输出：0
   解释：T0 由定义直接等于 0，不需要递推。
