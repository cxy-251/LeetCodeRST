1161. Maximum Level Sum of a Binary Tree
========================================

题目信息
--------

:题号: 1161
:难度: Medium
:主题: 二叉树、层序遍历、层和
:原题: `LeetCode 1161 <https://leetcode.com/problems/maximum-level-sum-of-a-binary-tree/>`_
:重点: 根节点位于第 ``1`` 层；计算每层实际节点值之和，若最大值并列则返回较小层号

题目重述
--------

给定一棵非空二叉树。根节点所在层编号为 ``1``，其孩子位于第 ``2`` 层，依此类推。

计算每一层所有实际节点值的总和。请返回层和最大的层编号；若多个层的总和相同且都为最大值，返回编号最小的层。

树中节点数在 ``[1, 10^4]`` 范围内，``-10^5 <= Node.val <= 10^5``。

自建示例
--------

最深一层拥有最大总和：

.. code-block:: text

   输入：root = [5,-2,3,4,4,-1,1]
   输出：3
   解释：三层总和分别为 5、1、8，因此最大层和出现在第 3 层。

单节点树：

.. code-block:: text

   输入：root = [-7]
   输出：1
   解释：树中只有第 1 层，即使节点值为负数，它仍是层和最大的唯一层。
