1110. Delete Nodes And Return Forest
====================================

题目信息
--------

:题号: 1110
:难度: Medium
:主题: 二叉树、节点删除、森林
:原题: `LeetCode 1110 <https://leetcode.com/problems/delete-nodes-and-return-forest/>`_
:重点: 删除节点后，其未被删除的孩子成为新树根；返回森林根节点顺序不限

题目重述
--------

给定一棵节点值互不相同的二叉树 ``root``，以及需要删除的节点值数组 ``to_delete``。删除所有指定节点及其与父节点之间的连接。

若某个被删除节点的孩子没有被删除，该孩子会成为森林中一棵新树的根；原根未被删除时仍是森林根。请返回最终森林中所有根节点，顺序不限。

树中节点数在 ``[1, 1000]`` 范围内，``1 <= Node.val <= 1000`` 且节点值互不相同；``1 <= to_delete.length <= 1000``，其中值互不相同并保证存在于树中。
