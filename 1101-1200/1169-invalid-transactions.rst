1169. Invalid Transactions
==========================

题目信息
--------

:题号: 1169
:难度: Medium
:主题: 字符串解析、交易记录、时间窗口
:原题: `LeetCode 1169 <https://leetcode.com/problems/invalid-transactions/>`_
:重点: 金额超过 ``1000`` 的交易无效；同名用户在相差不超过 ``60`` 分钟的另一城市交易时，两条交易都无效

题目重述
--------

给定交易字符串数组 ``transactions``。每条记录格式为 ``"name,time,amount,city"``，分别表示姓名、分钟时间、金额和城市。

若交易金额大于 ``1000``，则该交易无效。若存在另一条姓名相同、城市不同且时间差绝对值不超过 ``60`` 的交易，则两条交易都无效。请返回所有无效的原始交易字符串，顺序不限。

``1 <= transactions.length <= 1000``；姓名和城市只含小写英文字母且长度在 ``[1,10]``；``0 <= time <= 1000``，``0 <= amount <= 2000``。

自建示例
--------

时间边界与超额规则同时生效：

.. code-block:: text

   输入：transactions = ["amy,10,200,rome","amy,70,300,paris","bob,20,1200,rome"]
   输出：["amy,10,200,rome","amy,70,300,paris","bob,20,1200,rome"]
   解释：Amy 的两条交易相差恰好 60 分钟且城市不同，因此两条都无效；Bob 的金额超过 1000。

同一城市的临近交易不触发冲突：

.. code-block:: text

   输入：transactions = ["lee,5,100,seoul","lee,50,200,seoul"]
   输出：[]
   解释：两条交易金额均未超限，并且发生在同一城市，因此都有效。
