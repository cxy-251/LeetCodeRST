0018. 4Sum
===========

题目信息
--------

:题号: 0018
:难度: Medium
:主题: 数组、排序、双指针、去重、剪枝
:原题: `LeetCode 0018 <https://leetcode.com/problems/4sum/>`_
:教学重点: 固定两个元素、两数之和、四层去重、和值上下界、64 位求和

题目重述
--------

给定整数数组 ``nums`` 和目标值 ``target``，返回所有满足四个下标两两不同且四数和等于目标值的唯一四元组。
结果按值去重；相同四个值由不同下标产生时只保留一次。

自建示例
--------

.. code-block:: text

   nums = [-3, -2, -1, 0, 0, 1, 2, 3], target = 0
   答案包括 [-3,-2,2,3]、[-3,-1,1,3]、[-3,0,0,3]、[-2,-1,0,3] 等。

.. code-block:: text

   nums = [2,2,2,2,2], target = 8
   多组下标都产生 [2,2,2,2]，结果只保留一次。

   #include <algorithm>
   #include <set>
   #include <vector>

   class Solution {
   private:
       std::vector<std::vector<int>> enumerateFour(
           const std::vector<int>& nums,
           int target
       ) {
           std::set<std::vector<int>> unique;
           const int n = static_cast<int>(nums.size());
           for (int a = 0; a < n; ++a)
               for (int b = a + 1; b < n; ++b)
                   for (int c = b + 1; c < n; ++c)
                       for (int d = c + 1; d < n; ++d)
                           if (1LL * nums[a] + nums[b] + nums[c] + nums[d] == target) {
                               std::vector<int> values{nums[a], nums[b], nums[c], nums[d]};
                               std::sort(values.begin(), values.end());
                               unique.insert(values);
                           }
           return {unique.begin(), unique.end()};
       }

       std::vector<std::vector<int>> sortAndTwoPointers(
           std::vector<int> nums,
           int target
       ) {
           std::sort(nums.begin(), nums.end());
           std::vector<std::vector<int>> result;
           const int n = static_cast<int>(nums.size());

           for (int first = 0; first + 3 < n; ++first) {
               if (first > 0 && nums[first] == nums[first - 1]) continue;
               const long long min_first =
                   1LL * nums[first] + nums[first + 1] + nums[first + 2] + nums[first + 3];
               if (min_first > target) break;
               const long long max_first =
                   1LL * nums[first] + nums[n - 1] + nums[n - 2] + nums[n - 3];
               if (max_first < target) continue;

               for (int second = first + 1; second + 2 < n; ++second) {
                   if (second > first + 1 && nums[second] == nums[second - 1]) continue;
                   const long long min_second =
                       1LL * nums[first] + nums[second] + nums[second + 1] + nums[second + 2];
                   if (min_second > target) break;
                   const long long max_second =
                       1LL * nums[first] + nums[second] + nums[n - 1] + nums[n - 2];
                   if (max_second < target) continue;

                   int left = second + 1;
                   int right = n - 1;
                   while (left < right) {
                       const long long sum =
                           1LL * nums[first] + nums[second] + nums[left] + nums[right];
                       if (sum < target) {
                           ++left;
                       } else if (sum > target) {
                           --right;
                       } else {
                           result.push_back({
                               nums[first], nums[second], nums[left], nums[right]
                           });
                           const int left_value = nums[left];
                           const int right_value = nums[right];
                           while (left < right && nums[left] == left_value) ++left;
                           while (left < right && nums[right] == right_value) --right;
                       }
                   }
               }
           }
           return result;
       }

   public:
       std::vector<std::vector<int>> fourSum(
           std::vector<int>& nums,
           int target
       ) {
           return sortAndTwoPointers(nums, target);
       }
   };

题解
----

四重枚举为什么需要降维
~~~~~~~~~~~~~~~~~~~~~~

四个递增下标形成 ``O(n^4)`` 个候选，且重复值会产生大量相同四元组。排序后固定前两个元素，剩余问题变为有序
后缀中的两数之和，可以用双指针把最后两层从平方降为线性。

固定两个元素后的目标关系
~~~~~~~~~~~~~~~~~~~~~~~~

固定 ``first`` 和 ``second`` 后，需要：

.. math::

   nums[left]+nums[right]
   =target-nums[first]-nums[second]

当前总和小于目标时，减小右端只会让和值更小，必须增大左端；总和大于目标时必须减小右端。命中后记录四元组，
再越过左右两侧的重复值段。

四层去重分别消除什么重复
~~~~~~~~~~~~~~~~~~~~~~~~

``first`` 只保留相同值的第一个位置；在每个首值下，``second`` 也只保留相同值的第一个位置。命中后，左右指针
分别跳过当前值。这样四个数值层面都只选择一次，而不同值组合仍被完整保留。

最小和与最大和如何提前剪枝
~~~~~~~~~~~~~~~~~~~~~~~~~~

固定首值后，接下来三个最小可用值构成该首值下的最小四数和；若它已大于目标，更大的首值也只会更大，可直接
结束外层。首值加三个最大值仍小于目标时，当前首值不可能成功，继续下一个。

固定第二值后可做同样判断。剪枝不改变最坏 ``O(n^3)``，却能在值域偏斜时跳过大量无效区间。

状态演化
~~~~~~~~

固定 ``first=-3``、``second=-2``，目标为 0：

.. list-table::
   :header-rows: 1

   * - 左值
     - 右值
     - 四数和
     - 动作
   * - -1
     - 3
     - -3
     - 偏小，左移
   * - 0
     - 3
     - -2
     - 偏小，左移
   * - 0
     - 3
     - -2
     - 偏小，左移
   * - 1
     - 3
     - -1
     - 偏小，左移
   * - 2
     - 3
     - 0
     - 记录 ``[-3,-2,2,3]``

为什么双指针移动不会遗漏四元组
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

固定前两个值后，后缀有序。总和偏小时，所有使用当前左值且右端不超过当前位置的组合都不会更大到目标；总和
偏大时，所有使用当前右值且左端不小于当前位置的组合都不会更小到目标。当前边界候选已经检查，因此被跳过的
整组组合均不可能命中。

复杂度来源
~~~~~~~~~~

排序 ``O(n log n)``。两层固定索引形成 ``O(n^2)`` 组合，每组双指针合计 ``O(n)``，总时间 ``O(n^3)``。
除排序空间和输出外，工作空间 ``O(1)`` 或 ``O(log n)``。四数和及剪枝边界使用 64 位整数。

   #include <stdlib.h>

   static int cmp(const void* a, const void* b) {
       int x=*(const int*)a, y=*(const int*)b; return (x>y)-(x<y);
   }

   int** fourSum(int* nums, int n, int target, int* returnSize, int** returnColumnSizes) {
       qsort(nums,n,sizeof(int),cmp);
       int capacity = n*n*n/6 + 1, count = 0;
       int** result = malloc((size_t)capacity*sizeof(int*));
       int* columns = malloc((size_t)capacity*sizeof(int));
       for (int a=0; a+3<n; ++a) {
           if (a>0 && nums[a]==nums[a-1]) continue;
           for (int b=a+1; b+2<n; ++b) {
               if (b>a+1 && nums[b]==nums[b-1]) continue;
               int left=b+1, right=n-1;
               while (left<right) {
                   long long sum=(long long)nums[a]+nums[b]+nums[left]+nums[right];
                   if (sum<target) ++left; else if (sum>target) --right; else {
                       result[count]=malloc(4*sizeof(int));
                       result[count][0]=nums[a]; result[count][1]=nums[b];
                       result[count][2]=nums[left]; result[count][3]=nums[right];
                       columns[count++]=4;
                       int lv=nums[left], rv=nums[right];
                       while (left<right && nums[left]==lv) ++left;
                       while (left<right && nums[right]==rv) --right;
                   }
               }
           }
       }
       *returnSize=count; *returnColumnSizes=columns; return result;
   }
