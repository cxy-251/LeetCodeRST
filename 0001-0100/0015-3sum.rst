0015. 3Sum
==========

题目信息
--------

:题号: 0015
:难度: Medium
:主题: 数组、排序、双指针、去重
:原题: `LeetCode 0015 <https://leetcode.com/problems/3sum/>`_
:重点: 三个不同下标、和值为零、按数值去重、结果顺序不限定

题目重述
--------

给定整数数组 ``nums``，找出所有满足 ``i``、``j``、``k`` 两两不同且 ``nums[i] + nums[j] + nums[k] == 0`` 的三元组，并返回不重复的数值三元组集合。

同一组三个数无论来自哪些下标、内部按什么顺序排列，都只能在结果中出现一次。结果中三元组的顺序以及各三元组内部的顺序均不作要求。

``nums`` 的长度位于 ``[3, 3000]``，每个元素位于 ``[-10^5, 10^5]``。

自建示例
--------

包含重复值与多组答案：

.. code-block:: text

   输入：nums = [-4, -1, -1, 0, 1, 2, 3]
   输出：[[-4, 1, 3], [-1, -1, 2], [-1, 0, 1]]
   解释：这三种数值组合的和都为 0；两个 -1 来自不同下标。结果顺序可以不同。

没有合法三元组：

.. code-block:: text

   输入：nums = [2, 4, 7, 9]
   输出：[]
   解释：所有元素均为正数，任意三个数之和都不可能为 0。

全部为零：

.. code-block:: text

   输入：nums = [0, 0, 0, 0]
   输出：[[0, 0, 0]]
   解释：虽然可以选择多组不同下标，但对应的数值三元组相同，因此只返回一次。

   #include <algorithm>
   #include <climits>
   #include <set>
   #include <unordered_set>
   #include <vector>

   class Solution {
   private:
       std::vector<std::vector<int>> enumerateTriples(const std::vector<int>& nums) {
           std::set<std::vector<int>> unique;
           const int n = static_cast<int>(nums.size());
           for (int i = 0; i < n; ++i) {
               for (int j = i + 1; j < n; ++j) {
                   for (int k = j + 1; k < n; ++k) {
                       if (1LL * nums[i] + nums[j] + nums[k] == 0) {
                           std::vector<int> triple{nums[i], nums[j], nums[k]};
                           std::sort(triple.begin(), triple.end());
                           unique.insert(triple);
                       }
                   }
               }
           }
           return {unique.begin(), unique.end()};
       }

       std::vector<std::vector<int>> hashForEachFirst(const std::vector<int>& nums) {
           std::set<std::vector<int>> unique;
           const int n = static_cast<int>(nums.size());
           for (int i = 0; i < n; ++i) {
               std::unordered_set<int> seen;
               for (int j = i + 1; j < n; ++j) {
                   const long long needed = -1LL * nums[i] - nums[j];
                   if (needed >= INT_MIN && needed <= INT_MAX &&
                       seen.count(static_cast<int>(needed))) {
                       std::vector<int> triple{nums[i], nums[j], static_cast<int>(needed)};
                       std::sort(triple.begin(), triple.end());
                       unique.insert(triple);
                   }
                   seen.insert(nums[j]);
               }
           }
           return {unique.begin(), unique.end()};
       }

       std::vector<std::vector<int>> sortAndTwoPointers(std::vector<int> nums) {
           std::sort(nums.begin(), nums.end());
           std::vector<std::vector<int>> result;
           const int n = static_cast<int>(nums.size());

           for (int first = 0; first + 2 < n; ++first) {
               if (first > 0 && nums[first] == nums[first - 1]) continue;
               if (nums[first] > 0) break;

               int left = first + 1;
               int right = n - 1;
               while (left < right) {
                   const long long sum = 1LL * nums[first] + nums[left] + nums[right];
                   if (sum < 0) {
                       ++left;
                   } else if (sum > 0) {
                       --right;
                   } else {
                       result.push_back({nums[first], nums[left], nums[right]});
                       const int left_value = nums[left];
                       const int right_value = nums[right];
                       while (left < right && nums[left] == left_value) ++left;
                       while (left < right && nums[right] == right_value) --right;
                   }
               }
           }
           return result;
       }

   public:
       std::vector<std::vector<int>> threeSum(std::vector<int>& nums) {
           return sortAndTwoPointers(nums);
       }
   };

题解
----

三重枚举暴露了候选数量和重复来源
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

三个递增下标形成 ``O(n^3)`` 个候选。同一组值可能由大量下标组合产生，因此命中后还需要排序三元组并放入
集合去重。要同时减少搜索和去重成本，需要利用数值顺序。

固定首元素如何转化为两数之和
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

排序后固定 ``nums[first]``，剩余目标为：

.. math::

   nums[left]+nums[right]=-nums[first]

后缀有序。当前总和小于零时，右端已经是当前可用最大值，只有增大左值才可能到达零；总和大于零时，只有减小
右值才可能到达零。这种单调移动一次排除一整组不可能组合。

三层去重为什么分别发生在外层和命中后
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

外层首值与前一首值相同时，它能形成的值三元组已经被前一位置完整搜索，直接跳过。命中答案后，连续相同的
左值与右值只会再次产生同一三元组，因此先记录，再分别越过两个重复值段。若在命中前跳过，可能删除唯一答案；
若只移动一格，则会输出重复答案。

指针状态演化
~~~~~~~~~~~~

固定首值 ``-2``：

.. list-table::
   :header-rows: 1

   * - 左值
     - 右值
     - 总和
     - 动作
   * - -1
     - 2
     - -1
     - 总和偏小，左移
   * - -1
     - 2
     - -1
     - 总和偏小，左移
   * - 0
     - 2
     - 0
     - 记录 ``[-2,0,2]``，跳过当前值段
   * - 1
     - 1
     - 0
     - 记录 ``[-2,1,1]``

为什么移动一个指针能排除整组候选
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

若总和小于零，固定当前左值并选择任何更靠左的右端，只会使右值不增，和值仍小于零；这些组合全部可排除。
若总和大于零，固定当前右值并选择任何更靠右的左端，只会使左值不减，和值仍大于零。命中时当前值对已记录，
跳过相同数值只删除重复结果。因此所有唯一值对要么被检查，要么由单调性安全排除。

为什么首值大于零可以结束
~~~~~~~~~~~~~~~~~~~~~~~~

数组有序后，首值大于零意味着后面两个值也大于零，三数和必然为正。更后的首值只会更大，因此外层可以直接
终止。

复杂度来源
~~~~~~~~~~

排序耗时 ``O(n log n)``。外层最多 ``n`` 次，每个首元素对应的左右指针合计移动 ``O(n)``，总时间
``O(n^2)``。除排序实现和返回结果外，工作空间为常数或 ``O(log n)``。三数求和使用更宽类型避免溢出。

.. code-block:: c

   #include <stdlib.h>

   static int compare_int(const void* a, const void* b) {
       int x = *(const int*)a, y = *(const int*)b;
       return (x > y) - (x < y);
   }

   int** threeSum(int* nums, int numsSize, int* returnSize, int** returnColumnSizes) {
       qsort(nums, numsSize, sizeof(int), compare_int);
       int capacity = numsSize * numsSize / 2 + 1;
       int** result = malloc((size_t)capacity * sizeof(int*));
       int* columns = malloc((size_t)capacity * sizeof(int));
       int count = 0;
       for (int first = 0; first + 2 < numsSize; ++first) {
           if (first > 0 && nums[first] == nums[first - 1]) continue;
           if (nums[first] > 0) break;
           int left = first + 1, right = numsSize - 1;
           while (left < right) {
               long long sum = (long long)nums[first] + nums[left] + nums[right];
               if (sum < 0) ++left;
               else if (sum > 0) --right;
               else {
                   result[count] = malloc(3 * sizeof(int));
                   result[count][0] = nums[first];
                   result[count][1] = nums[left];
                   result[count][2] = nums[right];
                   columns[count++] = 3;
                   int lv = nums[left], rv = nums[right];
                   while (left < right && nums[left] == lv) ++left;
                   while (left < right && nums[right] == rv) --right;
               }
           }
       }
       *returnSize = count;
       *returnColumnSizes = columns;
       return result;
   }

       if (n < 3L) return(result)

           if (first > 1L && nums[[first]] == nums[[first - 1L]]) next

       }
