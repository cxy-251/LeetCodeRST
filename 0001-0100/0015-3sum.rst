0015. 3Sum
==========

题目信息
--------

:题号: 0015
:难度: Medium
:主题: 数组、排序、双指针、去重
:原题: `LeetCode 0015 <https://leetcode.com/problems/3sum/>`_
:重点: 固定一个数把三数问题降为两数问题，再利用有序性移动双指针，并在搜索层级内完成去重

题目重述
--------

给定整数数组 ``nums``，找出所有满足 ``i``、``j``、``k`` 两两不同且
``nums[i] + nums[j] + nums[k] == 0`` 的三元组。

结果按数值组合去重：同一组三个数即使来自不同下标，也只能出现一次。三元组之间的顺序以及每个三元组内部的
顺序都不作要求。数组长度位于 ``[3, 3000]``，元素位于 ``[-10^5, 10^5]``。

自建示例
--------

* 多组答案：``nums = [-4, -1, -1, 0, 1, 2, 3]``，答案包含 ``[-4, 1, 3]``、``[-1, -1, 2]``、
  ``[-1, 0, 1]``；
* 重复下标组合：``nums = [0, 0, 0, 0]``，虽然有多种下标选择，只返回一个 ``[0, 0, 0]``；
* 无答案：``nums = [2, 4, 7, 9]``，返回空集合；
* 需要两个相同值：``nums = [-2, 1, 1]``，两个 ``1`` 来自不同位置，返回 ``[-2, 1, 1]``；
* 全部为负：``nums = [-5, -3, -1]``，返回空集合；
* 最小规模：``nums = [-1, 0, 1]``，返回 ``[-1, 0, 1]``。

C++ 实现
--------

.. code-block:: cpp

   #include <algorithm>
   #include <set>
   #include <unordered_set>
   #include <vector>

   class Solution {
   private:
       std::vector<std::vector<int>> enumerateTriples(const std::vector<int>& nums) {
           std::set<std::vector<int>> unique;
           const int n = static_cast<int>(nums.size());
           for (int first = 0; first < n; ++first) {
               for (int second = first + 1; second < n; ++second) {
                   for (int third = second + 1; third < n; ++third) {
                       if (1LL * nums[first] + nums[second] + nums[third] != 0) {
                           continue;
                       }
                       std::vector<int> triple{nums[first], nums[second], nums[third]};
                       std::sort(triple.begin(), triple.end());
                       unique.insert(triple);
                   }
               }
           }
           return {unique.begin(), unique.end()};
       }

       std::vector<std::vector<int>> hashForEachFirst(const std::vector<int>& nums) {
           std::set<std::vector<int>> unique;
           const int n = static_cast<int>(nums.size());
           for (int first = 0; first < n; ++first) {
               std::unordered_set<int> seen;
               for (int second = first + 1; second < n; ++second) {
                   const int need = -nums[first] - nums[second];
                   if (seen.count(need)) {
                       std::vector<int> triple{nums[first], nums[second], need};
                       std::sort(triple.begin(), triple.end());
                       unique.insert(triple);
                   }
                   seen.insert(nums[second]);
               }
           }
           return {unique.begin(), unique.end()};
       }

       std::vector<std::vector<int>> sortAndTwoPointers(std::vector<int> nums) {
           std::sort(nums.begin(), nums.end());
           std::vector<std::vector<int>> result;
           const int n = static_cast<int>(nums.size());
           for (int first = 0; first + 2 < n; ++first) {
               if (first > 0 && nums[first] == nums[first - 1]) {
                   continue;
               }
               const long long smallest = 1LL * nums[first] + nums[first + 1] + nums[first + 2];
               if (smallest > 0) {
                   break;
               }
               const long long largest = 1LL * nums[first] + nums[n - 2] + nums[n - 1];
               if (largest < 0) {
                   continue;
               }
               int left = first + 1;
               int right = n - 1;
               while (left < right) {
                   const long long sum = 1LL * nums[first] + nums[left] + nums[right];
                   if (sum < 0) {
                       ++left;
                   } else if (sum > 0) {
                       --right;
                   } else {
                       result.push_back({nums[first], nums[left], nums[right]});
                       const int leftValue = nums[left];
                       const int rightValue = nums[right];
                       while (left < right && nums[left] == leftValue) {
                           ++left;
                       }
                       while (left < right && nums[right] == rightValue) {
                           --right;
                       }
                   }
               }
           }
           return result;
       }

   public:
       std::vector<std::vector<int>> threeSum(std::vector<int>& nums) {
           return sortAndTwoPointers(nums);
       }
   };

题解
----

三重枚举
~~~~~~~~

``enumerateTriples`` 使用三个递增下标覆盖全部组合，候选数量为 ``O(n³)``。命中后还要把三个数排序并放入
集合，因为不同下标组合可能产生相同数值三元组。

这里同时存在两个成本：搜索空间是三次方，结果去重又发生在搜索完成之后。要进一步优化，需要让数值顺序既能
排除候选，也能让重复值在生成阶段直接跳过。

固定首值
~~~~~~~~

固定 ``nums[first]`` 后，剩余两个数必须满足：

``nums[second] + nums[third] = -nums[first]``。

三数问题由此降为每个首值对应的一次两数之和。``hashForEachFirst`` 对后缀维护 ``seen``：扫描到
``nums[second]`` 时，查询所需补数是否已经出现。每个首值的后缀扫描为线性，总时间降为 ``O(n²)``。

哈希方法仍用外部集合统一去重，因为相同数值可能在不同首下标或不同后缀位置重复命中。它减少了搜索成本，
尚未把去重融入状态移动。

有序两数搜索
~~~~~~~~~~~~

排序后固定 ``first``，令 ``left = first + 1``、``right = n - 1``。当前三数和为 ``sum``：

* ``sum < 0`` 时，需要更大的数，只能右移 ``left``；
* ``sum > 0`` 时，需要更小的数，只能左移 ``right``；
* ``sum == 0`` 时，记录当前三元组并跳过两侧重复值。

当 ``sum < 0`` 时，固定当前左值并把右端移到任何更小位置，只会让和更小，因此这些组合可整体排除。
``sum > 0`` 时论证对称。两个指针都只向中间移动，一次后缀搜索为 ``O(n)``。

三层去重
~~~~~~~~

排序让相同数值连续出现，去重可以在生成答案时完成。

外层若 ``nums[first] == nums[first - 1]``，当前首值能够形成的所有数值组合已经由前一个相同首值完整搜索，
因此整个后缀搜索可以跳过。

命中三元组后，连续相同的 ``left`` 值都会与同一个首值和右值生成相同结果；右侧同理。代码先记录答案，再
越过左右两个重复值段。只移动一格会重复输出，命中前提前跳过则可能错过唯一合法组合。

边界剪枝
~~~~~~~~

固定首值后，排序还给出两个立即可计算的边界：

* 当前首值与后面最小两个数之和 ``smallest`` 已经大于零，之后首值只会更大，可以结束外层循环；
* 当前首值与数组最大两个数之和 ``largest`` 仍小于零，本轮不可能命中，可以直接处理下一个首值。

这两个判断只减少实际扫描次数，不改变最坏 ``O(n²)`` 复杂度。

状态推演
~~~~~~~~

以排序后的 ``[-4, -1, -1, 0, 1, 2, 3]`` 为例，固定首值 ``-1``：

.. list-table::
   :header-rows: 1

   * - 左值
     - 右值
     - 总和
     - 动作
   * - -1
     - 3
     - 1
     - 右指针左移
   * - -1
     - 2
     - 0
     - 记录 ``[-1, -1, 2]``，跳过左侧 ``-1`` 与右侧 ``2``
   * - 0
     - 1
     - 0
     - 记录 ``[-1, 0, 1]``，跳过两侧值

下一个外层位置仍为 ``-1``，会被首值去重直接跳过，因此这两组答案都只生成一次。

代码演进
~~~~~~~~

``enumerateTriples`` 用三层循环选择三个未知下标，并依靠集合在结果阶段去重。

``hashForEachFirst`` 固定一个下标，把后两个未知位置转换为补数查询。第三层循环消失，时间降为二次，但仍需
集合消除跨位置重复结果。

``sortAndTwoPointers`` 用排序建立单调性。哈希状态与结果集合消失；左右指针根据和值方向批量排除候选，重复值
则在首值层和命中位置直接跳过。

公开入口采用 ``sortAndTwoPointers``。它接收输入副本进行排序，因此不会改变调用者传入的 ``nums``。

复杂度分析
~~~~~~~~~~

.. list-table::
   :header-rows: 1

   * - 方法
     - 时间复杂度
     - 工作空间
     - 去重方式
   * - 三重枚举
     - ``O(n³)``
     - 取决于结果集合
     - 排序每个命中并放入集合
   * - 固定首值加哈希
     - 期望 ``O(n²)``
     - ``O(n)`` 加结果集合
     - 哈希找补数，集合统一去重
   * - 排序双指针
     - ``O(n²)``
     - ``O(n)`` 输入副本
     - 在首值与命中两端直接跳过重复段

排序耗时 ``O(n log n)``，被后续 ``O(n²)`` 扫描主导。三数求和使用 ``long long``，避免三个输入值相加时
依赖更窄范围；返回结果空间不计入工作空间。
