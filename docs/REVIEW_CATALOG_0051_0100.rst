当前事实更正
------------

R 递归闭包状态
~~~~~~~~~~~~~~

普通 ``x[i] <- value`` 复杂赋值会把结果绑定到当前函数调用帧。递归子调用的 enclosure 是函数定义
环境，不是调用者帧；需要共享并撤销状态时，使用显式参数、``environment`` 或经审计的 ``<<-``。

R ``seq.int`` 方向
~~~~~~~~~~~~~~~~~~

``seq.int(from, to, by)`` 在 ``to-from`` 与 ``by`` 符号相反时会报错。构造反向范围前必须验证端点
顺序，不能依赖 C 风格循环条件把非法范围变成零次迭代。

本批稳定模式
------------

* 标准排序的辅助空间和最坏保证按语言运行库说明；
* 强前提删除排序或搜索步骤时，证明前提与降阶的关系；
* 逻辑上的后缀扫描与 ``strlen``、编码转换等实际遍历分开计费；
* 方阵同步收缩允许弱化守卫时，必须证明高宽条件等价；
* 阶乘秩选择证明零基秩、块大小、合法下标和容器删除成本。

规则优先级
----------

#. ``state/PROGRESS.toml``：当前阶段和下一批；
#. ``state/REVIEW_INDEX.toml``：覆盖与事实更正；
#. 已完成阶段的完整前向规则；
#. 专项策略和模板；
#. 本轮结构化记录与详细证据；
#. 提交说明、PR 描述和对话报告。

执行方式
--------

审查由用户在当前对话中明确触发。每个五题批次完成内容读取、证据整理、状态更新和一致性检查后，
作为一个原子提交非强制快进到 ``main``。
