当前事实更正
------------

R 递归闭包状态
~~~~~~~~~~~~~~

普通 ``x[i] <- value`` 复杂赋值会把结果绑定到当前函数调用帧。递归子调用的 enclosure 是函数定义
环境，不是调用者帧；需要共享并撤销状态时，使用显式参数、``environment`` 或经审计的 ``<<-``。

R ``seq.int`` 方向
~~~~~~~~~~~~~~~~~~

``seq.int(from, to, by)`` 在 ``to-from`` 与 ``by`` 符号相反时会报错。构造反向范围前必须验证端点
顺序，不能依赖 C 风格循环条件把非法范围变成零次迭代。

Julia ``codeunits`` 成本
~~~~~~~~~~~~~~~~~~~~~~~

``codeunits(s)`` 默认返回轻量 ``CodeUnits`` 包装视图，不物化长度 ``n`` 的副本。Julia 扫描该视图的
辅助空间是 ``O(1)``；R ``utf8ToInt(s)`` 仍会物化 ``O(n)`` 码点向量。

R 路径栈累计复制
~~~~~~~~~~~~~~~~

``0071`` 的 R 实现反复执行 ``stack <- c(stack, segment)`` 和负下标删除。每次都会重建当前字符向量，
因此大量短组件或交替入栈出栈时，累计复制最坏为平方级，不能沿用通用 ``O(n)`` 时间结论。

编辑距离适配器空间
~~~~~~~~~~~~~~~~~~

``0072`` 的一行 DP 核心工作数组是 ``O(min(m,n))``。C++ 按值复制两个输入字符串，Julia
``collect(codeunits(...))`` 与 R ``utf8ToInt`` 物化两个输入数组，使这些适配器的额外和峰值空间达到
``O(m+n)``。

最小窗口 Go 子串存储
~~~~~~~~~~~~~~~~~~~~

``0076`` 的 Go 实现直接返回 ``s[start:end]``。该值可以共享原字符串的底层存储，并可能保留完整输入；
只有显式 ``strings.Clone`` 才保证新分配，因此不能统一写成复制 ``O(answer_length)``。

最小窗口 R 输入物化
~~~~~~~~~~~~~~~~~~~

``0076`` 的 R 实现分别对 ``s`` 与 ``t`` 调用 ``charToRaw``，随后再转换为整数向量。固定 128 项
``need`` 只说明滑动窗口核心状态为常数；适配器额外和峰值空间为 ``O(|s|+|t|)``。

Julia 合并数组修改可见性
~~~~~~~~~~~~~~~~~~~~~~~~

``0088`` 的 Julia ``Vector`` 参数采用共享可变对象语义。``merge_sorted!`` 在函数内写入元素时，调用者
传入的同一数组可以观察到修改；返回 ``nums1`` 是接口便利。R 的形式参数是调用帧中的局部绑定，适配器
需要返回更新后的向量，不能把两种语言统一解释为复制语义。

Gray Code 零维扩展
~~~~~~~~~~~~~~~~~~

``0089`` 的官方输入域是 ``n >= 1``。公式对 ``n = 0`` 返回 ``[0]``，但首尾异或为 ``0``，并不满足
字面上的“一位差”检查。若主动支持零维输入，必须显式声明退化约定。

R 唯一 BST 构造器名称
~~~~~~~~~~~~~~~~~~~~~

``0094`` 的 R 节点模型定义 ``new_tree_node(val, left, right)``。``0095`` 却调用 ``tree_node(...)``，
并且没有定义该别名。当前适配器会因找不到函数而失败；修复时应调用真实构造器，或在代码附近定义完全
一致的 helper。

本批稳定模式
------------

* 强制 token 先验证，再证明其消费边界和片段乘法组合；
* 最终答案上界保护中间值时给出局部单调和部分乘积支配关系；
* 链表区间重连使用前驱、固定尾、移动节点和后缀的边集合证书；
* 所有权语言替代算法重新证明节点身份、修改范围和复杂度等价；
* 固定段数回溯使用剩余长度双界与单调 ``break`` 条件；
* 显式栈定义递归续点，并由树高而非总节点数界定工作空间；
* 无访问集合遍历声明无环、唯一父节点和无共享子树前提；
* 空结构作为内部笛卡尔积单位元，与公开空输入返回值分层；
* 多个可变结果树通过深复制与跨结果节点身份检查保证独立；
* 跨题 helper 的调用符号、参数和返回类型与真实定义完全一致。

--------

作为一个原子提交非强制快进到 ``main``。
