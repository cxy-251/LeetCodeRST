当前事实更正
------------

R 递归闭包状态
~~~~~~~~~~~~~~

普通 ``x[i] <- value`` 复杂赋值会把结果绑定到当前函数调用帧。递归子调用的 enclosure 是函数定义
环境，不是调用者帧；需要共享并撤销状态时，使用显式参数、``environment`` 或经审计的 ``<<-``。

R ``seq.int`` 方向
~~~~~~~~~~~~~~~~~~

``seq.int(from, to, by)`` 在 ``to-from`` 与 ``by`` 符号相反时会报错。构造反向范围前必须验证端点
顺序，不能依赖 C 风格循环条件把非法范围变成零次迭代。

Julia ``codeunits`` 成本
~~~~~~~~~~~~~~~~~~~~~~~~

``codeunits(s)`` 默认返回轻量 ``CodeUnits`` 包装视图，不物化长度 ``n`` 的副本。Julia 扫描该视图的
辅助空间是 ``O(1)``；R ``utf8ToInt(s)`` 仍会物化 ``O(n)`` 码点向量。

本批稳定模式
------------

* 所有权输入是否复制按调用者可观察性决定；
* 输出缓冲被采用或复制会改变峰值对象数量；
* 版本限定 API 必须与最低版本和验证环境一致；
* 固定宽输出显式包含输出敏感下界和临时切片；
* 防溢出代数变换先证明符号、除零和舍入方向；
* 最终递推值约束中间状态前，证明单调性或其他支配关系。

--------

作为一个原子提交非强制快进到 ``main``。
