逐题审查证据与历史题处理规则
============================

当前状态
--------

``0001`` 至 ``0050`` 的第一次逐题审查已经完成。``0051`` 至 ``0100`` 正在执行第二轮逐题审查，
当前已覆盖 ``0051`` 至 ``0090``。

审查目的
--------

每轮逐题审查完成三件事：

#. 从真实 RST 和十语言代码中识别正向样本、确定性问题与验证限制；
#. 把可复用模式整理为带来源的前向质量规则；
#. 保留结构化证据和事实更正，方便后续追溯与独立修复。

审查证据
--------

内容结论来自：

* 对应题目的完整 RST；
* 题意、示例、算法状态、证明和复杂度；
* 十语言代码块；
* 与该题直接相关的仓库约定；
* 必要时使用目标语言官方文档核对语义。

PR 描述、提交信息、合并状态和对话报告只说明工作发生过，不证明题解质量。

记录分层
--------

单题观察
~~~~~~~~

只描述某一道题的具体表现。它可以是正向样本、确定性错误、复杂度偏差、语言差异或验证限制。

跨题模式
~~~~~~~~

多个题目出现相同根因，或单次出现就属于高风险内存、所有权、索引、数值、作用域、标准库契约或
语言语义问题时，形成跨题模式。

前向规则
~~~~~~~~

跨题模式只有转换为明确检查动作后，才进入批次 ``rules``。第二轮全部完成后，再把稳定规则归并为下一
阶段的完整执行规则。模糊描述如“注意边界”不构成规则。

冲突处理
--------

批次记录是审查快照，可能保留后来被更正的观察。出现冲突时：

#. 先读取 ``state/PROGRESS.toml``；
#. 再读取 ``state/REVIEW_INDEX.toml`` 的 ``corrections``；
#. 执行对应阶段已经完成归并的前向规则；
#. 批次记录和详细发现只用于追溯证据来源。

历史题边界
----------

被审查题目正文默认保持原样。审查发现不会自动触发回改，即使已经确认确定性问题或复杂度表述偏差。

用户明确指定某一道历史题需要修复时：

#. 重新读取该题完整 RST、审查记录和相关规则；
#. 明确缺陷属于算法、编译、运行、复杂度、接口、内存、所有权还是文档；
#. 只修改该题和确实受影响的公共文件；
#. 使用针对性运行或静态验证；
#. 形成独立原子提交，题号完成进度保持不变。

语言与标准库语义验证
--------------------

闭包赋值、范围构造、无符号算术、写时复制、所有权、平台位运算、排序算法和字符串转换等目标语言
路径，不能由其他语言的运行结果替代。缺少目标运行时时，只能标记静态未验证；高风险路径应使用官方
文档和最小可执行测试。

复杂度审查同时读取显式循环和隐藏在标准库调用中的完整扫描、排序缓冲、编码转换、切片复制和容器
删除。API 名称或“原地”字样不能替代真实资源契约。

对返回包装对象的 API，需要区分轻量 wrapper、零拷贝视图、延迟迭代器与物化副本。复杂度结论应由
官方语义和最小运行验证支撑，不能从“可索引”或函数名称推断复制成本。

所有权与调用者可观察性
----------------------

输入不变性按照调用者在函数返回后仍能观察到的对象定义。借用或共享容器需要在修改前复制；独占消费
输入时，允许直接复用其缓冲区作为结果。不能为了表面上的十语言同构，强制所有权语言保留已经不可观察
的原值副本。

空间复杂度除渐进阶外，还应说明输入、临时缓冲和最终结果是否在峰值时同时存活。字符串构造需要区分
缓冲区被结果采用、冻结复制、``join``、``toString`` 和重新编码等路径。

算法工作空间与适配器物化
------------------------

一行 DP、原地标记或常数状态描述的是算法核心工作空间。语言适配器若复制按值参数、收集字符视图、
拆分字符串或返回修改副本，必须另行报告其物化空间和峰值对象，不能用核心算法的空间界覆盖适配器成本。

对动态不可变或复制型容器反复执行尾部拼接、负下标删除或切片重建时，要按每轮容器长度累计复制成本。
峰值空间可能仍为线性，但总时间和累计分配可能达到平方级。

子串视图与新分配
----------------

返回子串时必须区分共享底层存储的视图与新分配副本。共享视图可以是常数时间，但可能保留完整输入；
接口要求新存储或需要释放大输入时，使用目标语言的显式克隆 API，并计入答案长度复制成本。

递归共享状态与快照
------------------

递归代码必须说明状态绑定在当前调用帧、词法外层环境还是显式引用对象中。普通局部复杂赋值、``<<-``
和环境字段赋值的可见范围不同，不能只根据语法相似性判断共享。

保存回溯答案时，快照独立性可以来自显式复制，也可以来自后续只进行新对象重绑定。无论采用哪种方式，
都要证明后续选择和撤销不会修改已经保存的对象，并用独立性测试覆盖。

临时标记与恢复
--------------

原地 DFS、临时环和线索等算法必须让成功、失败和短路路径经过统一恢复点。哨兵必须位于输入域之外；
按值拥有局部副本的语言还要区分内部恢复与调用者可观察的恢复契约。

读写前缀与遍历安全
------------------

遍历容器同时覆盖较早位置时，必须证明写位置不领先尚未读取的位置，并在覆盖前保存当前值。该证明只
适用于元素替换，不允许在遍历期间改变容器长度或使迭代器失效。

信息退化与复杂度保证
----------------------

比较、哈希或分区算法依赖输入提供的区分信息。重复值、碰撞或等价类使分支无法排除固定比例候选时，
分别说明通常和最坏复杂度。消歧操作只能删除已经证明不可能为答案的对象。

链表断链与资源责任
------------------

链表节点从结果中不可达，不等于节点内存已经释放。正文应分别说明指针断链、所有权转移、自动析构、
调用者释放责任和垃圾回收；测试同时检查保留节点身份、节点数量和无环性。

单调栈边界证书
--------------

单调栈弹栈时，必须证明当前元素是右侧首个阻断位置，弹栈后的栈顶是左侧最近阻断位置，两个边界之间
满足候选约束。摊还复杂度还要单独计算每个元素的入栈和出栈次数。

等高元素使用严格或非严格弹栈条件时，说明哪一个候选获得最大范围。虚拟哨兵只负责触发结算，不得
越界读取真实数组或修改只读输入。

降维映射与状态复用
------------------

高维问题压缩为逐层低维状态时，证明编码不变量、每个原对象在哪一层被完整覆盖，以及低维候选反向
映射后的合法性。复用子算法时重新检查哨兵、下标、数值和输入修改契约。

峰值工作空间与每轮重新分配分别报告。复用固定容量和反复创建同阶临时容器可以拥有相同渐进峰值，
但总分配行为不同。

稳定分区与拓扑隔离
------------------

稳定链表分区除值分类外，还要证明原节点身份守恒、每个分区内部的原相对顺序、节点数量和无环性。
节点离开原链时应断开旧边，或提供等价的尾部终止证明，保证旧拓扑不能逃逸到最终结果。

记忆化键与失败状态
------------------

记忆化键包含决定子问题语义的全部坐标、长度、剩余额度和模式。省略字段前必须证明它能由其他字段唯一
恢复。缓存使用未知、成功和失败的不同状态；只缓存成功结果可能继续重复展开指数级失败搜索。

必要条件剪枝只能提前否定。频次、多重集、上下界或奇偶性相同通常不构成充分条件，仍需执行完整转移。

逆向写入与修改可见性
--------------------

逆向原地写入给出未读前缀、已完成后缀和写位置的代数关系，逐轮证明写位置严格越过所有尚未读取的同容器
元素。接口说明还要区分共享可变对象、调用帧局部绑定、独占消费和返回副本。

Julia ``Vector`` 修改对调用者传入的同一对象可见；R 形式参数的局部更新不能作为修改调用者变量的通用
保证。不能仅因两个适配器都返回向量，就把它们归为相同复制语义。

闭式构造与退化扩展
------------------

闭式构造序列分别证明值域、局部相邻关系、单射或可逆性、完整覆盖和循环首尾条件。样例和输出长度不能
替代这些证书。

主动支持官方输入域外的空输入、零维或单元素情形时，明确原条件是按字面检查、真空成立，还是采用新的
退化约定。扩展实现可运行不代表原契约自动保持不变。

同层规范代表与输出载荷
----------------------

重复值枚举把去重条件限定在同一递归层，定义保留的规范代表，并证明保留分支覆盖被跳过兄弟，同时允许
深层继续选择重复副本。

枚举复杂度分别计入结果行数、元素总载荷、快照复制、当前路径和递归栈。每个结果不得共享后续仍会修改的
可变路径；排序输入、独占消费和局部副本按语言接口分别说明。

版本与输出契约
--------------

使用特定语言版本新增的预声明函数或标准库 API 时，最低版本、代码说明和验证环境必须一致。

必须物化固定宽度、多行或大型集合输出时，时间复杂度包含写出全部结果的下界；切片即使只复制引用，也
属于临时容器空间。字符串长度查询不是统一的常数操作，应按目标语言和重复调用次数计费。

原始见证与分阶段写入
--------------------

原地算法若把输入区域复用为标记区，必须先保存会被覆盖的原始见证，再按“收集标记、应用内部、处理
边界”的阶段执行。算法新增的标记值不能被后续扫描误认为原始输入见证。

虚拟视图与坐标映射
------------------

不复制底层数据而建立扁平索引、窗口或其他虚拟视图时，必须证明映射是一一对应、底层布局满足全局
顺序契约，并证明元素总数乘积和坐标换算不会溢出。闭区间和半开区间不能混用更新规则。

有限输入域兜底分支
------------------

``else``、通配模式或默认分支若代表某个唯一剩余值，其正确性依赖精确输入域。正文、类型或运行检查
必须保证没有第四种输入；输入域扩大时应改为显式分支或失败路径。

题目专用边界说明
----------------

公共模板中的边界、易错点和自检问题必须针对当前题目。矩阵、栈、滚动数组等其他题型的占位文字不能
原样遗留，否则会掩盖真正需要验证的状态和接口条件。

状态上界与截断
--------------

使用最终答案上界证明中间状态安全时，必须给出中间对象到最终对象的单射、单调扩展、递推单调性或其他
支配关系。存在障碍、删除、抵消或死路时，最终值可能小于中间状态。

使用饱和或截断状态时，必须证明截断算子与全部转移兼容，并证明保证范围内的最终真实答案严格低于
阈值。转移中的临时加法仍使用足够宽的类型。

代数防溢出变换
--------------

使用除法、重排或等价比较替代可能溢出的乘法时，先证明变量符号、非零分母和目标语言的除法舍入方向。
二分谓词、搜索区间与返回边界必须采用同一整数语义。

后续维护
--------

每个第二轮五题批次：

#. 完整读取五题正文和十语言代码；
#. 新增结构化记录与详细证据；
#. 更新 ``REVIEW_INDEX``、``PROGRESS`` 和资料目录；
#. 不修改历史题目正文；
#. 以一个原子提交更新 ``main``。
