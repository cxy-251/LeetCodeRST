逐题审查证据与历史题处理规则
============================

当前状态
--------

``0001`` 至 ``0050`` 的第一次逐题规则提炼和 ``0051`` 至 ``0100`` 的第二轮逐题审查均已完成。第二轮
81 条 promoted rules 与 14 项 active corrections 已归并为 ``docs/FORWARD_RULES_0101_0150.rst``。

已完成审查产物统一保存在：

* ``archive/reviews/0001-0050/MANIFEST.rst``；
* ``archive/reviews/0051-0100/MANIFEST.rst``。

新题生成不逐份读取归档批次。

审查目的
--------

每轮逐题审查完成三件事：

#. 从真实 RST、证明、复杂度和十语言代码中识别正向样本、确定性问题与验证限制；
#. 把可复用模式转换为带来源、可执行的前向质量规则；
#. 保留足以追溯规则来源和修复历史题的证据。

证据来源
--------

内容结论只来自题目完整 RST、真实代码、仓库接口和策略，以及必要的目标语言官方文档和最小语义测试。
PR 描述、提交信息和对话摘要只能证明工作发生过，不能证明题解正确。

活动记录与归档
--------------

审查轮次进行期间，五题批次状态和详细 findings 可以暂存在 ``state/reviews`` 与
``docs/review-findings``。整轮完成并生成自包含前向规则后，这些文件已经被消费，必须在同一个归并提交中
移入 ``archive/reviews/<range>/``。

归档文件保留当时证据，不因后续更正重写。``state/REVIEW_INDEX.toml`` 只保留当前 active corrections、
归档 manifest、规则归并状态和下一动作，不继续展开所有历史批次路径。

规则优先级
----------

#. ``state/PROGRESS.toml``；
#. ``state/REVIEW_INDEX.toml`` 的 active corrections；
#. 当前阶段完整前向规则；
#. 专项策略、模板和质量门；
#. ``archive/`` 中的历史批次与 findings；
#. 提交、PR 和对话摘要。

历史题边界
----------

被审查题目正文默认保持原样。只有用户明确指定修复某道历史题时才：

#. 读取该题完整 RST、active correction 和当前规则；
#. 根据 archive manifest 定位对应证据；
#. 明确缺陷类别；
#. 只修改该题和确实受影响的公共文件；
#. 使用针对性运行、对拍或静态验证；
#. 形成独立原子提交，题号进度保持不变。

事实更正
--------

active correction 高于历史正文和批次快照。完整文本保存在 ``state/REVIEW_INDEX.toml``。当前重点包括：

* Julia ``UnitRange``、``codeunits`` 和 ``Vector`` 修改可见性；
* R 递归绑定、``seq.int`` 方向、字符物化和复制型容器累计成本；
* 一行 DP 核心工作空间与 C++、Julia、R 适配器物化空间分层；
* Go 子串共享与 ``strings.Clone``；
* Gray Code 零维退化约定；
* 跨题 R 树构造器符号一致性；
* 历史题修复范围和对话触发工作流。

语言语义与复杂度证据
--------------------

闭包赋值、范围构造、无符号算术、写时复制、所有权、标准排序、字符串转换、子串存储和修改可见性必须按
目标语言验证。缺少运行时时只能标记静态未验证。

复杂度同时覆盖显式代码与标准库隐藏工作：完整扫描、排序缓冲、参数按值复制、编码转换、切片、子串共享、
返回副本、容器重建、输出载荷和峰值并存。核心算法空间不能覆盖适配器物化。

规则归并与产物处理
------------------

批次 promoted rules 经过同义去重、根因合并、严格动作保留、active correction 吸收和来源登记后，形成
下一阶段自包含规则。完成归并时必须同时：

#. 写入正式规则；
#. 更新 ``PROGRESS`` 与 ``REVIEW_INDEX``；
#. 将批次记录、findings、旧目录和归并记录移入 archive；
#. 删除无证据价值的 marker 与草稿；
#. 更新 archive manifest 和活动入口。

完整生命周期规则见 ``docs/ARTIFACT_LIFECYCLE_POLICY.rst``。
