题解冻结质量基线
==================

文件职责
--------

本文件冻结题解的写作结构、解释深度、证明质量和语言审查标准。它不是题目事实来源，
也不要求后续题目复制相同标题或篇幅。

最近生成题目不自动成为质量样本。最新产物只承担事实连续性，不具有格式示范权。

黄金题
------

以下题目经过既有审查，作为当前冻结样本：

.. list-table::
   :header-rows: 1

   * - 题目
     - 角色
     - 主要参考点
   * - ``problems/0001-0100/0001-two-sum.rst``
     - Easy、数组与哈希
     - 紧凑题解仍保持契约、状态、哈希语义和十语言接口完整
   * - ``problems/0001-0100/0050-powx-n.rst``
     - Medium、数学与数值边界
     - 状态递推、负指数、最小整数溢出和固定宽语言差异
   * - ``problems/0001-0100/0076-minimum-window-substring.rst``
     - Hard、滑动窗口与最优性
     - 可行性不变量、收缩安全性、最短答案提交和适配器成本
   * - ``problems/0001-0100/0100-same-tree.rst``
     - 树、递归与结构归纳
     - 成对递归状态、空节点基例、结构证明和平台节点复用
   * - ``problems/0101-0200/0128-longest-consecutive-sequence.rst``
     - Medium、哈希集合与期望线性
     - 起点判定、去重、工作不重复证明和哈希复杂度边界

黄金题只提供结构和解释深度。题目契约、算法事实、平台签名和当前语言版本必须从当前题可靠来源、
active corrections 和当前规则中确认。黄金题中的技术事实与 ``state/REVIEW_INDEX.toml`` 冲突时，
以 active correction 为准。

选择规则
--------

每份 ``state/BATCH_CONTRACT.toml`` 必须显式选择至少两个黄金题：

#. 一个匹配当前题的证明形状或难度；
#. 一个匹配当前题的主要语言、数值、对象或资源风险。

没有完全同类型样本时，按证明义务和风险选择，不得改用最近完成题目作为替代样本。

允许学习
--------

黄金题允许提供：

* 教学信息出现的最低覆盖范围；
* 从题面到算法模型的过渡方式；
* 状态与代码变量的映射强度；
* 正确性证明的论证粒度；
* 复杂度对实际语言成本的诚实程度；
* 十语言实现前后的必要语义解释；
* 验证证据和自检答案的完整程度。

禁止复制
--------

不得复制黄金题的：

* 题目事实、示例数据或算法结论；
* 固定章节数量；
* 固定段落长度或代码行数；
* 与当前题无关的语言差异；
* 历史错误或已被 active correction 覆盖的事实。

最近题目的权限
--------------

批次合同列出的最近题目只能提供：

* 已引入术语及解释衰减状态；
* 平台类型和仓库接口连续性；
* 关联题目、范围索引和知识账本事实；
* 上一批完成后留下的准确状态。

最近题目不得决定：

* 标题和章节结构；
* 正文、证明、代码注释或验证的密度；
* 哪些质量门可以省略；
* 文件是否拆分；
* 当前批次应完成多少题。

质量轮廓
--------

每道合格公开题应让读者能够独立回答：

#. 输入输出、强前提、副作用和平台接口是什么；
#. 自建示例如何区分正确方案与典型错误方案；
#. 题目被抽象成什么算法模型；
#. 为什么选择当前主解法；
#. 状态、转移和不变量如何映射到代码；
#. 正确性证明覆盖了哪些义务；
#. 时间、核心空间、输入物化、输出载荷和语言适配成本是什么；
#. 十语言是否保持同一问题语义；
#. 哪些边界和失败路径最容易出错；
#. 验证实际执行了什么，哪些只做了静态检查；
#. 本题新增、强化和关联了哪些知识；
#. 自检问题的答案依据在哪里。

检查不是标题计数。相邻内容可以合并，但任何核心答案都不能消失。

结构漂移判定
------------

出现以下任一情况，题目不得从 ``needs_revision`` 删除，也不得计入新题完成：

* 从问题抽象直接跳到代码；
* 状态只有名称，没有合法范围、更新时机或代码映射；
* 正确性只写“遍历全部所以正确”；
* 复杂度只写抽象算法，不包含实现中的复制、物化、哈希条件或输出载荷；
* 十语言仅机械翻译，未处理当前题真正存在的语义差异；
* 验证记录无法区分运行、编译、静态检查和对拍；
* 为缩短文件删除例子、证明、边界、自检或语言说明；
* 最近题目的低质量结构被继续复制；
* 一个公开题被拆成多个正文或代码分片。

黄金样本维护
------------

黄金样本列表是冻结配置：

* 新完成题目不会自动加入；
* 只因“更近”或“格式更新”不能替换；
* 修改列表必须由用户明确要求或专项质量审查触发；
* 修改应形成独立规则提交，并说明新增样本覆盖的缺口；
* 不能在普通生成或返工提交中顺手提升当前题为黄金样本。
