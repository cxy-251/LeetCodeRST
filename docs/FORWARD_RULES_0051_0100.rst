0051–0100 前向质量规则
=====================

适用范围
--------

本文件汇总 ``0001`` 至 ``0050`` 逐题审查后确认的执行规则，应用于 ``0051`` 至 ``0100``。
新题按“精确契约 → 算法状态 → 正确性证明 → 十语言实现 → 复杂度与验证”的顺序完成。

一、先确定题目契约
------------------

#. 写出影响实现的精确约束：长度上下界、数值范围、字符集合、输入合法性、输出顺序和是否允许修改输入。
#. 公开函数名、参数、返回类型、返回结构和平台元数据与题目接口一致。
#. 官方题目要求与主动支持的通用扩展分别说明。
#. 非空、正长度、等长、方阵、无环、节点互不相交和可达性等前提集中写入接口契约。
#. 数字字符串写明非空、字符域、零的唯一表示和前导零规则。
#. 字符串分别定义比较单位和返回下标单位：字节、UTF-16 代码单元、码点或字形簇。
#. 有效前缀题定义返回长度、允许检查的前缀、尾部语义和底层容器状态。
#. 覆盖边界、插入边界和末尾外位置属于抽象坐标；经过范围检查后才作为数组下标。
#. 浮点数学题列出 ``0^0``、零的负指数、除零等特殊或未定义输入域。

二、选择状态并完成证明
----------------------

统一证明要求
~~~~~~~~~~~~

#. 状态含义直接对应代码变量。
#. 循环或递归入口写出不变量。
#. 证明合法性、完整性、无重复和终止性。
#. 证明算法真正的决策，而不是逐行复述代码。
#. 一个核心推导只完整出现一次，后续章节引用结论并补充新边界。

二分、双指针与滑动窗口
~~~~~~~~~~~~~~~~~~~~~~

#. 二分证明搜索区间、单调谓词、移动方向、排除安全性、存在性、终止性和返回语义。
#. lower bound 与 upper bound 的谓词清楚表达相等元素落在哪一侧。
#. 双指针证明移走一端时，被删除的整批候选不会产生更优答案。
#. 在线结算位置或区间前，证明未来信息无法改变已经提交的值。
#. 滑动窗口证明重置与收缩只排除不可能候选，并给出元素进入、离开次数。

贪心与隐式图
~~~~~~~~~~~~

#. 贪心使用交换论证、上界排除、单调性、规范表示或 BFS 层序解释。
#. MRV 等启发式证明只改变搜索顺序，不删除合法候选。
#. 区间图压缩为边界时，证明当前层所有出边的并集连续。
#. ``current_end`` 与 ``farthest`` 分别表示当前承诺和下一层候选。
#. 每次边界提交对应一次 BFS 层转换。
#. 可达性前提或停滞检测保证边界能够继续推进。

回溯与枚举
~~~~~~~~~~

#. 状态说明固定前缀、候选后缀、路径、使用标记和撤销关系。
#. 保存答案时创建独立快照，后续撤销不能改写历史结果。
#. 重复值算法同时跟踪数值等价与输入下标身份。
#. 同层去重选择规范代表，并证明保留分支覆盖被跳过分支。
#. 排列、组合和搜索树的复杂度拆为预处理、访问节点和复制输出载荷。
#. 递归深度与最大输入规模和目标语言栈限制对应。

原地变换
~~~~~~~~

#. 原地压缩证明有效前缀、完整性、顺序性质和 ``write <= read``。
#. 原地值槽映射证明每次交换永久填好目标槽位、正确槽位不再被破坏、重复值能够停机。
#. 局部链表重连列出修改前后的边，证明连通、节点守恒和无环。
#. 破坏性分组操作在首次写入前完成只读可行性探测。
#. 矩阵和排列变换优先分解为可逆双射，证明复合坐标等于目标映射。
#. 每个位置或元素恰好处理一次，元素多重集保持不变。

受控回退与动态规划
~~~~~~~~~~~~~~~~~~

#. 受控回退给出单调进度量、最大回退次数和重复扫描区间。
#. 动态规划证明状态充分、转移完整、初始化正确和遍历顺序合法。
#. 记忆化递归写出共享状态、调用局部状态、递归深度和缓存更新成本。

三、数值、容量与资源
--------------------

数值表达式
~~~~~~~~~~

#. 危险算术先扩宽操作数，再执行加法、乘法、取负、绝对值和移位。
#. 数值安全覆盖整条表达式：目标差值、剪枝边界、累计结果、覆盖端点和最终窄化。
#. 聚合结果由“元素数量 × 单项最大贡献”推导宽度。
#. ``size_t``、``usize`` 和容器长度转换为 ``int`` / ``i32`` 时，上界覆盖最大下标、边界 ``n`` 和合法返回值 ``n+1``。
#. 平台相关 ``int`` / ``Int`` 宽度明确，固定宽题目优先使用固定宽类型。
#. TypeScript 检查安全整数范围，整数算法避免隐式 32 位位运算。
#. 整数逐位与倍增复杂度使用位数、表长或 ``O(log(|x|+1))``，覆盖零值。
#. 浮点算法区分数学不变量与 IEEE 754 舍入、上溢和下溢。

容量与分配
~~~~~~~~~~

#. 固定缓冲区容量由最大输出长度推导，并包含终止符、分隔符、哨兵和元数据。
#. 阶乘、组合数、Catalan 数和输出数量用于预分配前，验证中间乘积和类型转换。
#. 元素数量乘元素大小、矩阵尺寸、单词长度乘单词数和容量翻倍使用容量类型逐步检查。
#. C 的初始分配在首次写入前确认成功。
#. 多个相关缓冲区、哈希表、路径和元数据采用整体成功或整体清理。
#. ``realloc`` 使用临时指针，全部相关扩容成功后提交新状态。
#. 动态字符串构造检查长度加法、容量增长、返回值和终止符。
#. ``snprintf`` 检查返回值是否超过剩余容量，再更新偏移。

失败语义
~~~~~~~~

#. 资源失败返回明确失败状态，与合法的 ``false``、``0``、空结果和部分答案区分。
#. 已分配资源完整清理。
#. 不可达分支使用断言、异常或明确平台前提，不返回可能合法的默认值。
#. 非空断言、``unwrap``、``something`` 和解包操作由紧邻的不变量或见证元素支撑。

四、字符串、哈希与输出成本
--------------------------

字符串
~~~~~~

#. 字节操作由精确 ASCII 或单字节字符约束支撑。
#. 按字节重排、切片和重建字符串时保持编码边界。
#. ``[]byte``、``collect``、``strsplit``、``utf8ToInt``、切片、重新编码和子串返回计入成本。
#. 整串解码、正则编译、哈希构建和排序移出热循环。
#. 数字数组序列化计入切片、逐项字符串化、中间集合、``join`` / ``paste`` 和最终结果。
#. 后处理 ``findfirst``、``which`` 和解包操作具有存在性证明。

哈希与规范签名
~~~~~~~~~~~~~~

#. 哈希复杂度区分期望与最坏情况。
#. 复杂度包含桶、键数量和被拥有的键载荷。
#. 复合签名证明编码单射、字段边界和最大序列化长度。
#. 固定字母表签名的计数类型由单词最大长度推导。
#. 结果顺序无要求时，哈希表遍历顺序不属于正确性条件。
#. 把 ``O(f+g)`` 简化为 ``O(f)`` 前证明 ``g=O(f)``；允许空字符串时保留输入项数量 ``N``。

输出
~~~~

#. 区分算法工作空间、输入规范化、递归栈、当前路径、结果集合和返回复制。
#. 枚举题计入完整输出元素或字符总量。
#. 每个答案拥有独立快照，不共享会被后续修改的底层数组。
#. 结果追加按摊还、复制或写时复制语义计费。
#. 构造型算法按同一时刻并存的旧值、新值、片段容器和转换临时对象计算峰值空间。

五、十语言实现方式
------------------

共同要求
~~~~~~~~

#. 十语言实现同一问题语义，允许符合语言约束的不同控制流。
#. 正文中的剪枝、去重、优化和错误处理与对应代码一致。
#. 某语言采用不同算法或复制型适配器时，单独说明接口、证明和复杂度。
#. 标准库符号使用直接定义它的头文件、包、命名空间或 ``using``。
#. 版本相关 API、语法和编译器内建声明最低环境。
#. 平台预置节点、集合和辅助函数在代码附近说明。

C
~

* 二维返回同步维护外层容量、每行容量、``returnSize`` 和 ``returnColumnSizes``。
* 比较器使用关系比较，避免减法溢出。
* 所有分配、复制、序列化和扩容形成完整失败契约。
* 固定签名缓冲区由精确计数上界推导。
* 节点释放与平台所有权契约一致。

C++
~~~

* ``size_t`` 与有符号索引转换由精确上界支撑。
* ``vector``、``array``、``sort``、``swap``、``reverse``、``move`` 等包含直接头文件。
* 比较器满足严格弱序。
* 引用、迭代器和输入修改生命周期明确。

Python
~~~~~~

* 切片、列表复制、路径快照和递归深度计入成本。
* ``heapq`` 相等键使用稳定序号或其他可比较字段。
* 版本相关 API 说明最低版本。
* 任意精度整数能力不外推到固定宽语言。

Java 与 C#
~~~~~~~~~~

* 危险中间值先提升到 ``long``。
* 集合、装箱、字符串复制、递归和路径快照计入成本。
* 对象字段在公共入口初始化或清空。
* ``import``、``using`` 和运行时版本完整。

Rust
~~~~

* 代码符合真实借用检查。
* 输入所有权、``take``、``clone`` 和快照载荷明确。
* 无符号递减使用显式分支或有符号控制坐标。
* 字节字符串操作由 ASCII 契约支撑。
* 容器长度与固定宽返回值转换由精确上界证明。

Go
~~

* ``int`` 位宽由平台前提或固定宽类型支撑。
* ``[]byte``、切片共享和 ``append`` 扩容成本明确。
* 长生命周期容器移除引用后考虑对象滞留。
* 版本相关内建函数说明最低版本。

TypeScript / JavaScript
~~~~~~~~~~~~~~~~~~~~~~~

* ``number`` 安全整数范围经过边界验证。
* 位运算的 32 位转换单独检查。
* ``Map.get`` 的 ``undefined`` 与合法零值分开。
* 字符串下标是 UTF-16 代码单元坐标。
* 使用严格类型检查，并将类型验证与运行验证分开记录。

Julia
~~~~~

* 一基容器索引与零基算法坐标逐项转换。
* ``a:b`` 是隐式步长 ``+1`` 的 ``UnitRange``；``a>b`` 时为空。
* 递减遍历使用显式负步长，例如 ``n:-1:1``。
* ``collect``、切片、字符串重构和路径复制计入成本。
* 宿主 ``Int`` 位宽前提明确，宽常量在目标类型中构造。
* 范围、切片和标准库语义通过运行或官方文档确认。

R
~

* 调用局部变量使用 ``<-``，跨递归共享状态使用 ``environment`` 或明确外层绑定。
* ``<<-`` 只表示父绑定更新，向量、矩阵和列表的写时复制单独计算。
* 路径选择、撤销、堆交换、分组成员追加和答案积累按实际复制成本分析。
* 迭代范围使用 ``seq_len``、``seq_along`` 或明确边界。
* ``strsplit``、``utf8ToInt``、``substr``、``c`` 扩展和返回副本计入复杂度。
* 无法表达原地平台接口时，返回值标记为语言适配器。

六、验证与完成判定
------------------

每道新题完成时具备以下证据：

#. 精确契约支撑所有索引、字符、数值、所有权和特殊输入假设。
#. 十语言主代码完整、自洽并与平台接口一致。
#. 正确性证明覆盖真实算法决策、完整性、无重复和终止性。
#. 数值、容量、分配、失败和生命周期路径闭合。
#. 复杂度覆盖具体容器、规范化、搜索节点、输出载荷、快照和峰值空间。
#. 文档承诺与实际代码一致。
#. 导入、版本、编译器扩展和辅助接口完整。
#. 验证报告明确区分编译、运行、静态检查和基准对拍。
#. 题目 RST、范围索引、进度和知识账本同步。
