0051–0100 前向质量规则
=====================

适用范围
--------

本文件汇总从 ``0001`` 至当前已审查 RST 正文中提炼出的可执行规则，应用于 ``0051`` 至
``0100`` 的新题。历史题目保留原样，用户明确指定修复时进入独立修复流程。

证据与最终实现
--------------

#. 规则来源是完整题目 RST、十语言代码、证明和复杂度正文。
#. 验证结果分别记录运行、编译、静态检查和基准对拍。
#. 正文确认的守卫、导入和修复直接进入主代码块。
#. 边界说明、证明、复杂度和代码描述同一个最终实现。
#. 范围、切片、下标、复制和标准库行为按目标语言实际语义验证。

题意、约束与平台接口
--------------------

#. 列出影响实现的精确约束：长度上下界、数值范围、字符集合、输入合法性、结果顺序和输入修改语义。
#. 官方题目契约与主动支持的通用扩展分开说明。
#. 十语言共享非空、正长度、等长和合法输入等官方前提；语言适配器差异单独说明。
#. 公开函数名、参数类型、返回类型、返回结构和平台元数据与题目接口一致。
#. 内部宽类型在最终返回前由精确约束证明可安全窄化。
#. ``size_t``、``usize`` 和容器长度转换为 ``int`` / ``i32`` 时，上界覆盖最大下标、末尾边界 ``n`` 和合法返回值 ``n+1``。
#. 非空断言、``unwrap``、``something`` 和不可达分支由紧邻的不变量支撑。
#. 平台节点类型、辅助构造器和访问函数直接定义、导入或引用统一接口。
#. 链表和图结构写明无环、节点相交和共享后缀前提。
#. 有效前缀题定义返回长度、可检查前缀、尾部语义、稳定性和底层容器状态。
#. 二分函数定义返回命中下标、插入边界、末尾外位置或失败哨兵。
#. 固定 9×9、81 格等问题同时给出精确工作量、约束内常数界和推广模型。
#. 数字字符串写明非空、字符域、零的唯一表示和前导零规则。
#. 可达范围边界、插入边界和答案上界是抽象坐标；未经裁剪或范围检查不作为数组下标访问。

字符模型与字符串成本
--------------------

#. 字符串题先定义比较单位：字节、UTF-16 代码单元、Unicode 码点或字形簇。
#. 返回下标单位单独定义，并证明内部坐标可映射到平台坐标。
#. 十语言使用不同字符单位时，由精确字符域证明等价。
#. 按字节重排或切片后重建字符串时，证明编码边界保持完整。
#. ``[]byte``、``collect``、``strsplit``、``utf8ToInt``、切片、重新编码和返回子串复制计入复杂度。
#. 整串解码、正则编译、哈希构建和排序等预处理在热循环外执行必要次数。
#. 标准库查找 API 的返回坐标与题目要求保持一致。
#. 迭代字符串构造的空间峰值统计旧值、新值、片段容器和转换临时对象。
#. 数字数组序列化为字符串时，计入切片、逐项字符串化、中间字符串集合、``join`` / ``paste`` 和最终结果。
#. 核心算法只保存常数索引时，语言实现的字符规范化副本仍按 ``O(m+n)`` 等真实空间报告。

数值表达式与容量
----------------

#. 危险算术先扩宽操作数，再执行加法、乘法、取负、绝对值或移位。
#. 数值安全覆盖连续表达式、目标差值、剪枝上下界、哨兵和最终窄化。
#. 最小有符号值、平台 ``int`` 位宽和 TypeScript 32 位位运算单独检查。
#. 平台相关整数宽度声明目标平台，固定宽题目优先使用固定宽类型。
#. 数值宽度由精确输入上界推导。
#. 累计结果由元素数量与单项最大贡献共同推导，例如总水量、路径端点和输出计数。
#. 覆盖端点 ``index + step``、长度和 ``n+1`` 在目标类型中完成并验证溢出。
#. 固定缓冲区容量由最大输出长度推导，并包含终止符、哨兵和元数据。
#. 元素数量乘元素大小、分支数乘积、单词长度乘单词数和矩阵尺寸使用容量类型逐步检查。
#. Catalan、排列和组合数量用于预分配或索引前，验证中间乘积、除法顺序和类型转换。
#. C 的初始分配在首次写入前确认成功。
#. 多个相关缓冲区、哈希表和计数数组采用整体成功或整体清理的资源契约。
#. C 的 ``realloc`` 使用临时指针，相关扩容全部成功后提交新状态。
#. C 动态字符串构造同时检查容量增长、长度加法和新缓冲区提交。

复杂度与输出
------------

#. 定义 ``n``、``m``、``d``、搜索节点数 ``N``、输出载荷 ``P``、单词长度 ``w`` 和唯一键数量 ``u``。
#. 区分最坏、平均、期望和摊还复杂度；哈希题同时说明期望与最坏界。
#. 区分算法工作空间、输入规范化、递归栈、当前路径、结果集合和返回复制。
#. 固定输入域同时说明精确常数界和推广模型。
#. 枚举与回溯时间写成预处理、访问搜索节点和复制输出载荷之和。
#. 排列、组合、分组和字符串构造计入完整输出字符或元素数量。
#. 结果追加按语言的摊还、复制或写时复制语义计费。
#. 可预知输出数量时使用精确预分配；动态容器说明扩容模型。
#. 抽象数据结构复杂度由目标语言具体表示支撑。
#. 哈希空间包含桶、键数量和被拥有的键载荷，例如 ``O(u*w)``。
#. 滑动窗口区分逻辑操作次数与切片、哈希、比较读取的字符总量。
#. 整数逐位与倍增算法使用位数、表长或 ``O(log(|x| + 1))``。
#. 递归解法写出最坏深度，并与最大输入规模和运行时栈限制对应。
#. 构造型算法按同一时刻并存对象计算峰值空间。
#. 受控回退分别统计单调回退次数和被重复扫描片段的总工作量。
#. 复制型语言适配器的输入重排、字符拆分和返回副本成本覆盖核心算法的抽象 ``O(1)`` 结论。

证明质量
--------

#. 正确性依据证明算法决策，而不是复述循环。
#. 二分证明覆盖区间、单调谓词、移动方向、排除安全性、返回语义、存在性和终止性。
#. lower bound 与 upper bound 的参数名、谓词和调用点清楚表达相等值落在哪一侧。
#. 双指针证明被删除端点对应的整批候选可安全排除。
#. 在线结算位置或区间前，证明已知限制边界已经决定最终值，未来信息不能改变本次提交。
#. 原地压缩证明有效前缀、完整性、顺序性质和 ``write <= read``。
#. 原地排列证明元素多重集、结果方向、邻接最优和回绕分支。
#. 原地值槽映射证明每次交换永久完成目标槽位、正确槽位不会被破坏，并用重复值守卫保证停机。
#. 贪心使用交换论证、上界排除、单调性或规范表示语法。
#. 回溯证明状态含义、合法性、完整性、无重复、撤销恢复和终止性。
#. MRV 等启发式证明只改变搜索顺序，合法候选全集保持不变。
#. 同层去重证明保留分支与被跳过分支等价，并说明保留分支的可用后缀覆盖关系。
#. 动态规划证明状态充分、转移完整、初始化和遍历顺序。
#. 滑动窗口证明重置与收缩的排除安全性以及元素进入、离开次数。
#. 受控回退给出单调进度量、最大回退次数和重扫区间上界。
#. 区间边界压缩 BFS 时，证明当前层出边并集连续、下一层边界完整，并且一次提交对应一次层转换。
#. 链表局部重连列出改写前后的边，证明连通、节点守恒和无环。
#. 破坏性分组操作在首次写入前完成只读可行性探测。
#. 无边界扫描、``pop`` 和非空断言由紧邻的见证元素、哨兵或非空状态支撑。
#. 后处理 ``findfirst``、``which`` 和解包操作由早退分支或不变量证明见证存在。
#. 哨兵栈说明初始化、弹出前非空、弹空后的恢复和哨兵语义。
#. 一个核心推导只完整出现一次，复现题聚焦新增状态、边界和语言差异。

讲解与十语言实现一致
--------------------

#. 十语言实现同一问题语义，并允许符合语言约束的不同控制流。
#. 正文中的剪枝、去重和优化与对应代码保持一致。
#. 部分语言采用的可选优化注明适用范围。
#. 语言因所有权、字符串或容器语义采用不同算法时，单独提供状态、证明和复杂度。
#. 复制型语言适配器说明接口、返回副本和调用后语义。
#. 对象字段、闭包环境和辅助缓存在每次公共入口建立本次调用状态。
#. 多次调用同一对象时，公共入口清空上一轮数据；单次调用生命周期作为明确平台前提。
#. 值派生数组下标的值域守卫与短路求值顺序在代码和证明中一致。
#. 覆盖边界可以超过数组末尾，正文不得把它误写为可直接解引用的合法下标。
#. 复杂度与证明覆盖实际代码和实际语言容器。

导入、版本与辅助代码
--------------------

#. 每个标准库符号使用直接定义它的头文件、包、命名空间或 ``using``。
#. 平台预置内容在语言标题或代码注释中说明。
#. 版本相关 API、语法和编译器内建声明最低环境，并可提供可移植辅助实现。
#. 非平台辅助函数、比较器、状态对象和节点访问函数完整。
#. 堆比较器满足目标语言的顺序契约，相等键使用稳定序号或可比较字段。
#. ``pop`` 和类型断言由紧邻的非空不变量支撑。

失败路径与资源
--------------

#. 资源失败返回明确失败状态，并与正常答案区分。
#. C 分配失败时清理已经建立的完整或部分资源。
#. 多行结果、列长度和路径缓冲区保持容量与提交状态一致。
#. C 扩容先保留旧指针，验证新分配后更新状态。
#. 数字字符串的零早退与非零后处理形成完整分支，后处理不得依赖未声明的规范表示。
#. 输入合法前提作为接口契约；通用校验模式提供完整错误语义。
#. 十语言使用各自惯用的错误机制表达同一失败语义。

输入修改、所有权与生命周期
--------------------------

#. 排序、交换、移动、消费和原地修改输入时说明调用后状态。
#. 原地数组题说明底层长度、有效前缀和尾部语义。
#. 原地排列和槽位置换题说明旧顺序被重排，复制型适配器说明局部副本成本。
#. 复用链表节点时说明原入口、原拓扑和外部节点引用的调用后可用性。
#. Rust 的 ``take``、``clone``、移动和借用生命周期符合真实借用检查。
#. 链表删除与拼接说明节点所有者和回收责任。
#. 局部重连在首次写入前保存后续仍需使用的节点。
#. 回溯保存答案时创建独立路径快照，并计算复制载荷。

高风险语言补充
--------------

C
~

* 二维返回同步维护外层容量、每行容量、``returnSize`` 和 ``returnColumnSizes``；
* 分配结果在首次写入前检查，多缓冲区整体提交；
* 比较器使用关系比较表达顺序；
* 长度转换、无符号下溢、``n + 1``、聚合量、乘法和扩容表达式重点验证；
* 值派生下标只在短路值域检查后访问；
* 动态字符串构造采用事务式扩容和完整清理。

C++
~~~

* ``size_t`` 与有符号下标的转换由精确上界支撑，并覆盖 ``n+1``；
* 迭代器、引用生命周期和比较器顺序契约清楚；
* ``vector``、``swap``、``reverse``、``move`` 等符号直接包含对应头文件；
* ``__builtin_*`` 等编译器扩展注明编译环境或使用可移植辅助实现。

Python
~~~~~~

* 切片、列表复制、闭包状态、路径快照和递归深度计入成本；
* ``heapq`` 相等键使用序号或其他可比较字段；
* ``int.bit_count`` 等 API 声明最低版本；
* 大整数能力不外推为固定宽语言安全。

Java 与 C#
~~~~~~~~~~

* 中间运算先提升到 ``long``，累计量按完整上界选择类型；
* 集合、装箱、字符串复制、递归和路径快照计入真实成本；
* 对象字段在公共入口初始化或清空；
* 版本相关 API 声明目标运行时；
* ``import``、``using`` 或平台预置边界完整。

Rust
~~~~

* 代码通过真实借用检查；
* ``usize`` 窄化覆盖边界 ``n`` 与返回值 ``n+1``；
* 无符号递减使用显式分支或有符号控制坐标；
* 输入所有权和 ``clone`` 载荷明确；
* 非负值转 ``usize`` 前建立符号前提，并验证后续加法；
* 字节字符串操作由精确 ASCII 约束证明；
* ``let-else`` 等语法声明最低 Rust 版本。

Go
~~

* ``int`` 位宽由平台前提或固定宽类型支撑；
* ``[]byte``、切片共享和 ``append`` 扩容成本明确；
* ``clear`` 等内建声明最低 Go 版本；
* 长生命周期容器移除引用后考虑对象滞留。

TypeScript / JavaScript
~~~~~~~~~~~~~~~~~~~~~~~

* ``number`` 安全整数和位运算 32 位转换经过边界验证；
* ``Map.get`` 的 ``undefined`` 与合法零值分开；
* 字符串下标使用 UTF-16 代码单元坐标；
* 数组 ``slice`` 与字符串 ``join`` 的中间复制计入峰值空间；
* 非空断言紧邻建立事实的条件；
* ``--strict`` 类型检查与运行验证分别记录。

Julia
~~~~~

* 一基索引与零基算法坐标逐项转换；
* ``a:b`` 在 ``a > b`` 时形成递减范围，循环按真实最小长度或后缀耗尽条件守卫；
* ``collect``、``Vector(codeunits)``、切片、字符串重构和路径复制计入成本；
* ``findfirst`` 返回值在解包前由规范输入或早退证明存在；
* 具体容器使用稳定元素类型；
* 宽类型常量在目标类型中构造，宿主 ``Int`` 位宽前提明确；
* 范围与标准库语义通过实际运行或官方文档确认。

R
~

* 调用局部变量使用 ``<-``，跨递归共享状态使用 ``environment``；
* ``<<-`` 表示父绑定更新，向量、矩阵和列表的写时复制另行计算；
* 堆交换、路径追加、原地数组适配和答案积累按实际复制成本分析；
* 循环使用 ``seq_len``、``seq_along`` 或明确的最小长度守卫；
* ``strsplit``、``utf8ToInt``、``substr``、``which``、向量扩展和字符串序列化计入复杂度；
* ``which(...)[[1]]`` 前证明至少存在一个结果；
* 复制型接口标记为语言适配器；
* 大量结果使用预分配列表和索引写入。

单题完成判定
------------

新题计入完成时同时满足：

#. 精确约束支撑代码中的索引、数值、字符、规范表示和生命周期假设；
#. 公开接口与平台一致，适配器差异已说明；
#. 十语言主代码完整、自洽且语义一致；
#. 正确性证明覆盖真实决策、永久槽位、未来信息终局性、受控回退、区间层压缩、启发式顺序、去重等价性和撤销恢复；
#. 数值、聚合量、容量、分配、失败和所有权路径闭合；
#. 复杂度包含具体容器、规范化副本、序列化管线、并存峰值、搜索节点、输出载荷和递归深度；
#. 文档承诺、语言语义和代码实现一致；
#. 导入、版本、编译器扩展和辅助接口完整；
#. 验证证据描述准确；
#. RST、索引、进度和知识账本同步。
