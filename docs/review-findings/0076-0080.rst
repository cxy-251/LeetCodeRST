0076. Minimum Window Substring
------------------------------

正向样本
~~~~~~~~

``need[c]`` 同时表达正缺口、刚好满足和多余副本，``missing`` 精确保存全部正缺口总和。字符进入窗口时
先判断旧 ``need`` 是否为正，字符移出时先递增再判断是否变正，能够正确处理目标字符的重复次数。

对每个右端，收缩循环检查全部合法左边界并停在首个非法位置，因此不会遗漏全局最短窗口。ASCII 字符域
也正确支撑固定 128 项频次数组和各语言的字节或代码单元索引。

Go 子串不保证新分配
~~~~~~~~~~~~~~~~~~~

Go 实现返回：

.. code-block:: go

   return s[bestStart : bestStart+bestLength]

字符串切片可以共享原字符串的底层存储，因此返回操作本身可以是常数时间，也可能让一个很短的答案继续
保留完整 ``s``。Go 标准库只有 ``strings.Clone`` 明确保证产生新分配。

这不影响返回字符内容，也不产生可变别名，因为 Go 字符串不可变。它与正文“返回独立字符串”和
“复制 ``O(answer_length)`` 个字符”的统一资源描述冲突。接口若要求新存储，应显式调用
``strings.Clone``，同时注明 Go 1.18 版本门槛。

R 输入物化
~~~~~~~~~~

R 实现依次执行：

.. code-block:: r

   source <- as.integer(charToRaw(s))
   target <- as.integer(charToRaw(t))

``charToRaw`` 生成原始字节向量，``as.integer`` 再生成整数表示。固定 128 项 ``need`` 只证明滑动窗口
核心状态为 ``O(1)``；R 适配器需要 ``O(|s|+|t|)`` 输入物化空间，返回阶段还会建立答案对象。

前向规则
~~~~~~~~

* 返回子串时区分共享视图、不可变别名、新分配和大输入保留；
* 固定频次数组只约束算法状态，不能覆盖字符转换产生的线性输入副本；
* 多重集窗口使用字符副本缺口，不把“满足种类数”误当成“满足全部次数”；
* 结果复制成本按目标语言 API 的真实存储语义说明。

0077. Combinations
------------------

正向样本
~~~~~~~~

严格递增路径为每个组合提供唯一表示，``last_start = n-needed+1`` 的容量剪枝由剩余可选数量直接推出。
叶子只在路径长度等于 ``k`` 时提交，结果数量、单行长度和输出主导复杂度均正确。

C 先计算 ``C(n,k)`` 并预分配外层容量，分配失败时释放已经完成的全部结果行。当前约束
``n <= 20`` 也使最终容量和乘除中间值安全。

R 共享状态绑定
~~~~~~~~~~~~~~

R 使用固定长度 ``path``，并在 ``combine`` 调用环境中通过 ``<<-`` 修改 ``path`` 和 ``result``。
递归子调用共享函数的词法外层环境，因此该写法与 ``0051`` 中普通局部 ``x[i] <- value`` 的错误模式
不同。

叶子调用 ``as.integer(path)`` 保存结果。后续路径修改应通过 R 的复制或重绑定语义保持历史结果独立；
这类实现必须用快照独立性测试验证，不能只看到“加入结果容器”就假设已经复制。

前向规则
~~~~~~~~

* 递归共享状态逐个确认绑定环境，区分普通局部赋值、``<<-`` 和显式环境；
* 快照独立性可以来自显式复制或后续重绑定，但必须证明并测试；
* 组合数预分配同时证明最终容量和乘除中间值不会溢出；
* 输出复杂度包含每个叶子复制 ``k`` 个整数的成本。

0078. Subsets
-------------

正向样本
~~~~~~~~

任意递归节点都是合法子集，进入节点即提交路径，能够自然包含空集和所有非叶子子集。严格递增输入下标
让子集与递归节点形成双射，结果数量恰好为 ``2^n``。

通过每个输入元素出现在一半子集中，可以精确得到全部结果复制
``n × 2^(n-1)`` 个整数，时间与返回空间均为 ``Theta(n × 2^n)``。

R 重绑定快照
~~~~~~~~~~~~

R 把当前 ``path`` 放入结果后，选择和撤销分别执行 ``c(path, value)`` 与负下标提取，二者都会建立新的
路径对象并重新绑定 ``path``。因此历史列表项不会被后续路径重绑定修改，语义上可以形成独立快照。

这些路径重建的累计工作仍需要计入语言适配器成本。其总量受递归边数和路径深度约束，落在本题已有的
``Theta(n × 2^n)`` 输出主导上界内，但常数和累计分配明显高于可变栈实现。

前向规则
~~~~~~~~

* “保存引用”是否安全取决于后续是原对象原地修改还是绑定到新对象；
* 指数输出题用返回元素总量给出时间和空间下界；
* ``1 << n`` 预分配依赖位宽、符号与精确输入上界；
* 不把语言适配器的路径重建误写成可摊还常数 ``push/pop``。

0079. Word Search
-----------------

正向样本
~~~~~~~~

字符匹配后才写入域外哨兵，四方向短路结果先汇总到 ``found``，随后统一恢复原字符。成功路径和失败路径
都经过恢复点，因此可变接口不会污染调用者矩阵。

``len(word) > rows×cols`` 的剪枝正确；递归深度由单词长度约束。Rust 按值接收矩阵，只修改局部所有权
副本，其他可变语言则依赖显式恢复。

R 环境状态与载荷
~~~~~~~~~~~~~~~~

R 使用 ``environment`` 保存矩阵绑定，递归调用共享同一个环境，因此访问标记能够跨递归层可见。环境
本身不会按值复制，这解决了普通递归调用帧无法继承父层局部复杂赋值的问题。

``state$board[row,col] <- value`` 仍是矩阵载荷的复杂赋值。R 运行时是否能够复用底层矩阵取决于对象共享
状态和实现，不能仅凭“放入环境”就把完整适配器空间断言为 ``O(L)``。核心 DFS 状态与矩阵载荷复制应
分开报告并用目标运行时测量。

前向规则
~~~~~~~~

* 临时标记必须位于输入域之外，并让成功、失败和短路路径经过统一恢复点；
* 环境提供共享绑定，不自动保证绑定对象的内部修改零拷贝；
* 按值拥有局部输入时，内部恢复与调用者可观察恢复是不同契约；
* 指数 DFS 复杂度保留起点数量、分支因子和最大深度三个维度。

0080. Remove Duplicates from Sorted Array II
---------------------------------------------

正向样本
~~~~~~~~

``write`` 同时表示有效前缀长度和下一个写入位置。当前值与有效前缀倒数第二项比较，依赖有序性即可判断
是否已经保留两个当前值。前两个元素无条件保留，之后只跳过第三个及更后的副本。

从左到右稳定写入保持相对顺序，``write`` 从不领先读取位置。各语言在覆盖前先把当前值保存到局部变量，
所以遍历同一容器期间写回较早位置不会破坏尚未读取的后缀。

遍历与覆盖契约
~~~~~~~~~~~~~~

范围遍历或 ``foreach`` 与原地覆盖同时出现时，正确性不能只凭“写在前面”判断。这里安全是因为：

* 只替换现有元素，不改变容器长度；
* 写位置不超过当前读取位置；
* 当前值在写入前已经复制到局部变量；
* 后续迭代器位置和数组布局保持有效。

R 返回 ``list(k=write, nums=nums)``，因此接口载荷包含完整向量；算法工作状态仍为 ``O(1)``，调用者获得
修改结果的返回空间为 ``O(n)``。

前向规则
~~~~~~~~

* 遍历中覆盖必须证明写指针不领先读取指针，且禁止结构性修改容器；
* 有效前缀接口只保证 ``[0,k)``，尾部内容不进入正确性要求；
* 算法工作空间与返回完整容器的接口载荷分开说明；
* “最多保留 ``q`` 次”可推广为 ``write < q`` 或与 ``write-q`` 位置比较。

跨题统一归纳
------------

本批规则可以归并为六个检查动作：

#. **子串存储。** 区分共享底层、显式克隆、答案复制和大输入保留。
#. **状态分层。** 固定数组或常数指针不覆盖输入转换与返回载荷。
#. **递归绑定。** 明确普通局部、词法外层、``<<-`` 和环境对象的可见范围。
#. **快照证明。** 显式复制和新对象重绑定都要验证历史结果不会被修改。
#. **恢复路径。** 临时标记在所有返回路径前恢复，哨兵排除在输入域之外。
#. **读写安全。** 遍历中覆盖证明写后不伤害未读数据，也不使迭代器失效。
