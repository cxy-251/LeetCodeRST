0096. Unique Binary Search Trees
--------------------------------

正向样本
~~~~~~~~

状态只记录节点数量。任意连续有序键集都能通过保持相对次序的重命名映射到 ``1..nodes``，BST 结构和
根位置划分不变，因此具体键值不是额外状态。

固定根位置后，左右子树使用互不相交的键区间，结构可以独立选择，贡献是两侧计数的乘积。不同根位置对应
不同左节点数量，结构集合互不重叠。``counts[0] = 1`` 把空树作为乘法单位元，使叶节点自然贡献一次组合。

固定宽实现使用 64 位状态或乘法中间值。题目保证 ``C_19`` 可转换为 32 位返回值，但乘法必须先在宽类型
中完成，不能让窄类型先溢出再转换。

可复用规则
~~~~~~~~~~

* 删除具体标签前证明同一摘要状态之间存在保持解集合的双射；
* 空选择作为递推单位元时，与公开空输入接口分层；
* 最终窄返回范围不能代替宽中间运算。

0097. Interleaving String
-------------------------

正向样本
~~~~~~~~

``state(i,j)`` 已经唯一确定目标前缀长度 ``i+j``。最后一个目标字符只能来自第一个来源的末字符或第二个
来源的末字符，两类转移覆盖全部交错路径。

一行压缩后，更新前的 ``dp[column]`` 是上一行同列状态，已经更新的 ``dp[column-1]`` 是当前行左邻居。
因此必须从左到右覆盖。交换两个来源字符串不改变问题，只让列维度选择较短字符串，将核心工作数组降为
``O(min(m,n))``。

确定性更正
~~~~~~~~~~

教程把 ``O(min(m,n))`` 写成统一额外空间结论，实际只描述核心布尔 DP 数组：

* C++ 接口按值接收 ``s1``、``s2``、``s3``，三个字符串副本同时存活，额外和峰值空间为
  ``O(m+n+|s3|)``；
* Julia 对两个来源调用 ``collect(codeunits(...))``，物化 ``O(m+n)`` 字节数组；目标字符串的
  ``codeunits`` 是轻量包装；
* R 对三个字符串调用 ``utf8ToInt``，物化 ``O(m+n+|s3|)`` 整数向量；
* Rust 消费拥有的 ``String`` 后转为字节向量，可复用原有缓冲区，不能与额外复制型适配器统一解释。

该问题不改变算法正确性，但属于确定性的完整空间复杂度偏差，已登记到 ``REVIEW_INDEX``。

可复用规则
~~~~~~~~~~

* 压缩 DP 的更新方向必须由旧同列和新邻居的依赖关系推导；
* 核心工作空间与参数复制、编码转换和容器物化分别报告；
* 峰值空间统计同时存活的输入副本、转换数组和 DP 数组。

0098. Validate Binary Search Tree
---------------------------------

正向样本
~~~~~~~~

完整中序序列严格递增是 BST 合法性的充要条件。显式栈产生真实中序次序，``previous`` 始终是当前节点的
直接中序前驱；任何全局非严格有序序列都存在相邻下降或相等见证，因此逐对检查不会遗漏跨层祖先约束。

``has_previous`` 与 ``previous`` 分离表达“尚无前驱”。这避免把 ``INT_MIN``、``typemin(Int)`` 等合法
输入值错误用作控制哨兵。比较使用 ``<=``，从而拒绝重复键。

可复用规则
~~~~~~~~~~

* 可选状态用独立标志、Option 或空引用表达，不与数据域混合；
* 用局部相邻见证证明全局性质前，先证明遍历覆盖与见证必然性；
* 严格序关系必须显式处理相等值。

0099. Recover Binary Search Tree
--------------------------------

正向样本
~~~~~~~~

严格递增序列中交换两个值后，相邻交换产生一次下降，非相邻交换产生两次下降。第一次下降的左端始终是
被放到过早位置的较大值，最后一次下降的右端始终是被放到过晚位置的较小值。因此 ``first`` 只在第一次
下降设置，``second`` 在每次下降更新。

算法完成整次中序扫描后才交换两个 ``val`` 字段。所有父子边、节点身份和树形均保持不变；C 的栈分配或
扩容失败发生在写入前，退出不会留下半完成修复。Rust 先读取两个值，再分别取得可变借用完成交换，避免
``RefCell`` 借用重叠。

可复用规则
~~~~~~~~~~

* 首次见证与最终见证可能采用不同更新策略，不能为了形式对称而统一；
* 修复仅针对值错误时，不重连正确拓扑；
* 尽量把不可逆写入延迟到完整见证和资源准备结束之后。

0100. Same Tree
---------------

正向样本
~~~~~~~~

递归状态是两个对应位置的节点对。双空返回真，单边空返回假；两者都非空时要求当前值相等，并同方向比较
左右孩子。该定义直接保留结构信息，不会把左右方向不同但值序列相同的树误判为相同。

对最大树高做结构归纳即可证明完整性。布尔短路在首个差异处停止，只减少实际访问量；两棵树完全相同时仍
比较全部对应节点，最坏时间 ``O(n)``，调用栈由较深树高度界定为 ``O(h)``。

可复用规则
~~~~~~~~~~

* 比较树或嵌套结构时以对应位置对作为递归状态；
* 空位置本身属于结构数据，值遍历不能替代结构比较；
* 左右子结构必须同方向配对，交叉配对属于镜像问题。

跨题归纳
--------

本批提升以下稳定模式：

* 计数状态删除具体标签前证明等价类和解集合双射；
* 宽中间运算先于窄返回转换；
* 一行 DP 的遍历方向由覆盖前后槽位语义决定；
* 核心工作空间与语言适配器物化分层；
* 控制状态不使用输入域内数据哨兵；
* 全局顺序性质通过完整遍历和相邻见证建立；
* 两值交换恢复使用第一次下降左端和最后一次下降右端；
* 写入延迟到完整见证收集结束；
* 成对结构递归保留 null 位置和左右方向。
