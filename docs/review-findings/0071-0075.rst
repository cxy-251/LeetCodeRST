0071. Simplify Path
-------------------

正向样本
~~~~~~~~

组件栈准确区分空组件、``.``、``..`` 和普通名称，根目录上的 ``..`` 不会继续弹出。C 实现用写入位置栈
回滚结果缓冲，避免为每个组件单独分配字符串；特殊语义只匹配完整组件，不会误处理 ``...`` 或
``.hidden``。

R 动态栈复杂度偏差
~~~~~~~~~~~~~~~~~~

R 实现使用：

.. code-block:: r

   stack <- c(stack, segment)
   stack <- stack[-length(stack)]

字符向量不是可摊还常数尾部操作的动态栈。每次拼接或删除都需要构造新向量并复制保留元素。若路径包含
``k`` 个短普通组件，连续入栈的累计复制量为 ``1+2+...+k``，最坏达到 ``Theta(k^2)``。峰值仍为
``O(k)``，但总时间和累计分配不能写成通用的 ``O(n)``。

前向规则
~~~~~~~~

* 栈抽象不能掩盖目标容器的真实尾部操作成本；
* 不可变或复制型向量反复扩展时，按每次当前长度累计复制；
* 路径特殊标记只在完整组件相等时生效；
* 字符串拆分、组件容器和最终连接分别计入峰值对象。

0072. Edit Distance
-------------------

正向样本
~~~~~~~~

前缀状态、插入、删除、替换三类最后操作，以及一行覆盖顺序均完整。``diagonal`` 保存左上旧值，
更新前的 ``dp[col]`` 是上方，更新后的 ``dp[col-1]`` 是左侧。把较短字符串放在列方向使核心 DP
工作数组为 ``O(min(m,n))``。

适配器物化空间
~~~~~~~~~~~~~~

核心滚动数组的空间界不能直接代表全部语言适配器：

* C++ 参数按值接收两个字符串，进入函数时已经复制 ``O(m+n)`` 字符；
* Julia 对两个 ``codeunits`` 调用 ``collect``，物化两个字节数组；
* R 对两个输入调用 ``utf8ToInt``，物化两个整数向量。

因此这些实现的算法 DP 状态仍为 ``O(min(m,n))``，但适配器额外空间和峰值空间为 ``O(m+n)``。
Julia 若直接保留 ``codeunits`` 包装视图，可以避免这两份输入副本。

前向规则
~~~~~~~~

* 区分核心状态压缩与输入适配器的复制或编码转换；
* 参数按值、``collect`` 和字符解码都属于额外物化空间；
* 对称交换只改变 DP 维度，不自动消除已经发生的输入复制；
* ASCII 字符域使字节索引正确，不代表字节视图一定零拷贝。

0073. Set Matrix Zeroes
-----------------------

正向样本
~~~~~~~~

四阶段顺序正确保存原始零见证：

#. 保存首行和首列是否原本含零；
#. 只扫描内部区域，把原始零投影到首列和首行；
#. 根据标记处理内部区域；
#. 最后处理首行和首列。

这保证算法新增的零不会继续触发额外行列。首行首列是可变标记区，两个布尔量消除了
``matrix[0][0]`` 同时代表行和列的歧义。

接口空间
~~~~~~~~

C、C++、Python、Java、Rust、Go、TypeScript、C# 和 Julia 直接修改调用者矩阵，核心额外状态为常数。
R 返回修改后的矩阵，调用者可观察的接口可能复制 ``O(mn)`` 数据；这不改变标记算法本身的
``O(1)`` 工作状态，但必须在适配器空间中单独说明。

前向规则
~~~~~~~~

* 复用输入作为标记区前，先保存即将被覆盖的原始边界信息；
* 标记收集与标记应用必须分阶段，避免新增值伪装成原始见证；
* 原地算法和返回副本适配器分别报告调用后副作用及空间；
* 单行、单列时内部区域为空，范围构造必须安全产生零次迭代。

0074. Search a 2D Matrix
------------------------

正向样本
~~~~~~~~

行内非递减和跨行严格边界合成全局有序序列。零基扁平位置通过 ``index/cols`` 和 ``index%cols``
一一映射到矩阵坐标，无需复制矩阵。Rust 使用半开 lower-bound 区间，避免无符号下标执行
``mid-1``；其他实现使用闭区间。

前向风险
~~~~~~~~

虚拟扁平二分依赖三个强前提：

* 矩阵非空且规则，每行列数相同；
* 下一行首元素严格大于上一行末元素；
* ``rows*cols`` 和下标换算在所选整数类型中安全。

若只有每行有序，扁平序列不一定全局有序；若元素总数乘积溢出，二分区间和坐标映射都会失效。

前向规则
~~~~~~~~

* 虚拟视图必须证明每个虚拟下标与底层位置一一对应；
* 全局二分必须由跨块边界条件证明整体单调；
* 元素总数乘积、终点下标和坐标换算统一做容量证明；
* 闭区间和半开区间各自使用完整一致的终止与移动规则。

0075. Sort Colors
-----------------

正向样本
~~~~~~~~

四段不变量完整：零区、一区、未知区和二区始终连续。处理 ``0`` 后换入值来自已分类前缀，可以同时推进
``low`` 与 ``current``；处理 ``2`` 后换入值来自未知区，所以只缩小 ``high``，必须复查当前位置。
未知区每轮严格缩短，交换保持数组多重集不变。

有限输入域
~~~~~~~~~~

多个实现使用 ``else`` 或 Rust ``_`` 把所有非 ``0``、非 ``1`` 的值当作 ``2``。在题目明确保证输入
只含 ``0``、``1``、``2`` 时完全正确。若接口未来允许其他整数，该分支会静默把非法值归入颜色 2，
因此这种兜底写法的正确性必须与精确输入域绑定。

前向规则
~~~~~~~~

* 默认分支表示唯一剩余值时，正文和测试锁定完整有限输入域；
* 右端交换后是否推进扫描指针，由换入元素来自已分类区还是未知区决定；
* 循环变式直接使用未知区长度，证明每轮严格减少；
* 原地验证同时检查排序结果、长度和元素多重集。

跨题统一归纳
------------

本批规则可以归并为六个检查动作：

#. **累计复制。** 动态复制型容器的反复扩展和删除按每轮长度求和。
#. **空间分层。** 核心算法工作状态与参数复制、字符物化和返回副本分别报告。
#. **见证保护。** 原地标记先保存原始证据，再分阶段写入和应用。
#. **虚拟视图。** 证明底层布局、映射双射、全局顺序和容量边界。
#. **输入域。** 默认分支代表唯一剩余值时锁定精确有限域。
#. **模板专用化。** 边界、易错点和自检必须全部针对当前问题。
