核心语言实现
~~~~~~~~~~~~

语言顺序固定为：C、C++、Python、Java、Rust、Go、TypeScript、C#、Julia、R。

语言语法、标准库 API 和类型语义的解释写在对应代码块内。短解释使用行尾注释；较长解释放到目标代码上一行。代码优先不超过 88 个显示列，任何行不超过 100 个显示列。

Python
^^^^^^

.. code-block:: python

   class Solution:
       def solve(self, values: list[int]) -> int:
           seen: set[int] = set()  # set 保存不重复元素

           for value in values:
               if value in seen:  # ``in`` 查询集合成员
                   return value
               seen.add(value)

           return -1

C++
^^^

.. code-block:: cpp

   class Solution {
   public:
       int solve(const std::vector<int>& values) {
           std::unordered_set<int> seen;

           for (const int value : values) {
               // insert 返回值中的 second 表示是否首次插入。
               const auto [iterator, inserted] = seen.insert(value);
               if (!inserted) {
                   return value;
               }
           }

           return -1;
       }
   };
