内容语言规范
============

总原则
------

本仓库面向中文读者。题目 RST 的讲解文字和代码注释统一使用简体中文。

中文内容范围
------------

以下内容必须使用中文：

* 题目重述；
* 问题抽象；
* 解法思路与正确性依据；
* 复杂度解释；
* 易错点；
* ``note``、``warning`` 和图后说明；
* Mermaid 节点中的解释性标签；
* 最小自检与答案要点；
* 所有语言代码块中的教学注释。

代码注释规则
------------

代码注释使用中文，重点解释：

* 当前语法或 API 的真实语义；
* 为什么选择这种写法；
* 状态或指针发生了什么变化；
* 容易写错的边界；
* 当前语言与其他语言实现的重要差异。

注释不得逐行翻译代码。短解释使用行尾注释；较长解释放在目标代码上一行。代码和注释优先控制在 88 个显示列以内，硬上限为 100。

.. code-block:: python

   seen: dict[int, int] = {}  # 键保存数值，值保存下标

   for index, value in enumerate(nums):
       need = target - value
       if need in seen:  # ``in`` 查询字典中的键
           return [seen[need], index]

保留英文的内容
--------------

以下内容保留官方或语言本身的英文形式：

* LeetCode 官方英文题名；
* 文件名中的英文 slug；
* 变量名、函数名、类名和类型名；
* 编程语言关键字；
* 标准库、API 和包名；
* 原始错误信息；
* 复杂度符号，例如 ``O(n)``；
* 无法准确翻译的正式技术名称。

代码标识符保持语言惯用的英文命名，不使用中文变量名。

术语写法
--------

重要术语第一次出现时，优先采用“中文名称（英文名称）”形式，例如：

* 哈希表（hash table）；
* 双端队列（deque）；
* 所有权（ownership）；
* 多重派发（multiple dispatch）。

后续正文直接使用中文名称。API、类型或关键字继续使用英文，并用双反引号标记。

Mermaid 语言
------------

Mermaid 的解释性标签使用中文，变量名和代码中的对象名保持原样。

.. mermaid::

   flowchart LR
       A["前驱 prev"] --> B["当前节点 current"]
       B --> C["后继 next"]

图后的文字说明使用中文，并指出读者需要观察的状态、指针或边。

题目标题
--------

题目顶级标题保留编号和官方英文题名，例如：

.. code-block:: rst

   0001. Two Sum
   =============

正文标题使用中文，例如“问题抽象”“主解法”“易错点”。

检查清单
--------

#. RST 正文是否以中文完成；
#. 代码中的教学注释是否全部为中文；
#. 标识符是否保持语言惯用的英文命名；
#. 首次出现的重要术语是否给出必要的英文原名；
#. Mermaid 解释标签和图后说明是否使用中文；
#. 是否避免了无意义的中英文混杂句子。
