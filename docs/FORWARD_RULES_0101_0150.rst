0101–0150 前向质量规则
=====================

适用范围
--------

本文件把以下内容归并为 ``0101`` 至 ``0150`` 的单一执行规则：

* ``docs/FORWARD_RULES_0051_0100.rst`` 中已经稳定的首轮规则；
* ``0051`` 至 ``0100`` 十个第二轮审查批次提升的 81 条规则；
* ``state/REVIEW_INDEX.toml`` 中当前生效的事实更正；
* ``docs/REVIEW_AND_PREVENTION_POLICY.rst`` 中的证据、历史题和静态审查边界。

从 ``0101`` 开始，生成单题时应直接读取本文件，不需要逐份拼接十个第二轮批次。批次记录和详细 findings
继续作为证据与来源追溯资料。若本文与事实更正冲突，以 ``state/REVIEW_INDEX.toml`` 的 active correction
为准。

执行顺序
--------

每道题按以下顺序完成：

#. 精确题目契约与平台接口；
#. 状态、转移和算法选择；
#. 正确性证明与终止性；
#. 十语言实现和语言适配器；
#. 数值、容量、资源、所有权和失败路径；
#. 完整时间、工作空间、物化空间、返回载荷与峰值空间；
#. 静态审查证据、未运行未编译声明和剩余风险；
#. RST、题目索引、进度和知识账本同步。

一、题目契约与输入域
--------------------

精确契约
~~~~~~~~

#. 写明长度、数值、字符集合、结构形状、输入合法性、输出顺序和输入是否允许修改。
#. 公开函数名、参数、返回类型、平台节点模型和辅助函数必须与真实平台接口一致。
#. 非空、等长、方阵、规则矩阵、无环、唯一父节点、节点不共享、已排序和两两不重叠等前提集中列出。
#. 官方输入域与主动支持的扩展分别定义；空输入、零维和单元素扩展不得默认继承原条件。
#. ``else``、默认或通配分支代表唯一剩余值时，必须由题意、类型或运行检查锁定完整有限输入域。
#. 抽象覆盖端点、插入位置、半开终点可以位于容器外；只有经过真实下标检查后才能读取元素。
#. 字符串题固定比较单位与返回下标单位：字节、UTF-16 代码单元、码点或字形簇。
#. 数字字符串写明字符域、零的表示、前导零、符号、小数点和指数规则。
#. 有效前缀接口定义返回长度、允许读取的前缀和尾部未定义区域。
#. 原地接口分别声明调用者可观察的对象修改、返回值和资源责任。

强前提降阶
~~~~~~~~~~

#. 利用已排序、不重叠、方阵、固定字符域或可达区间闭包降低复杂度时，证明该前提具体删除了哪些工作。
#. 输入前提弱化后，不得沿用原算法、复杂度或局部守卫。
#. 把离散状态压缩为连续前缀或区间前，证明每个动作覆盖全部中间端点；固定长度动作产生空洞时保留离散状态。
#. 只检查一个维度却访问另一维边界时，证明形状或同步收缩使两个条件等价。

二、状态、转移与证明
------------------

统一证明要求
~~~~~~~~~~~~

#. 状态含义直接对应代码变量和数组槽位。
#. 循环或递归入口写出不变量；更新后证明不变量保持。
#. 正确性至少覆盖合法性、完整性、无重复、终止性和接口副作用。
#. 证明真实算法决策，不逐行复述代码。
#. 采用替代算法的语言重新证明语义和复杂度，不以输出样例代替等价性证明。
#. 一个核心推导只完整出现一次，后续关联题引用结论并补充新增边界。

状态摘要与可选状态
~~~~~~~~~~~~~~~~~~

#. 删除具体标签、键值、坐标或身份前，证明同一摘要状态实例之间存在保持解集合的双射。
#. 非空优化问题从首个合法候选初始化，或使用显式不存在状态；不得用非法的空答案或零改变全负等边界。
#. “尚未初始化、无前驱、无边界”使用布尔标志、``Option`` 或可空引用，不使用输入域内普通值作哨兵。
#. 语法扫描中某标记触发后续必需成分时，建立独立待满足见证；触发时重置，合法成分出现时恢复，结束时检查。
#. 强制 token 或字符对先整体验证，再证明其消费边界、跨界阻断和剩余片段独立性。

动态规划与记忆化
~~~~~~~~~~~~~~~~

#. DP 证明状态充分、转移完整、初始化正确和遍历顺序合法。
#. 一维覆盖二维 DP 时，逐项标明旧同列、旧对角、新左邻或新右邻的语义，并由依赖边决定更新方向。
#. 把较短维度作为滚动数组时，交换后的行列角色、字符位置和复杂度符号同步更新。
#. 滚动标量先保存会被覆盖的旧值，或使用真正的并行赋值。
#. 记忆化键包含决定子问题语义的全部坐标、长度、剩余额度和模式；省略字段前证明可唯一恢复。
#. 未计算、成功和失败状态分离；失败结果同样缓存。
#. 必要条件剪枝只能提前否定，多重集、频次或奇偶性相同通常不构成充分条件。
#. 固定段数回溯使用“剩余段数 × 单段最小/最大长度”的双界，并由该界证明完成深度时输入恰好耗尽。
#. 候选使用 ``break`` 时，证明后续扩展在目标度量上单调不可能恢复合法；否则使用 ``continue``。

计数、上界与截断
~~~~~~~~~~~~~~~~

#. 空结构作为递归组合单位元时，内部返回“包含一个空对象的选择列表”；公开空输入返回值单独定义。
#. 固定根、左右子结构或独立片段使用乘法组合时，证明笛卡尔积双射和不同分支互斥。
#. 用最终答案界定中间状态前，给出中间对象到最终对象的单射、单调扩展或递推单调性。
#. 障碍、删除、抵消、死路或吸收状态可能让中间值大于最终值，必须独立确定中间上界。
#. 使用饱和或截断 DP 时，证明截断算子与全部转移兼容，并证明最终真实答案严格低于阈值。
#. 片段计数乘法用最终答案保护中间值时，证明局部计数单调、各因子至少为一、部分乘积不超过最终乘积。
#. 组合秩选择写明一基到零基、块大小、商的下标范围、模后的新秩和阶乘中间宽度。

三、搜索、顺序与边界证书
----------------------

二分与比较信息
~~~~~~~~~~~~~~

#. 二分统一搜索区间、谓词、移动方向、排除安全性、终止条件和返回语义。
#. 闭区间和半开区间不得混用 ``mid-1``、``mid+1`` 与最终返回规则。
#. 无符号 ``mid-1`` 仅在 ``mid>0`` 且仍符合区间方案时执行。
#. lower bound 与 upper bound 明确相等元素归属哪一侧。
#. 重复值、哈希碰撞或等价类降低区分能力时，分别给出通常和最坏复杂度。
#. 消歧收缩只能删除已经证明不可能等于目标的对象。
#. 用除法或重排替代可能溢出的乘法时，证明符号、非零分母和目标语言整数除法方向。

相邻见证与全局顺序
~~~~~~~~~~~~~~~~~~

#. 用相邻下降证明全局有序或定位异常前，证明遍历覆盖全部对象，且任意全局违规必然产生相邻见证。
#. 严格有序使用 ``<=`` 拒绝重复；只在题目保证互异并定位下降时使用 ``>``。
#. 恢复严格递增序列中的两值交换时，第一次下降保存左端，之后每次下降更新右端，并覆盖一次与两次下降。
#. 有序连续段处理先定义每段保留零个、一个或至多 ``q`` 个对象，再设计前驱推进和段提交。
#. 相邻比较只有在有序输入中才能代表整段性质。

滑动窗口、双指针与单调栈
~~~~~~~~~~~~~~~~~~~~~~~~

#. 双指针移动一端时，证明被排除的整批候选不能产生更优答案。
#. 滑动窗口的计数状态必须处理目标元素重复次数；收缩只删除已证明不可能更优的左边界。
#. 单调栈弹栈时同时证明当前元素是右侧首个阻断位置、弹栈后栈顶是左侧最近阻断位置、区间内部合法。
#. 等值元素使用严格或非严格弹栈时，说明哪一个代表获得最大范围。
#. 虚拟哨兵只触发结算，不修改只读输入；哨兵下标入栈时证明之后不会读取真实数组该位置。
#. 摊还复杂度单独计算每个元素入栈、出栈、进入窗口和离开窗口次数。

四、回溯、枚举与构造
------------------

递归共享状态
~~~~~~~~~~~~

#. 明确状态绑定在当前调用帧、词法外层、superassignment 目标、显式环境还是引用对象。
#. R 普通 ``x[i] <- value`` 只更新当前调用帧的局部绑定，递归子调用不会自动继承父调用帧修改。
#. R 需要共享状态时使用显式参数、``environment`` 或经过审计的 ``<<-``，并重新计算复制成本。
#. 所有语言区分共享对象元素修改与局部变量重绑定。
#. 高风险闭包、范围、位运算、写时复制和所有权路径按语言规范静态核对；无法确认时标记剩余风险。

快照、去重与输出
~~~~~~~~~~~~~~~~

#. 保存答案后证明历史结果不会被后续选择或撤销修改；来源可以是显式复制、不可变对象或安全重绑定。
#. 静态检查多个可变树、图、路径或矩阵行没有共享后续会修改的节点或数组。
#. 重复值去重限定在同一递归层，定义保留的规范代表，并证明保留分支覆盖被跳过兄弟。
#. 严格递增下标、选择向量或其他规范编码需要建立结果与搜索路径的双射。
#. 枚举复杂度分别记录结果行数、元素总载荷、快照复制、当前路径、递归栈和元数据。
#. 组合数、``2^n``、Catalan 数或选择向量用于预分配时，验证最终容量、乘法、位移和终点下标。

闭式构造
~~~~~~~~

#. 闭式序列分别证明值域、局部相邻关系、单射或可逆性、完整覆盖和循环首尾条件。
#. 输出长度和样例不能替代构造证明。
#. 单元素编码为单字符时证明值域小于 token 上限；扩展到多位元素时重新定义输出和字典序。

五、原地修改、拓扑与所有权
------------------------

读写前沿与阶段提交
~~~~~~~~~~~~~~~~~~

#. 正向覆盖证明 ``write`` 不领先尚未读取位置；逆向覆盖证明写位置越过同容器全部未读元素。
#. 覆盖前保存当前值，遍历期间不改变容器长度，不使迭代器失效。
#. 复用输入区域作为标记前，保存会被覆盖的原始见证，再按收集标记、应用内部、处理边界分阶段执行。
#. 算法新增标记不得被后续扫描误认为原始输入见证。
#. 不可逆写入延迟到完整见证收集和资源申请成功后；失败或提前退出不得留下部分修改。

临时修改与恢复
~~~~~~~~~~~~~~

#. 临时环、线索、哨兵链接、访问标记或字符哨兵列出进入点、统一恢复点和全部退出路径。
#. 成功、失败和短路路径都经过恢复；新增提前返回必须位于修改前或先恢复。
#. 哨兵值证明位于合法输入域之外。
#. 所有权语言按值拥有局部副本时，区分内部恢复与调用者可观察的恢复义务。

链表与树拓扑
~~~~~~~~~~~~

#. 链表区间重连列出前驱、固定尾、被移动节点和后缀的修改前后边。
#. 证明节点身份守恒、节点数量、目标区间外顺序、连通性、无重复和无环。
#. 稳定分区同时证明值分类和各分区内部原相对顺序。
#. 节点离开原链时断开旧边，或提供等价的最终尾部终止证明。
#. 节点不可达、立即释放、自动析构、调用者释放和垃圾回收是不同资源结论。
#. 不使用访问集合的树遍历声明无环、唯一父节点和无共享子树；扩大为图或 DAG 时增加访问机制。
#. 显式栈说明每个元素保存的递归续点、提交节点时机和弹栈后的下一子问题。
#. 比较两棵树或嵌套结构时，以对应位置对为状态，同时保留 null 位置和左右方向。

所有权替代算法
~~~~~~~~~~~~~~

#. 十语言实现同一问题语义，不要求逐语句同构。
#. Rust 等所有权语言采用取出区间、线性拼接或消费输入缓冲区时，重新证明节点身份、修改范围和峰值空间。
#. 输入不变性按调用者返回后仍可观察的对象定义；独占消费后的容器允许复用为结果。
#. ``clone``、``take``、``Rc`` 克隆、借用和移动分别说明是否复制载荷、只增加引用计数或转移所有权。

六、树、图、矩阵与虚拟视图
------------------------

#. 虚拟扁平索引、窗口或坐标视图证明映射双射、底层布局、全局顺序、元素总数乘积和坐标换算安全。
#. 行内有序合成全局有序时，证明相邻块边界严格满足全局顺序条件。
#. 高维问题降为逐层低维状态时，证明编码不变量、每个原对象在哪一层完整覆盖，以及低维候选反向合法。
#. 方阵成立的边界守卫不能复制到矩形；规则矩阵前提必须覆盖所有行长度。
#. 二维输出每一行独立分配或独立拥有，禁止复用同一可变行对象。
#. 工作栈按树高或同时存活的搜索前沿计费，不无条件写成节点总数。

七、数值、容量与失败语义
----------------------

数值宽度
~~~~~~~~

#. 危险算术先扩宽操作数，再执行加法、乘法、取负、绝对值、移位和面积计算。
#. 最终返回值可窄化时，中间表达式仍在宽类型中完成；最终范围不能修复已发生的溢出。
#. 数值安全覆盖临时候选、累计状态、剪枝边界、容量表达式和最终窄化。
#. 聚合上界由元素数量乘单项最大贡献推导。
#. 路径和按单条合法路径实际访问元素数计算，不按状态空间总元素数计算。
#. TypeScript 静态核对安全整数范围；整数算法避免未审计的隐式 32 位位运算。
#. 平台 ``int``、``Int`` 和无符号类型位宽与输入上界一致。

容量与分配
~~~~~~~~~~

#. 固定缓冲容量包含载荷、终止符、分隔符、哨兵和元数据。
#. 元素数量乘元素大小、矩阵尺寸、容量翻倍和阶乘乘法使用容量类型逐步检查。
#. C 在首次写入前检查初始分配；``realloc`` 使用临时指针。
#. 多缓冲、二维结果、路径和元数据采用整体成功或整体清理。
#. 顺序容器中间删除按后缀移动或复制成本计算，不能视为 ``O(1)``。
#. 复制型或不可变容器反复拼接、负下标删除或切片重建时，按每轮当前长度累计成本。

失败语义
~~~~~~~~

#. 资源失败值与合法 ``false``、``0``、空结果或部分答案区分；无法区分时明确接口限制。
#. 已分配资源在全部失败路径完整清理。
#. 非空解包、``unwrap``、``something`` 和断言由紧邻的不变量或见证支撑。
#. 平台 ``void`` 原地接口发生资源失败时，保证没有部分修改，或明确无法报告的限制。

八、字符串、标准库与适配器物化
----------------------------

字符串与字符单位
~~~~~~~~~~~~~~~~

#. ASCII 字节实现由精确字符域支撑；扩展到 Unicode 后重新选择索引和长度单位。
#. 字符串逻辑只访问后缀，不代表运行时只扫描后缀；``strlen``、trim、split、编码转换和索引建立均计费。
#. ``codeunits``、``collect``、``charToRaw``、``utf8ToInt``、切片和重新编码按真实语义区分视图与副本。
#. 循环内常量分类码、正则或整串转换移到热循环外。
#. 字符串长度查询不是统一常数时间，按目标语言和调用次数计算。

核心空间与适配器空间
~~~~~~~~~~~~~~~~~~~~

#. 分别报告算法核心工作状态、参数按值复制、字符物化、临时切片、返回副本和峰值并存。
#. 一行 DP 的 ``O(min(m,n))`` 只描述滚动数组，不能覆盖 C++ 按值字符串、Julia ``collect`` 或 R ``utf8ToInt``。
#. 固定频次数组或常数指针只描述窗口核心，不覆盖完整输入转换。
#. R 返回修改后的完整向量或矩阵时，算法工作状态可为常数，接口返回载荷仍为线性或矩阵规模。

视图、子串与输出缓冲
~~~~~~~~~~~~~~~~~~~~

#. 返回子串区分共享底层存储、不可变别名和新分配副本。
#. Go ``s[start:end]`` 可能保留完整原字符串；需要独立存储时使用 ``strings.Clone`` 并声明最低版本。
#. 输出缓冲说明最终结果是否直接采用，或在 reverse、join、``toString``、冻结和重新编码时产生第二份载荷。
#. 必须物化固定宽度、多行或大型集合输出时，时间包含写出全部载荷的不可避免下界。
#. 只复制引用的切片仍属于临时容器空间。

标准排序与标准库
~~~~~~~~~~~~~~~~

#. 标准排序分别记录输入是否重排、稳定性需求、平均/最坏时间、辅助缓冲和递归栈。
#. 不得用抽象“原地排序”统一覆盖 Python、Java、JavaScript、C ``qsort`` 等运行库。
#. 特定版本新增 API 的最低版本、代码说明和声明的目标环境一致。
#. 跨题复用 helper、构造器、导入、包和返回类型必须与真实定义精确一致。

九、十语言必须单独检查的事项
--------------------------

C
~

* 所有分配、扩容、二维结果和失败清理形成闭合事务。
* 比较器使用关系比较，避免减法溢出。
* 节点断链与释放责任按平台所有权说明。
* 容量、返回行数和列长度元数据同步维护。

C++
~~~

* 按值参数复制、引用生命周期和输入重排分别说明。
* ``size_t`` 与有符号索引转换由精确上界支撑。
* 标准容器与算法包含直接头文件，比较器满足严格弱序。

Python
~~~~~~

* 切片、列表复制、路径快照、字符串构造和递归深度计入成本。
* 任意精度整数能力不能外推到固定宽语言。
* 版本相关 API 和类型注解环境明确。

Java 与 C#
~~~~~~~~~~

* 危险中间值先提升到 ``long``。
* 集合、装箱、对象数组排序缓冲、字符串复制和递归计入成本。
* 对象字段在公共入口初始化或清空，导入与运行时版本完整。

Rust
~~~~

* 代码符合真实借用检查，不以伪代码绕过所有权。
* ``take``、``clone``、``Rc``、``RefCell`` 和消费输入的载荷与峰值明确。
* 无符号递减使用显式分支或有符号控制坐标。
* 字节字符串操作由 ASCII 契约支撑。

Go
~~

* ``int`` 位宽由平台前提或固定宽类型支撑。
* 切片共享、``append`` 扩容、子串保留和 ``strings.Clone`` 语义明确。
* 版本相关预声明函数与最低 Go 版本一致。

TypeScript / JavaScript
~~~~~~~~~~~~~~~~~~~~~~~

* ``number`` 安全整数和位运算 32 位转换独立静态核对。
* ``Map.get`` 的 ``undefined`` 与合法零值分开。
* 字符串下标按 UTF-16 代码单元解释。
* 手工核对静态类型约束与 JavaScript 运行时语义，不调用类型检查器或运行代码。

Julia
~~~~~

* 一基数组槽位与零基算法坐标逐项映射。
* ``a:b`` 是步长 ``+1`` 的 ``UnitRange``，``a>b`` 时为空；递减遍历使用显式负步长。
* ``codeunits(s)`` 是轻量 ``CodeUnits`` wrapper；只有 ``collect(codeunits(s))`` 才物化数组。
* ``Vector`` 参数采用共享可变对象语义，元素修改对调用者可见。
* ``collect``、切片、字符串重建和宿主 ``Int`` 位宽单独说明。

R
~

* 普通复杂赋值绑定到当前调用帧；递归共享状态使用参数、环境或审计后的 ``<<-``。
* ``seq.int`` 的端点与步长方向在构造前静态核对；不能依赖 C 风格零次循环。
* ``utf8ToInt``、``charToRaw``、``c`` 拼接、负下标删除、矩阵更新和返回副本计入真实复制成本。
* 反复 ``c`` 追加与删除可能具有平方级累计复制，即使峰值容器仍为线性。
* 形式参数局部更新不保证修改调用者变量；需要返回修改后的适配器结果。
* 无法表达平台原地接口时，正文明确其为返回值适配器。

--------------------

每道题完成前必须满足：

#. 契约支撑所有索引、字符、数值、形状、所有权和特殊输入假设。
#. 核心状态、转移、更新方向和终止性与十语言代码一致。
#. 证明覆盖合法性、完整性、无重复和真实副作用。
#. 数值、容量、分配、失败、恢复和生命周期路径闭合。
#. 复杂度分开报告核心工作、适配器物化、输出载荷、累计复制和峰值空间。
#. 所有结果快照、树、矩阵行和链表节点满足要求的身份独立性。
#. 标准库、版本、导入、helper 和平台节点模型可解析。
#. 不运行或编译题解代码，不执行固定案例、随机对拍、穷举、属性测试、sanitizer 或最小程序。
#. 人工推演示例与关键边界，逐语言静态核对接口、索引、语法、位宽、所有权和字符语义。
