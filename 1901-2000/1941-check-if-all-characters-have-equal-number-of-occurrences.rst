1941. Check if All Characters Have Equal Number of Occurrences
=============================================================

题目信息
--------

:题号: 1941
:难度: Easy
:主题: 字符串、计数
:原题: `LeetCode 1941 <https://leetcode.com/problems/check-if-all-characters-have-equal-number-of-occurrences/>`_
:重点: 只比较字符串中实际出现字符的频次

题目重述
--------

判断字符串中每一种出现过的字符，其出现次数是否完全相同。

自建示例
--------

.. code-block:: text

   输入：s = "aabbcc"
   输出：true
   解释：a、b、c 都出现两次。

.. code-block:: text

   输入：s = "abac"
   输出：false
   解释：a 出现两次，b 和 c 各出现一次。
