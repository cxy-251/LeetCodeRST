1923. Longest Common Subpath
============================

题目信息
--------

:题号: 1923
:难度: Hard
:主题: 二分查找、滚动哈希
:原题: `LeetCode 1923 <https://leetcode.com/problems/longest-common-subpath/>`_
:重点: 寻找所有路径都包含的最长连续城市序列

题目重述
--------

每条路径是城市编号序列。返回一个连续子路径的最大长度，使该子路径在每条给定路径中都连续出现。

自建示例
--------

.. code-block:: text

   输入：n = 5, paths = [[0,1,2,3],[2,3,4],[1,2,3]]
   输出：2
   解释：连续子路径 [2,3] 出现在全部路径中。

.. code-block:: text

   输入：n = 4, paths = [[0,1],[2,3]]
   输出：0
   解释：两条路径没有共同城市。
