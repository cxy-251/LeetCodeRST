1982. Find Array Given Subset Sums
=================================

题目信息
--------

:题号: 1982
:难度: Hard
:主题: 分治、排序、哈希计数
:原题: `LeetCode 1982 <https://leetcode.com/problems/find-array-given-subset-sums/>`_
:重点: 根据全部 ``2^n`` 个子集和恢复任意一个原数组

题目重述
--------

给定未知长度 ``n`` 数组的所有子集和，顺序任意且可重复。返回任意一个能够产生这些子集和的长度 ``n`` 数组。

自建示例
--------

.. code-block:: text

   输入：n = 2, sums = [-3,-2,-1,0]
   输出：[-1,-2]
   解释：数组 [-1,-2] 的子集和为 0、-1、-2、-3。

.. code-block:: text

   输入：n = 1, sums = [0,5]
   输出：[5]
   解释：空集和为 0，唯一非空子集和为 5。
