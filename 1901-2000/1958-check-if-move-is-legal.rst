1958. Check if Move is Legal
============================

题目信息
--------

:题号: 1958
:难度: Medium
:主题: 矩阵、方向枚举、模拟
:原题: `LeetCode 1958 <https://leetcode.com/problems/check-if-move-is-legal/>`_
:重点: 新棋子需与同色棋子在某方向夹住至少一个异色棋子

题目重述
--------

在 8×8 棋盘的空位放置指定颜色棋子。若某个水平、垂直或对角方向上，放置点与另一枚同色棋子之间存在一个或多个连续异色棋子，则该步合法。

自建示例
--------

.. code-block:: text

   输入：board = ["........","........","........","...BW...","........","........","........","........"], rMove = 3, cMove = 5, color = "B"
   输出：true
   解释：向左依次遇到 W、B，异色棋子被两枚黑棋夹住。

.. code-block:: text

   输入：board = ["........","........","........","........","........","........","........","........"], rMove = 4, cMove = 4, color = "W"
   输出：false
   解释：棋盘没有另一枚同色棋子可形成夹击。
