1932. Merge BSTs to Create Single BST
====================================

题目信息
--------

:题号: 1932
:难度: Hard
:主题: 二叉搜索树、深度优先搜索、哈希表
:原题: `LeetCode 1932 <https://leetcode.com/problems/merge-bsts-to-create-single-bst/>`_
:重点: 每次把一棵树的根嫁接到另一棵树同值叶节点，最终必须形成合法 BST

题目重述
--------

给定若干小型二叉搜索树。可以把一棵树的根与另一棵树中同值叶节点合并，每棵树必须恰好使用一次。返回合并后的合法二叉搜索树根；无法完成返回空。

自建示例
--------

.. code-block:: text

   输入：trees = [[2,1],[3,2]]
   输出：[3,2,null,1]
   解释：把根为 2 的树接到根为 3 的树的左叶节点 2 上，得到合法 BST。

.. code-block:: text

   输入：trees = [[2,1],[1,null,3]]
   输出：[]
   解释：合并后值 3 会位于根 2 的左子树中，违反 BST 条件。
