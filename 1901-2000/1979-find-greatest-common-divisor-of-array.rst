1979. Find Greatest Common Divisor of Array
==========================================

题目信息
--------

:题号: 1979
:难度: Easy
:主题: 数组、最大公约数
:原题: `LeetCode 1979 <https://leetcode.com/problems/find-greatest-common-divisor-of-array/>`_
:重点: 只需计算数组最小值与最大值的最大公约数

题目重述
--------

找到数组中的最小元素和最大元素，返回二者的最大公约数。

自建示例
--------

.. code-block:: text

   输入：nums = [2,5,6,9,10]
   输出：2
   解释：最小值为 2，最大值为 10，最大公约数为 2。

.. code-block:: text

   输入：nums = [7]
   输出：7
   解释：最小值与最大值都是 7。
