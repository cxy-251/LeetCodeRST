1901. Find a Peak Element II
============================

题目信息
--------

:题号: 1901
:难度: Medium
:主题: 矩阵、二分查找
:原题: `LeetCode 1901 <https://leetcode.com/problems/find-a-peak-element-ii/>`_
:重点: 峰值严格大于上下左右相邻元素，返回任意峰值坐标

题目重述
--------

在矩阵中寻找一个元素，使它严格大于存在的上、下、左、右邻居。返回任意满足条件的 ``[row,col]``。

自建示例
--------

.. code-block:: text

   输入：mat = [[1,4],[3,2]]
   输出：[0,1]
   解释：元素 4 大于左侧 1 和下方 2。

.. code-block:: text

   输入：mat = [[7]]
   输出：[0,0]
   解释：单个元素没有相邻元素，因此是峰值。
