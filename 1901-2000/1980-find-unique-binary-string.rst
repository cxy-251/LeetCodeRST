1980. Find Unique Binary String
==============================

题目信息
--------

:题号: 1980
:难度: Medium
:主题: 字符串、集合、构造
:原题: `LeetCode 1980 <https://leetcode.com/problems/find-unique-binary-string/>`_
:重点: 返回任意一个长度为 ``n`` 且不在输入集合中的二进制串

题目重述
--------

给定 ``n`` 个互不相同、长度都为 ``n`` 的二进制字符串，返回任意另一个长度为 ``n``、未出现在数组中的二进制字符串。

自建示例
--------

.. code-block:: text

   输入：nums = ["00","01"]
   输出："10"
   解释："10" 长度为 2 且不在输入中；"11" 也可接受。

.. code-block:: text

   输入：nums = ["0"]
   输出："1"
   解释：长度 1 的另一个二进制串为 "1"。
