1970. Last Day Where You Can Still Cross
=======================================

题目信息
--------

:题号: 1970
:难度: Hard
:主题: 并查集、二分查找、矩阵
:原题: `LeetCode 1970 <https://leetcode.com/problems/last-day-where-you-can-still-cross/>`_
:重点: 每天一个陆地格变水，求仍可从顶行走到达底行的最后一天

题目重述
--------

初始网格全为陆地，第 ``i`` 天 ``cells[i]`` 指定格子变为水。只能上下左右经过陆地，返回仍存在顶行到底行路径的最后一天编号。

自建示例
--------

.. code-block:: text

   输入：row = 2, col = 2, cells = [[1,1],[2,1],[1,2],[2,2]]
   输出：2
   解释：第 2 天仍可沿第二列穿过，第 3 天顶行全部被水淹没。

.. code-block:: text

   输入：row = 1, col = 1, cells = [[1,1]]
   输出：0
   解释：第 1 天唯一格子变水，因此只能在第 0 天穿过。
