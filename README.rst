LeetCode 多语言代码仓库
========================

本仓库按 LeetCode 题号顺序整理多语言算法代码。每道公开算法题对应一个自包含 RST 文件，在同一文件中提供固定语言顺序的代码，并配少量必要说明，方便读者复制、运行、调试和自行验证。

项目目标
--------

* 按题号递增推进；
* 普通算法题覆盖 C、C++、Python、Java、Rust、Go、TypeScript、C#、Julia 和 R；
* 每道公开算法题使用一个自包含 RST 文件；
* 题解以代码为主，说明文字服务于接口、思路、复杂度和必要语言差异；
* 代码验证由读者在本地或 LeetCode 环境中完成；
* Premium、Database、Shell 或题面信息不足的题目只做进度登记；
* 单题文件直接内联全部代码和必要说明。

控制文件
--------

本仓库使用三个控制文件：

* ``README.rst``：仓库简介、目标和目录结构；
* ``AGENTS.md``：ChatGPT/Codex 生成和修改题解代码的规则；
* ``PROGRESS.rst``：下一次对话接续任务、当前入口和已完成范围。

范围目录中的 ``README.rst`` 只作为题目索引。

目录结构
--------

题解按百题范围放置：

* ``0001-0100/``；
* ``0101-0200/``；
* ``0201-0300/``。

每个范围目录包含该范围的题解 RST 和一个范围索引 ``README.rst``。新题跨过百题边界时，进入新的百题目录。

题解最低形态
------------

公开算法题的 RST 至少包含：

#. 题号、英文题名和文件标题；
#. 必要的平台接口或输入输出说明；
#. 固定十语言代码；
#. 必要时保留很短的思路、复杂度或语言差异说明。

执行入口
--------

新的 ChatGPT/Codex 对话按顺序读取：

#. ``README.rst``；
#. ``AGENTS.md``；
#. ``PROGRESS.rst``；
#. 当前题号所属范围的 ``README.rst``；
#. 当前要生成或修改的题解文件。
