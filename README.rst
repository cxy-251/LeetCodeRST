LeetCode 多语言分析题解仓库
============================

本仓库按 LeetCode 题号顺序整理多语言算法题解。每道公开算法题对应一个自包含 RST 文件，用分析讲清题目、算法和关键状态，再给出十语言实现。

项目目标
--------

* 按题号递增推进；
* 普通算法题覆盖 C、C++、Python、Java、Rust、Go、TypeScript、C#、Julia 和 R；
* 每道公开算法题使用一个自包含 RST 文件；
* 题解以分析为骨架，以代码为落点；
* 分析围绕题目契约、问题抽象、解法取舍、关键状态、正确性理由、复杂度和必要语言差异展开；
* 代码由读者在本地或 LeetCode 环境中运行和验证；
* Premium、Database、Shell 或题面信息不足的题目只做进度登记。

控制文件
--------

本仓库使用三个控制文件：

* ``README.rst``：说明仓库目标、产物形态和目录结构；
* ``AGENTS.md``：长期稳定的题解书写与任务执行规则；
* ``PROGRESS.rst``：面向下一次对话的当前任务接力单。

范围目录中的 ``README.rst`` 只维护该范围的题目索引。

接续方式
--------

每次新对话按以下方式接续：

#. 先读 ``PROGRESS.rst``，确认本轮要完成的题号、目标文件和任务范围；
#. 再读 ``AGENTS.md``，按统一规则组织分析和十语言代码；
#. 读取当前范围索引以及 ``PROGRESS.rst`` 指定的参考题解；
#. 完成本轮题解并同步范围索引；
#. 重写 ``PROGRESS.rst``，把它更新为下一次对话的任务说明。

``PROGRESS.rst`` 始终描述下一轮，不作为历史日志累积本轮过程。

目录结构
--------

题解按百题范围放置：

* ``0001-0100/``；
* ``0101-0200/``；
* ``0201-0300/``。

每个范围目录包含该范围的题解 RST 和一个范围索引 ``README.rst``。题号跨过百题边界时，在新的百题目录中继续。
