LeetCode 多语言分析题解仓库
============================

本仓库按 LeetCode 题号顺序整理多语言算法题解。每道公开算法题对应一个自包含 RST 文件，目标不是只堆代码，而是用清晰的分析把题目、算法、关键状态和十语言实现串起来。

项目目标
--------

* 按题号递增推进；
* 普通算法题覆盖 C、C++、Python、Java、Rust、Go、TypeScript、C#、Julia 和 R；
* 每道公开算法题使用一个自包含 RST 文件；
* 题解以分析为骨架，以代码为落点；
* 分析重点放在题目契约、解法取舍、关键状态、正确性理由、复杂度和必要语言差异；
* 代码验证由读者在本地或 LeetCode 环境中完成；
* Premium、Database、Shell 或题面信息不足的题目只做进度登记；
* 单题文件直接内联全部分析、代码和必要说明。

控制文件
--------

本仓库使用三个控制文件：

* ``README.rst``：仓库简介、目标和目录结构；
* ``AGENTS.md``：ChatGPT/Codex 生成和修改题解时遵守的写作规则；
* ``PROGRESS.rst``：下一次对话接续任务、当前入口和已完成范围。

范围目录中的 ``README.rst`` 只作为题目索引。

目录结构
--------

题解按百题范围放置：

* ``0001-0100/``；
* ``0101-0200/``；
* ``0201-0300/``。

每个范围目录包含该范围的题解 RST 和一个范围索引 ``README.rst``。新题跨过百题边界时，进入新的百题目录。

题解形态
--------

公开算法题的 RST 通常包含：

#. 题号、英文题名、难度、主题和原题链接；
#. 题目重述或精确契约；
#. 能暴露关键点的示例或边界；
#. 问题抽象和解法选择；
#. 关键状态、不变量或核心判断；
#. 正确性理由和复杂度；
#. 固定十语言代码；
#. 必要的语言差异说明。

简单题保持紧凑，复杂题展开关键分析。说明文字服务于读者理解代码，不写空泛长文。

执行入口
--------

新的 ChatGPT/Codex 对话按顺序读取：

#. ``README.rst``；
#. ``AGENTS.md``；
#. ``PROGRESS.rst``；
#. 当前题号所属范围的 ``README.rst``；
#. 当前要生成或修改的题解文件。
