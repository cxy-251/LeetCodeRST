1331. Rank Transform of an Array
================================

题目信息
--------

:题号: 1331
:难度: Easy
:主题: 数组、排序、离散化
:原题: `LeetCode 1331 <https://leetcode.com/problems/rank-transform-of-an-array/>`_
:重点: 最小值排名为 ``1``，较大不同值排名递增，相同值排名相同且排名尽可能小

题目重述
--------

给定整数数组 ``arr``。把每个元素替换为它在所有不同数值中的排名：最小不同值排名为 ``1``，数值越大排名越大，相同数值使用相同排名。

排名必须连续且尽可能小。返回替换后的数组，保持原下标顺序。

``0 <= arr.length <= 10^5``，``-10^9 <= arr[i] <= 10^9``。

自建示例
--------

重复值共享同一排名：

.. code-block:: text

   输入：arr = [40,10,20,20]
   输出：[3,1,2,2]
   解释：三个不同值按 10、20、40 排名为 1、2、3。

空数组保持为空：

.. code-block:: text

   输入：arr = []
   输出：[]
   解释：没有元素需要替换。
