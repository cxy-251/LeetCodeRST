1362. Closest Divisors
======================

题目信息
--------

:题号: 1362
:难度: Medium
:主题: 数学、因数、平方根枚举
:原题: `LeetCode 1362 <https://leetcode.com/problems/closest-divisors/>`_
:重点: 在乘积等于 ``num+1`` 或 ``num+2`` 的正整数对中，返回绝对差最小的一对

题目重述
--------

给定正整数 ``num``。寻找两个正整数 ``a`` 和 ``b``，使 ``a * b`` 等于 ``num + 1`` 或 ``num + 2``。

在所有合法数对中，返回 ``|a-b|`` 最小的一对，顺序不限。题目保证存在答案。

``1 <= num <= 10^9``。

自建示例
--------

完全平方数给出差为零的因数对：

.. code-block:: text

   输入：num = 8
   输出：[3,3]
   解释：num+1=9，因数对 3 和 3 的差为零。

更接近平方根的候选来自 ``num+2``：

.. code-block:: text

   输入：num = 13
   输出：[3,5]
   解释：14 的最佳因数对为 2、7，差为 5；15 的 3、5 差为 2，更小。
