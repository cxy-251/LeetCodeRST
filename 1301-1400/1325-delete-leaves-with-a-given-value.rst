1325. Delete Leaves With a Given Value
======================================

题目信息
--------

:题号: 1325
:难度: Medium
:主题: 二叉树、后序遍历、递归删除
:原题: `LeetCode 1325 <https://leetcode.com/problems/delete-leaves-with-a-given-value/>`_
:重点: 反复删除值等于 ``target`` 的叶节点；父节点可能因孩子被删而成为新的目标叶节点

题目重述
--------

给定二叉树 ``root`` 和整数 ``target``。删除所有值为 ``target`` 的叶节点。删除后若某个父节点变成叶节点且它的值也等于 ``target``，则继续删除。

反复执行直到不存在可删除节点，返回最终树的根；整棵树可能被删除为空。

树中节点数不超过 ``3000``，节点值和 ``target`` 位于 ``[1,1000]``。

自建示例
--------

删除会向父节点连锁传播：

.. code-block:: text

   输入：root = [1,2,3,2,null,2,4], target = 2
   输出：[1,null,3,null,4]
   解释：三个值为 2 的叶节点依次被删除，左侧父节点也在孩子删除后成为目标叶节点。

根节点本身是目标叶节点：

.. code-block:: text

   输入：root = [5], target = 5
   输出：[]
   解释：唯一节点被删除，结果为空树。
