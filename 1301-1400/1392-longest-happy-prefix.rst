1392. Longest Happy Prefix
==========================

题目信息
--------

:题号: 1392
:难度: Hard
:主题: 字符串、前缀函数、KMP
:原题: `LeetCode 1392 <https://leetcode.com/problems/longest-happy-prefix/>`_
:重点: 快乐前缀是同时为字符串前缀和后缀的非空字符串，但不能等于整个字符串；返回最长者

题目重述
--------

给定小写字符串 ``s``。若非空字符串 ``p`` 同时是 ``s`` 的前缀和后缀，并且 ``p`` 的长度严格小于 ``s``，则 ``p`` 是快乐前缀。

请返回最长快乐前缀。若不存在，返回空字符串。

``1 <= s.length <= 10^5``。

自建示例
--------

重复的整段可以形成较长前后缀：

.. code-block:: text

   输入：s = "levellevel"
   输出："level"
   解释：前五个字符与后五个字符相同，且不是整个字符串。

没有相同的非空前后缀：

.. code-block:: text

   输入：s = "abcd"
   输出：""
   解释：任何真前缀都不等于同长度后缀。
