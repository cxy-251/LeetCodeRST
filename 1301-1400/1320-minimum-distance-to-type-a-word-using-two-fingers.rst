1320. Minimum Distance to Type a Word Using Two Fingers
=======================================================

题目信息
--------

:题号: 1320
:难度: Hard
:主题: 动态规划、键盘距离、双指针状态
:原题: `LeetCode 1320 <https://leetcode.com/problems/minimum-distance-to-type-a-word-using-two-fingers/>`_
:重点: 字母按六列排布，移动距离为曼哈顿距离；两个手指初始位置可任意选择且不产生费用

题目重述
--------

字母 ``A`` 到 ``Z`` 按每行六个字符排列在键盘上。使用两个手指按顺序输入给定大写单词；每次可选择任意一个手指移动到下一个字母并按下。

手指从一个字母移动到另一个字母的费用为行差绝对值与列差绝对值之和。两个手指最初尚未放置，第一次放到任意字母不收费。请返回输入整个单词的最小总移动距离。

``2 <= word.length <= 300``。

自建示例
--------

第三个字符开始可能需要移动手指：

.. code-block:: text

   输入：word = "ABC"
   输出：1
   解释：两个手指可免费放在 A 和 C；输入 A 后，把 A 上的手指移到 B，费用为 1，再用另一个手指输入 C。

两个字符可分别由两个初始手指输入：

.. code-block:: text

   输入：word = "AZ"
   输出：0
   解释：两个手指初始分别放在 A 和 Z，不产生移动费用。
