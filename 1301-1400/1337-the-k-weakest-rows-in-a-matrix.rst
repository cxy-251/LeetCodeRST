1337. The K Weakest Rows in a Matrix
====================================

题目信息
--------

:题号: 1337
:难度: Easy
:主题: 矩阵、计数、排序
:原题: `LeetCode 1337 <https://leetcode.com/problems/the-k-weakest-rows-in-a-matrix/>`_
:重点: 每行的 ``1`` 都位于 ``0`` 之前；士兵数更少的行更弱，数量相同时下标更小的行更弱

题目重述
--------

给定二进制矩阵 ``mat``，每行先出现若干个 ``1``，之后全部为 ``0``。行中 ``1`` 的数量表示该行士兵数。

按士兵数升序排列各行；士兵数相同时按原行下标升序排列。返回最弱的前 ``k`` 个行下标。

``2 <= mat.length, mat[i].length <= 100``，``1 <= k <= mat.length``。

自建示例
--------

按士兵数量和下标共同排序：

.. code-block:: text

   输入：mat = [[1,0],[1,1],[0,0]], k = 2
   输出：[2,0]
   解释：三行士兵数分别为 1、2、0，因此最弱两行为 2 和 0。

士兵数相同时下标小者优先：

.. code-block:: text

   输入：mat = [[1,0],[1,0]], k = 1
   输出：[0]
   解释：两行士兵数相同，行 0 更弱。
