1324. Print Words Vertically
============================

题目信息
--------

:题号: 1324
:难度: Medium
:主题: 字符串、矩阵转置、格式处理
:原题: `LeetCode 1324 <https://leetcode.com/problems/print-words-vertically/>`_
:重点: 单词按空格分隔并竖直书写；每一输出行保留必要的前导和中间空格，但删除末尾空格

题目重述
--------

给定由大写英文字母和单个空格组成的句子 ``s``。把各单词按原顺序排列成列，从每个单词的第一个字符开始逐行读取，生成竖直文本。

当某个单词长度不足时用空格占位；每个输出字符串末尾的空格必须删除。返回所有非空输出行。

``1 <= s.length <= 200``，单词之间恰好一个空格，句首句尾无空格。

自建示例
--------

等长单词直接按列读取：

.. code-block:: text

   输入：s = "HOW ARE"
   输出：["HA","OR","WE"]
   解释：两个三字母单词分别作为两列。

短单词产生必要的前导空格：

.. code-block:: text

   输入：s = "A BCD"
   输出：["AB"," C"," D"]
   解释：第二、三行第一列没有字符，因此保留前导空格；行尾没有多余空格。
