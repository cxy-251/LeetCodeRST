1356. Sort Integers by The Number of 1 Bits
===========================================

题目信息
--------

:题号: 1356
:难度: Easy
:主题: 数组、位计数、排序
:原题: `LeetCode 1356 <https://leetcode.com/problems/sort-integers-by-the-number-of-1-bits/>`_
:重点: 先按二进制中 ``1`` 的数量升序排序，数量相同时按整数值升序排序

题目重述
--------

给定非负整数数组 ``arr``。计算每个整数二进制表示中值为 ``1`` 的位数。

按一位数量从少到多排序；若两个整数的一位数量相同，则较小整数在前。返回排序后的数组。

``1 <= arr.length <= 500``，``0 <= arr[i] <= 10^4``。

自建示例
--------

位数相同时比较整数大小：

.. code-block:: text

   输入：arr = [3,8,4,7]
   输出：[4,8,3,7]
   解释：4 和 8 各有一个 1，按数值升序；3 有两个 1，7 有三个 1。

零没有任何一位：

.. code-block:: text

   输入：arr = [1,0,2]
   输出：[0,1,2]
   解释：0 的一位数量为零，1 和 2 各有一个 1。
