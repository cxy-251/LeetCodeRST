1305. All Elements in Two Binary Search Trees
=============================================

题目信息
--------

:题号: 1305
:难度: Medium
:主题: 二叉搜索树、中序遍历、归并
:原题: `LeetCode 1305 <https://leetcode.com/problems/all-elements-in-two-binary-search-trees/>`_
:重点: 收集两棵二叉搜索树中的全部节点值，并按非递减顺序返回；重复值需要保留

题目重述
--------

给定两棵二叉搜索树 ``root1`` 和 ``root2``。请收集两棵树中所有节点的值，并将它们按从小到大的顺序组成数组返回。

同一数值在不同节点中出现多次时，每个节点都应在结果中保留一次；任意一棵树都可能为空。

两棵树节点总数不超过 ``5000``，节点值位于 ``[-10^5,10^5]``。

自建示例
--------

两棵树的有序序列需要归并：

.. code-block:: text

   输入：root1 = [2,1,4], root2 = [3,2,5]
   输出：[1,2,2,3,4,5]
   解释：两个值为 2 的节点分别保留。

两棵树都为空时返回空数组：

.. code-block:: text

   输入：root1 = [], root2 = []
   输出：[]
   解释：没有任何节点值可收集。
