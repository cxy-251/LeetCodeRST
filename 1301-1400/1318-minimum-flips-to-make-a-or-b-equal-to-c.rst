1318. Minimum Flips to Make a OR b Equal to c
=============================================

题目信息
--------

:题号: 1318
:难度: Medium
:主题: 位运算、逐位统计
:原题: `LeetCode 1318 <https://leetcode.com/problems/minimum-flips-to-make-a-or-b-equal-to-c/>`_
:重点: 一次操作翻转 ``a`` 或 ``b`` 的任意一个二进制位；求使按位或结果等于 ``c`` 的最少操作数

题目重述
--------

给定非负整数 ``a``、``b`` 和 ``c``。一次操作可以选择 ``a`` 或 ``b`` 的任意二进制位，把 ``0`` 改为 ``1`` 或把 ``1`` 改为 ``0``。

请返回使 ``(a OR b) == c`` 所需的最少翻转次数。

``1 <= a,b,c <= 10^9``。

自建示例
--------

目标位为零时两个一都需要翻转：

.. code-block:: text

   输入：a = 2, b = 6, c = 5
   输出：3
   解释：最低位需要补一个 1，中间位在 a 和 b 中都是 1，需要分别翻成 0，共三次。

已经满足条件时无需翻转：

.. code-block:: text

   输入：a = 4, b = 1, c = 5
   输出：0
   解释：4 OR 1 恰好等于 5。
