1309. Decrypt String from Alphabet to Integer Mapping
=====================================================

题目信息
--------

:题号: 1309
:难度: Easy
:主题: 字符串、解析、映射
:原题: `LeetCode 1309 <https://leetcode.com/problems/decrypt-string-from-alphabet-to-integer-mapping/>`_
:重点: ``1`` 到 ``9`` 映射为 ``a`` 到 ``i``，``10#`` 到 ``26#`` 映射为 ``j`` 到 ``z``；带 ``#`` 的两位编码应优先整体解析

题目重述
--------

给定一个编码字符串 ``s``。单个字符 ``'1'`` 到 ``'9'`` 分别表示字母 ``a`` 到 ``i``；三字符编码 ``"10#"`` 到 ``"26#"`` 分别表示字母 ``j`` 到 ``z``。

请按这些规则解码并返回原小写字符串。输入保证是合法编码。

``1 <= s.length <= 1000``，``s`` 只包含数字和 ``#``。

自建示例
--------

单数字与带井号编码可以混合出现：

.. code-block:: text

   输入：s = "1" + "10#" + "26#"
   输出："ajz"
   解释：1、10#、26# 分别映射为 a、j、z。

全部由单数字编码组成：

.. code-block:: text

   输入：s = "987"
   输出："ihg"
   解释：9、8、7 分别映射为 i、h、g。
