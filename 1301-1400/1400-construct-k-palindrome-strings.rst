1400. Construct K Palindrome Strings
====================================

题目信息
--------

:题号: 1400
:难度: Medium
:主题: 字符串、频次奇偶性、构造判断
:原题: `LeetCode 1400 <https://leetcode.com/problems/construct-k-palindrome-strings/>`_
:重点: 必须使用 ``s`` 的全部字符并重新分配为恰好 ``k`` 个非空回文串；奇数频次字符数不能超过 ``k``，且 ``k`` 不能超过字符串长度

题目重述
--------

给定小写字符串 ``s`` 和整数 ``k``。可以任意重排并分配 ``s`` 中的全部字符，构造恰好 ``k`` 个非空字符串。

请判断是否能让这 ``k`` 个字符串全部为回文串。每个字符实例必须且只能使用一次。

``1 <= s.length <= 10^5``，``1 <= k <= 10^5``。

自建示例
--------

一个奇数频次字符可以作为某个回文中心：

.. code-block:: text

   输入：s = "aabbc", k = 2
   输出：true
   解释：可以构造 "abba" 和 "c"，恰好使用全部字符。

奇数频次字符多于回文串数量时无解：

.. code-block:: text

   输入：s = "abc", k = 2
   输出：false
   解释：a、b、c 都出现奇数次，每个都需要独立的回文中心，但只有两个回文串。
