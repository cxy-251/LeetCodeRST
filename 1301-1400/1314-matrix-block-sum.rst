1314. Matrix Block Sum
======================

题目信息
--------

:题号: 1314
:难度: Medium
:主题: 矩阵、二维前缀和、区域求和
:原题: `LeetCode 1314 <https://leetcode.com/problems/matrix-block-sum/>`_
:重点: 对每个位置求行列距离均不超过 ``k`` 的矩形区域元素和，超出矩阵的边界需要截断

题目重述
--------

给定 ``m x n`` 整数矩阵 ``mat`` 和整数 ``k``。输出矩阵 ``answer`` 与原矩阵同形，其中 ``answer[i][j]`` 等于所有满足 ``|r-i| <= k`` 且 ``|c-j| <= k`` 的合法格子 ``mat[r][c]`` 之和。

区域边界超出矩阵时只统计实际存在的格子。

``1 <= m,n <= 100``，``0 <= k <= 100``，矩阵元素非负。

自建示例
--------

边缘位置的区域会被截断：

.. code-block:: text

   输入：mat = [[1,2,3],[4,5,6]], k = 1
   输出：[[12,21,16],[12,21,16]]
   解释：左上角只能覆盖前两行、前两列，和为 12；中间列可覆盖全部六个元素，和为 21。

半径为零时结果等于原矩阵：

.. code-block:: text

   输入：mat = [[7,8]], k = 0
   输出：[[7,8]]
   解释：每个位置只统计自身。
