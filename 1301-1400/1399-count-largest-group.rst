1399. Count Largest Group
=========================

题目信息
--------

:题号: 1399
:难度: Easy
:主题: 整数、数位和、分组计数
:原题: `LeetCode 1399 <https://leetcode.com/problems/count-largest-group/>`_
:重点: 把 ``1`` 到 ``n`` 按十进制数位和分组，返回成员数达到最大值的组数量

题目重述
--------

给定正整数 ``n``。对于闭区间 ``[1,n]`` 中每个整数，计算其十进制各位数字之和，并把数位和相同的整数放入同一组。

找出组大小的最大值，并返回具有该最大大小的组数量。

``1 <= n <= 10^4``。

自建示例
--------

   输入：n = 13
   输出：4
   解释：数位和为 1、2、3、4 的组分别含两个数，其余组更小。

.. code-block:: text

   输出：2
   解释：1 和 2 分属两个大小为一的组。
