1390. Four Divisors
===================

题目信息
--------

:题号: 1390
:难度: Medium
:主题: 数学、因数枚举、计数
:原题: `LeetCode 1390 <https://leetcode.com/problems/four-divisors/>`_
:重点: 对数组中每个数，仅当其正因数数量恰好为四时，才把这四个因数之和加入答案

题目重述
--------

给定正整数数组 ``nums``。对于每个元素，找出它的全部正因数。

若该数恰好有四个不同正因数，则把四个因数之和加入总答案；因数数量少于或多于四时贡献为零。返回所有元素贡献之和，重复数值按出现次数分别处理。

``1 <= nums.length <= 10^4``，``1 <= nums[i] <= 10^5``。

自建示例
--------

多个恰有四因数的数分别贡献：

.. code-block:: text

   输入：nums = [6,8,10]
   输出：45
   解释：三组因数和分别为 12、15、18，总和为 45。

质数只有两个因数，不产生贡献：

.. code-block:: text

   输入：nums = [7]
   输出：0
   解释：7 的正因数只有 1 和 7。
