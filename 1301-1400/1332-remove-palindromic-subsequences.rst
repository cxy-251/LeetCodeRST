1332. Remove Palindromic Subsequences
=====================================

题目信息
--------

:题号: 1332
:难度: Easy
:主题: 字符串、回文、子序列
:原题: `LeetCode 1332 <https://leetcode.com/problems/remove-palindromic-subsequences/>`_
:重点: 每次删除任意非空回文子序列；输入只包含 ``a`` 和 ``b``，因此答案只可能为 ``1`` 或 ``2``

题目重述
--------

给定只包含 ``a`` 和 ``b`` 的非空字符串 ``s``。一次操作可以选择一个非空回文子序列并删除其中全部字符，剩余字符保持相对顺序。

请返回删除整个字符串所需的最少操作次数。子序列不要求连续。

``1 <= s.length <= 1000``。

自建示例
--------

整个字符串是回文时一次删除：

.. code-block:: text

   输入：s = "abba"
   输出：1
   解释：可以把整个字符串作为一个回文子序列删除。

非回文字符串可分别删除全部同字符：

.. code-block:: text

   输入：s = "ababb"
   输出：2
   解释：先删除所有 a，再删除所有 b；两组同字符子序列都为回文。
