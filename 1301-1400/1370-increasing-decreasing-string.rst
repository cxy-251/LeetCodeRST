1370. Increasing Decreasing String
==================================

题目信息
--------

:题号: 1370
:难度: Easy
:主题: 字符串、频次统计、模拟
:原题: `LeetCode 1370 <https://leetcode.com/problems/increasing-decreasing-string/>`_
:重点: 反复按严格递增顺序取可用字符，再按严格递减顺序取可用字符，直到全部字符用完

题目重述
--------

给定小写字符串 ``s``。构造结果时，先从剩余字符中依次选择最小字符、比上一个严格大的最小字符，直到无法继续；然后反向选择最大字符、比上一个严格小的最大字符，直到无法继续。

重复上述升序和降序过程，直到使用完所有字符，返回结果字符串。每次选择会消耗一个对应字符实例。

``1 <= s.length <= 500``。

自建示例
--------

多轮升降过程消耗重复字符：

.. code-block:: text

   输入：s = "aaaabbbbcccc"
   输出："abccbaabccba"
   解释：每轮升序取 abc，降序取 cba，共执行两轮。

只有一种字符时顺序不变：

.. code-block:: text

   输入：s = "zz"
   输出："zz"
   解释：每轮只能取一个 z。
