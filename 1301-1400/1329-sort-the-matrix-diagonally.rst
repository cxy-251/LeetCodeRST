1329. Sort the Matrix Diagonally
================================

题目信息
--------

:题号: 1329
:难度: Medium
:主题: 矩阵、对角线、排序
:原题: `LeetCode 1329 <https://leetcode.com/problems/sort-the-matrix-diagonally/>`_
:重点: 每条从左上到右下的对角线独立按非递减顺序排序

题目重述
--------

给定 ``m x n`` 整数矩阵 ``mat``。把所有具有相同 ``行下标 - 列下标`` 的格子视为一条从左上到右下的对角线。

请分别对每条对角线中的元素按升序重新排列，并返回最终矩阵。不同对角线之间的元素不能交换。

``1 <= m,n <= 100``，``1 <= mat[i][j] <= 100``。

自建示例
--------

每条对角线独立排序：

.. code-block:: text

   输入：mat = [[3,2,1],[2,1,0],[1,0,2]]
   输出：[[1,0,1],[0,2,2],[1,2,3]]
   解释：主对角线 [3,1,2] 排为 [1,2,3]，其余对角线也分别排序。

单行矩阵的每条对角线长度都为一：

.. code-block:: text

   输入：mat = [[4,2,3]]
   输出：[[4,2,3]]
   解释：没有任何对角线包含两个元素。
