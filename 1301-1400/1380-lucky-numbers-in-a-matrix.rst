1380. Lucky Numbers in a Matrix
===============================

题目信息
--------

:题号: 1380
:难度: Easy
:主题: 矩阵、行最小值、列最大值
:原题: `LeetCode 1380 <https://leetcode.com/problems/lucky-numbers-in-a-matrix/>`_
:重点: 幸运数必须同时是所在行的最小值和所在列的最大值；返回所有符合条件的元素

题目重述
--------

给定元素互不相同的 ``m x n`` 整数矩阵 ``matrix``。若某个元素是其所在行的最小值，同时也是其所在列的最大值，则它是幸运数。

请返回矩阵中的所有幸运数，顺序不限。

``1 <= m,n <= 50``，矩阵元素位于 ``[1,10^5]`` 且互不相同。

自建示例
--------

一个元素同时满足两种极值条件：

.. code-block:: text

   输入：matrix = [[7,8],[1,2]]
   输出：[7]
   解释：7 是第一行最小值，也是第一列最大值。

不存在幸运数时返回空数组：

.. code-block:: text

   输入：matrix = [[1,10,11],[9,2,12],[8,7,3]]
   输出：[]
   解释：各行最小值 1、2、3 都不是对应列的最大值。
