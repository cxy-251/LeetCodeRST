1385. Find the Distance Value Between Two Arrays
================================================

题目信息
--------

:题号: 1385
:难度: Easy
:主题: 数组、绝对差、二分查找
:原题: `LeetCode 1385 <https://leetcode.com/problems/find-the-distance-value-between-two-arrays/>`_
:重点: 统计 ``arr1`` 中满足与 ``arr2`` 每个元素绝对差都严格大于 ``d`` 的元素实例数量

题目重述
--------

给定整数数组 ``arr1``、``arr2`` 和非负整数 ``d``。对于 ``arr1`` 中的每个元素 ``x``，若对 ``arr2`` 中所有元素 ``y`` 都有 ``|x-y| > d``，则 ``x`` 贡献一。

请返回满足条件的 ``arr1`` 元素数量。重复元素按下标分别判断和计数。

两个数组长度不超过 ``500``，元素位于 ``[-1000,1000]``，``0 <= d <= 100``。

自建示例
--------

只要存在一个距离不超过阈值的元素就不计数：

.. code-block:: text

   输入：arr1 = [4,5,8], arr2 = [1,10], d = 2
   输出：2
   解释：4 和 5 与 arr2 所有元素距离都大于 2；8 与 10 的距离为 2。

阈值为零时相同数值被排除：

.. code-block:: text

   输入：arr1 = [1,2], arr2 = [2], d = 0
   输出：1
   解释：1 与 2 的距离为 1，元素 2 与 arr2 中的 2 相同。
