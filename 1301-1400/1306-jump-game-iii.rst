题目重述
--------

给定非负整数数组 ``arr`` 和起始下标 ``start``。当前位于下标 ``i`` 时，可以跳到 ``i + arr[i]`` 或 ``i - arr[i]``，但目标下标必须位于数组范围内。

可以执行任意次数跳跃。请判断是否能够到达某个值为 ``0`` 的位置；允许经过同一位置，但实现需要避免无限循环。

``1 <= arr.length <= 5 * 10^4``，``0 <= arr[i] < arr.length``，``0 <= start < arr.length``。

自建示例
--------

通过多次正负方向跳跃到达零：

.. code-block:: text

   输入：arr = [3,0,2,1,2], start = 4
   输出：true
   解释：4 -> 2 -> 0 -> 3 -> 2 会循环，但也可 4 -> 2 -> 0 -> 3 -> 4；从 2 还能跳到下标 1，那里值为 0。

零位置被可达范围隔离时失败：

.. code-block:: text

   输入：arr = [1,2,0], start = 0
   输出：false
   解释：从 0 只能到 1，从 1 的两个目标都越界或回不到下标 2。
