1304. Find N Unique Integers Sum up to Zero
===========================================

题目信息
--------

:题号: 1304
:难度: Easy
:主题: 构造、数组、对称数
:原题: `LeetCode 1304 <https://leetcode.com/problems/find-n-unique-integers-sum-up-to-zero/>`_
:重点: 返回任意 ``n`` 个互不相同且总和为零的整数

题目重述
--------

给定正整数 ``n``，构造一个长度为 ``n`` 的整数数组。数组中的所有元素必须互不相同，并且元素总和恰好为 ``0``。

任意满足条件的数组均可返回，元素顺序不限。

``1 <= n <= 1000``。

自建示例
--------

偶数个元素可全部成相反数对：

.. code-block:: text

   输入：n = 4
   输出：[-2,-1,1,2]
   解释：四个整数互不相同，总和为零。

只有一个元素时必须选择零：

.. code-block:: text

   输入：n = 1
   输出：[0]
   解释：长度为一且总和为零的数组只能包含 0。
