1394. Find Lucky Integer in an Array
====================================

题目信息
--------

:题号: 1394
:难度: Easy
:主题: 数组、频次统计
:原题: `LeetCode 1394 <https://leetcode.com/problems/find-lucky-integer-in-an-array/>`_
:重点: 幸运整数的数值必须等于它在数组中的出现次数；存在多个时返回最大值，无则返回 ``-1``

题目重述
--------

给定整数数组 ``arr``。若正整数 ``x`` 在数组中恰好出现 ``x`` 次，则 ``x`` 是幸运整数。

请返回数组中最大的幸运整数。若不存在任何幸运整数，返回 ``-1``。

``1 <= arr.length <= 500``，``1 <= arr[i] <= 500``。

自建示例
--------

多个幸运整数中返回较大者：

.. code-block:: text

   输入：arr = [2,2,3,3,3]
   输出：3
   解释：2 出现两次，3 出现三次，两者都幸运，返回 3。

数值与频次不相等时无答案：

.. code-block:: text

   输入：arr = [1,1]
   输出：-1
   解释：1 出现两次，数组中也没有值为 2 的元素。
