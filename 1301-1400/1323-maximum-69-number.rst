1323. Maximum 69 Number
=======================

题目信息
--------

:题号: 1323
:难度: Easy
:主题: 整数、贪心、数位修改
:原题: `LeetCode 1323 <https://leetcode.com/problems/maximum-69-number/>`_
:重点: 数字只由 ``6`` 和 ``9`` 组成，最多把一个数位在二者之间互换；返回可得到的最大整数

题目重述
--------

给定一个十进制正整数 ``num``，它的每一位都是 ``6`` 或 ``9``。最多选择一个数位，把 ``6`` 改为 ``9``，或把 ``9`` 改为 ``6``。

请返回所有允许结果中的最大值；也可以不修改任何数位。

``1 <= num <= 10^4``。

自建示例
--------

应优先修改最高位的六：

.. code-block:: text

   输入：num = 6969
   输出：9969
   解释：把最左侧的 6 改成 9，增量最大。

没有六时保持不变：

.. code-block:: text

   输入：num = 999
   输出：999
   解释：把任何 9 改成 6 都会减小数值。
