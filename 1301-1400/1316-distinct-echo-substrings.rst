1316. Distinct Echo Substrings
==============================

题目信息
--------

:题号: 1316
:难度: Hard
:主题: 字符串、子串、字符串哈希
:原题: `LeetCode 1316 <https://leetcode.com/problems/distinct-echo-substrings/>`_
:重点: 回声子串必须能写成 ``a + a``，两半完全相同且非空；只统计内容不同的子串

题目重述
--------

给定小写字符串 ``text``。若某个连续子串可以分成两个长度相等、内容完全相同的非空字符串，则它是回声子串。

请返回 ``text`` 中不同回声子串的数量。相同内容即使出现在多个位置，也只计一次。

``1 <= text.length <= 2000``。

自建示例
--------

不同长度的重复结构分别计数：

.. code-block:: text

   输入：text = "aaaa"
   输出：2
   解释：不同回声子串为 "aa" 和 "aaaa"；多个位置出现的 "aa" 只计一次。

不存在连续重复两半时返回零：

.. code-block:: text

   输入：text = "abcd"
   输出：0
   解释：没有任何非空子串能写成两份相同字符串的连接。
