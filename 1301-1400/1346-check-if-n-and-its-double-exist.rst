1346. Check If N and Its Double Exist
=====================================

题目信息
--------

:题号: 1346
:难度: Easy
:主题: 数组、哈希集合、倍数关系
:原题: `LeetCode 1346 <https://leetcode.com/problems/check-if-n-and-its-double-exist/>`_
:重点: 必须存在两个不同下标 ``i`` 和 ``j``，满足 ``arr[i] == 2 * arr[j]``；零需要至少出现两次

题目重述
--------

给定整数数组 ``arr``。请判断是否存在两个不同下标 ``i`` 和 ``j``，使一个位置的值恰好是另一个位置值的两倍。

若存在返回 ``true``，否则返回 ``false``。同一个数组元素不能同时充当两个下标。

``2 <= arr.length <= 500``，``-10^3 <= arr[i] <= 10^3``。

自建示例
--------

负数同样可以满足倍数关系：

.. code-block:: text

   输入：arr = [-2,-4,3]
   输出：true
   解释：-4 等于 -2 的两倍。

单个零不能与自身配对：

.. code-block:: text

   输入：arr = [0,1]
   输出：false
   解释：虽然 0 等于 0 的两倍，但数组中只有一个零，无法使用两个不同下标。
