1328. Break a Palindrome
========================

题目信息
--------

:题号: 1328
:难度: Medium
:主题: 字符串、贪心、回文
:原题: `LeetCode 1328 <https://leetcode.com/problems/break-a-palindrome/>`_
:重点: 必须恰好替换一个字符，使结果不再是回文串，并在所有可行结果中取字典序最小者；无解返回空字符串

题目重述
--------

给定一个只包含小写英文字母的回文字符串 ``palindrome``。必须选择恰好一个位置，把该字符替换为另一个小写字母。

要求修改后的字符串不是回文串，并且在所有满足条件的结果中按字典序最小。若不存在可行结果，返回空字符串。

``1 <= palindrome.length <= 1000``。

自建示例
--------

优先把前半部分最早的非 ``a`` 改成 ``a``：

.. code-block:: text

   输入：palindrome = "abba"
   输出："aaba"
   解释：修改第二个字符即可破坏回文，同时获得最小字典序。

长度为一时无法破坏回文性质：

.. code-block:: text

   输入：palindrome = "z"
   输出：""
   解释：任何单字符字符串都是回文串。
