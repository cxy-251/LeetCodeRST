1366. Rank Teams by Votes
=========================

题目信息
--------

:题号: 1366
:难度: Medium
:主题: 字符串、计数、排序
:原题: `LeetCode 1366 <https://leetcode.com/problems/rank-teams-by-votes/>`_
:重点: 依次比较各队获得第一名、第二名等位置的票数；所有位置计数都相同时按队名字母升序

题目重述
--------

给定投票字符串数组 ``votes``。每个字符串包含相同的一组大写字母且每个字母恰好一次，字符顺序表示该投票者对各队的排名。

先比较各队获得第一名的票数，较多者在前；若相同，再比较第二名票数，依此类推。若所有排名票数都相同，按队名字母升序。返回最终排名字符串。

``1 <= votes.length <= 1000``，队伍数量不超过 ``26``。

自建示例
--------

高位排名票数优先决定顺序：

.. code-block:: text

   输入：votes = ["ABC","ACB","BAC"]
   输出："ABC"
   解释：A 获得两张第一名票，B 获得一张，C 没有第一名票。

所有排名计数完全相同时按字母排序：

.. code-block:: text

   输入：votes = ["ABC","BCA","CAB"]
   输出："ABC"
   解释：每队在三个排名位置各出现一次，因此使用字母顺序。
