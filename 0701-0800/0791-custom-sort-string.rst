0791. Custom Sort String
========================================================================================================================

题目信息
--------

:题号: 0791
:难度: Medium
:主题: 字符串、自定义顺序、字符重排
:原题: `LeetCode 0791 <https://leetcode.com/problems/custom-sort-string/>`_
:重点: ``order`` 中字符互不重复，只约束其中字符在结果里的相对先后；必须保留 ``s`` 的全部字符及次数，不在 ``order`` 中的字符可放在任意位置

题目重述
--------

给定两个只含小写英文字母的字符串 ``order`` 和 ``s``。``order`` 中的字符互不重复，并定义了这些字符之间的自定义先后顺序。

请重新排列 ``s`` 中的全部字符，使得对于任意两个同时出现在 ``order`` 中的字符 ``x`` 和 ``y``，若 ``x`` 在 ``order`` 中位于 ``y`` 之前，则结果中所有 ``x`` 也应排在所有 ``y`` 之前。必须保留 ``s`` 中每个字符的出现次数。

未出现在 ``order`` 中的字符没有位置约束，可以放在结果中的任意位置。答案可能不唯一，返回任意合法排列即可。

``1 <= order.length <= 26``，``1 <= s.length <= 200``。

自建示例
--------

未声明顺序的字符可以自由放置：

.. code-block:: text

   输入：order = "zyx", s = "xxyzaa"
   输出："zyxxaa"
   解释：结果保留一个 z、一个 y、两个 x 和两个 a，并让 z 位于 y 之前、y 位于所有 x 之前。字符 a 不在 order 中，也可以放在其他位置，因此合法答案不唯一。
