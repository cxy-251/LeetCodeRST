0784. Letter Case Permutation
========================================================================================================================

题目信息
--------

:题号: 0784
:难度: Medium
:主题: 字符串、大小写变换、组合枚举
:原题: `LeetCode 0784 <https://leetcode.com/problems/letter-case-permutation/>`_
:重点: 每个字母位置可以独立选择小写或大写，数字保持不变；需要返回所有不同结果，顺序不限

题目重述
--------

给定一个由英文字母和数字组成的字符串 ``s``。对于其中的每个字母，可以独立选择把它写成小写或大写；数字不能改变，所有字符的位置也保持不变。

请返回通过这些大小写选择能够得到的全部不同字符串。结果顺序不限。

``1 <= s.length <= 12``，``s`` 只包含小写字母、大写字母和数字。

自建示例
--------

原串同时包含大写字母、数字和小写字母：

.. code-block:: text

   输入：s = "a9B"
   输出：["a9b","a9B","A9b","A9B"]
   解释：字母 a 和 B 的大小写可以分别独立选择，数字 9 保持不变，因此共有 2 x 2 = 4 个结果；返回顺序可以不同。

字符串中没有字母：

.. code-block:: text

   输入：s = "907"
   输出：["907"]
   解释：三个字符都是数字，没有任何位置可以切换大小写，因此只存在原字符串这一种结果。
