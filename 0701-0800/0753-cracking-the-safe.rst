0753. Cracking the Safe
========================================================================================================================

题目信息
--------

:题号: 0753
:难度: Hard
:主题: 字符串、组合覆盖、序列构造
:原题: `LeetCode 0753 <https://leetcode.com/problems/cracking-the-safe/>`_
:重点: 密码由 ``0`` 至 ``k - 1`` 的数字组成且长度为 ``n``；返回任意一个字符串，使每种可能密码都作为长度为 ``n`` 的连续子串出现

题目重述
--------

一个保险箱的密码长度为 ``n``，每一位都可以是 ``0`` 至 ``k - 1`` 中的任一数字。保险箱会持续读取最近输入的 ``n`` 个数字；只要这 ``n`` 个数字恰好等于真实密码，保险箱就会打开。

请返回任意一个数字字符串，使得无论真实密码是哪一种可能的长度 ``n`` 密码，在依次输入该字符串后都必然曾作为某个连续的长度 ``n`` 子串出现。答案可以有多种，返回任意合法字符串即可。

``1 <= n <= 4``，``1 <= k <= 10``，并且 ``k^n <= 4096``。字符串只能使用表示数字 ``0`` 至 ``k - 1`` 的字符。

自建示例
--------

覆盖四种二位二进制密码：

.. code-block:: text

   输入：n = 2, k = 2
   输出："00110"
   解释：长度为 2 的连续子串依次包含 "00"、"01"、"11" 和 "10"，正好覆盖由数字 0、1 组成的全部二位密码。其他能够覆盖全部密码的字符串也合法。

单字符密码：

.. code-block:: text

   输入：n = 1, k = 3
   输出："201"
   解释：三个长度为 1 的密码 "0"、"1"、"2" 都在字符串中出现；字符顺序不受限制。
