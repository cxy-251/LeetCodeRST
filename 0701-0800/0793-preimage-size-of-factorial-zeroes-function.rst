0793. Preimage Size of Factorial Zeroes Function
========================================================================================================================

题目信息
--------

:题号: 0793
:难度: Hard
:主题: 阶乘、末尾零、原像数量
:原题: `LeetCode 0793 <https://leetcode.com/problems/preimage-size-of-factorial-zeroes-function/>`_
:重点: 定义域是所有非负整数并约定 ``0! = 1``；统计满足阶乘末尾零数量恰好等于 ``k`` 的整数 ``x`` 个数，而不是寻找某一个 ``x``

题目重述
--------

定义函数 ``f(x)`` 为非负整数 ``x`` 的阶乘 ``x!`` 在十进制表示末尾连续零的数量，并约定 ``0! = 1``，因此 ``f(0) = 0``。

给定非负整数 ``k``，请返回满足 ``f(x) = k`` 的非负整数 ``x`` 的数量。某些 ``k`` 可能没有任何原像。

``0 <= k <= 10^9``。

自建示例
--------

存在一组连续的五个原像：

.. code-block:: text

   输入：k = 4
   输出：5
   解释：20!、21!、22!、23!、24! 的末尾都恰好有 4 个零，因此 x = 20 至 24 共五个值满足条件。

某个末尾零数量会被跳过：

.. code-block:: text

   输入：k = 11
   输出：0
   解释：49! 的末尾有 10 个零，而 50! 的末尾直接增加到 12 个零，因此不存在末尾恰好有 11 个零的阶乘。
