0766. Toeplitz Matrix
========================================================================================================================

题目信息
--------

:题号: 0766
:难度: Easy
:主题: 矩阵、对角线、一致性判断
:原题: `LeetCode 0766 <https://leetcode.com/problems/toeplitz-matrix/>`_
:重点: 只检查从左上到右下方向的每条对角线；同一条对角线上的全部元素必须相等，长度为 1 的对角线自然满足条件

题目重述
--------

给定一个 ``m x n`` 整数矩阵 ``matrix``。若矩阵中每一条从左上方延伸到右下方的对角线都只包含同一个数，则称其为托普利茨矩阵。

请判断输入矩阵是否满足该性质，满足时返回 ``true``，否则返回 ``false``。``1 <= m, n <= 20``，矩阵元素在 ``[0, 99]`` 范围内。

自建示例
--------

所有左上至右下对角线保持一致：

.. code-block:: text

   输入：matrix = [[7,8,9],[4,7,8],[3,4,7],[1,3,4]]
   输出：true
   解释：主对角线全为 7，其右侧相邻对角线分别全为 8 和 9，左侧对角线分别由相同的 4、3、1 组成。

某条对角线出现不同元素：

.. code-block:: text

   输入：matrix = [[5,2,1],[8,5,2],[7,9,5]]
   输出：false
   解释：位置 (1,0) 与 (2,1) 位于同一条左上至右下对角线上，但其值分别为 8 和 9。
