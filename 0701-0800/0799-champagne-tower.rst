0799. Champagne Tower
========================================================================================================================

题目信息
--------

:题号: 0799
:难度: Medium
:主题: 三角结构、液体溢出、状态模拟
:原题: `LeetCode 0799 <https://leetcode.com/problems/champagne-tower/>`_
:重点: 每只杯子容量为一杯，超出部分才平均流向下一行左、右相邻杯；查询行列均从 0 开始，返回目标杯的装满比例且结果不超过 1

题目重述
--------

把杯子叠成三角塔：第 0 行有 1 只杯子，第 1 行有 2 只，依此类推，最多考虑到第 99 行。每只杯子的容量为 1 杯香槟。

向顶端杯子倒入 ``poured`` 杯香槟。某只杯子装满后，超过 1 杯的部分会平均分到它下一行紧邻的左、右两只杯子；未超过容量的液体不会继续下流。最底层流出的多余液体落到地面。

给定从 0 开始编号的 ``query_row`` 和 ``query_glass``，请返回该杯最终装入量占容量的比例。即使实际流入量超过 1，返回值也只能为 ``1.0``。

``0 <= poured <= 10^9``，``0 <= query_glass <= query_row < 100``。

自建示例
--------

查询第三行边缘杯：

.. code-block:: text

   输入：poured = 4, query_row = 2, query_glass = 0
   输出：0.25
   解释：顶杯装满后有 3 杯溢出，第二行两只杯各收到 1.5 杯；它们各有 0.5 杯继续溢出并平分。第三行最左杯只收到左上杯溢出量的一半，即 0.25 杯。
