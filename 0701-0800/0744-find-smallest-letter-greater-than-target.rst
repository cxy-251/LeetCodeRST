0744. Find Smallest Letter Greater Than Target
========================================================================================================================

题目信息
--------

:题号: 0744
:难度: Easy
:主题: 有序数组、字符比较、循环边界
:原题: `LeetCode 0744 <https://leetcode.com/problems/find-smallest-letter-greater-than-target/>`_
:重点: 查找严格大于目标字符的最小字母；数组允许重复且按非递减顺序排列，没有更大字母时返回首元素

题目重述
--------

给定按字典序非递减排列的小写英文字母数组 ``letters`` 和一个小写字母 ``target``。返回数组中严格大于 ``target`` 的最小字母。

若数组中不存在严格大于 ``target`` 的字母，则按循环规则返回 ``letters[0]``。数组中可以有重复字母，但保证至少包含两个不同字符。

``2 <= letters.length <= 10^4``；数组元素和 ``target`` 都是小写英文字母。

自建示例
--------

跳过与目标相等的重复字母：

.. code-block:: text

   输入：letters = ["b","d","d","h"], target = "d"
   输出："h"
   解释：两个 "d" 都不严格大于目标字符，数组中满足条件的最小字母是 "h"。

不存在更大字母时循环到首元素：

.. code-block:: text

   输入：letters = ["b","d","d","h"], target = "z"
   输出："b"
   解释：数组中没有字母严格大于 "z"，因此返回首元素 "b"。
