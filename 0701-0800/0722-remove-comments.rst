0722. Remove Comments
========================================================================================================================

题目信息
--------

:题号: 0722
:难度: Medium
:主题: 字符串、源码解析、注释状态
:原题: `LeetCode 0722 <https://leetcode.com/problems/remove-comments/>`_
:重点: 行注释只影响当前行，块注释可跨行并删除其中隐含换行；按阅读顺序以首个有效注释标记为准，结果不保留空行

题目重述
--------

给定字符串数组 ``source``，其中每个元素是 C++ 源码的一行。请删除源码中的两类注释，并以相同的逐行字符串数组形式返回剩余代码：

* ``//`` 开始行注释，从该标记起到当前行末的内容全部忽略；
* ``/*`` 开始块注释，直到之后按从左到右、逐行阅读顺序遇到的第一个不与开头重叠的 ``*/`` 为止，范围内的所有字符和跨行换行都被删除。

只有当前不处于其他注释中时，注释起始标记才生效；注释内部出现的其他标记均忽略。每个位置按最先遇到的有效标记处理，例如进入行注释后，本行后续的 ``/*`` 不再生效。删除完成后，不把空字符串作为结果行返回；块注释跨越多行时，其前后的代码可能连接到同一个结果行。

输入保证每个块注释最终闭合，没有控制字符、单引号或双引号，也没有宏等结构干扰注释识别。``source`` 行数在 ``[1, 100]`` 范围内，每行长度在 ``[0, 80]`` 范围内，字符均为可打印 ASCII 字符。

自建示例
--------

行注释与跨行块注释同时出现：

.. code-block:: text

   输入：source = ["int x = 1; // keep value","/* open","hidden */x++;","return x;"]
   输出：["int x = 1; ","x++;","return x;"]
   解释：第一行从 // 起被删除；第二行开始的块注释跨到第三行，在 */ 后剩余的 "x++;" 成为一行输出。

块注释会删除其中的换行：

.. code-block:: text

   输入：source = ["ab/*cut","middle","end*/cd","//only","ef"]
   输出：["abcd","ef"]
   解释：块注释前的 "ab" 与闭合标记后的 "cd" 连接成同一结果行；只含行注释的第四行删除后为空，因此不输出。
