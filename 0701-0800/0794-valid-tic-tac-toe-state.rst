0794. Valid Tic-Tac-Toe State
========================================================================================================================

题目信息
--------

:题号: 0794
:难度: Medium
:主题: 矩阵、井字棋、状态合法性
:原题: `LeetCode 0794 <https://leetcode.com/problems/valid-tic-tac-toe-state/>`_
:重点: X 固定先手且双方轮流落子，只能落在空格；任一方形成一行、一列或对角线三连后游戏立即结束，不能再继续落子

题目重述
--------

给定一个 ``3 x 3`` 井字棋棋盘 ``board``，每个位置是字符 ``'X'``、``'O'`` 或空格 ``' '``。请判断该棋盘是否可能在一局遵守规则的游戏过程中出现。

游戏开始时棋盘为空。两名玩家轮流在空格中落子，第一名玩家始终使用 ``X`` 并先手，第二名玩家使用 ``O``；已经落子的格子不能被覆盖。当某一行、某一列或某条对角线出现三个相同的非空字符时，游戏立即结束；棋盘填满时也结束，结束后不能继续落子。

只有存在某种合法落子顺序能够到达给定棋盘时才返回 ``true``，否则返回 ``false``。

自建示例
--------

对局尚未结束的合法状态：

.. code-block:: text

   输入：board = ["XOX","OX "," XO"]
   输出：true
   解释：棋盘中有 4 个 X 和 3 个 O，符合 X 先手轮流落子的数量关系；双方都尚未形成三连，可以通过合法落子顺序到达该状态。

获胜后又出现了额外落子：

.. code-block:: text

   输入：board = ["XXX","OO ","  O"]
   输出：false
   解释：X 已在第一行获胜，但棋盘中 X 与 O 都有 3 枚，说明形成三连之后 O 又落了一子，这不符合游戏结束后禁止继续落子的规则。
