0796. Rotate String
========================================================================================================================

题目信息
--------

:题号: 0796
:难度: Easy
:主题: 字符串、循环移位、等价判断
:原题: `LeetCode 0796 <https://leetcode.com/problems/rotate-string/>`_
:重点: 一次移位只把当前最左字符移动到最右端，可执行任意次包括零次；需要判断能否精确得到 ``goal``，长度不同必然不可达

题目重述
--------

给定两个只含小写英文字母的字符串 ``s`` 和 ``goal``。对 ``s`` 的一次移位操作，是取出当前最左侧字符并把它放到字符串最右端，其余字符的相对顺序保持不变。

请判断能否对 ``s`` 执行零次或多次这样的移位，使结果与 ``goal`` 完全相同。``1 <= s.length, goal.length <= 100``。

自建示例
--------

含重复字符的字符串经过三次移位：

.. code-block:: text

   输入：s = "aabaca", goal = "acaaab"
   输出：true
   解释：依次移位得到 "abacaa"、"bacaaa"、"acaaab"，第三次移位后与 goal 相同。

字符数量相同但相对次序不属于循环移位：

.. code-block:: text

   输入：s = "aabaca", goal = "aacaba"
   输出：false
   解释：s 的六种循环位置为 "aabaca"、"abacaa"、"bacaaa"、"acaaab"、"caaaba" 和 "aaabac"，其中不包含 "aacaba"。
