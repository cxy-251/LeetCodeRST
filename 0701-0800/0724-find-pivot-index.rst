0724. Find Pivot Index
========================================================================================================================

题目信息
--------

:题号: 0724
:难度: Easy
:主题: 数组、前缀和、平衡下标
:原题: `LeetCode 0724 <https://leetcode.com/problems/find-pivot-index/>`_
:重点: 下标从零开始，比较严格位于左右两侧的元素和；边界外一侧的和视为零，存在多个答案时返回最左者

题目重述
--------

给定整数数组 ``nums``。若某个零基下标 ``i`` 左侧所有元素之和，等于其右侧所有元素之和，则称 ``i`` 为枢轴下标。下标 ``i`` 对应的元素本身不计入任一侧。

当 ``i`` 位于数组最左端时，左侧没有元素，其和视为 ``0``；位于最右端时同理。若存在多个枢轴下标，返回最左边的一个；若不存在，返回 ``-1``。

数组长度在 ``[1, 10^4]`` 范围内，``-1000 <= nums[i] <= 1000``。

自建示例
--------

枢轴位于末尾：

.. code-block:: text

   输入：nums = [1,-1,0]
   输出：2
   解释：下标 2 左侧元素和为 1 + (-1) = 0，右侧为空且和为 0，因此下标 2 是枢轴下标。

多个答案时返回最左者：

.. code-block:: text

   输入：nums = [0,0,0]
   输出：0
   解释：三个下标的左右元素和都相等，但题目要求返回最左边的枢轴下标 0。
