0733. Flood Fill
========================================================================================================================

题目信息
--------

:题号: 0733
:难度: Easy
:主题: 矩阵、连通区域、图遍历
:原题: `LeetCode 0733 <https://leetcode.com/problems/flood-fill/>`_
:重点: 只修改与起点四方向连通且颜色等于起点原始颜色的像素；对角相邻不连通，返回修改后的图像

题目重述
--------

给定一个 ``m x n`` 整数矩阵 ``image`` 表示图像，其中 ``image[i][j]`` 是对应像素的颜色值；另给起点行下标 ``sr``、列下标 ``sc`` 和新颜色 ``color``。

从像素 ``image[sr][sc]`` 开始执行填充：将起点以及所有能通过上、下、左、右相邻像素到达、且原始颜色与起点原始颜色相同的像素改为 ``color``。不通过对角线连接，其他像素保持原值。返回完成填充后的图像。

``1 <= m, n <= 50``，起点下标保证有效；像素值和 ``color`` 均在 ``[0, 2^16)`` 范围内。

自建示例
--------

同色区域经四方向连接：

.. code-block:: text

   输入：image = [[2,2,0],[2,0,0],[2,2,2]], sr = 0, sc = 0, color = 5
   输出：[[5,5,0],[5,0,0],[5,5,5]]
   解释：所有值为 2 的像素都能从左上角起点通过四方向相邻关系到达，因此全部改为 5；值为 0 的像素不变。

新颜色等于原颜色：

.. code-block:: text

   输入：image = [[3,3],[0,3]], sr = 0, sc = 1, color = 3
   输出：[[3,3],[0,3]]
   解释：目标颜色与起点原始颜色相同，连通区域的数值不会发生变化。
