0739. Daily Temperatures
========================================================================================================================

题目信息
--------

:题号: 0739
:难度: Medium
:主题: 数组、下一更高温度、距离计算
:原题: `LeetCode 0739 <https://leetcode.com/problems/daily-temperatures/>`_
:重点: 对每一天寻找其后第一个温度严格更高的日期并返回等待天数；相同温度不算更暖，没有答案时填 ``0``

题目重述
--------

给定整数数组 ``temperatures``，其中 ``temperatures[i]`` 表示第 ``i`` 天的温度。返回同长度数组 ``answer``，使 ``answer[i]`` 表示从第 ``i`` 天开始，需要等待多少天才能遇到之后第一个温度严格高于当天的日期。

若未来没有任何一天的温度严格更高，则 ``answer[i]`` 为 ``0``。相同温度不满足“更高”条件，下标差就是等待天数。

``temperatures`` 的长度在 ``[1, 10^5]`` 范围内，每个温度在 ``[30, 100]`` 范围内。

自建示例
--------

未来最近的更高温度位置不同：

.. code-block:: text

   输入：temperatures = [70,68,69,72,71]
   输出：[3,1,1,0,0]
   解释：第 0 天需要等 3 天遇到 72；第 1 天和第 2 天都只需等 1 天。最后两天之后没有更高温度，因此填 0。

相同温度不算更暖：

.. code-block:: text

   输入：temperatures = [60,60,61]
   输出：[2,1,0]
   解释：第 0 天后的第一个 60 与当天相同，必须继续等到第 2 天的 61，因此等待 2 天。
