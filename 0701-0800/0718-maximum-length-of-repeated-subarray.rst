0718. Maximum Length of Repeated Subarray
========================================================================================================================

题目信息
--------

:题号: 0718
:难度: Medium
:主题: 数组、连续子数组、公共片段
:原题: `LeetCode 0718 <https://leetcode.com/problems/maximum-length-of-repeated-subarray/>`_
:重点: 寻找的是在两个数组中都连续出现的相同值序列，而不是可跳过元素的子序列；返回最大长度

题目重述
--------

给定两个整数数组 ``nums1`` 和 ``nums2``，找出一个值序列，使它分别作为连续子数组出现在两个数组中，并返回这类公共连续子数组的最大长度。

公共片段在两个数组中的起始下标可以不同，但片段内元素的顺序和值必须逐项相同，而且在各自数组中都必须连续。两个数组的长度均在 ``[1, 1000]`` 范围内，元素值均在 ``[0, 100]`` 范围内。

自建示例
--------

最长公共片段位于不同位置：

.. code-block:: text

   输入：nums1 = [5,1,2,3,8], nums2 = [0,1,2,3,9]
   输出：3
   解释：连续片段 [1,2,3] 同时出现在两个数组中，长度为 3；不存在更长的公共连续片段。

相同元素不足以构成更长连续片段：

.. code-block:: text

   输入：nums1 = [2,2,3], nums2 = [2,3,2]
   输出：2
   解释：公共连续片段 [2,3] 的长度为 2。虽然两个数组都含有多个 2，但无法在两边连续匹配出长度 3 的相同片段。

两个最短数组没有公共元素：

.. code-block:: text

   输入：nums1 = [1], nums2 = [2]
   输出：0
   解释：两个数组都达到最小长度 1，但唯一元素不同，因此连长度为 1 的公共连续子数组也不存在。
