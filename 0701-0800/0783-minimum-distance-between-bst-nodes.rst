0783. Minimum Distance Between BST Nodes
========================================================================================================================

题目信息
--------

:题号: 0783
:难度: Easy
:主题: 二叉搜索树、节点值、最小差值
:原题: `LeetCode 0783 <https://leetcode.com/problems/minimum-distance-between-bst-nodes/>`_
:重点: 比较任意两个不同节点的值之差的绝对值，而不是树上路径距离；输入是节点值互不相同的二叉搜索树

题目重述
--------

给定一棵二叉搜索树的根节点 ``root``。树中至少有两个节点，并且所有节点值互不相同。

请在任意两个不同节点之间，计算它们节点值之差的绝对值，并返回其中的最小值。这里的“距离”只指数值差，不是两个节点之间经过的边数。

树中节点数在 ``[2, 100]`` 范围内，节点值在 ``[0, 10^5]`` 范围内。

自建示例
--------

比较整棵树中的节点值：

.. code-block:: text

   输入：root 的节点关系为：10 的左、右孩子分别是 5、15；5 的左、右孩子分别是 2、7；15 的左、右孩子分别是 13、20
   输出：2
   解释：按数值排序为 2、5、7、10、13、15、20，其中 5 与 7、13 与 15 的差值都是 2，没有更小的节点值差。

只有两个节点且取到数值范围两端：

.. code-block:: text

   输入：root = [0,null,100000]
   输出：100000
   解释：树中只有值 0 和 100000 两个节点，二者满足二叉搜索树关系。可比较的节点对只有这一组，所以最小差值就是 100000。
