0746. Min Cost Climbing Stairs
========================================================================================================================

题目信息
--------

:题号: 0746
:难度: Easy
:主题: 数组、楼梯、最小代价
:原题: `LeetCode 0746 <https://leetcode.com/problems/min-cost-climbing-stairs/>`_
:重点: 可以从下标 ``0`` 或 ``1`` 开始；每次支付当前台阶代价后上升一阶或两阶，楼顶位于数组末尾之后且无需支付代价

题目重述
--------

给定整数数组 ``cost``，其中 ``cost[i]`` 表示踏上并离开第 ``i`` 级台阶时需要支付的代价。支付当前台阶的代价后，可以向上移动一阶或两阶。

可以选择从下标 ``0`` 或下标 ``1`` 的台阶开始。楼顶位于最后一级台阶之后，到达楼顶本身不产生额外代价。返回到达楼顶所需支付的最小总代价。

``2 <= cost.length <= 1000``，``0 <= cost[i] <= 999``。

自建示例
--------

从第二级台阶开始更便宜：

.. code-block:: text

   输入：cost = [4,2,7,1]
   输出：3
   解释：从下标 1 开始支付 2，向上两阶到下标 3；再支付 1 并走一阶到达楼顶，总代价为 3。

零代价台阶可直接到达楼顶：

.. code-block:: text

   输入：cost = [0,5]
   输出：0
   解释：从下标 0 开始，支付 0 后向上两阶即可到达数组末尾之后的楼顶。
