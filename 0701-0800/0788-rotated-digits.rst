0788. Rotated Digits
========================================================================================================================

题目信息
--------

:题号: 0788
:难度: Medium
:主题: 数字、数位、区间计数
:原题: `LeetCode 0788 <https://leetcode.com/problems/rotated-digits/>`_
:重点: 数字的每一位都必须旋转；旋转后既要仍是有效数字，又必须与原数不同，统计范围是闭区间 ``[1, n]``

题目重述
--------

把一个整数的每一位数字都旋转 180 度。数字 ``0``、``1``、``8`` 旋转后保持不变；``2`` 与 ``5`` 互相变换；``6`` 与 ``9`` 互相变换；``3``、``4``、``7`` 旋转后不再是有效数字。

若一个正整数的所有数位旋转后仍能组成有效数字，并且所得数字与原数不同，则称它为好数。每一位都必须旋转，不能选择跳过某些数位。

给定整数 ``n``，请返回闭区间 ``[1, n]`` 中好数的数量。``1 <= n <= 10^4``。

自建示例
--------

两位数也必须逐位有效：

.. code-block:: text

   输入：n = 15
   输出：6
   解释：范围内的好数是 2、5、6、9、12、15。数字 10、11 旋转后不变，不属于好数；含有 3、4、7 的数字旋转后无效。

上界以内同时包含无效和旋转不变数字：

.. code-block:: text

   输入：n = 8
   输出：3
   解释：1 和 8 旋转后仍是自身，不属于好数；3、4、7 旋转后无效；2、5、6 旋转后分别变为 5、2、9，因此共有 3 个好数。
