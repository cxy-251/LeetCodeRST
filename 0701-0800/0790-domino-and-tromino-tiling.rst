========================================================================================================================

题目重述
--------

有两类可任意旋转的拼块：覆盖两个相邻格子的 ``2 x 1`` 多米诺，以及覆盖三个格子的 L 形托米诺。给定整数 ``n``，请用这些拼块完整覆盖一个 ``2 x n`` 棋盘。

每个格子必须恰好被一个拼块覆盖，拼块不能超出棋盘或相互重叠。若两种覆盖中存在一对四方向相邻格子，在其中一种覆盖里属于同一块拼块、而在另一种覆盖里不属于同一块拼块，则视为不同铺法。

返回不同铺法的数量。由于结果可能很大，需要对 ``10^9 + 7`` 取模。``1 <= n <= 1000``。
