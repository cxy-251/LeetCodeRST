0704. Binary Search
========================================================================================================================

题目信息
--------

:题号: 0704
:难度: Easy
:主题: 数组、二分查找
:原题: `LeetCode 0704 <https://leetcode.com/problems/binary-search/>`_
:重点: 数组严格升序且元素互不相同，返回目标值的零基下标；找不到时返回 ``-1``，运行时间必须为 ``O(log n)``

题目重述
--------

给定一个按严格升序排列的整数数组 ``nums`` 和一个整数 ``target``。数组中的元素互不相同。请在数组中查找 ``target``：若存在，返回它的零基下标；若不存在，返回 ``-1``。

算法的运行时间必须为 ``O(log n)``。数组长度在 ``[1, 10^4]`` 范围内，且 ``-10^4 < nums[i], target < 10^4``。

自建示例
--------

目标值位于数组内部：

.. code-block:: text

   输入：nums = [-8,-3,0,4,11], target = 4
   输出：3
   解释：下标从 0 开始，数值 4 位于 ``nums[3]``。

目标值不存在：

.. code-block:: text

   输入：nums = [2,6,9,15], target = 8
   输出：-1
   解释：数组中没有数值 8，因此返回 -1。
