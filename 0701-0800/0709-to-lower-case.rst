0709. To Lower Case
========================================================================================================================

题目信息
--------

:题号: 0709
:难度: Easy
:主题: 字符串、字符转换、ASCII
:原题: `LeetCode 0709 <https://leetcode.com/problems/to-lower-case/>`_
:重点: 只把每个英文字母大写形式替换为对应小写形式；其他可打印 ASCII 字符保持原样

题目重述
--------

给定一个字符串 ``s``，将其中每个大写英文字母替换为对应的小写英文字母，并返回转换后的字符串。原本的小写字母、数字、空格、标点和其他可打印 ASCII 字符都保持不变。

字符串长度在 ``[1, 100]`` 范围内，并且仅由可打印 ASCII 字符组成。

自建示例
--------

字母与其他字符混合：

.. code-block:: text

   输入：s = "C0de-OK!"
   输出："c0de-ok!"
   解释：大写字母 C、O、K 分别变为 c、o、k，数字、连字符和感叹号不变。

没有需要转换的字符：

.. code-block:: text

   输入：s = "already 42"
   输出："already 42"
   解释：字符串中没有大写英文字母，因此返回内容与输入相同。
