0725. Split Linked List in Parts
========================================================================================================================

题目信息
--------

:题号: 0725
:难度: Medium
:主题: 链表、连续分段、均衡划分
:原题: `LeetCode 0725 <https://leetcode.com/problems/split-linked-list-in-parts/>`_
:重点: 返回恰好 ``k`` 个按原顺序排列的连续链表部分；长度差不超过一，较长部分必须位于前面，不足时末尾部分为空

题目重述
--------

给定单链表头节点 ``head`` 和正整数 ``k``，把原链表按节点出现顺序切分为恰好 ``k`` 个连续部分，并返回由这 ``k`` 个部分的头节点组成的数组。

各部分长度应尽可能均匀，任意两部分的长度差不能超过 ``1``；若不能完全等分，较长的部分必须排在较短部分之前。原链表节点数少于 ``k`` 时，后面的若干部分为 ``null``。每个非空部分应成为独立链表，节点顺序与原链表一致。

链表节点数在 ``[0, 1000]`` 范围内，``0 <= Node.val <= 1000``，``1 <= k <= 50``。

自建示例
--------

两部分不能等长时前一部分多一个节点：

.. code-block:: text

   输入：head = [4,1,9,2,6], k = 2
   输出：[[4,1,9],[2,6]]
   解释：5 个节点分成 2 部分时，长度只能为 3 和 2；较长的部分必须位于前面，并且两部分都保持原链表中的连续顺序。

输入链表为空：

.. code-block:: text

   输入：head = [], k = 3
   输出：[[],[],[]]
   解释：原链表没有节点，但返回数组仍必须恰好包含 3 个部分，因此三个部分全部为空。
