1051. Height Checker
====================

题目信息
--------

:题号: 1051
:难度: Easy
:主题: 数组、非递减顺序、位置比较
:原题: `LeetCode 1051 <https://leetcode.com/problems/height-checker/>`_
:重点: ``expected`` 是将全部身高按非递减顺序排列后的数组；统计原数组与该目标数组在相同下标处数值不同的位置数量

题目重述
--------

给定学生当前站立顺序对应的身高数组 ``heights``。期望队列按照身高非递减排列，即前一个学生的身高不能大于后一个学生。

把 ``heights`` 排序后得到目标数组 ``expected``。请统计有多少个下标 ``i`` 满足 ``heights[i] != expected[i]``，并返回该数量。重复身高需要保留全部实例。

``1 <= heights.length <= 100``，``1 <= heights[i] <= 100``。

自建示例
--------

只有交换位置的两个下标不符合目标：

.. code-block:: text

   输入：heights = [1,3,2,2,4]
   输出：2
   解释：排序结果为 [1,2,2,3,4]，原数组在下标 1 和 3 与目标不同，因此答案为 2。

当前顺序已经符合要求：

.. code-block:: text

   输入：heights = [1,2,2,5]
   输出：0
   解释：数组本身已经按非递减顺序排列，与 expected 完全相同。
