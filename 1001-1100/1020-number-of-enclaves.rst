1020. Number of Enclaves
========================

题目信息
--------

:题号: 1020
:难度: Medium
:主题: 二进制网格、四向连通、边界可达性
:原题: `LeetCode 1020 <https://leetcode.com/problems/number-of-enclaves/>`_
:重点: 只能在上下左右相邻的陆地格之间移动；统计无法通过陆地路径走到网格边界之外的陆地格数量，而不是连通块数量

题目重述
--------

给定由 ``0`` 和 ``1`` 组成的矩阵 ``grid``，其中 ``0`` 表示海水，``1`` 表示陆地。可以从一个陆地格移动到上下左右相邻的另一个陆地格；位于边界的陆地格可以再向网格外迈出一步。

请统计有多少个陆地格无法通过一系列陆地移动最终走出网格。只要某个陆地格与任意边界陆地四向连通，它就不计入答案。

``1 <= grid.length, grid[i].length <= 500``，每个格子为 ``0`` 或 ``1``。

自建示例
--------

边界陆地与内部飞地同时存在：

.. code-block:: text

   输入：grid = [[0,0,0,0],[0,1,1,0],[0,1,0,0],[0,0,1,0]]
   输出：3
   解释：中间相连的三个陆地格无法到达边界；最后一行的陆地格本身位于边界，可以走出网格，因此不计入答案。
