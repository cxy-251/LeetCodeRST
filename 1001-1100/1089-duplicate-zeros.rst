1089. Duplicate Zeros
=====================

题目信息
--------

:题号: 1089
:难度: Easy
:主题: 定长数组、原地修改、零复制
:原题: `LeetCode 1089 <https://leetcode.com/problems/duplicate-zeros/>`_
:重点: 每个原始零要在其后复制一次，并把后续元素右移；数组长度固定，越过末尾的元素丢弃，必须原地修改且不返回数组

题目重述
--------

给定固定长度的整数数组 ``arr``。从左到右处理原数组中的每个 ``0``，在它后面插入一个额外的 ``0``，并将后续元素向右移动一位。

数组容量不能改变，因此所有移出原长度范围的元素直接丢弃。需要在输入数组本身上完成修改，函数不返回新的数组；复制产生的新零不再被重复处理。

``1 <= arr.length <= 10^4``，``0 <= arr[i] <= 9``。

自建示例
--------

末尾元素因容量固定而被截断：

.. code-block:: text

   输入：arr = [1,0,2,3,0,4]
   输出：arr = [1,0,0,2,3,0]
   解释：完整展开会得到 [1,0,0,2,3,0,0,4]，只保留原数组长度的前六个元素。

零位于数组最后：

.. code-block:: text

   输入：arr = [1,2,0]
   输出：arr = [1,2,0]
   解释：末尾零的副本会落到数组容量之外，因此可见内容保持不变。
