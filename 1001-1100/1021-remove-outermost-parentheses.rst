1021. Remove Outermost Parentheses
==================================

题目信息
--------

:题号: 1021
:难度: Easy
:主题: 有效括号串、原语分解、外层删除
:原题: `LeetCode 1021 <https://leetcode.com/problems/remove-outermost-parentheses/>`_
:重点: 先把整个有效括号串唯一分解为若干不可再拆分的原语，再分别删除每个原语最外层的一对括号

题目重述
--------

给定一个非空有效括号字符串 ``s``。一个非空有效括号串若不能写成两个非空有效括号串的连接，则称为原语。任意有效括号串都可以唯一分解为若干原语的顺序连接。

对每个原语删除最开始的左括号和最后的右括号，再按照原顺序连接剩余内容。请返回最终字符串。

``1 <= s.length <= 10^5``，``s`` 只包含 ``(`` 和 ``)``，并保证本身有效。

自建示例
--------

长度为二的原语删除后为空：

.. code-block:: text

   输入：s = "((()))()"
   输出："(())"
   解释：s 分解为原语 "((()))" 和 "()"；删除各自外层后得到 "(())" 和空串，连接结果为 "(())"。
