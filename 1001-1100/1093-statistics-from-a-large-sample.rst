1093. Statistics from a Large Sample
====================================

题目信息
--------

:题号: 1093
:难度: Medium
:主题: 频次数组、描述统计量、大样本
:原题: `LeetCode 1093 <https://leetcode.com/problems/statistics-from-a-large-sample/>`_
:重点: ``count[i]`` 表示数值 ``i`` 的出现次数；按固定顺序返回最小值、最大值、平均值、中位数和唯一众数

题目重述
--------

给定长度为 ``256`` 的非负整数数组 ``count``，其中 ``count[i]`` 表示大样本中整数 ``i`` 出现了多少次。样本至少包含一个数，但不直接展开存储。

请返回五个浮点数 ``[minimum, maximum, mean, median, mode]``：样本最小值、最大值、算术平均值、中位数以及出现次数最多的值。偶数个样本的中位数是中间两个数的平均值；题目保证众数唯一。

``count.length == 256``，``0 <= count[i] <= 10^9``，全部频次之和至少为 ``1``。

自建示例
--------

偶数个样本的中位数取中间两项平均：

.. code-block:: text

   输入：count[1] = 1, count[2] = 2, count[5] = 1，其余为 0
   输出：[1.0,5.0,2.5,2.0,2.0]
   解释：样本为 [1,2,2,5]；平均值为 2.5，中间两项都是 2，数值 2 也是唯一众数。
