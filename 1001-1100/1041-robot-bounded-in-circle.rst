1041. Robot Bounded In Circle
=============================

题目信息
--------

:题号: 1041
:难度: Medium
:主题: 平面机器人、方向旋转、无限重复
:原题: `LeetCode 1041 <https://leetcode.com/problems/robot-bounded-in-circle/>`_
:重点: 机器人从原点朝北出发并无限重复同一指令串；判断其所有访问位置是否始终位于某个有限圆内

题目重述
--------

机器人初始位于坐标 ``(0, 0)``，面向北方。字符串 ``instructions`` 由 ``G``、``L``、``R`` 组成：``G`` 表示沿当前方向前进一步，``L`` 和 ``R`` 分别表示原地左转或右转 90 度。

机器人会把整个指令串按原顺序无限重复执行。若存在一个有限大小的圆，能够包含机器人执行过程中访问的所有位置，则返回 ``true``；若机器人最终会无限远离原点，返回 ``false``。

``1 <= instructions.length <= 100``，字符串只包含 ``G``、``L`` 和 ``R``。

自建示例
--------

一轮结束时回到原点：

.. code-block:: text

   输入：instructions = "GLLG"
   输出：true
   解释：机器人先向北一步，连续左转两次后向南一步，回到原点。重复执行时轨迹始终有界。
