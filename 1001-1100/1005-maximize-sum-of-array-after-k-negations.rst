1005. Maximize Sum Of Array After K Negations
=============================================

题目信息
--------

:题号: 1005
:难度: Easy
:主题: 数组、取反操作、最大化总和
:原题: `LeetCode 1005 <https://leetcode.com/problems/maximize-sum-of-array-after-k-negations/>`_
:重点: 必须恰好执行 ``k`` 次操作；每次可将任意一个元素变为相反数，同一下标允许被重复选择

题目重述
--------

给定整数数组 ``nums`` 和整数 ``k``。一次操作选择任意下标 ``i``，把 ``nums[i]`` 替换为 ``-nums[i]``。必须执行恰好 ``k`` 次操作，同一个元素可以被取反多次。

请返回完成全部操作后，数组元素总和能够达到的最大值。

``1 <= nums.length <= 10^4``，``-100 <= nums[i] <= 100``，``1 <= k <= 10^4``。

自建示例
--------

消除负数后仍需完成剩余操作：

.. code-block:: text

   输入：nums = [-4,-2,3], k = 3
   输出：5
   解释：先把 -4 和 -2 取反得到 [4,2,3]；还必须执行一次操作，选择绝对值最小的 2 变为 -2，最终总和为 4 - 2 + 3 = 5。
