1054. Distant Barcodes
======================

题目信息
--------

:题号: 1054
:难度: Medium
:主题: 数组重排、重复值、相邻限制
:原题: `LeetCode 1054 <https://leetcode.com/problems/distant-barcodes/>`_
:重点: 必须保留所有条码值及其出现次数，并重新排列使任意相邻位置不同；题目保证至少存在一种方案，任意合法答案均可

题目重述
--------

给定整数数组 ``barcodes``，每个元素表示一个商品条码。需要重新排列数组中的全部元素，使任意两个相邻位置的条码值都不相同。

返回任意一个满足条件的排列。每个输入元素实例都必须在结果中出现一次，不能增加、删除或修改条码值；题目保证合法排列一定存在。

``1 <= barcodes.length <= 10^4``，``1 <= barcodes[i] <= 10^4``。

自建示例
--------

最高频条码与其他值交错放置：

.. code-block:: text

   输入：barcodes = [4,4,4,7,7,8]
   输出：[4,7,4,8,4,7]
   解释：结果保留了三个 4、两个 7 和一个 8，并且所有相邻条码都不同；其他合法排列也可以返回。

只有一个条码：

.. code-block:: text

   输入：barcodes = [6]
   输出：[6]
   解释：单元素数组不存在相邻位置，原排列已经合法。
