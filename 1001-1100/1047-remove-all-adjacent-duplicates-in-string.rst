1047. Remove All Adjacent Duplicates In String
==============================================

题目信息
--------

:题号: 1047
:难度: Easy
:主题: 字符串、相邻重复、连续消除
:原题: `LeetCode 1047 <https://leetcode.com/problems/remove-all-adjacent-duplicates-in-string/>`_
:重点: 每次删除一对相邻且相同的字符；删除后新相邻字符可以继续触发消除，最终结果保证唯一

题目重述
--------

给定只包含小写英文字母的字符串 ``s``。一次操作可以选择两个相邻且相同的字符，并把这两个字符同时删除。

反复执行操作，直到字符串中不再存在相邻重复字符。删除顺序可以任意选择，题目保证最终无法继续删除时得到的字符串唯一。请返回这个最终字符串。

``1 <= s.length <= 10^5``，``s`` 只包含小写英文字母。

自建示例
--------

一次删除会引发新的相邻重复：

.. code-block:: text

   输入：s = "abccba"
   输出：""
   解释：先删除 cc 得到 abba，再删除 bb 得到 aa，最后删除 aa，字符串变为空。

字符串中没有可删除字符：

.. code-block:: text

   输入：s = "abc"
   输出："abc"
   解释：任意相邻字符都不同，字符串保持不变。
