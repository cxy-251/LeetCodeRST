1072. Flip Columns For Maximum Number of Equal Rows
===================================================

题目信息
--------

:题号: 1072
:难度: Medium
:主题: 二进制矩阵、整列翻转、统一行
:原题: `LeetCode 1072 <https://leetcode.com/problems/flip-columns-for-maximum-number-of-equal-rows/>`_
:重点: 一次选择会翻转某一整列的所有位；目标是让尽可能多的行各自变成全 ``0`` 或全 ``1``，这些行不必变成同一种值

题目重述
--------

给定只包含 ``0`` 和 ``1`` 的矩阵 ``matrix``。可以选择任意若干列；对每个被选中的列，把该列所有格子的 ``0`` 与 ``1`` 互换。每列至多需要翻转一次。

完成统一的列翻转后，若某一行中的所有元素都相等，即全为 ``0`` 或全为 ``1``，则该行符合要求。请返回能够同时符合要求的最大行数。

``1 <= matrix.length, matrix[i].length <= 300``，每个元素为 ``0`` 或 ``1``。

自建示例
--------

互为补集的两行可以同时变为统一行：

.. code-block:: text

   输入：matrix = [[0,1,0],[1,0,1],[0,1,1]]
   输出：2
   解释：翻转第 1 列后，前两行分别变为 [0,0,0] 和 [1,1,1]，都满足行内元素相等；第三行仍不统一。
