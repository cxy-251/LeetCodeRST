1006. Clumsy Factorial
======================

题目信息
--------

:题号: 1006
:难度: Medium
:主题: 整数表达式、循环运算符、除法规则
:原题: `LeetCode 1006 <https://leetcode.com/problems/clumsy-factorial/>`_
:重点: 从 ``n`` 递减到 ``1``，依次循环使用乘、除、加、减；表达式遵循通常优先级，整数除法向零截断

题目重述
--------

给定正整数 ``n``。把 ``n, n-1, ..., 1`` 按顺序写入表达式，并在相邻数字之间依次循环放置运算符 ``*``、``/``、``+``、``-``，直到所有数字都被使用。

表达式按照通常的运算优先级计算：乘法和除法先于加法和减法，同级运算从左到右；除法使用整数除法并向零截断。请返回最终计算结果。

``1 <= n <= 10^4``。

自建示例
--------

最后一组运算符可能不完整：

.. code-block:: text

   输入：n = 5
   输出：7
   解释：表达式为 5 * 4 / 3 + 2 - 1。先计算乘除得到 6，再计算 6 + 2 - 1，结果为 7。

只有一个数字：

.. code-block:: text

   输入：n = 1
   输出：1
   解释：表达式中没有相邻数字，因此不会使用任何运算符，结果就是 1。
