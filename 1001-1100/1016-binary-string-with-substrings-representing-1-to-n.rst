1016. Binary String With Substrings Representing 1 To N
=======================================================

题目信息
--------

:题号: 1016
:难度: Medium
:主题: 二进制字符串、连续子串、范围覆盖
:原题: `LeetCode 1016 <https://leetcode.com/problems/binary-string-with-substrings-representing-1-to-n/>`_
:重点: 对每个整数 ``x`` 从 ``1`` 到 ``n``，其不含前导零的标准二进制表示都必须作为 ``s`` 的连续子串出现

题目重述
--------

给定只包含 ``0`` 和 ``1`` 的字符串 ``s``，以及正整数 ``n``。对于每个整数 ``x``，取它不含前导零的标准二进制表示。

判断区间 ``[1, n]`` 内每个整数的二进制表示是否都能在 ``s`` 中找到一个连续出现的位置。全部存在时返回 ``true``，只要缺少任意一个就返回 ``false``。

``1 <= s.length <= 1000``，``s`` 只包含 ``0`` 和 ``1``，``1 <= n <= 10^9``。

自建示例
--------

不同长度的二进制表示都被覆盖：

.. code-block:: text

   输入：s = "11010100", n = 5
   输出：true
   解释：1、2、3、4、5 的二进制表示分别为 1、10、11、100、101，它们都作为连续子串出现在 s 中。

缺少其中一个标准表示：

.. code-block:: text

   输入：s = "101", n = 3
   输出：false
   解释：1 和 2 的二进制表示 1、10 都能找到，但 3 的标准表示 11 不是 s 的连续子串。
