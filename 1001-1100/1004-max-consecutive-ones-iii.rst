1004. Max Consecutive Ones III
==============================

题目信息
--------

:题号: 1004
:难度: Medium
:主题: 二进制数组、连续子数组、有限翻转
:原题: `LeetCode 1004 <https://leetcode.com/problems/max-consecutive-ones-iii/>`_
:重点: 最多把 ``k`` 个值为 ``0`` 的位置改成 ``1``；需要返回最终能够形成的最长连续 ``1`` 区间长度

题目重述
--------

给定二进制数组 ``nums`` 和整数 ``k``。可以选择至多 ``k`` 个原值为 ``0`` 的位置，将它们改为 ``1``；也允许少于 ``k`` 次或完全不修改。

请返回经过允许的修改后，数组中能够出现的最长连续 ``1`` 子数组长度。只关心某个连续区间内需要翻转的零数量，区间外的元素不影响答案。

``1 <= nums.length <= 10^5``，``nums[i]`` 为 ``0`` 或 ``1``，``0 <= k <= nums.length``。

自建示例
--------

翻转两个相邻零形成最长区间：

.. code-block:: text

   输入：nums = [1,0,1,0,0,1,1], k = 2
   输出：5
   解释：修改两个零后，可得到长度为 5 的连续 1 区间；长度更大的区间至少包含三个零。

修改次数为零：

.. code-block:: text

   输入：nums = [1,1,0,1,0], k = 0
   输出：2
   解释：数组保持不变，最长连续 1 区间是开头两个元素。
