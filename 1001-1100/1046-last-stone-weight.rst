1046. Last Stone Weight
=======================

题目信息
--------

:题号: 1046
:难度: Easy
:主题: 石子重量、两两碰撞、最终状态
:原题: `LeetCode 1046 <https://leetcode.com/problems/last-stone-weight/>`_
:重点: 每轮必须选当前最重的两颗石子；重量相等时都消失，否则只留下两者重量差

题目重述
--------

给定正整数数组 ``stones``，每个元素表示一颗石子的重量。反复选择当前重量最大的两颗石子，设较轻者为 ``x``、较重者为 ``y``，其中 ``x <= y``。

若 ``x == y``，两颗石子都被摧毁；若 ``x < y``，两颗原石子消失，并产生一颗重量为 ``y - x`` 的新石子。继续执行直到至多剩一颗，返回最后石子的重量；若没有剩余石子，返回 ``0``。

``1 <= stones.length <= 30``，``1 <= stones[i] <= 1000``。

自建示例
--------

最终两颗等重石子同时消失：

.. code-block:: text

   输入：stones = [3,7,2,8]
   输出：0
   解释：8 与 7 碰撞后留下 1；3 与 2 碰撞后也留下 1；最后两个 1 同时被摧毁，因此返回 0。

初始只有一颗石子：

.. code-block:: text

   输入：stones = [9]
   输出：9
   解释：没有第二颗石子可供碰撞，唯一石子直接成为最终结果。
