1037. Valid Boomerang
=====================

题目信息
--------

:题号: 1037
:难度: Easy
:主题: 平面几何、三点共线、面积判断
:原题: `LeetCode 1037 <https://leetcode.com/problems/valid-boomerang/>`_
:重点: 三个输入点互不相同；只有它们不在同一直线上、能够形成面积非零的三角形时才是有效回旋镖

题目重述
--------

给定平面上的三个互不相同的点 ``points[0]``、``points[1]`` 和 ``points[2]``。若这三个点不共线，则称它们构成一个有效回旋镖。

请判断三点能否形成面积严格大于零的三角形。若能返回 ``true``，若三点位于同一条直线上则返回 ``false``。

``points.length == 3``，每个坐标分量在 ``[0, 100]`` 范围内，三个点互不相同。

自建示例
--------

斜率不同的三点不共线：

.. code-block:: text

   输入：points = [[0,0],[2,1],[4,3]]
   输出：true
   解释：从第一个点到后两个点的方向比例不同，因此三点不在同一直线上，能够形成非零面积三角形。

三个点位于同一条水平线：

.. code-block:: text

   输入：points = [[0,5],[3,5],[9,5]]
   输出：false
   解释：三个点的纵坐标都为 5，形成的三角形面积为 0。
