1033. Moving Stones Until Consecutive
=====================================

题目信息
--------

:题号: 1033
:难度: Medium
:主题: 三个石子、端点移动、最少与最多步数
:原题: `LeetCode 1033 <https://leetcode.com/problems/moving-stones-until-consecutive/>`_
:重点: 每次只能移动最左或最右石子，并必须把它放到另外两颗石子之间的空位置；返回达到连续位置所需的最少和最多移动次数

题目重述
--------

数轴上有三颗石子，位置分别为互不相同的整数 ``a``、``b``、``c``。每次操作选择当前最左边或最右边的石子，把它移动到一个未被占用的整数位置；移动后，该石子必须位于另外两颗石子之间，不能仍是端点。

当三颗石子占据三个连续整数位置时游戏结束。返回数组 ``[minimum, maximum]``，分别表示采用不同合法移动策略时，结束游戏所需的最少和最多操作次数。

``1 <= a, b, c <= 100``，三个位置互不相同。

自建示例
--------

两个间隔都大于一时至少需要两步：

.. code-block:: text

   输入：a = 1, b = 4, c = 7
   输出：[2,4]
   解释：最少可先把 1 移到 5，再把 4 移到 6，得到 5、6、7；通过每次只缩小一个空位，可以把过程延长到 4 步。
