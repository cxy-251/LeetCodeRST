1033. Moving Stones Until Consecutive
=====================================

题目信息
--------

:题号: 1033
:难度: Medium
:主题: 三个石子、端点移动、最少与最多步数
:原题: `LeetCode 1033 <https://leetcode.com/problems/moving-stones-until-consecutive/>`_
:重点: 每次选择当前最左或最右石子，并把它移到本次操作前两个端点之间的空整数位置；返回达到连续位置所需的最少和最多移动次数

题目重述
--------

数轴上有三颗石子，位置分别为互不相同的整数 ``a``、``b``、``c``。设当前三个位置排序后为 ``x < y < z``。一次操作可以选择位于 ``x`` 或 ``z`` 的端点石子，把它移动到满足 ``x < k < z``、``k != y`` 的未占用整数位置 ``k``。

当三颗石子占据三个连续整数位置时游戏结束。返回数组 ``[minimum, maximum]``，分别表示采用不同合法移动策略时，结束游戏所需的最少和最多操作次数。

``1 <= a, b, c <= 100``，三个位置互不相同。

自建示例
--------

两个相邻间隔相同：

.. code-block:: text

   输入：a = 1, b = 4, c = 7
   输出：[2,2]
   解释：可以把 1 移到 5，得到 4、5、7，再把 7 移到 6，得到连续位置 4、5、6。任意合法策略都不能少于两步，也无法超过两步。
