1030. Matrix Cells in Distance Order
====================================

题目信息
--------

:题号: 1030
:难度: Easy
:主题: 矩阵坐标、曼哈顿距离、排序输出
:原题: `LeetCode 1030 <https://leetcode.com/problems/matrix-cells-in-distance-order/>`_
:重点: 返回矩阵中的每个坐标恰好一次，并按它到中心格的曼哈顿距离非递减排列；同距离坐标顺序不限

题目重述
--------

给定矩阵行数 ``rows``、列数 ``cols``，以及矩阵内的中心坐标 ``(rCenter, cCenter)``。坐标 ``(r, c)`` 到中心的距离定义为 ``|r - rCenter| + |c - cCenter|``。

请返回矩阵中全部 ``rows * cols`` 个坐标，使它们对应的距离按非递减顺序排列。每个坐标必须出现且只出现一次；距离相同的坐标可以采用任意相对顺序。

``1 <= rows, cols <= 100``，中心坐标保证位于矩阵内。

自建示例
--------

同一距离层内顺序可以不同：

.. code-block:: text

   输入：rows = 2, cols = 3, rCenter = 0, cCenter = 1
   输出：[[0,1],[0,0],[0,2],[1,1],[1,0],[1,2]]
   解释：这些坐标到中心的距离依次为 0、1、1、1、2、2；距离相同的坐标交换顺序仍然合法。
