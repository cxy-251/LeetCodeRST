1002. Find Common Characters
============================

题目信息
--------

:题号: 1002
:难度: Easy
:主题: 字符串、字符频次、多重集合交集
:原题: `LeetCode 1002 <https://leetcode.com/problems/find-common-characters/>`_
:重点: 返回所有字符串共同拥有的字符实例；同一字符可以按共同的最少出现次数重复返回，结果顺序不限

题目重述
--------

给定由小写英文字母组成的字符串数组 ``words``。需要找出在数组中每个字符串里都出现的字符，并把这些公共字符作为字符串数组返回。

字符按出现次数计算：若某个字母在所有字符串中的最少出现次数为 ``m``，它应在结果中出现 ``m`` 次。不同结果字符的排列顺序没有要求。

``1 <= words.length <= 100``，``1 <= words[i].length <= 100``，每个字符串只包含小写英文字母。

自建示例
--------

多个字符都按共同最小次数返回：

.. code-block:: text

   输入：words = ["abca","caba","aacb"]
   输出：["a","a","b","c"]
   解释：三个字符串都恰好至少包含两个 a、一个 b 和一个 c，因此这些字符实例全部属于结果；返回顺序不限。

没有任何公共字符：

.. code-block:: text

   输入：words = ["ab","cd"]
   输出：[]
   解释：两个字符串不共享任何字母，因此结果为空数组。
