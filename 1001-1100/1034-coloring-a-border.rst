1034. Coloring A Border
=======================

题目信息
--------

:题号: 1034
:难度: Medium
:主题: 网格连通分量、边界判断、颜色修改
:原题: `LeetCode 1034 <https://leetcode.com/problems/coloring-a-border/>`_
:重点: 从指定格出发只连接原颜色相同的四邻格；只把该连通分量的边界格改色，内部格保持原颜色

题目重述
--------

给定整数矩阵 ``grid``、起始坐标 ``(row, col)`` 和新颜色 ``color``。把与起始格颜色相同、并能通过上下左右相邻关系到达的所有格子视为一个连通分量。

连通分量中的格子若位于矩阵边缘，或者它至少有一个四邻格不属于该分量，则它是边界格。请把这个分量的全部边界格改为 ``color``，其余格子保持不变，并返回修改后的矩阵。

``1 <= grid.length, grid[i].length <= 50``，``1 <= grid[i][j], color <= 1000``，起始坐标位于矩阵内。

自建示例
--------

与不同颜色相邻的内部位置也是边界：

.. code-block:: text

   输入：grid = [[1,1,1],[1,1,2],[1,1,2]], row = 1, col = 1, color = 3
   输出：[[3,3,3],[3,3,2],[3,3,2]]
   解释：所有值为 1 的格子属于起始分量；它们要么位于矩阵边缘，要么与值为 2 的格子相邻，因此都属于边界并被改为 3。
