1017. Convert to Base -2
========================

题目信息
--------

:题号: 1017
:难度: Medium
:主题: 进制转换、负基数、二进制字符串
:原题: `LeetCode 1017 <https://leetcode.com/problems/convert-to-base-2/>`_
:重点: 使用基数 ``-2`` 和数位 ``0``、``1`` 表示非负整数；除结果 ``0`` 外不得含前导零

题目重述
--------

给定非负整数 ``n``，将它转换为以 ``-2`` 为基数的表示。返回字符串中的每一位只能是 ``0`` 或 ``1``；若字符串从右到左的位权从 ``(-2)^0`` 开始递增，各位乘以对应位权后的总和必须等于 ``n``。

结果应使用最短的标准表示，不含前导零；当 ``n = 0`` 时返回 ``"0"``。

``0 <= n <= 10^9``。

自建示例
--------

负位权参与表示正整数：

.. code-block:: text

   输入：n = 6
   输出："11010"
   解释：按基数 -2 计算，11010 表示 16 - 8 - 2 = 6，因此它是 6 的合法标准表示。

零使用单个数位表示：

.. code-block:: text

   输入：n = 0
   输出："0"
   解释：零的标准表示为单个字符 0，不能返回空字符串或带前导零的形式。
