1019. Next Greater Node In Linked List
======================================

题目信息
--------

:题号: 1019
:难度: Medium
:主题: 链表、后继节点、严格更大值
:原题: `LeetCode 1019 <https://leetcode.com/problems/next-greater-node-in-linked-list/>`_
:重点: 对每个节点寻找其右侧第一个值严格更大的节点；不存在时结果为 ``0``，相等值不能作为答案

题目重述
--------

给定一个非空单链表。按照从头到尾的顺序，把链表节点编号为 ``0`` 到 ``n - 1``。

对于每个节点 ``i``，在它之后寻找下标最小且节点值严格大于当前值的节点 ``j``。若找到，则结果数组第 ``i`` 项为该节点值；若后面没有更大的节点，则该项为 ``0``。返回全部结果组成的数组。

链表节点数在 ``[1, 10^4]`` 范围内，``1 <= Node.val <= 10^9``。

自建示例
--------

更大值必须选择最先出现的一个：

.. code-block:: text

   输入：head = [5,1,4,6,2]
   输出：[6,4,6,0,0]
   解释：5 之后第一个更大值是 6；1 之后先遇到 4；4 之后先遇到 6；最后两个节点右侧都没有严格更大的值。
