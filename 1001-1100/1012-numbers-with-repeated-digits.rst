1012. Numbers With Repeated Digits
==================================

题目信息
--------

:题号: 1012
:难度: Hard
:主题: 十进制数字、重复数位、区间计数
:原题: `LeetCode 1012 <https://leetcode.com/problems/numbers-with-repeated-digits/>`_
:重点: 统计闭区间 ``[1, n]`` 内十进制表示至少有一个数字重复出现的正整数；前导零不属于数字表示

题目重述
--------

给定正整数 ``n``。对于区间 ``1`` 到 ``n`` 中的每个正整数，查看其通常的十进制表示；若其中某个数位至少出现两次，则该整数属于需要统计的对象。

请返回闭区间 ``[1, n]`` 内含有重复数位的正整数数量。十进制表示不包含前导零，因此不足相同位数的数字不能通过补零制造重复。

``1 <= n <= 10^9``。

自建示例
--------

两位数范围中的重复数字：

.. code-block:: text

   输入：n = 25
   输出：2
   解释：1 到 25 中只有 11 和 22 的十进制表示含有重复数位，因此答案为 2。
