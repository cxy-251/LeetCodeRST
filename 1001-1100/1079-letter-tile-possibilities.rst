1079. Letter Tile Possibilities
===============================

题目信息
--------

:题号: 1079
:难度: Medium
:主题: 字母牌、多重集合、不同非空序列
:原题: `LeetCode 1079 <https://leetcode.com/problems/letter-tile-possibilities/>`_
:重点: 每张字母牌至多使用一次；相同字母牌不可区分，只按最终字符串内容统计不同的非空序列数量

题目重述
--------

给定字符串 ``tiles``，每个字符代表一张带有大写字母的牌。可以从中选择一张或多张牌，并把选中的牌按任意顺序排列成字符串。

每张牌最多使用一次。若不同的牌选择或排列过程得到相同文本，只计为一种字符串。请返回能够组成的不同非空字符串数量。

``1 <= tiles.length <= 7``，``tiles`` 只包含大写英文字母。

自建示例
--------

重复字母不会产生重复结果：

.. code-block:: text

   输入：tiles = "AABC"
   输出：34
   解释：长度 1、2、3、4 的不同字符串数量分别为 3、7、12、12，总计 34；两张 A 互不可区分。
