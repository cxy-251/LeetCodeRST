1018. Binary Prefix Divisible By 5
==================================

题目信息
--------

:题号: 1018
:难度: Easy
:主题: 二进制前缀、整除判断、布尔数组
:原题: `LeetCode 1018 <https://leetcode.com/problems/binary-prefix-divisible-by-5/>`_
:重点: 第 ``i`` 个结果对应 ``nums[0..i]`` 作为完整二进制数的值；前导零允许存在且不改变数值

题目重述
--------

给定二进制数组 ``nums``。对于每个下标 ``i``，把从 ``nums[0]`` 到 ``nums[i]`` 的前缀按二进制数解释，最高位在左、最低位在右，记其十进制值为 ``x_i``。

返回长度相同的布尔数组 ``answer``，其中 ``answer[i]`` 表示 ``x_i`` 是否能被 ``5`` 整除。前缀可能以零开头，仍按通常二进制数值计算。

``1 <= nums.length <= 10^5``，每个元素为 ``0`` 或 ``1``。

自建示例
--------

后续前缀可以连续保持可整除：

.. code-block:: text

   输入：nums = [1,0,1,0,0]
   输出：[false,false,true,true,true]
   解释：各前缀的十进制值依次为 1、2、5、10、20，后三个都能被 5 整除。
