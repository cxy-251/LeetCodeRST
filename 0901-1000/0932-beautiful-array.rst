0932. Beautiful Array
=====================

题目信息
--------

:题号: 0932
:难度: Medium
:主题: 构造、排列、等差中项限制
:原题: `LeetCode 0932 <https://leetcode.com/problems/beautiful-array/>`_
:重点: 结果必须是 ``1`` 至 ``n`` 的一个排列；对任意 ``i < k < j``，中间位置的值不能成为两端值的算术平均数，任意合法排列都可返回

题目重述
--------

给定正整数 ``n``，构造一个长度为 ``n`` 的数组 ``nums``，使它恰好包含整数 ``1, 2, ..., n`` 各一次。

数组还必须满足：对于任意下标 ``0 <= i < k < j < n``，都不能出现 ``2 * nums[k] == nums[i] + nums[j]``。请返回任意一个满足条件的排列；题目保证答案存在。

``1 <= n <= 1000``。

自建示例
--------

一种长度为五的合法排列：

.. code-block:: text

   输入：n = 5
   输出：[1,5,3,2,4]
   解释：数组包含 1 至 5 各一次。任取 i < k < j，都不存在中间位置的值恰好等于两端值平均数的情况；其他合法排列也可返回。

只有一个整数：

.. code-block:: text

   输入：n = 1
   输出：[1]
   解释：数组中不足三个下标，等差中项限制自然成立；唯一排列 [1] 是合法答案。
