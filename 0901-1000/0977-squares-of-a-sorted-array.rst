0977. Squares of a Sorted Array
===============================

题目信息
--------

:题号: 0977
:难度: Easy
:主题: 有序数组、平方值、非递减输出
:原题: `LeetCode 0977 <https://leetcode.com/problems/squares-of-a-sorted-array/>`_
:重点: 输入按非递减顺序排列但可能含负数；需要对每个元素平方后重新按非递减顺序返回，重复值必须保留

题目重述
--------

给定按非递减顺序排列的整数数组 ``nums``。对每个元素计算平方，并返回这些平方值按非递减顺序排列后的数组。

由于负数绝对值可能大于正数，原数组顺序在平方后不一定仍然有序。结果必须包含每个输入元素对应的一个平方值，并保留重复次数。

``1 <= nums.length <= 10^4``，``-10^4 <= nums[i] <= 10^4``。

自建示例
--------

负数平方后移动到较后位置：

.. code-block:: text

   输入：nums = [-4,-1,2,3]
   输出：[1,4,9,16]
   解释：逐项平方得到 [16,1,4,9]，重新按非递减顺序排列后得到结果。

数组只有一个负数：

.. code-block:: text

   输入：nums = [-3]
   输出：[9]
   解释：唯一元素平方为 9，单元素结果已经有序。
