0995. Minimum Number of K Consecutive Bit Flips
===============================================

题目信息
--------

:题号: 0995
:难度: Hard
:主题: 二进制数组、固定长度翻转、最少操作
:原题: `LeetCode 0995 <https://leetcode.com/problems/minimum-number-of-k-consecutive-bit-flips/>`_
:重点: 一次操作必须选择恰好 ``k`` 个连续元素并同时翻转全部位；目标是把数组变成全 ``1``，返回最少次数或无法完成时的 ``-1``

题目重述
--------

给定二进制数组 ``nums`` 和整数 ``k``。一次 ``k`` 位翻转可以选择任意长度恰好为 ``k`` 的连续子数组，并同时把其中每个 ``0`` 改为 ``1``、每个 ``1`` 改为 ``0``。

可以对重叠区间执行多次操作。请返回把整个数组变成全 ``1`` 所需的最少翻转次数；若不存在可行操作序列，返回 ``-1``。

``1 <= nums.length <= 10^5``，``1 <= k <= nums.length``。

自建示例
--------

两个重叠区间完成翻转：

   输入：nums = [0,1,0], k = 2
   输出：2
   解释：先翻转下标 [0,1] 得到 [1,0,0]，再翻转下标 [1,2] 得到 [1,1,1]。
