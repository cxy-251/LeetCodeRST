0992. Subarrays with K Different Integers
=========================================

题目信息
--------

:题号: 0992
:难度: Hard
:主题: 数组、连续子数组、不同整数计数
:原题: `LeetCode 0992 <https://leetcode.com/problems/subarrays-with-k-different-integers/>`_
:重点: 统计恰好包含 ``k`` 种不同整数的非空连续子数组；同一数值序列出现在不同下标范围时分别计数

题目重述
--------

给定整数数组 ``nums`` 和正整数 ``k``。请统计有多少个非空连续子数组，其中不同整数的种类数恰好等于 ``k``。

子数组必须连续，由起止下标确定；重复出现的同一个整数只算一种，但不同下标区间属于不同方案。包含少于或多于 ``k`` 种不同整数的子数组都不计入。

``1 <= nums.length <= 2 * 10^4``，``1 <= nums[i], k <= nums.length``。

自建示例
--------

重复值扩展多个合法区间：

.. code-block:: text

   输入：nums = [1,2,1,3], k = 2
   输出：4
   解释：合法子数组为 [1,2]、[1,2,1]、[2,1] 和 [1,3]，共四个下标区间。

整个数组只有一种不同整数：

.. code-block:: text

   输入：nums = [1,1], k = 2
   输出：0
   解释：任意非空连续子数组都只包含整数 1，无法恰好包含两种不同整数。
