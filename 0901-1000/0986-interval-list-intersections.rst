0986. Interval List Intersections
================================

题目信息
--------

:题号: 0986
:难度: Medium
:主题: 区间列表、闭区间、交集
:原题: `LeetCode 0986 <https://leetcode.com/problems/interval-list-intersections/>`_
:重点: 两个输入列表内部各自按起点排序且区间互不相交；区间为闭区间，端点相同也形成单点交集

题目重述
--------

给定两个闭区间列表 ``firstList`` 和 ``secondList``。每个列表中的区间都按起点严格递增排列，并且同一列表内任意两个区间互不相交。

请返回两个列表所有区间两两相交后得到的非空交集，结果按起点递增排列。若两个闭区间只共享一个端点，该单点也属于合法交集；若没有任何交集，返回空数组。

两个列表长度均不超过 ``1000``，每个区间满足 ``0 <= start <= end <= 10^9``。

自建示例
--------

一个长区间分别与两个短区间相交：

.. code-block:: text

   输入：firstList = [[0,2],[5,7]], secondList = [[1,6]]
   输出：[[1,2],[5,6]]
   解释：[1,6] 与第一个区间的交集为 [1,2]，与第二个区间的交集为 [5,6]。
