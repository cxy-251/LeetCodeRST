0958. Check Completeness of a Binary Tree
=========================================

题目信息
--------

:题号: 0958
:难度: Medium
:主题: 二叉树、完全二叉树、层序结构
:原题: `LeetCode 0958 <https://leetcode.com/problems/check-completeness-of-a-binary-tree/>`_
:重点: 除最后一层外每层必须填满；最后一层节点必须从左到右连续出现，不能在空位置之后再出现节点

题目重述
--------

给定二叉树根节点 ``root``，判断它是否为完全二叉树。完全二叉树的每一层除可能的最后一层外都包含最大数量的节点；最后一层的节点必须尽可能靠左，层序位置中不能出现空缺后又出现节点。

若树满足该结构返回 ``true``，否则返回 ``false``。节点值不影响判断，只比较节点是否存在及其位置。

树中节点数在 ``[1, 100]`` 范围内，``1 <= node.val <= 1000``。

自建示例
--------

最后一层中间出现空缺：

.. code-block:: text

   输入：root = [1,2,3,4,5,null,7]
   输出：false
   解释：节点 3 的左孩子位置为空，但其右孩子 7 存在；最后一层没有从左到右连续填充，因此不是完全二叉树。
