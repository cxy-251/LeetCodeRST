0908. Smallest Range I
======================

题目信息
--------

:题号: 0908
:难度: Easy
:主题: 数组、独立调整、极差
:原题: `LeetCode 0908 <https://leetcode.com/problems/smallest-range-i/>`_
:重点: 每个元素可以独立加上 ``[-k, k]`` 内的任意整数；目标是最小化调整后数组的最大值与最小值之差

题目重述
--------

给定整数数组 ``nums`` 和非负整数 ``k``。对每个下标 ``i``，可以独立选择一个整数 ``x_i``，其中 ``-k <= x_i <= k``，并把 ``nums[i]`` 改为 ``nums[i] + x_i``。

完成所有选择后，数组的分数定义为最大元素与最小元素之差。请返回能够得到的最小分数。每个元素的调整值可以不同，也允许选择 ``0``。

``1 <= nums.length <= 10^4``，``0 <= nums[i] <= 10^4``，``0 <= k <= 10^4``。

自建示例
--------

两端向中间靠拢：

.. code-block:: text

   输入：nums = [3,10,14], k = 4
   输出：3
   解释：可以把数组调整为 [7,8,10]，分数为 10 - 7 = 3。原始最大值与最小值相差 11，而两端最多合计缩小 8，因此分数不可能小于 3。
