0959. Regions Cut By Slashes
============================

题目信息
--------

:题号: 0959
:难度: Medium
:主题: 方格、斜线分割、连通区域
:原题: `LeetCode 0959 <https://leetcode.com/problems/regions-cut-by-slashes/>`_
:重点: 每个字符对应一个单位方格，``/`` 或 ``\`` 会把方格沿对角线分开，空格不分割；需要统计整个正方形边界内形成的连通区域数

题目重述
--------

给定长度为 ``n`` 的字符串数组 ``grid``，每个字符串也长为 ``n``，表示一个由 ``n x n`` 个单位方格组成的大正方形。每个方格中的字符为 ``/``、``\`` 或空格。

斜线连接该方格的一对对角顶点，并把方格内部隔开；空格表示方格内部没有分隔线。相邻方格未被线阻断的部分彼此连通。请返回整个大正方形内部被这些线划分出的连通区域数量。

``1 <= n <= 30``。

--------

   输入：grid = ["/"]
   输出：2
   解释：从左下角到右上角的斜线把单位正方形内部划分为两个互不连通的三角区域。
