0945. Minimum Increment to Make Array Unique
============================================

题目信息
--------

:题号: 0945
:难度: Medium
:主题: 数组、重复值、最少递增操作
:原题: `LeetCode 0945 <https://leetcode.com/problems/minimum-increment-to-make-array-unique/>`_
:重点: 一次操作只能把一个元素增加 ``1``，不能减小；目标是让所有元素两两不同并最小化操作总数

题目重述
--------

给定整数数组 ``nums``。一次操作可以选择一个下标 ``i``，把 ``nums[i]`` 增加 ``1``。

可以对同一元素执行多次操作。请返回使数组中所有元素互不相同所需的最少操作次数。元素之间不要求排序，最终值也没有给定上限。

``1 <= nums.length <= 10^5``，``0 <= nums[i] <= 10^5``。

自建示例
--------

后面的重复值需要继续向右移动：

.. code-block:: text

   输入：nums = [1,1,1,3]
   输出：4
   解释：可把三个重复的 1 依次安排为 1、2、3，并把原来的 3 增加到 4，操作数为 0 + 1 + 2 + 1 = 4。
