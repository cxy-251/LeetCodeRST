0989. Add to Array-Form of Integer
=================================

题目信息
--------

:题号: 0989
:难度: Easy
:主题: 数字数组、大整数加法、进位
:原题: `LeetCode 0989 <https://leetcode.com/problems/add-to-array-form-of-integer/>`_
:重点: ``num`` 按最高位到最低位表示一个非负整数且除数字零外没有前导零；返回该数加 ``k`` 后的十进制数位数组

题目重述
--------

给定整数数组 ``num``，它按从最高位到最低位的顺序表示一个非负整数。例如 ``[1,2,3]`` 表示整数 ``123``。除单独的 ``[0]`` 外，输入不含前导零。

另给定正整数 ``k``。请计算数组所表示的整数与 ``k`` 之和，并按相同的最高位到最低位格式返回结果数位数组。结果不能包含多余的前导零。

``1 <= num.length <= 10^4``，``0 <= num[i] <= 9``，``1 <= k <= 10^4``。

自建示例
--------

加法产生跨多位进位：

   输入：num = [9,9,5], k = 8
   输出：[1,0,0,3]
   解释：数组表示 995，995 + 8 = 1003，因此结果数位为 [1,0,0,3]。

结果增加一个最高位：

.. code-block:: text

   输入：num = [9], k = 1
   输出：[1,0]
   解释：9 + 1 = 10，进位在原数位之前产生新的最高位 1。
