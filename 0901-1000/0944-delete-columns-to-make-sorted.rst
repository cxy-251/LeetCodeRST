0944. Delete Columns to Make Sorted
===================================

题目信息
--------

:题号: 0944
:难度: Easy
:主题: 字符串数组、按列检查、删除计数
:原题: `LeetCode 0944 <https://leetcode.com/problems/delete-columns-to-make-sorted/>`_
:重点: 每一列独立判断从上到下是否为非递减顺序；只返回需要删除的列数，不要求删除后各行之间整体字典序有序

题目重述
--------

给定由等长小写字符串组成的数组 ``strs``，把这些字符串按行排成矩阵。对于每个列下标 ``j``，依次观察 ``strs[0][j], strs[1][j], ...``。

若某一列从上到下不是非递减的，即存在 ``i`` 使 ``strs[i][j] > strs[i + 1][j]``，则必须删除该列。请返回需要删除的列数。不同列之间互不影响。

``1 <= strs.length <= 100``，``1 <= strs[i].length <= 100``，所有字符串长度相同。

自建示例
--------

两列分别出现下降：

.. code-block:: text

   输入：strs = ["abc","acc","abb"]
   输出：2
   解释：第 0 列为 a、a、a，合法；第 1 列为 b、c、b，第 2 列为 c、c、b，都不是非递减顺序，因此删除两列。
