0993. Cousins in Binary Tree
============================

题目信息
--------

:题号: 0993
:难度: Easy
:主题: 二叉树、节点深度、父节点关系
:原题: `LeetCode 0993 <https://leetcode.com/problems/cousins-in-binary-tree/>`_
:重点: 堂兄弟节点必须位于相同深度但拥有不同父节点；节点值互不相同，``x`` 和 ``y`` 保证存在且彼此不同

题目重述
--------

给定一棵二叉树的根节点 ``root``，以及两个不同节点值 ``x`` 和 ``y``。树中所有节点值互不相同，并保证值为 ``x`` 和 ``y`` 的节点都存在。

若两个节点从根开始的深度相同，但直接父节点不同，则它们互为堂兄弟节点。请判断值为 ``x`` 和 ``y`` 的两个节点是否满足该条件。

树中节点数在 ``[2, 100]`` 范围内，``1 <= node.val <= 100``。

自建示例
--------

同一深度且父节点不同：

.. code-block:: text

   输入：root = [1,2,3,4,null,null,5], x = 4, y = 5
   输出：true
   解释：节点 4 和 5 都位于深度 2，但父节点分别为 2 和 3，因此它们是堂兄弟节点。

同一深度但拥有相同父节点：

.. code-block:: text

   输入：root = [8,4,12,2,6], x = 2, y = 6
   输出：false
   解释：节点 2 和 6 都位于深度 2，但它们的父节点都是 4，因此二者是兄弟节点而不是堂兄弟节点。
