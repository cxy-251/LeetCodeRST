0962. Maximum Width Ramp
========================

题目信息
--------

:题号: 0962
:难度: Medium
:主题: 数组、下标对、最大距离
:原题: `LeetCode 0962 <https://leetcode.com/problems/maximum-width-ramp/>`_
:重点: 坡由下标对 ``(i, j)`` 构成，要求 ``i < j`` 且 ``nums[i] <= nums[j]``；宽度是下标差 ``j - i``，与数值差无关

题目重述
--------

给定整数数组 ``nums``。若两个下标 ``i`` 和 ``j`` 满足 ``0 <= i < j < nums.length`` 且 ``nums[i] <= nums[j]``，则它们构成一个坡，坡的宽度定义为 ``j - i``。

请返回所有合法坡中的最大宽度。若没有满足条件的正宽度下标对，返回 ``0``。

``2 <= nums.length <= 5 * 10^4``，``0 <= nums[i] <= 5 * 10^4``。

自建示例
--------

较小元素与远处较大元素形成最宽坡：

.. code-block:: text

   输入：nums = [6,0,4,2,5]
   输出：3
   解释：下标 1 和 4 满足 0 <= 5，宽度为 4 - 1 = 3；不存在宽度更大的合法下标对。
