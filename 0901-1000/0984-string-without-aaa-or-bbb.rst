0984. String Without AAA or BBB
===============================

题目信息
--------

:题号: 0984
:难度: Medium
:主题: 字符串构造、字符计数、连续重复限制
:原题: `LeetCode 0984 <https://leetcode.com/problems/string-without-aaa-or-bbb/>`_
:重点: 结果必须恰好使用 ``a`` 个字符 ``a`` 和 ``b`` 个字符 ``b``，且不能包含 ``aaa`` 或 ``bbb``；答案保证存在并可返回任意一个

题目重述
--------

给定非负整数 ``a`` 和 ``b``。构造一个长度为 ``a + b`` 的字符串 ``s``，使其中恰好有 ``a`` 个小写字符 ``'a'`` 和 ``b`` 个小写字符 ``'b'``。

字符串中不能出现连续三个 ``a``，也不能出现连续三个 ``b``。题目保证给定数量下至少存在一个合法字符串，请返回任意一个。

``0 <= a, b <= 100``，``1 <= a + b``。

自建示例
--------

两种字符交替避免三连：

.. code-block:: text

   输入：a = 3, b = 2
   输出："ababa"
   解释：字符串恰好包含三个 a 和两个 b，并且没有出现 "aaa" 或 "bbb"。其他合法字符串也可以返回。

只需要一种字符：

.. code-block:: text

   输入：a = 0, b = 2
   输出："bb"
   解释：结果恰好包含两个 b，没有字符 a，且连续 b 的数量没有达到三个。
