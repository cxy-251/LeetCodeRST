0941. Valid Mountain Array
==========================

题目信息
--------

:题号: 0941
:难度: Easy
:主题: 数组、严格单调、山峰位置
:原题: `LeetCode 0941 <https://leetcode.com/problems/valid-mountain-array/>`_
:重点: 数组必须先严格递增再严格递减；峰值不能位于首尾，任一相邻元素相等都会使数组无效

题目重述
--------

给定整数数组 ``arr``。若存在下标 ``i``，满足 ``0 < i < arr.length - 1``，并且 ``arr[0] < arr[1] < ... < arr[i]``、``arr[i] > arr[i+1] > ... > arr[arr.length-1]``，则称它为有效山脉数组。

请判断 ``arr`` 是否满足该定义。只有递增没有下降、只有下降没有上升、出现平台相等值，或长度小于 ``3``，都不是有效山脉数组。

``1 <= arr.length <= 10^4``，``0 <= arr[i] <= 10^4``。

自建示例
--------

峰值位于数组内部：

.. code-block:: text

   输入：arr = [1,3,5,4,2]
   输出：true
   解释：数组从 1 严格递增到峰值 5，再严格递减到 2，且峰值不在端点。

数组长度不足三：

.. code-block:: text

   输入：arr = [1,0]
   输出：false
   解释：长度为 2 的数组不存在同时不位于首尾的峰值下标，因此不可能成为山脉数组。
