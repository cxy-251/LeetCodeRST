0933. Number of Recent Calls
============================

题目信息
--------

:题号: 0933
:难度: Easy
:主题: 设计题、时间窗口、请求计数
:原题: `LeetCode 0933 <https://leetcode.com/problems/number-of-recent-calls/>`_
:重点: ``ping`` 的时间参数严格递增；每次调用先记录当前请求，再统计闭区间 ``[t - 3000, t]`` 内的全部请求

题目重述
--------

实现 ``RecentCounter`` 类。对象创建后会多次调用 ``ping(t)``，每次调用表示在整数时刻 ``t`` 收到一条新请求，并且后续调用的 ``t`` 保证严格递增。

``ping(t)`` 需要返回从时刻 ``t - 3000`` 到 ``t`` 的闭区间内一共有多少条请求，当前这次请求也包含在内。对象必须在多次调用之间保存此前请求的时间。

``1 <= t <= 10^9``，``ping`` 的调用次数不超过 ``10^4``。

自建示例
--------

左端点属于统计区间：

.. code-block:: text

   输入：
   ["RecentCounter","ping","ping","ping","ping"]
   [[],[10],[1000],[3010],[4011]]
   输出：[null,1,2,3,2]
   解释：时刻 3010 的窗口为 [10,3010]，包含前三次请求；时刻 4011 的窗口为 [1011,4011]，只包含 3010 和 4011。
