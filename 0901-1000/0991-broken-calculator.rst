0991. Broken Calculator
=======================

题目信息
--------

:题号: 0991
:难度: Medium
:主题: 整数变换、两种操作、最少次数
:原题: `LeetCode 0991 <https://leetcode.com/problems/broken-calculator/>`_
:重点: 从 ``startValue`` 开始，每次只能把当前数乘以 ``2`` 或减去 ``1``；需要恰好变为 ``target`` 并返回最少操作次数

题目重述
--------

一个计算器初始显示正整数 ``startValue``，只剩下两个可用操作：把当前显示值乘以 ``2``，或把当前显示值减去 ``1``。

可以按任意顺序重复使用这两个操作。请返回使显示值恰好变为正整数 ``target`` 所需的最少操作次数。

``1 <= startValue, target <= 10^9``。

自建示例
--------

先翻倍、减一，再翻倍：

.. code-block:: text

   输入：startValue = 3, target = 10
   输出：3
   解释：3 乘以 2 得到 6，减 1 得到 5，再乘以 2 得到 10，共三次操作。两次操作无法从 3 得到 10。
