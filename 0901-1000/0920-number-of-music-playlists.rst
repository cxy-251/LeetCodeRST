0920. Number of Music Playlists
===============================

题目信息
--------

:题号: 0920
:难度: Hard
:主题: 动态规划、组合计数、播放限制
:原题: `LeetCode 0920 <https://leetcode.com/problems/number-of-music-playlists/>`_
:教学重点: 按播放长度和已使用歌曲数量设计状态，区分首次播放与重复播放。

题目重述
--------

有 ``n`` 首不同歌曲，需要生成长度为 ``goal`` 的播放列表。每首歌至少出现一次，并且同一首歌再次播放前，必须先播放至少 ``k`` 首其他歌曲。返回满足条件的播放列表数量，并按题目指定模数取值。

自建示例
--------

``n=3``、``goal=3``、``k=1`` 时，三首歌都必须各出现一次，因此所有 ``3!`` 种排列都合法，答案为 ``6``。
