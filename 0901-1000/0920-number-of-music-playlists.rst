0920. Number of Music Playlists
===============================

题目信息
--------

:题号: 0920
:难度: Hard
:主题: 播放列表、组合计数、重复间隔
:原题: `LeetCode 0920 <https://leetcode.com/problems/number-of-music-playlists/>`_
:重点: 长度为 ``goal`` 的列表必须覆盖全部 ``n`` 首不同歌曲；同一首歌再次出现前必须已经播放至少 ``k`` 首其他歌曲

题目重述
--------

有 ``n`` 首彼此不同的歌曲，需要生成一个恰好包含 ``goal`` 次播放的有序列表。每首歌曲必须在列表中至少出现一次，歌曲可以重复播放。

若某首歌曲已经播放过，则它再次出现之前，二者之间必须至少播放 ``k`` 首其他歌曲。请返回满足全部条件的不同播放列表数量，并对 ``10^9 + 7`` 取模。

``1 <= n <= goal <= 100``，``0 <= k < n``。播放位置不同或任一位置所选歌曲不同，就视为不同列表。
