0917. Reverse Only Letters
==========================

题目信息
--------

:题号: 0917
:难度: Easy
:主题: 字符串、字母筛选、位置保持
:原题: `LeetCode 0917 <https://leetcode.com/problems/reverse-only-letters/>`_
:重点: 只反转英文字母的出现顺序；所有非字母字符必须保持原字符和原下标不变，大小写字母都参与反转

题目重述
--------

给定字符串 ``s``，其中可能包含大小写英文字母和若干非字母字符。把所有英文字母按它们在字符串中的出现顺序完全反转，并将反转后的字母依次放回原来的字母位置。

每个非字母字符必须保留在原下标，不能移动或改变。请返回转换后的字符串。

``1 <= s.length <= 100``；字符的 ASCII 值在 ``[33, 122]`` 范围内，并且字符串不包含双引号 ``"`` 或反斜线 ``\``。

自建示例
--------

标点位置保持不变：

.. code-block:: text

   输入：s = "a-bC-d!"
   输出："d-Cb-a!"
   解释：字母序列 a、b、C、d 反转为 d、C、b、a，再放回下标 0、2、3、5；字符 '-' 和 '!' 保持原位置。
