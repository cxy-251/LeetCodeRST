0917. Reverse Only Letters
==========================

题目信息
--------

:题号: 0917
:难度: Easy
:主题: 字符串、双指针、字符判断
:原题: `LeetCode 0917 <https://leetcode.com/problems/reverse-only-letters/>`_
:教学重点: 只交换字母，并保持所有非字母字符的位置不变。

题目重述
--------

给定字符串 ``s``，将其中所有英文字母的出现顺序反转；非字母字符保持在原下标。返回转换后的字符串。

自建示例
--------

输入 ``"Ab-cD!e"``，字母序列反转后得到 ``"eD-cb!A"``，其中 ``-`` 和 ``!`` 的位置没有变化。
