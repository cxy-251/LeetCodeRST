0955. Delete Columns to Make Sorted II
======================================

题目信息
--------

:题号: 0955
:难度: Medium
:主题: 字符串数组、统一删列、字典序
:原题: `LeetCode 0955 <https://leetcode.com/problems/delete-columns-to-make-sorted-ii/>`_
:重点: 对所有字符串删除相同下标集合后，要求字符串数组按原行顺序呈非递减字典序；目标是最小删除列数

题目重述
--------

给定由等长小写字符串组成的数组 ``strs``。可以选择若干列下标，并从每个字符串中同时删除这些位置的字符，剩余字符保持原相对顺序。

删除后必须满足 ``strs[0] <= strs[1] <= ...`` 的字典序关系。请返回达到该条件所需删除的最少列数。这里比较的是各行形成的完整字符串，而不是要求每一列单独有序。

``1 <= strs.length <= 100``，``1 <= strs[i].length <= 100``，所有字符串长度相同。

自建示例
--------

删除首列后数组恢复字典序：

.. code-block:: text

   输入：strs = ["ca","bb","ac"]
   输出：1
   解释：删除第 0 列后得到 ["a","b","c"]，按字典序非递减。保留首列时 "ca" 排在 "bb" 之后，因此至少需要删除一列。
