0988. Smallest String Starting From Leaf
========================================

题目信息
--------

:题号: 0988
:难度: Medium
:主题: 二叉树、叶到根路径、字典序
:原题: `LeetCode 0988 <https://leetcode.com/problems/smallest-string-starting-from-leaf/>`_
:重点: 节点值 ``0`` 至 ``25`` 分别对应 ``a`` 至 ``z``；每个候选字符串从叶节点读向根节点，返回字典序最小者

题目重述
--------

给定二叉树根节点 ``root``。每个节点值在 ``0`` 至 ``25`` 之间，分别表示小写字母 ``a`` 至 ``z``。

对于每个叶节点，从该叶节点沿父节点一路读到根节点，形成一个字符串。请返回所有叶到根字符串中字典序最小的一个。只有没有孩子的节点才是叶节点；字符串方向不能反转为根到叶。

树中节点数在 ``[1, 8500]`` 范围内。

自建示例
--------

比较两个叶节点产生的字符串：

.. code-block:: text

   输入：root = [1,0,2]
   输出："ab"
   解释：左叶节点 0 到根节点 1 形成 "ab"；右叶节点 2 到根形成 "cb"。按字典序 "ab" 更小。
