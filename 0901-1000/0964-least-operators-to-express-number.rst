0964. Least Operators to Express Number
=======================================

题目信息
--------

:题号: 0964
:难度: Hard
:主题: 数学表达式、固定操作数、最少运算符
:原题: `LeetCode 0964 <https://leetcode.com/problems/least-operators-to-express-number/>`_
:重点: 表达式中每个数都只能写成 ``x``，运算符只能是 ``+``、``-``、``*``、``/``；不允许括号和一元负号，除法按有理数计算并遵循通常优先级

题目重述
--------

给定正整数 ``x`` 和 ``target``。需要写出形如 ``x op x op x ...`` 的表达式，使其值恰好等于 ``target``；其中每个 ``op`` 只能是加、减、乘、除四种二元运算符。

表达式中不能使用其他数字，不能使用括号，也不能使用一元负号。乘除优先于加减，同级运算从左到右；除法结果按有理数精确计算。请返回达到目标值所需的最少运算符数量。

``2 <= x <= 100``，``1 <= target <= 2 * 10^8``。
