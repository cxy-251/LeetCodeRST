0957. Prison Cells After N Days
===============================

题目信息
--------

:题号: 0957
:难度: Medium
:主题: 状态演化、八个牢房、指定天数
:原题: `LeetCode 0957 <https://leetcode.com/problems/prison-cells-after-n-days/>`_
:重点: 每天所有牢房依据前一天状态同时更新；内部牢房仅在左右邻居状态相同时变为占用，两个端点因缺少双邻居始终变为 ``0``

题目重述
--------

给定长度固定为 ``8`` 的二进制数组 ``cells``，``1`` 表示牢房被占用，``0`` 表示空闲。每天结束时，所有位置同时根据当天状态更新。

对于下标 ``1`` 至 ``6``，若它左右相邻牢房当天状态相同，则次日该位置为 ``1``，否则为 ``0``。下标 ``0`` 和 ``7`` 没有两个邻居，因此次日必为 ``0``。给定正整数 ``n``，返回经过 ``n`` 天后的状态。

``cells.length == 8``，``1 <= n <= 10^9``。

自建示例
--------

相邻位置呈交替状态：

.. code-block:: text

   输入：cells = [1,0,1,0,1,0,1,0], n = 1
   输出：[0,1,1,1,1,1,1,0]
   解释：每个内部位置的左右邻居都相同，因此下标 1 至 6 次日都为 1；两个端点为 0。

全零状态演化两天：

.. code-block:: text

   输入：cells = [0,0,0,0,0,0,0,0], n = 2
   输出：[0,0,1,1,1,1,0,0]
   解释：第一天内部六格的左右邻居都相同，状态变为 [0,1,1,1,1,1,1,0]；第二天再次同时更新后得到结果。
