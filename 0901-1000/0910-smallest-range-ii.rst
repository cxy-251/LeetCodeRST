0910. Smallest Range II
=======================

题目信息
--------

:题号: 0910
:难度: Medium
:主题: 数组、二选一调整、极差
:原题: `LeetCode 0910 <https://leetcode.com/problems/smallest-range-ii/>`_
:重点: 每个元素必须恰好选择加 ``k`` 或减 ``k``；目标是最小化调整后数组的最大值与最小值之差

题目重述
--------

给定整数数组 ``nums`` 和非负整数 ``k``。对于每个下标 ``i``，必须独立选择将 ``nums[i]`` 改为 ``nums[i] + k`` 或 ``nums[i] - k``，不能选择区间中的其他调整量。

完成全部调整后，数组的分数为最大元素与最小元素之差。请返回所有选择方案中能够得到的最小分数。调整后的元素允许为负数。

``1 <= nums.length <= 10^5``，``0 <= nums[i] <= 10^4``，``0 <= k <= 10^4``。

自建示例
--------

不同元素选择不同方向：

.. code-block:: text

   输入：nums = [1,6,10], k = 4
   输出：4
   解释：可得到 [5,2,6]，分数为 6 - 2 = 4。其他选择无法把三个数压缩到长度小于 4 的区间内。
