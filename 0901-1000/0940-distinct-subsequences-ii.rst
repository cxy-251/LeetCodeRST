0940. Distinct Subsequences II
==============================

题目信息
--------

:题号: 0940
:难度: Hard
:主题: 字符串、非空子序列、去重计数
:原题: `LeetCode 0940 <https://leetcode.com/problems/distinct-subsequences-ii/>`_
:重点: 子序列通过删除任意字符并保持相对顺序得到；只按最终字符串内容去重，不统计空子序列，结果需要取模

题目重述
--------

给定只包含小写英文字母的字符串 ``s``。可以删除任意数量的字符而不改变剩余字符的相对顺序，从而得到一个子序列。

请统计能够得到多少种内容互不相同的非空子序列。由不同下标选择得到但最终字符序列相同的结果只计一次；空字符串不计入。返回答案对 ``10^9 + 7`` 取模后的值。

``1 <= s.length <= 2000``。

自建示例
--------

重复字符导致下标方案合并：

.. code-block:: text

   输入：s = "aba"
   输出：6
   解释：不同非空子序列为 "a"、"b"、"ab"、"aa"、"ba"、"aba"。两个位置产生的单字符 "a" 内容相同，只计一次。
