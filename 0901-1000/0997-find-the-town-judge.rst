0997. Find the Town Judge
=========================

题目信息
--------

:题号: 0997
:难度: Easy
:主题: 有向信任关系、入度出度、唯一候选人
:原题: `LeetCode 0997 <https://leetcode.com/problems/find-the-town-judge/>`_
:重点: 法官本人不信任任何人，其他每个人都必须信任法官；若不存在同时满足两项条件的唯一编号则返回 ``-1``

题目重述
--------

小镇共有 ``n`` 个人，编号为 ``1`` 至 ``n``。数组 ``trust`` 中每个 ``[a, b]`` 表示人物 ``a`` 信任人物 ``b``，所有信任关系互不重复且 ``a != b``。

若某个人不信任任何人，并且其余 ``n - 1`` 个人都信任他，则该人是小镇法官。请返回法官编号；若不存在满足条件的人，返回 ``-1``。题目保证若法官存在则只有一个。

``1 <= n <= 1000``，``0 <= trust.length <= 10^4``。

自建示例
--------

唯一获得所有人信任的人自己也信任别人：

.. code-block:: text

   输入：n = 4, trust = [[1,3],[2,3],[4,3],[3,1]]
   输出：-1
   解释：人物 3 获得其余三人的信任，但他还信任人物 1，因此不满足法官不信任任何人的条件；其他人也不可能成为法官。

小镇只有一个人：

.. code-block:: text

   输入：n = 1, trust = []
   输出：1
   解释：没有其他人需要信任他，人物 1 也没有信任任何人，因此满足法官条件。
