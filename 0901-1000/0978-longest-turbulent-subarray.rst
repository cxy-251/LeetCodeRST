0978. Longest Turbulent Subarray
================================

题目信息
--------

:题号: 0978
:难度: Medium
:主题: 数组、交替比较、最长连续区间
:原题: `LeetCode 0978 <https://leetcode.com/problems/longest-turbulent-subarray/>`_
:重点: 子数组必须连续，任意相邻比较符号要在 ``>`` 与 ``<`` 之间交替；相邻元素相等会中断湍流区间

题目重述
--------

给定整数数组 ``arr``。若一个连续子数组中，相邻元素的大小关系严格交替，即比较符号呈 ``> < > < ...`` 或 ``< > < > ...``，则称它为湍流子数组。

长度为 ``1`` 的子数组也视为湍流。若任意相邻元素相等，或连续两次比较方向相同，该位置不能继续同一个湍流区间。请返回最长湍流连续子数组的长度。

``1 <= arr.length <= 4 * 10^4``，``0 <= arr[i] <= 10^9``。

自建示例
--------

相等元素结束前面的交替区间：

.. code-block:: text

   输入：arr = [4,1,3,2,2,5]
   输出：4
   解释：子数组 [4,1,3,2] 的关系为 4 > 1 < 3 > 2，长度为 4；随后两个 2 相等，无法继续。
