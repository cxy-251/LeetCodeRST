0965. Univalued Binary Tree
===========================

题目信息
--------

:题号: 0965
:难度: Easy
:主题: 二叉树、节点值一致性、遍历判断
:原题: `LeetCode 0965 <https://leetcode.com/problems/univalued-binary-tree/>`_
:重点: 只判断树中所有实际存在节点的值是否完全相同；空孩子不参与比较，输入根节点非空

题目重述
--------

给定一棵非空二叉树的根节点 ``root``。若树中每一个节点的值都相同，则称它为单值二叉树。

请判断给定二叉树是否为单值二叉树。树的形状没有限制，只需比较所有存在节点的 ``val``；若全部相同返回 ``true``，否则返回 ``false``。

树中节点数在 ``[1, 100]`` 范围内，``0 <= node.val < 100``。

自建示例
--------

不同深度的节点值仍然一致：

.. code-block:: text

   输入：root = [4,4,4,null,4]
   输出：true
   解释：树中四个实际节点的值都为 4，空孩子不参与比较。

单节点树：

.. code-block:: text

   输入：root = [9]
   输出：true
   解释：树中只有一个实际节点，不存在与它不同的节点值。
