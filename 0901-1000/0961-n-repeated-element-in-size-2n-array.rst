0961. N-Repeated Element in Size 2N Array
=========================================

题目信息
--------

:题号: 0961
:难度: Easy
:主题: 数组、重复元素、频次保证
:原题: `LeetCode 0961 <https://leetcode.com/problems/n-repeated-element-in-size-2n-array/>`_
:重点: 数组长度为 ``2n``，恰有一个值出现 ``n`` 次，其余 ``n`` 个值各出现一次；返回这个唯一高频值

题目重述
--------

给定长度为 ``2n`` 的整数数组 ``nums``。输入保证数组中包含 ``n + 1`` 个不同的值：其中恰好一个值出现 ``n`` 次，其余每个不同值都只出现一次。

请返回出现 ``n`` 次的那个元素。该元素由题目保证唯一存在。

``2 <= nums.length <= 5000``，数组长度为偶数，``0 <= nums[i] <= 10^4``。

自建示例
--------

重复元素占数组一半：

.. code-block:: text

   输入：nums = [5,1,5,2,5,3]
   输出：5
   解释：数组长度为 6，因此 n = 3；元素 5 恰好出现 3 次，其他元素各出现一次。

最小规模的合法数组：

.. code-block:: text

   输入：nums = [9,1,9,2]
   输出：9
   解释：数组长度为 4，因此 n = 2；9 出现两次，1 和 2 各出现一次。
