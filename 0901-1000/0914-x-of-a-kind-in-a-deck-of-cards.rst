0914. X of a Kind in a Deck of Cards
=====================================

题目信息
--------

:题号: 0914
:难度: Easy
:主题: 数组、相同值分组、统一组大小
:原题: `LeetCode 0914 <https://leetcode.com/problems/x-of-a-kind-in-a-deck-of-cards/>`_
:重点: 所有牌必须恰好分完；每组大小必须是同一个整数 ``x >= 2``，并且一组内的牌面值完全相同

题目重述
--------

给定整数数组 ``deck``，其中每个元素表示一张牌的牌面值。判断是否存在整数 ``x >= 2``，使所有牌能够被划分为若干组，并同时满足：每组恰好有 ``x`` 张牌，同一组中的牌面值全部相同，且每张牌恰好属于一组。

不同牌面值可以形成不同数量的组，但所有组的大小必须相同。若存在这样的划分返回 ``true``，否则返回 ``false``。

``1 <= deck.length <= 10^4``，``0 <= deck[i] < 10^4``。

自建示例
--------

每种牌都能按四张分组：

.. code-block:: text

   输入：deck = [4,4,4,4,7,7,7,7]
   输出：true
   解释：可以取 x = 4，分别组成一组四张 4 和一组四张 7，全部牌都被使用。

只有一张牌：

.. code-block:: text

   输入：deck = [6]
   输出：false
   解释：组大小必须至少为 2，唯一一张牌无法组成任何合法分组。
