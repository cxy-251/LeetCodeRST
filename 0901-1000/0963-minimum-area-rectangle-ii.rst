0963. Minimum Area Rectangle II
===============================

题目信息
--------

:题号: 0963
:难度: Medium
:主题: 平面点集、任意方向矩形、最小面积
:原题: `LeetCode 0963 <https://leetcode.com/problems/minimum-area-rectangle-ii/>`_
:重点: 矩形可以旋转，不要求边平行于坐标轴；四个顶点都必须来自输入，返回最小非零面积，不存在时返回 ``0``

题目重述
--------

给定平面上互不相同的整数点数组 ``points``。从中选择四个点作为一个非退化矩形的四个顶点，矩形可以采用任意方向，不要求边与坐标轴平行。

请返回所有可构成矩形中的最小面积。若无法从给定点中构成任何非零面积矩形，返回 ``0``。返回值允许使用浮点数，判题按题目给定误差范围接受。

``1 <= points.length <= 50``，``0 <= x_i, y_i <= 4 * 10^4``，所有点互不相同。

自建示例
--------

四点组成旋转四十五度的正方形：

.. code-block:: text

   输入：points = [[0,1],[1,0],[2,1],[1,2]]
   输出：2.0
   解释：相邻顶点距离均为 sqrt(2)，四点组成一个菱形方向的正方形，面积为 sqrt(2) * sqrt(2) = 2。
