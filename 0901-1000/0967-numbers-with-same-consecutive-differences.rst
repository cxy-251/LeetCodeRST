0967. Numbers With Same Consecutive Differences
===============================================

题目信息
--------

:题号: 0967
:难度: Medium
:主题: 数字构造、相邻数位、无前导零
:原题: `LeetCode 0967 <https://leetcode.com/problems/numbers-with-same-consecutive-differences/>`_
:重点: 返回所有恰好 ``n`` 位且任意相邻数位绝对差为 ``k`` 的整数；首位不能为零，答案顺序不限且不应包含重复值

题目重述
--------

给定整数 ``n`` 和 ``k``。请返回所有十进制长度恰好为 ``n`` 的非负整数，使每一对相邻数位的绝对差都等于 ``k``。

结果中的整数不能有前导零。每个满足条件的整数只返回一次，返回顺序不限。

``2 <= n <= 9``，``0 <= k <= 9``。

自建示例
--------

相邻数位必须相差九：

.. code-block:: text

   输入：n = 2, k = 9
   输出：[90]
   解释：两位数的首位不能为 0；只有数位 9、0 的绝对差为 9，因此唯一结果是 90。
