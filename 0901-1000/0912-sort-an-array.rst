0912. Sort an Array
===================

题目信息
--------

:题号: 0912
:难度: Medium
:主题: 排序、归并排序、堆排序、快速排序
:原题: `LeetCode 0912 <https://leetcode.com/problems/sort-an-array/>`_
:教学重点: 在受控复杂度下实现通用整数排序，并处理重复值。

题目重述
--------

给定整数数组 ``nums``，将其中所有元素按非递减顺序排列并返回。输入可能包含负数和重复值，结果保留全部元素及其出现次数。

自建示例
--------

输入 ``[5,1,4,2,8]``，输出 ``[1,2,4,5,8]``。
