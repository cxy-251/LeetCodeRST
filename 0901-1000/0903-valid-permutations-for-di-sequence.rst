0903. Valid Permutations for DI Sequence
=========================================

题目信息
--------

:题号: 0903
:难度: Hard
:主题: 动态规划、排列计数、前缀和
:原题: `LeetCode 0903 <https://leetcode.com/problems/valid-permutations-for-di-sequence/>`_
:教学重点: 用相对排名代替具体数值，并用前缀和优化转移。

题目重述
--------

给定只含 ``I`` 和 ``D`` 的字符串 ``s``，长度为 ``n``。统计 ``0`` 到 ``n`` 的所有排列中，满足 ``I`` 位置递增、``D`` 位置递减的排列数量，结果按题目要求取模。

自建示例
--------

``s="ID"`` 时，需要满足 ``perm[0] < perm[1] > perm[2]``。合法排列为 ``[0,2,1]`` 和 ``[1,2,0]``，答案为 ``2``。
