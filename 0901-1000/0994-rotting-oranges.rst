0994. Rotting Oranges
=====================

题目信息
--------

:题号: 0994
:难度: Medium
:主题: 网格、同步传播、最少时间
:原题: `LeetCode 0994 <https://leetcode.com/problems/rotting-oranges/>`_
:重点: 每分钟所有腐烂橘子同时使上下左右相邻的新鲜橘子腐烂；空格不传播，返回全部腐烂所需时间，无法完成时返回 ``-1``

题目重述
--------

给定整数网格 ``grid``，其中 ``0`` 表示空格，``1`` 表示新鲜橘子，``2`` 表示腐烂橘子。

每经过一分钟，当前所有腐烂橘子会同时使其上、下、左、右相邻的新鲜橘子变为腐烂。对角线不相邻，空格也不能传递腐烂。请返回使网格中不再存在新鲜橘子所需的最少分钟数；若有新鲜橘子永远无法被感染，返回 ``-1``。若初始没有新鲜橘子，返回 ``0``。

``1 <= grid.length, grid[i].length <= 10``。

自建示例
--------

腐烂沿弯曲路径逐分钟传播：

.. code-block:: text

   输入：grid = [[2,1,0],[0,1,1]]
   输出：3
   解释：第 1 分钟上方中格腐烂，第 2 分钟下方中格腐烂，第 3 分钟右下角腐烂。
