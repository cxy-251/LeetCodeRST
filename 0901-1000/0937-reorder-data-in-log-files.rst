0937. Reorder Data in Log Files
===============================

题目信息
--------

:题号: 0937
:难度: Easy
:主题: 字符串、分类排序、稳定顺序
:原题: `LeetCode 0937 <https://leetcode.com/problems/reorder-data-in-log-files/>`_
:重点: 字母日志全部排在数字日志之前；字母日志先按内容排序、内容相同再按标识符排序，数字日志保持输入中的相对顺序

题目重述
--------

给定日志字符串数组 ``logs``。每条日志的第一个单词是只含字母和数字的标识符，其后是由空格分隔的内容。若内容中的每个单词都只含小写字母，则为字母日志；若内容中的每个单词都只含数字，则为数字日志。

重新排列日志，使所有字母日志位于数字日志之前。字母日志按去掉标识符后的内容字典序排列；内容相同时按标识符字典序排列。数字日志之间必须保持原有相对顺序。返回排列后的数组。

``1 <= logs.length <= 100``，每条日志长度在 ``[3, 100]`` 范围内，并且格式有效。

自建示例
--------

字母内容相同则比较标识符：

.. code-block:: text

   输入：logs = ["d1 3 2","l2 red fox","l1 red ant","d2 1 4","l3 red ant"]
   输出：["l1 red ant","l3 red ant","l2 red fox","d1 3 2","d2 1 4"]
   解释：字母内容 "red ant" 排在 "red fox" 前；两条 "red ant" 日志按标识符 l1、l3 排序。数字日志保持 d1、d2 的原顺序。

全部都是数字日志：

.. code-block:: text

   输入：logs = ["d2 3 4","d1 1 2"]
   输出：["d2 3 4","d1 1 2"]
   解释：没有字母日志需要提前，数字日志必须保持输入中的相对顺序，因此结果不变。
