0968. Binary Tree Cameras
=========================

题目信息
--------

:题号: 0968
:难度: Hard
:主题: 二叉树、监控覆盖、最少摄像头
:原题: `LeetCode 0968 <https://leetcode.com/problems/binary-tree-cameras/>`_
:重点: 摄像头只能安装在树节点上，并同时监控该节点、父节点和直接左右孩子；必须覆盖全部节点且最小化摄像头数量

题目重述
--------

给定一棵二叉树的根节点 ``root``。可以在任意树节点上安装摄像头。一个摄像头能够监控它所在的节点、该节点的父节点以及该节点直接连接的左孩子和右孩子。

请返回监控树中全部节点所需的最少摄像头数量。摄像头不能监控距离超过一条边的节点，空孩子无需覆盖。

树中节点数在 ``[1, 1000]`` 范围内，节点值均为 ``0``。

自建示例
--------

在三节点链的中间安装摄像头：

.. code-block:: text

   输入：root = [0,0,null,0]
   输出：1
   解释：在中间节点安装一个摄像头，可以同时覆盖它的父节点、它自身以及它的左孩子，因此全部三个节点都被监控。
