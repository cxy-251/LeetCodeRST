0922. Sort Array By Parity II
=============================

题目信息
--------

:题号: 0922
:难度: Easy
:主题: 数组、奇偶位置、任意合法排列
:原题: `LeetCode 0922 <https://leetcode.com/problems/sort-array-by-parity-ii/>`_
:重点: 输入保证奇数和偶数数量相等；结果要求偶数下标放偶数、奇数下标放奇数，满足条件的任意排列都可返回

题目重述
--------

给定偶数长度的整数数组 ``nums``，其中恰好一半元素为偶数，另一半为奇数。重新排列全部元素，使每个偶数下标 ``i`` 上的值为偶数，每个奇数下标上的值为奇数。

返回任意一种满足条件的排列。结果必须保留输入中的全部元素及其重复次数，不要求同奇偶元素保持原相对顺序。

``2 <= nums.length <= 2 * 10^4``，数组长度为偶数，``0 <= nums[i] <= 1000``。

自建示例
--------

交错放置奇偶元素：

.. code-block:: text

   输入：nums = [3,4,1,2]
   输出：[4,3,2,1]
   解释：下标 0、2 的值 4、2 为偶数，下标 1、3 的值 3、1 为奇数。其他合法排列也可以返回。
