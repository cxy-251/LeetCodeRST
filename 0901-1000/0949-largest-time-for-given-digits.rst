0949. Largest Time for Given Digits
===================================

题目信息
--------

:题号: 0949
:难度: Medium
:主题: 四位数字、时间格式、最大合法排列
:原题: `LeetCode 0949 <https://leetcode.com/problems/largest-time-for-given-digits/>`_
:重点: 四个数字必须各使用恰好一次组成 ``HH:MM``；小时在 ``00`` 至 ``23``、分钟在 ``00`` 至 ``59``，不存在合法排列时返回空字符串

题目重述
--------

给定长度为 ``4`` 的数字数组 ``arr``，每个元素在 ``0`` 至 ``9`` 之间。重新排列这四个数字并各使用恰好一次，组成格式固定为 ``"HH:MM"`` 的 24 小时时间。

合法时间要求 ``00 <= HH <= 23`` 且 ``00 <= MM <= 59``。请返回能够组成的最晚时间；必须保留两位小时和两位分钟的前导零。若无法组成任何合法时间，返回空字符串。

``arr.length == 4``。

自建示例
--------

最大小时仍需给分钟留下合法数字：

.. code-block:: text

   输入：arr = [0,1,5,9]
   输出："19:50"
   解释：19:50 使用四个数字各一次且时间合法。无法组成 20 点以上的合法小时，因此它是最晚时间。

无法组成合法小时：

.. code-block:: text

   输入：arr = [7,7,7,7]
   输出：""
   解释：小时十位只能是 0、1 或 2，而四个数字全为 7，因此不存在合法时间。
