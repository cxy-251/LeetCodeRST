0905. Sort Array By Parity
==========================

题目信息
--------

:题号: 0905
:难度: Easy
:主题: 数组、奇偶分区、任意合法排列
:原题: `LeetCode 0905 <https://leetcode.com/problems/sort-array-by-parity/>`_
:重点: 只要求所有偶数出现在所有奇数之前；两个区域内部的相对顺序没有限制，存在多个答案时可返回任意一个

题目重述
--------

给定整数数组 ``nums``，重新排列数组中的全部元素，使每个偶数都位于每个奇数之前。返回任意一种满足条件的排列。

返回数组必须与输入包含完全相同的元素及重复次数。题目不要求保持偶数之间或奇数之间原有的相对顺序，也不要求结果按数值排序。

``1 <= nums.length <= 5000``，``0 <= nums[i] <= 5000``。

自建示例
--------

一种合法分区结果：

.. code-block:: text

   输入：nums = [5,2,7,4,1,6]
   输出：[2,4,6,5,7,1]
   解释：输出保留了输入中的全部元素，前三项都是偶数，后三项都是奇数。偶数区和奇数区内部还可以采用其他顺序。

数组只有一个奇数：

.. code-block:: text

   输入：nums = [7]
   输出：[7]
   解释：输入只有一个元素，不存在偶数必须移到它前面，因此原数组本身就是合法答案。
