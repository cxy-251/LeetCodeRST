0905. Sort Array By Parity
==========================

题目信息
--------

:题号: 0905
:难度: Easy
:主题: 数组、双指针、原地交换
:原题: `LeetCode 0905 <https://leetcode.com/problems/sort-array-by-parity/>`_
:教学重点: 用左右指针把偶数分区到奇数之前。

题目重述
--------

给定整数数组 ``nums``，重新排列元素，使所有偶数都位于所有奇数之前。偶数区和奇数区内部的相对顺序没有要求，返回任意满足条件的数组。

自建示例
--------

输入 ``[5,2,7,4,1,6]``，可以返回 ``[2,4,6,5,7,1]``。前三个元素均为偶数，后三个元素均为奇数。
