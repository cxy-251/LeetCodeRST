0902. Numbers At Most N Given Digit Set
========================================

题目信息
--------

:题号: 0902
:难度: Hard
:主题: 数位动态规划、组合计数、前缀限制
:原题: `LeetCode 0902 <https://leetcode.com/problems/numbers-at-most-n-given-digit-set/>`_
:教学重点: 分开统计位数更短的数字，并沿 ``n`` 的前缀统计等长数字。

题目重述
--------

给定一组互不相同的数字字符 ``digits`` 和正整数 ``n``。每个字符可以重复使用，统计能够由这些字符组成且不大于 ``n`` 的正整数数量。结果中的数字不带前导零。

自建示例
--------

``digits=["1","3","5"]``，``n=400``。一位数有 3 个，两位数有 9 个，三位数首位只能取 1 或 3，共 ``2*3*3=18`` 个，因此答案为 ``30``。
