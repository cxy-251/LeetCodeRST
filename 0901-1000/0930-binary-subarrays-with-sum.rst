0930. Binary Subarrays With Sum
===============================

题目信息
--------

:题号: 0930
:难度: Medium
:主题: 二进制数组、连续子数组、目标和计数
:原题: `LeetCode 0930 <https://leetcode.com/problems/binary-subarrays-with-sum/>`_
:重点: 统计所有非空连续子数组实例；相同数值序列位于不同下标时分别计数，``goal`` 可以为零

题目重述
--------

给定只包含 ``0`` 和 ``1`` 的数组 ``nums``，以及非负整数 ``goal``。请统计有多少个非空连续子数组的元素和恰好等于 ``goal``。

子数组由连续的起止下标确定。即使两个子数组包含相同的数值，只要下标范围不同，就属于不同方案并分别计数。

``1 <= nums.length <= 3 * 10^4``，``0 <= goal <= nums.length``。
