0970. Powerful Integers
=======================

题目信息
--------

:题号: 0970
:难度: Medium
:主题: 幂、两数求和、去重集合
:原题: `LeetCode 0970 <https://leetcode.com/problems/powerful-integers/>`_
:重点: 强大整数形如 ``x^i + y^j``，其中 ``i``、``j`` 为非负整数且零次幂为 ``1``；只返回不超过 ``bound`` 的不同结果，顺序不限

题目重述
--------

给定正整数 ``x``、``y`` 和非负整数 ``bound``。若整数能够写成 ``x^i + y^j``，其中 ``i >= 0``、``j >= 0``，则称它为强大整数。

请返回所有小于或等于 ``bound`` 的不同强大整数。不同指数对产生相同数值时只保留一次，返回顺序不限。按照定义，``x^0`` 和 ``y^0`` 都等于 ``1``。

``1 <= x, y <= 100``，``0 <= bound <= 10^6``。

自建示例
--------

不同指数对产生重复结果：

.. code-block:: text

   输入：x = 2, y = 5, bound = 20
   输出：[2,3,5,6,7,9,13,17]
   解释：这些不同数值都能写成 2^i + 5^j 且不超过 20；例如 3 = 2 + 1，17 = 16 + 1。返回顺序可以不同。

上界小于最小强大整数：

.. code-block:: text

   输入：x = 1, y = 1, bound = 1
   输出：[]
   解释：任意指数下 1^i + 1^j 都等于 2，超过上界 1，因此结果为空。
