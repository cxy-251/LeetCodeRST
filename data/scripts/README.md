# 目录职责

`data/scripts/` 存放脚本文案样本、人工整理的旁白文本或测试输入文本。

# 允许内容

- 文案草稿
- 旁白样本
- 测试脚本输入

# 禁止内容

- 可执行代码
- 共享类型
- 自动生成缓存

# 修改前必须阅读

- `../README.md`
- `../../README.md`
- `../../PROJECT_MAP.md`
- `../../AGENTS.md`

# 命名规则

- `*.md`
- `*.txt`
- `*.json`

# 边界说明

这里是文本输入资源区，不是逻辑实现区。
实际 TTS 生成逻辑仍在 `tools/` 与 `services/tts-python/`。

# Codex 规则

- 修改本目录文件前必须阅读本 README。
- 不允许把运行期产物写回这里。
