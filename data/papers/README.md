# 目录职责

`data/papers/` 预留给手工维护的论文输入文件或样本文档。

# 允许内容

- 手工放入的 PDF 样本
- 辅助说明文本

# 禁止内容

- 生成缓存
- 应用源码
- 最终视频产物

# 修改前必须阅读

- `../README.md`
- `../../README.md`
- `../../PROJECT_MAP.md`
- `../../AGENTS.md`

# 命名规则

- PDF：`<paper-id>.pdf`
- 说明：`<paper-id>.md` 或 `README.md`

# 边界说明

这里是手工输入区，不是缓存区。
自动抓取缓存仍应留在 `output/cache/papers/`。

# Codex 规则

- 修改本目录文件前必须阅读本 README。
- 不允许把缓存文件直接复制成长期手工资产，除非明确整理命名。
