# 目录职责

`data/source-bundles/` 预留给手工整理的论文来源 bundle 说明。

# 允许内容

- Source bundle 结构文档
- 人工整理后的样例 bundle

# 禁止内容

- 业务代码
- 自动缓存
- 大体积二进制资源

# 修改前必须阅读

- `../README.md`
- `../../README.md`
- `../../PROJECT_MAP.md`
- `../../AGENTS.md`

# 命名规则

- Bundle：`*.json`
- 目录说明：`README.md`

# 边界说明

自动生成的 bundle 默认走忽略规则。
这里更适合放样例、格式说明和需要长期保留的手工结果。

# Codex 规则

- 修改本目录文件前必须阅读本 README。
- 自动生成文件如果要转为长期资产，先重命名并确认边界。
