0415. Add Strings
=================

题目信息
--------

:题号: 0415
:难度: Easy
:主题: 字符串、竖式加法、双指针
:原题: `LeetCode 415 <https://leetcode.com/problems/add-strings/>`_
:教学重点: 从最低位向最高位逐位相加，并独立维护进位。

题目重述
--------

给定两个表示非负整数的十进制字符串 ``num1`` 和 ``num2``，返回它们的和。不能把完整字符串直接转换为内置整数，也不能使用大整数库。

两个字符串从末尾开始对齐；某一方位数耗尽后按 0 处理，最后若仍有进位需要追加最高位。

自建示例
--------

``num1 = "987"``，``num2 = "65"``。从低位开始计算得到 ``7+5=12``、``8+6+1=15``、``9+1=10``，最终返回 ``"1052"``。
