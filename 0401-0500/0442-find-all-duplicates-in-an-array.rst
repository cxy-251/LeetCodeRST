0442. Find All Duplicates in an Array
=====================================

题目信息
--------

:题号: 0442
:难度: Medium
:主题: 长度为 ``n`` 的数组、数值范围 ``1..n``、出现两次、重复值集合
:原题: `LeetCode 0442 <https://leetcode.com/problems/find-all-duplicates-in-an-array/>`_
:重点: 每个值只出现一次或两次、结果只列出现两次的值、顺序不限、要求线性时间和常数额外空间

题目重述
--------

给定长度为 ``n`` 的整数数组 ``nums``，每个元素都位于 ``[1, n]``，并且每个整数在数组中出现一次或两次。返回所有恰好出现两次的整数。

``n`` 位于 ``[1, 10^5]``。每个重复值在结果中只出现一次，结果顺序不限。题目要求使用 ``O(n)`` 时间，并且除返回结果外只使用常数额外空间；允许在处理过程中修改输入数组。

自建示例
--------

存在两个重复值：

.. code-block:: text

   输入：nums = [1, 3, 4, 2, 2, 3]
   输出：[2,3]
   解释：2 和 3 各出现两次，1 和 4 各出现一次；输出顺序也可以是 [3,2]。

没有重复值：

.. code-block:: text

   输入：nums = [1, 2, 3]
   输出：[]
   解释：每个数都只出现一次，因此结果为空。
