0406. Queue Reconstruction by Height
====================================

题目信息
--------

:题号: 0406
:难度: Medium
:主题: 贪心、排序、插入
:原题: `LeetCode 406 <https://leetcode.com/problems/queue-reconstruction-by-height/>`_
:教学重点: 先安排高个子，使后插入的矮个子不会改变已确定的前方高个子数量。

题目重述
--------

每个人由 ``[h, k]`` 表示，其中 ``h`` 是身高，``k`` 表示排在此人前面且身高不低于 ``h`` 的人数。给定所有人的信息，重建任意一个满足全部约束的队列。

所有人必须恰好出现一次。常见做法按身高从高到低、``k`` 从小到大排序，再把每个人插入结果的下标 ``k``。

自建示例
--------

输入 ``[[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]``，一种合法队列为 ``[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]``。
