0420. Strong Password Checker
=============================

题目信息
--------

:题号: 0420
:难度: Hard
:主题: 贪心、字符串、分类计数
:原题: `LeetCode 420 <https://leetcode.com/problems/strong-password-checker/>`_
:教学重点: 统一处理长度限制、字符类别缺失和连续重复段，并让删除优先减少替换次数。

题目重述
--------

给定密码字符串，使其满足：长度在 ``6..20``；至少包含一个小写字母、一个大写字母和一个数字；不能出现三个连续相同字符。每次可以插入、删除或替换一个字符，返回最少操作数。

长度不足时，插入既能补长度、也可能补字符类别或打断重复。长度超过 20 时必须先删除，并优先从长度模 3 合适的重复段中删除，以最大程度减少后续替换。

自建示例
--------

``password = "aA1aaa"`` 长度和字符类别都满足，只存在三个连续 ``a``，替换其中一个字符即可，因此答案为 ``1``。``password = "a"`` 需要补足长度并补齐大写字母和数字，最少为 ``5`` 次插入。
