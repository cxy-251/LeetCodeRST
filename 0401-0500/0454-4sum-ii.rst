0454. 4Sum II
==============

题目信息
--------

:题号: 0454
:难度: Medium
:主题: 四个等长数组、下标四元组、元素和为零、方案计数
:原题: `LeetCode 0454 <https://leetcode.com/problems/4sum-ii/>`_
:重点: 分别从四个数组各选一个下标、相同数值的不同下标分别计数、只返回四元组数量

题目重述
--------

给定四个长度均为 ``n`` 的整数数组 ``nums1``、``nums2``、``nums3``、``nums4``，统计满足以下条件的下标四元组 ``(i, j, k, l)`` 数量：

.. code-block:: text

   nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0

每个下标分别取自对应数组，范围都是 ``[0, n-1]``。``n`` 位于 ``[1, 200]``，元素位于 ``[-2^28, 2^28]``，题目保证答案不超过 ``2^31-1``。不同下标组合要分别计数，即使选中的数值完全相同。

自建示例
--------

重复零值产生多个下标组合：

.. code-block:: text

   输入：nums1 = [1,-1]
         nums2 = [-1,1]
         nums3 = [0,0]
         nums4 = [0,0]
   输出：8
   解释：前两个数组有两种下标配对使和为 0；后两个数组各有两个零，可形成 2×2 = 4 种下标组合，因此总数为 2×4 = 8。

没有零和四元组：

.. code-block:: text

   输入：nums1 = [1]，nums2 = [1]，nums3 = [1]，nums4 = [1]
   输出：0
   解释：唯一四元组的元素和为 4，不满足条件。
