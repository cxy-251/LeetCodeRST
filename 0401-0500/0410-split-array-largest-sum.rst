0410. Split Array Largest Sum
=============================

题目信息
--------

:题号: 0410
:难度: Hard
:主题: 二分答案、贪心、动态规划
:原题: `LeetCode 410 <https://leetcode.com/problems/split-array-largest-sum/>`_
:教学重点: 固定最大允许和后，贪心计算最少需要多少个连续子数组。

题目重述
--------

给定非负整数数组 ``nums`` 和整数 ``k``，把数组划分为恰好 ``k`` 个非空连续子数组，使这些子数组元素和中的最大值尽可能小，返回这个最小可能值。

答案下界是数组最大元素，上界是数组总和。对于候选上限，可以从左到右贪心装入元素，判断所需分段数是否不超过 ``k``。

自建示例
--------

``nums = [7,2,5,10,8]``，``k = 2``。划分为 ``[7,2,5]`` 和 ``[10,8]`` 时两个和为 ``14``、``18``，最大值为 ``18``，且无法取得更小答案。
