0459. Repeated Substring Pattern
================================

题目信息
--------

:题号: 0459
:难度: Easy
:主题: 小写字符串、非空子串、完整重复、模式判断
:原题: `LeetCode 0459 <https://leetcode.com/problems/repeated-substring-pattern/>`_
:重点: 基本子串必须比原串短、从头到尾连续重复至少两次、不能遗漏或重排字符

题目重述
--------

给定只包含小写英文字母的非空字符串 ``s``，判断是否存在一个非空且长度小于 ``s`` 的字符串 ``t``，使 ``s`` 恰好由 ``t`` 连续重复若干次组成。

重复次数必须至少为 2，所有字符都必须被完整覆盖，不能只让某个前缀或子串满足重复关系。``s.length`` 位于 ``[1, 10^4]``。

自建示例
--------

同一模式重复三次：

.. code-block:: text

   输入：s = "abcabcabc"
   输出：true
   解释：字符串可由非空子串 abc 连续重复 3 次得到。

前后局部相似但不能完整重复：

.. code-block:: text

   输入：s = "abac"
   输出：false
   解释：不存在一个较短子串能够从头到尾重复并恰好覆盖全部四个字符。
