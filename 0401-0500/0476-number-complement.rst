0476. Number Complement
=======================

题目信息
--------

:题号: 0476
:难度: Easy
:主题: 正整数、有效二进制位、逐位取反、前导零忽略
:原题: `LeetCode 0476 <https://leetcode.com/problems/number-complement/>`_
:重点: 只翻转从最高有效位到最低位的二进制位、无限前导零不参与、返回取反后的整数

题目重述
--------

给定正整数 ``num``，把它的二进制表示中所有有效位逐位取反：0 变为 1，1 变为 0。返回取反后表示的整数。

有效位从原数最高的 1 开始，到最低位结束；更高位置隐含的前导零不参与翻转。``num`` 位于 ``[1, 2^31-1]``，因此输入不存在符号位和数字 0 的特殊情况。

自建示例
--------

高低位同时翻转：

.. code-block:: text

   输入：num = 10
   输出：5
   解释：10 的有效二进制表示为 1010，逐位取反得到 0101，即十进制 5；最左侧新增的 0 不影响数值。

只有一个有效位：

.. code-block:: text

   输入：num = 1
   输出：0
   解释：二进制 1 取反后为 0。
