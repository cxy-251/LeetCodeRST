0414. Third Maximum Number
==========================

题目信息
--------

:题号: 0414
:难度: Easy
:主题: 数组、有序状态、去重
:原题: `LeetCode 414 <https://leetcode.com/problems/third-maximum-number/>`_
:教学重点: 名次按不同数值计算，重复元素不能占用多个排名。

题目重述
--------

给定整数数组，返回第三大的不同数值。若不同数值不足三个，返回数组中的最大值。

可以维护三个严格递减的候选值；遇到与已有候选相同的元素时直接跳过，并注意整数最小值也是合法输入。

自建示例
--------

``nums = [2,2,3,1]`` 的不同数值为 ``3,2,1``，因此返回 ``1``。``nums = [1,2]`` 不足三个不同值，返回最大值 ``2``。
