0456. 132 Pattern
=================

题目信息
--------

:题号: 0456
:难度: Medium
:主题: 三个下标、严格不等式、132 相对大小、存在性判断
:原题: `LeetCode 0456 <https://leetcode.com/problems/132-pattern/>`_
:重点: 必须满足 ``i < j < k``、数值关系为 ``nums[i] < nums[k] < nums[j]``、三个值严格不等

题目重述
--------

给定整数数组 ``nums``，判断是否存在三个下标 ``i``、``j``、``k``，满足 ``i < j < k``，同时满足：

.. code-block:: text

   nums[i] < nums[k] < nums[j]

这种下标顺序和数值关系称为 132 模式。``nums.length`` 位于 ``[1, 2 * 10^5]``，元素在 32 位有符号整数范围内。三个不等式都是严格的，相等值不能充当其中两个不同层级。

自建示例
--------

存在非连续的 132 模式：

.. code-block:: text

   输入：nums = [6, 1, 5, 3, 4]
   输出：true
   解释：选择下标 1、2、3，数值为 1、5、3，满足 1 < 3 < 5。

只有递增关系：

.. code-block:: text

   输入：nums = [1, 2, 3, 4]
   输出：false
   解释：任意较晚元素都不会落在先前较小值和中间较大值之间，无法形成 132 模式。
