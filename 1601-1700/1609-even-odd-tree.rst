1609. Even Odd Tree
===================

题目信息
--------

:题号: 1609
:难度: Medium
:主题: 二叉树、层序遍历、奇偶与单调性
:原题: `LeetCode 1609 <https://leetcode.com/problems/even-odd-tree/>`_
:重点: 偶数层值为奇数且严格递增，奇数层值为偶数且严格递减

题目重述
--------

给定二叉树，根为第 ``0`` 层。判断每层节点值是否同时满足指定奇偶性和从左到右的严格单调顺序。

空缺节点不参与比较。

自建示例
--------

.. code-block:: text

   输入：root = [1,10,8,3,5,7,9]
   输出：true
   解释：第 0 层奇数；第 1 层 10>8 且均为偶数；第 2 层 3<5<7<9 且均为奇数。

.. code-block:: text

   输入：root = [2]
   输出：false
   解释：第 0 层必须包含奇数值。
