1632. Rank Transform of a Matrix
===============================

题目信息
--------

:题号: 1632
:难度: Hard
:主题: 矩阵、并查集、拓扑关系
:原题: `LeetCode 1632 <https://leetcode.com/problems/rank-transform-of-a-matrix/>`_
:重点: 同行或同列中较小值排名必须较小，相同值排名相同，并使排名尽可能小

题目重述
--------

把整数矩阵转换为正整数排名矩阵。同行或同列中，原值较小时排名严格较小，原值相等时排名相等；在满足规则的前提下每个排名应尽可能小。

自建示例
--------

.. code-block:: text

   输入：matrix = [[1,2],[3,4]]
   输出：[[1,2],[2,3]]
   解释：行列中的递增关系共同决定最小排名。

.. code-block:: text

   输入：matrix = [[5,5]]
   输出：[[1,1]]
   解释：同行相同值必须获得相同排名。
