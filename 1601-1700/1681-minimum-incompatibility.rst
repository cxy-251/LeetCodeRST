1681. Minimum Incompatibility
=============================

题目信息
--------

:题号: 1681
:难度: Hard
:主题: 状态压缩、分组动态规划
:原题: `LeetCode 1681 <https://leetcode.com/problems/minimum-incompatibility/>`_
:重点: 把数组分成 ``k`` 个等大小组，每组值互不相同，代价为组内最大值减最小值

题目重述
--------

给定长度为 ``n`` 的数组 ``nums`` 和能整除 ``n`` 的 ``k``。把全部元素划分为 ``k`` 组，每组大小为 ``n/k``，且组内不能有重复值。返回各组不相容性之和的最小值；无法划分时返回 ``-1``。

自建示例
--------

.. code-block:: text

   输入：nums = [1,2,1,4], k = 2
   输出：4
   解释：可分为 [1,2] 与 [1,4]，代价为 1 + 3。

.. code-block:: text

   输入：nums = [1,1], k = 1
   输出：-1
   解释：唯一分组含重复值。
