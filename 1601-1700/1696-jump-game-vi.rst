1696. Jump Game VI
==================

题目信息
--------

:题号: 1696
:难度: Medium
:主题: 动态规划、单调队列
:原题: `LeetCode 1696 <https://leetcode.com/problems/jump-game-vi/>`_
:重点: 从位置 ``i`` 可跳到后续至多 ``k`` 步的位置，路径得分为访问元素之和

题目重述
--------

从数组下标 ``0`` 出发到达最后一个下标。每次向右跳 ``1`` 到 ``k`` 步，返回可获得的最大路径元素和。

自建示例
--------

.. code-block:: text

   输入：nums = [1,-1,-2,4,-7,3], k = 2
   输出：7
   解释：路径 0 -> 1 -> 3 -> 5 的得分为 1-1+4+3=7。

.. code-block:: text

   输入：nums = [-5], k = 1
   输出：-5
   解释：起点同时是终点。
