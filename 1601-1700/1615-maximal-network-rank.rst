1615. Maximal Network Rank
==========================

题目信息
--------

:题号: 1615
:难度: Medium
:主题: 图、度数、枚举
:原题: `LeetCode 1615 <https://leetcode.com/problems/maximal-network-rank/>`_
:重点: 两座城市的网络秩为二者关联道路总数，二者之间的直接道路只计一次

题目重述
--------

给定 ``n`` 座城市和无向道路数组。对任意两座不同城市，计算至少连接其中一座城市的道路数量，返回所有城市对中的最大值。

道路不重复。

自建示例
--------

.. code-block:: text

   输入：n = 4, roads = [[0,1],[0,2],[1,2],[2,3]]
   输出：4
   解释：城市 0 与 2 的度数和为 5，二者直接道路重复计算一次，网络秩为 4。

.. code-block:: text

   输入：n = 3, roads = []
   输出：0
   解释：没有道路，任意城市对的网络秩均为零。
