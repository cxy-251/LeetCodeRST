1652. Defuse the Bomb
=====================

题目信息
--------

:题号: 1652
:难度: Easy
:主题: 循环数组、滑动窗口
:原题: `LeetCode 1652 <https://leetcode.com/problems/defuse-the-bomb/>`_
:重点: ``k>0`` 取后续 ``k`` 项，``k<0`` 取前面 ``|k|`` 项，``k=0`` 全置零

题目重述
--------

给定循环数组 ``code``。用指定方向相邻元素之和替换每个位置，所有计算基于原数组，返回替换后的数组。

自建示例
--------

.. code-block:: text

   输入：code = [5,7,1,4], k = 2
   输出：[8,5,9,12]
   解释：每项等于其后两个循环元素之和。

.. code-block:: text

   输入：code = [2,3], k = 0
   输出：[0,0]
   解释：k 为零时所有位置替换为零。
