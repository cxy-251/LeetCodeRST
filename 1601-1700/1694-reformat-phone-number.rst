1694. Reformat Phone Number
===========================

题目信息
--------

:题号: 1694
:难度: Easy
:主题: 字符串、模拟
:原题: `LeetCode 1694 <https://leetcode.com/problems/reformat-phone-number/>`_
:重点: 去除空格和短横线后，从左到右分成长度 3 的块，末尾四位分成 2+2

题目重述
--------

清理电话号码中的空格与 ``-``，再按规则重新分组。任何块长度不得为 1，块之间用短横线连接。

自建示例
--------

.. code-block:: text

   输入：number = "1-23-45 6"
   输出："123-456"
   解释：六个数字分成两个三位块。

.. code-block:: text

   输入：number = "123 4-567"
   输出："123-45-67"
   解释：最后四位必须拆成两个两位块。
