1664. Ways to Make a Fair Array
===============================

题目信息
--------

:题号: 1664
:难度: Medium
:主题: 前缀和、奇偶下标
:原题: `LeetCode 1664 <https://leetcode.com/problems/ways-to-make-a-fair-array/>`_
:重点: 删除一个元素后右侧下标奇偶性翻转，统计新数组奇数位和等于偶数位和的删除位置

题目重述
--------

给定整数数组。删除恰好一个元素并重新编号，若剩余数组偶数下标元素和与奇数下标元素和相等，则该删除位置有效。返回有效位置数量。

自建示例
--------

.. code-block:: text

   输入：nums = [2,1,6,4]
   输出：1
   解释：删除 1 后得到 [2,6,4]，偶数位和 6 等于奇数位和 6。

.. code-block:: text

   输入：nums = [5]
   输出：1
   解释：删除唯一元素后两类下标的和都为零。
