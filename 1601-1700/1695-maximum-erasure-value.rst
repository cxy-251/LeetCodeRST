1695. Maximum Erasure Value
===========================

题目信息
--------

:题号: 1695
:难度: Medium
:主题: 滑动窗口、哈希集合
:原题: `LeetCode 1695 <https://leetcode.com/problems/maximum-erasure-value/>`_
:重点: 删除一个连续子数组且其中元素互不相同，最大化元素和

题目重述
--------

给定正整数数组。选择一个所有元素都不同的连续子数组并删除，得分为其元素和。返回最大可能得分。

自建示例
--------

.. code-block:: text

   输入：nums = [4,2,4,5,6]
   输出：17
   解释：选择 [2,4,5,6]，其元素互不相同且和为 17。

.. code-block:: text

   输入：nums = [1,1,1]
   输出：1
   解释：合法子数组最多只含一个 1。
