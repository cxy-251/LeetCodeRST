1631. Path With Minimum Effort
==============================

题目信息
--------

:题号: 1631
:难度: Medium
:主题: 网格、最短路、二分查找
:原题: `LeetCode 1631 <https://leetcode.com/problems/path-with-minimum-effort/>`_
:重点: 路径代价是沿途相邻高度差的最大值，目标最小化该最大值

题目重述
--------

从高度矩阵左上角四向移动到右下角。一次路径的体力值定义为路径上相邻格高度差绝对值的最大值。返回所有路径中的最小体力值。

自建示例
--------

.. code-block:: text

   输入：heights = [[1,3],[2,4]]
   输出：2
   解释：两条最短路径的最大高度差均为 2。

.. code-block:: text

   输入：heights = [[7]]
   输出：0
   解释：起点即终点，不经过任何边。
