1630. Arithmetic Subarrays
==========================

题目信息
--------

:题号: 1630
:难度: Medium
:主题: 子数组、排序、等差数列
:原题: `LeetCode 1630 <https://leetcode.com/problems/arithmetic-subarrays/>`_
:重点: 每个查询截取闭区间子数组，允许重新排列后判断能否形成等差数列

题目重述
--------

给定数组和多组 ``l[i], r[i]``。对每个闭区间取出元素，判断是否能通过任意重排形成相邻差相同的等差数列，按查询顺序返回布尔值。

自建示例
--------

.. code-block:: text

   输入：nums = [5,1,3,7], l = [0,1], r = [2,3]
   输出：[true,false]
   解释：[5,1,3] 可排为 1,3,5；[1,3,7] 的相邻差无法相等。

.. code-block:: text

   输入：nums = [2,2,2], l = [0], r = [2]
   输出：[true]
   解释：公差可以为 0。
