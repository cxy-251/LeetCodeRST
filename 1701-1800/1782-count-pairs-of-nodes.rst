1782. Count Pairs Of Nodes
==========================

题目信息
--------

:题号: 1782
:难度: Hard
:主题: 图、度数、排序、重复边
:原题: `LeetCode 1782 <https://leetcode.com/problems/count-pairs-of-nodes/>`_
:重点: 对每个查询统计无序节点对，使至少连接其中一个节点的边数严格大于查询值

题目重述
--------

给定允许重复边的无向图。对查询 ``q``，统计 ``a < b`` 且与 ``a`` 或 ``b`` 相连的不同边数量严格大于 ``q`` 的节点对，按查询顺序返回数量。

自建示例
--------

.. code-block:: text

   输入：n = 3, edges = [[1,2],[2,3]], queries = [1]
   输出：[3]
   解释：任意节点对都至少关联两条给定边，因此都严格大于 1。

.. code-block:: text

   输入：n = 2, edges = [[1,2],[1,2]], queries = [2]
   输出：[0]
   解释：两条重复边只形成两条关联边，不严格大于 2。
