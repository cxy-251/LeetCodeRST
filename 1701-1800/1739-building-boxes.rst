1739. Building Boxes
====================

题目信息
--------

:题号: 1739
:难度: Hard
:主题: 数学、贪心、立体堆叠
:原题: `LeetCode 1739 <https://leetcode.com/problems/building-boxes/>`_
:重点: 箱子放在其他箱子上时其四个竖直侧面都必须有相邻箱子支撑，求最少接地箱数

题目重述
--------

把 ``n`` 个单位立方体堆在房间角落并满足支撑规则。返回与地面接触的最少箱子数量。

自建示例
--------

.. code-block:: text

   输入：n = 4
   输出：3
   解释：三个箱子放在地面可支撑第四个箱子形成最小底层。

.. code-block:: text

   输入：n = 1
   输出：1
   解释：唯一箱子必须接触地面。
