1706. Where Will the Ball Fall
==============================

题目信息
--------

:题号: 1706
:难度: Medium
:主题: 矩阵、模拟
:原题: `LeetCode 1706 <https://leetcode.com/problems/where-will-the-ball-fall/>`_
:重点: 斜板方向为 ``1`` 或 ``-1``，V 形、边界或相反方向会卡住球

题目重述
--------

从网格顶端每一列各放一个球。球按每格斜板方向移动到下一行；若撞墙或两块斜板形成 V 形则卡住。返回每个球最终离开的列，卡住返回 ``-1``。

自建示例
--------

.. code-block:: text

   输入：grid = [[1,1],[-1,-1]]
   输出：[0,-1]
   解释：第一颗球右移后再左移并从列 0 离开；第二颗球第一行即撞右边界。

.. code-block:: text

   输入：grid = [[-1]]
   输出：[-1]
   解释：唯一球立即撞到左边界。
