1765. Map of Highest Peak
=========================

题目信息
--------

:题号: 1765
:难度: Medium
:主题: 多源广度优先搜索、矩阵
:原题: `LeetCode 1765 <https://leetcode.com/problems/map-of-highest-peak/>`_
:重点: 水域高度为零，相邻格高度差至多一，最大化整张图最高高度

题目重述
--------

给定水域标记矩阵。为每格分配非负整数高度，使所有水格高度为 ``0``，上下左右相邻高度差绝对值不超过 ``1``。返回任意使最高点尽可能高的高度矩阵。

自建示例
--------

.. code-block:: text

   输入：isWater = [[1,0],[0,0]]
   输出：[[0,1],[1,2]]
   解释：高度等于到最近水格的曼哈顿距离。

.. code-block:: text

   输入：isWater = [[1]]
   输出：[[0]]
   解释：唯一格是水域。
