0141. Linked List Cycle
=======================

题目信息
--------

:题号: 0141
:难度: Easy
:主题: 链表、双指针、对象身份
:原题: `LeetCode 0141 <https://leetcode.com/problems/linked-list-cycle/>`_
:访问状态: Available
:教学重点: 快慢指针相遇、身份比较、无环终止

题目重述
--------

给定单链表头节点，判断沿 ``next`` 指针不断前进时是否会再次到达已经访问过的节点。链表可能为空。
只返回是否存在环，不允许修改节点连接关系。

算法
----

维护慢指针 ``slow`` 和快指针 ``fast``，初始都指向头节点。每轮让 ``slow`` 前进一步，让 ``fast``
前进两步。

若链表无环，``fast`` 必然先到达空引用，返回假。若链表有环，两个指针进入环后，快指针每轮相对慢指针
多前进一步；它们在有限个环内位置中必然相遇，返回真。

比较的是节点对象身份，不能比较 ``val``，因为不同节点可以保存相同数值。

正确性
~~~~~~

无环时，沿 ``next`` 的路径有限且不会重复。快指针每轮前进两步，最终必然到达空引用，算法返回假。

有环时，慢指针和快指针最终都进入环。设环长为 ``c``，进入环后两者位置差每轮增加一并对 ``c`` 取模。
至多经过 ``c`` 轮，位置差会变为零，两者指向同一节点，算法返回真。因此算法恰好识别存在环的链表。

复杂度
~~~~~~

设从头节点可到达的不同节点数为 ``n``。时间 ``O(n)``，只保存两个节点引用，算法额外空间 ``O(1)``。
Rust 适配器使用 ``Rc::ptr_eq``，R 使用 ``identical``，都比较节点身份而不是节点内容。

关键边界
--------

* 空链表和单个无自环节点返回假；
* 单节点 ``next`` 指向自身时返回真；
* 两个不同节点即使 ``val`` 相同也不能视为相遇；
* 循环条件必须先确认 ``fast`` 和 ``fast.next`` 非空；
* 算法只读取指针，不改变原链表。

验证
----

运行空链表、单节点、自环、两节点环和无环长链表；Python、C 与 C++ 结果一致。其余语言完成节点身份、
空引用和步进顺序静态检查。

最小自检
--------

#. 为什么快慢指针在有环时一定会相遇？
#. 为什么不能通过节点值相等判断相遇？
#. 无环链表中为什么只检查快指针的空引用就足以终止？
