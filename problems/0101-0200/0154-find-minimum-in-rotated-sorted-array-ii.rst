题目重述
--------

给定一个非空整数数组。它由一个非递减数组在未知位置旋转得到，允许出现重复值，也可能保持原顺序。
返回其中的最小值。算法不修改输入；应尽量利用二分结构，同时准确说明重复值导致的最坏复杂度。

算法
----

仍维护包含最小值的闭区间 ``[left, right]``，比较中点与右端：

* ``nums[mid] > nums[right]``：最小值严格位于 ``mid`` 右侧；
* ``nums[mid] < nums[right]``：最小值位于 ``[left, mid]``；
* ``nums[mid] == nums[right]``：删除右端，即令 ``right -= 1``。

等值分支不能判断旋转断点位于哪侧。删除右端仍然安全：若右端不是最小值，删除它无影响；若右端是最小值，
中点保存了一个相同的最小值见证，因此候选区间内仍至少保留一个答案。

正确性
~~~~~~

循环不变量是：当前区间中至少存在一个值等于全局最小值的元素。前两个比较分支与互异版本相同，分别排除
不可能含最小值的较大递增段，或保留可能成为最小值的中点。

当 ``nums[mid] == nums[right]`` 时，删除右端不会破坏不变量。若 ``nums[right]`` 大于全局最小值，它本来
就不是答案；若它等于全局最小值，则 ``nums[mid]`` 与它相等，中点仍在新区间中。每轮至少移动一个边界，
最终区间缩为一个元素；由不变量，该元素值就是全局最小值。

复杂度
~~~~~~

通常不相等比较会删除约一半区间，运行接近 ``O(log n)``。大量重复值可能让每轮只能执行 ``right -= 1``，
例如所有元素相等时，最坏时间复杂度为 ``O(n)``。额外空间为 ``O(1)``，所有实现只读取输入。

关键边界
--------

* 全部元素相等时结果正确，但运行时间退化为线性；
* ``[10, 1, 10, 10, 10]`` 表明等值时不能固定选择左半或右半；
* 最小值可以出现多次，算法只需保留至少一个最小值见证；
* 等值分支只能删除已由中点复制见证的右端，不能直接删除中点；
* 单元素、未旋转、旋转点两侧重复值均由同一闭区间不变量覆盖。

最小自检
--------

#. ``nums[mid] == nums[right]`` 时为什么无法判断旋转点在哪一侧？
#. 删除右端时，哪一个位置为可能被删除的最小值提供了等值见证？
#. 为什么重复值版本只能给出通常对数、最坏线性的时间界？
