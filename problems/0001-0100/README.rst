0068–0070 学习重点
------------------

* 贪心选择每行可容纳的最大连续单词前缀，并证明下一个单词无法合法加入；
* 用整数商与余数分配普通行空格，让较大的间隔优先位于左侧；
* 区分普通两端对齐、最后一行左对齐和单词独占行；
* 把 ``mid² <= x`` 改写为 ``mid <= x / mid``，避免固定宽整数平方溢出；
* 使用闭区间二分寻找最后一个满足单调谓词的整数；
* 按最后一步为一级或二级划分走法，并把斐波那契型递推压缩为两个状态。
