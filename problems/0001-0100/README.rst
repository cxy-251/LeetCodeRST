0087–0088 学习重点
------------------

* 用 ``(i, j, length)`` 表示两个等长区间之间的 scramble 关系；
* 对每个切分点完整检查交换与不交换两种根结点对应；
* 用固定字母表前缀频次安全剪除字符多重集不同的状态；
* 从数组尾部写入两个有序前缀的较大元素，避免覆盖 ``nums1`` 未读值；
* 用 ``write = first + second + 1`` 证明逆向写入位置安全；
* ``nums2`` 耗尽后，``nums1`` 剩余前缀已经位于最终位置。
