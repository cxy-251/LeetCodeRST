题目目录
========

本目录按 LeetCode 题号保存题目讲解。

目录规则
--------

每 100 题一个目录：

::

   0001-0100/
   0101-0200/
   0201-0300/

每道题只保留一个正式 RST 文件：

::

   0001-0100/0001-two-sum.rst

多语言代码直接写在该题 RST 中。只有确实需要单独验证、保存较长辅助程序或记录特殊输入时，才增加独立代码文件。

推进规则
--------

* 从 ``state/PROGRESS.toml`` 的 ``next_problem`` 开始。
* 严格按题号递增。
* 公开题完成后推进下一题。
* 无法访问的 Premium 题登记后跳过。
* 不因为题目简单而跳号。
* 不按专题重排主线。

教学规则
--------

* 基础语法解释逐步衰减。
* 疑难算法周期性复现。
* 简单题保持短小。
* 复杂题充分解释状态、不变量、证明和边界。
* 多语言实现强调各语言真实差异，不做机械翻译。

新增题目前先阅读 ``AGENTS.md``、``docs/RST_STYLE_GUIDE.rst``、状态账本和最近题目。
