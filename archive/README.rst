历史产物归档
============

用途
----

本目录保存已经完成、已经被后续规则或状态吸收的阶段产物。归档内容用于证据追溯、历史题修复和规则来源核对，
不属于新题生成时的默认读取集合。

归档原则
--------

#. ``docs/``、``state/`` 和根目录只保留当前执行入口、当前状态、模板和长期策略。
#. 审查批次、逐批 findings、旧阶段目录和规则归并记录在阶段结束后移入本目录。
#. 归档文件保持原始内容，不因后续更正而重写；事实冲突以 ``state/REVIEW_INDEX.toml`` 的 active corrections 为准。
#. 新对话只有在追溯某条规则、修复历史题或核对审查证据时才读取归档。
#. 归档移动与入口更新必须位于同一个原子提交，禁止留下半迁移路径。

现有归档
--------

* ``reviews/0051-0100/MANIFEST.rst``：第二轮逐题审查、批次证据与规则归并记录。
