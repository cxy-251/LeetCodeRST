0021. Merge Two Sorted Lists
----------------------------

正向样本
~~~~~~~~

两个当前头节点覆盖全局最小未处理节点的证明完整；稳定归并的 ``<=`` 选择也清楚区分了
“值序列正确”与“相等值来源顺序确定”。

前向风险
~~~~~~~~

主解法直接复用并重连输入节点。调用结束后，原 ``list1``、``list2`` 不再保持原来的链表拓扑。
Rust 直接消费两个输入所有权，其他语言保留入口引用却修改节点链接，因此十语言的调用后语义并不相同。

算法还隐含两条链表无环且节点集合互不相交。若两条输入共享后缀，同一个节点可能同时作为两个
候选再次进入归并，导致重复链接甚至形成环。

提升规则
~~~~~~~~

* 破坏性链表算法明确调用后原入口和节点引用是否仍可使用；
* 明确输入链表是否要求无环、互不相交；
* 所有权消费、引用修改和节点复用按语言分别说明。

0022. Generate Parentheses
--------------------------

正向样本
~~~~~~~~

合法前缀不变量、完整性、无重复和 Catalan 输出规模推导完整。固定数组覆盖与追加—撤销两种路径
实现也都解释了叶子处为什么需要复制结果。

前向风险
~~~~~~~~

C 版本的 ``realloc`` 直接覆盖唯一结果指针，所有分配路径都没有失败处理。``2*n``、容量翻倍和
Catalan 数若用于精确预分配，也需要在目标容量类型中检查中间乘积与转换。

R 在每个叶子执行 ``c(result, value)``，会反复复制已有输出，不能继续用其他语言的摊还追加成本
描述该实现。

提升规则
~~~~~~~~

* 组合计数公式用于容量前，检查公式和中间值是否可表示；
* 动态数组扩容使用事务式更新；
* 输出累加器按目标语言真实复制语义计费。

0023. Merge k Sorted Lists
--------------------------

正向样本
~~~~~~~~

候选头节点覆盖、堆顶全局最小和堆大小不超过 ``k`` 的证明完整。Python 的序号避免相等键继续
比较 ``ListNode``；Rust 用 ``take`` 分离后继所有权，均是良好的语言边界样本。

前向风险
~~~~~~~~

C 的堆存储分配没有失败契约。C# ``PriorityQueue`` 依赖较新的 .NET 版本，需要声明版本或提供
兼容实现。

R 使用普通 ``list`` 和 ``<<-`` 完成每次堆交换。``<<-`` 只决定绑定位置，不能证明底层列表为
常数时间原地更新；写时复制可能使单次堆更新退化，抽象二叉堆的 ``O(log k)`` 不能直接外推。

提升规则
~~~~~~~~

* 数据结构复杂度以具体语言容器语义为准；
* 堆比较器满足语言要求的严格顺序，相等键不得继续比较无序节点对象；
* ``pop``、``unwrap``、类型断言必须由堆非空不变量支撑；
* 标准库优先队列声明最低运行时版本。

0024. Swap Nodes in Pairs
-------------------------

正向样本
~~~~~~~~

正文把局部结构明确拆成 ``prev -> first -> second -> after``，并列出交换后的三条链接。证明同时
覆盖局部顺序、后缀保留、奇数尾节点和节点守恒。Rust 的可变链接槽位也给出了真实所有权实现。

提升规则
~~~~~~~~

所有局部链表重连都应：

* 在改写前保存仍需使用的后缀；
* 列出被删除和新增的边；
* 证明组前、组内、组后重新连通；
* 证明节点集合不变且不会形成环；
* 让非空断言紧邻建立该事实的循环条件。

0025. Reverse Nodes in k-Group
------------------------------

正向样本
~~~~~~~~

“先只读探测完整分组，再执行破坏性反转”是本批最重要的可复用结构。半开区间、把
``group_next`` 作为初始前驱、旧组头变新组尾的证明完整。Rust 采用不同所有权算法，也单独声明了
递归栈成本。

提升规则
~~~~~~~~

* 可能因边界不足而放弃的破坏性操作，必须先完成只读可行性探测；
* 首次写入前确定操作必然完成，失败路径保持输入完全不变；
* 分组变换证明同时覆盖区间边界、节点守恒、无环和下一组入口；
* 语言特化递归实现仍需用精确最大规模证明栈深安全。

本批提升的统一规则
------------------

破坏性输入与别名契约
~~~~~~~~~~~~~~~~~~~~

* 复用节点或原地重排时，明确调用后原输入是否仍保持可遍历、原入口是否仍代表原结构；
* 链表与图结构列出无环、无共享节点或允许共享的精确前提；
* 十语言的消费所有权、引用修改、垃圾回收和显式释放差异分别说明。

具体容器决定数据结构复杂度
~~~~~~~~~~~~~~~~~~~~~~~~~~

* “使用堆”不自动保证所有语言都是 ``O(log k)`` 更新；
* R 写时复制列表、不可变集合和持续化结构需要按具体更新成本重新分析；
* 自定义堆必须检查非空前提、比较器顺序和相等键处理。

局部重连需要边清单
~~~~~~~~~~~~~~~~~~

* 保存后缀，再修改链接；
* 对照列出重连前后的边；
* 证明边界连通、节点守恒和无环；
* 更新下一轮入口时说明它为何正好指向未处理部分。

先探测后破坏
~~~~~~~~~~~~

* 边界不足、容量不足或结构不完整会取消操作时，先只读验证；
* 只有确定操作可完整完成后才进行首次写入；
* 失败路径无需回滚，并且原输入保持不变。

组合计数的数值与累加成本
~~~~~~~~~~~~~~~~~~~~~~~~

* Catalan、排列、组合数量不能在窄类型中直接用于容量；
* 计数公式的中间乘法、除法和转换均需验证；
* 输出追加的渐进成本按语言实现计算，尤其避免 R 循环中的反复向量拼接。
