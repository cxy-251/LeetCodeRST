0091. Decode Ways
-----------------

正向样本
~~~~~~~~

教程没有直接沿用普通整串滚动 DP，而是先验证所有 ``0``，再把合法的 ``10`` / ``20`` 当作强制边界。
每个零必须消费其前一位，因此零前一位不能继续留在左侧无零片段中。对每个无零片段，最后一个编码只有
单字符和合法双字符两类，滚动状态精确覆盖全部方案。

分段乘法的证明成立。强制双字符编码阻断左右跨界选择，且自身只有一种取法；各无零片段可以独立选择，
全串方案数是各片段方案数的乘积。``1010``、``11106`` 和 ``2101`` 等边界的片段坐标与代码一致。

数值安全
~~~~~~~~

正文没有简单把“最终答案适合 32 位”外推到任意前缀。它先排除非法零，再证明无零片段的滚动计数单调
不减，任一中间值不超过该片段最终因子；每个因子至少为一，所以部分乘积不超过最终答案。由此固定宽
语言中的实际计数安全。

Julia 使用 ``codeunits`` 视图，一基 ``start`` / ``stop`` 与正文半开片段边界逐项换算；R 在段长至少为
二时才构造 ``seq.int(start + 2, stop)``，不会产生方向错误。

前向规则
~~~~~~~~

* 强制 token 或强制边界先说明消费位置和被阻断的跨界选择；
* 独立片段相乘必须证明组合双射，而不只是观察样例；
* 最终答案上界保护中间值时，要证明局部单调与部分乘积支配关系；
* 非法输入应在可能累积巨大中间状态前退出。

0092. Reverse Linked List II
----------------------------

正向样本
~~~~~~~~

哨兵节点把 ``left = 1`` 统一为普通前驱场景。``current`` 固定为原区间首节点，每轮取出
``current.next``，先让 ``current`` 越过该节点，再把被移动节点插到 ``before`` 之后。执行
``right-left`` 次后，区间中除首节点外的所有节点恰好逆序移动一次。

四条链接赋值具备完整拓扑证书：被移动节点先从旧位置摘除，因此不会丢失后继；它再指向已反转前缀，
而固定尾 ``current`` 继续指向未处理区间或最终后缀，因此不会形成返回环。区间前缀和后缀内部链接保持
原样。

所有权版本
~~~~~~~~~~

Rust 没有强行照搬可变裸指针头插，而是从所有权链中取出目标区间，逐节点反转，再找到反转段尾并接回
后缀。控制流不同，仍满足相同节点身份、修改范围、区间外顺序和 ``O(n)`` 时间、常数容器空间契约。

前向规则
~~~~~~~~

* 链表区间重连列出 ``before``、固定尾、移动节点和后缀的修改前后边；
* 非空解包必须由位置合法性和循环次数紧邻支撑；
* 所有权语言使用替代算法时重新证明完整语义，不以代码形状一致为目标；
* 验证同时检查节点集合、区间外顺序、长度和无环性。

0093. Restore IP Addresses
--------------------------

正向样本
~~~~~~~~

状态由已消费位置和已完成段数决定。剩余 ``k`` 段至少需要 ``k`` 个字符，最多容纳 ``3k`` 个字符；
``k <= r <= 3k`` 同时给出必要下界和上界。深度达到四时，该剪枝保证只有字符全部消费的状态能够提交。

每段按十进制增量构造。首字符为零时，长度大于一的候选都具有前导零，可以停止；数值首次超过 255 后，
继续追加数字只会让正十进制值更大，同样可以停止。这两个 ``break`` 都有单调性依据。

容量与输出
~~~~~~~~~~

每段长度只有 1、2、3 三种选择，四段长度向量最多 ``3^4 = 81`` 个，因此 C 的 81 个外层结果槽位是
安全上界。它是候选长度向量上界，不是所有输入都能达到的有效地址精确数量。地址字符串最大 15 字符，
16 字节分配包含终止符。

前向规则
~~~~~~~~

* 固定段数问题在每层检查剩余容量的最小值与最大值；
* 完成深度提交前必须由状态证明输入恰好耗尽；
* 使用 ``break`` 剪枝时证明后续候选单调不可能恢复合法；
* 预分配槽位由选择向量上界、输出字符长度和终止符分别推导。

0094. Binary Tree Inorder Traversal
-----------------------------------

正向样本
~~~~~~~~

显式栈保存递归中的未完成续点：沿左链入栈时节点自身尚不能访问；到达空孩子后，栈顶节点的左子树已经
完成，它才成为下一个中序节点。输出后转向右孩子，再展开该右子树的最左路径，精确模拟
“左子树—根—右子树”。

每个节点只通过唯一父边到达一次，入栈和弹栈各一次。该结论依赖输入确实是无环且没有共享子树的二叉树；
若输入扩大为一般图，必须增加访问状态。

资源说明
~~~~~~~~

工作栈只保存当前祖先链，空间为 ``O(h)``；返回数组是 ``Theta(n)``。C 的 100 项节点栈由题目节点上界
支撑，动态结果数组扩容路径完整。Rust 克隆 ``Rc`` 只增加引用计数，不复制树。R 的列表栈和结果向量
具有不同复制行为，逐项扩展结果的累计复制最坏为 ``O(n^2)``，正文已单独说明。

前向规则
~~~~~~~~

* 递归改显式栈时定义每个栈元素保存的续点；
* 节点提交时机必须对应其依赖子问题已经完成；
* 不使用访问集合时声明树结构前提；
* 区分树高工作空间、总节点返回载荷和语言容器复制成本。

0095. Unique Binary Search Trees II
-----------------------------------

正向样本
~~~~~~~~

每棵 BST 的根值唯一。选定根后，左子树只能使用更小连续值域，右子树只能使用更大连续值域；递归生成
左右全部结构并取笛卡尔积，完整覆盖全部树且不会重复。

空区间返回 ``[null]`` 是组合单位元。若返回空列表，叶节点的空左树与空右树没有可枚举组合，递归将无法
生成任何叶节点。该内部占位与公开 ``n = 0`` 返回空外层列表是不同接口层次。

深复制与成本
~~~~~~~~~~~~

同一子树模板可能与多个另一侧模板组合。直接复用会让不同结果树共享可变节点，因此每个最终根都深复制
左右模板。结果共有 ``C_n`` 棵树、每棵 ``n`` 个节点，输出本身需要 ``Theta(n C_n)`` 时间和空间；
临时左右森林的生成与释放也需要纳入峰值生命周期分析。

确定性问题：R 构造器符号
~~~~~~~~~~~~~~~~~~~~~~~~

``0094`` 的 R 节点模型定义构造器为 ``new_tree_node(val, left, right)``。``0095`` 的 R 代码在
``clone_tree`` 和 ``build_trees`` 中却调用 ``tree_node(...)``，当前文件没有定义该符号，也没有声明外部
别名。按仓库现有上下文执行会报找不到函数，因而不能宣称该 R 适配器接口完整。

该问题登记为 ``r_unique_bst_constructor_name``。按历史题处理规则，本批不修改 ``0095`` 正文；后续若
单独修复，应统一调用 ``new_tree_node``，或在代码附近明确定义名称、参数和返回节点语义完全一致的
``tree_node``。

前向规则
~~~~~~~~

* 空结构作为递归组合单位元时，与公开空输入返回值分层定义；
* 可变结果对象承诺独立时，用跨结果节点身份检查验证深复制；
* 临时模板、最终树和克隆过程按同时存活对象计算峰值；
* 跨题复用 helper 时，调用符号、参数顺序和返回类型必须与真实定义精确一致。

跨题归纳
--------

本批形成四组稳定模式：

* 强制边界把全局计数分解为独立片段，并需要完整中间值支配证明；
* 局部链表变换通过边集合证书保证节点守恒和拓扑安全；
* 固定段数回溯结合剩余长度双界与单调停止；
* 树算法区分递归续点、空结构单位元、模板共享和最终结果节点独立性。
