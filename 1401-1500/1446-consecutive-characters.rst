1446. Consecutive Characters
============================

题目信息
--------

:题号: 1446
:难度: Easy
:主题: 字符串、连续段、计数
:原题: `LeetCode 1446 <https://leetcode.com/problems/consecutive-characters/>`_
:重点: 字符串强度定义为相同字符连续子串的最大长度

题目重述
--------

给定非空小写字符串 ``s``。寻找一个由同一字符重复组成的最长连续非空子串。

请返回该子串的长度，即字符串的强度。

``1 <= s.length <= 500``，``s`` 只包含小写英文字母。

自建示例
--------

最长连续段可以位于字符串中间：

.. code-block:: text

   输入：s = "abbcccaa"
   输出：3
   解释：字符 c 连续出现三次，比其他连续段都长。

单字符字符串的强度为一：

.. code-block:: text

   输入：s = "z"
   输出：1
   解释：唯一连续子串长度为一。
