1405. Longest Happy String
==========================

题目信息
--------

:题号: 1405
:难度: Medium
:主题: 贪心、字符串、优先队列
:原题: `LeetCode 1405 <https://leetcode.com/problems/longest-happy-string/>`_
:重点: 字符串只使用给定数量以内的 ``a``、``b``、``c``，且不能出现三个连续相同字符；返回任意最长结果

题目重述
--------

给定三个非负整数 ``a``、``b`` 和 ``c``，分别表示可使用字符 ``a``、``b``、``c`` 的最大数量。

构造一个不包含 ``aaa``、``bbb`` 或 ``ccc`` 的字符串，并使长度尽可能大。每种字符的使用次数不能超过对应上限；若最长结果不唯一，可返回任意一个。

``0 <= a, b, c <= 100``，并且 ``a + b + c > 0``。

自建示例
--------

数量悬殊时可能无法用完最多的字符：

.. code-block:: text

   输入：a = 1, b = 1, c = 7
   输出："ccaccbcc"
   解释：该字符串长度为 8，没有三个连续 c；两个其他字符最多只能把 c 分成三个长度不超过二的区段，因此第七个 c 无法使用。

只有一种字符且数量不超过二时可全部使用：

.. code-block:: text

   输入：a = 0, b = 0, c = 2
   输出："cc"
   解释：结果不包含三个连续相同字符。
