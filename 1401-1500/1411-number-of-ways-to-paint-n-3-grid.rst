1411. Number of Ways to Paint N × 3 Grid
========================================

题目信息
--------

:题号: 1411
:难度: Hard
:主题: 动态规划、状态压缩、计数
:原题: `LeetCode 1411 <https://leetcode.com/problems/number-of-ways-to-paint-n-3-grid/>`_
:重点: 使用三种颜色给 ``n x 3`` 网格染色，任何水平或竖直相邻格颜色不同；答案取模

题目重述
--------

给定正整数 ``n``，使用红、黄、绿三种颜色给 ``n`` 行 ``3`` 列的网格染色。

要求任意共享边的两个格子颜色不同。请返回合法染色方案数量对 ``10^9 + 7`` 取模后的结果。

``1 <= n <= 5000``。
