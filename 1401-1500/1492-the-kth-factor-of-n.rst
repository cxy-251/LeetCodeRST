1492. The kth Factor of n
=========================

题目信息
--------

:题号: 1492
:难度: Medium
:主题: 数论、因数枚举
:原题: `LeetCode 1492 <https://leetcode.com/problems/the-kth-factor-of-n/>`_
:重点: 把 ``n`` 的正因数按升序排列，返回第 ``k`` 个；因数数量不足时返回 ``-1``

题目重述
--------

给定正整数 ``n`` 和正整数 ``k``。若正整数 ``x`` 能整除 ``n``，则 ``x`` 是 ``n`` 的因数。

把全部正因数按升序排列，请返回第 ``k`` 个因数；若因数总数少于 ``k``，返回 ``-1``。

``1 <= n <= 1000``，``1 <= k <= n``。

自建示例
--------

按数值升序选择指定因数：

.. code-block:: text

   输入：n = 12, k = 4
   输出：4
   解释：12 的因数依次为 1、2、3、4、6、12。

请求序号超过因数数量时返回负一：

.. code-block:: text

   输入：n = 7, k = 3
   输出：-1
   解释：质数 7 只有因数 1 和 7。
