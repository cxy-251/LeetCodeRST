1436. Destination City
======================

题目信息
--------

:题号: 1436
:难度: Easy
:主题: 字符串、哈希集合、有向路径
:原题: `LeetCode 1436 <https://leetcode.com/problems/destination-city/>`_
:重点: 路径构成一条无环单链，终点城市只作为目的地出现，从未作为出发城市出现

题目重述
--------

给定路径数组 ``paths``，每条路径 ``[cityA, cityB]`` 表示从 ``cityA`` 直接前往 ``cityB``。所有路径共同构成一条不会循环的旅行路线。

请返回最终目的地城市，即没有任何路径从该城市继续出发的城市。题目保证答案唯一。

``1 <= paths.length <= 100``，城市名称由英文字母和空格组成。

自建示例
--------

最终城市只出现在目的地集合中：

.. code-block:: text

   输入：paths = [["A","B"],["B","C"]]
   输出："C"
   解释：A 和 B 都作为出发城市出现，C 没有后续路径。

只有一条路径时直接返回其终点：

.. code-block:: text

   输入：paths = [["Rome","Paris"]]
   输出："Paris"
   解释：Paris 从未作为出发城市出现。
