1488. Avoid Flood in The City
=============================

题目信息
--------

:题号: 1488
:难度: Medium
:主题: 贪心、有序集合、调度
:原题: `LeetCode 1488 <https://leetcode.com/problems/avoid-flood-in-the-city/>`_
:重点: 下雨日对应湖泊变满且答案固定为 ``-1``；晴天可排干任意一湖，必须在同一满湖再次下雨前完成排干

题目重述
--------

给定数组 ``rains``。若 ``rains[i] > 0``，第 ``i`` 天湖泊 ``rains[i]`` 下雨并变满；若该湖此前已满且未排干，就会发生洪水。若 ``rains[i] == 0``，当天可以选择一座湖排干。

返回任意避免洪水的计划：下雨日答案必须为 ``-1``，晴天答案为当天排干的湖泊编号；无需排干关键湖泊时可填任意正整数。若无法避免洪水，返回空数组。

``1 <= rains.length <= 10^5``，``0 <= rains[i] <= 10^9``。

自建示例
--------

两个晴天可分别处理两座即将再次下雨的湖：

.. code-block:: text

   输入：rains = [1,2,0,0,1,2]
   输出：[-1,-1,1,2,-1,-1]
   解释：在两座湖第二次下雨前分别将它们排干。

晴天数量不足时无法避免洪水：

.. code-block:: text

   输入：rains = [1,2,0,1,2]
   输出：[]
   解释：唯一晴天只能排干一座湖，另一座湖再次下雨时仍为满状态。
