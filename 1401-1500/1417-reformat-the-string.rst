1417. Reformat The String
=========================

题目信息
--------

:题号: 1417
:难度: Easy
:主题: 字符串、分类、交替排列
:原题: `LeetCode 1417 <https://leetcode.com/problems/reformat-the-string/>`_
:重点: 重新排列全部字符，使字母与数字严格交替；无法做到时返回空字符串

题目重述
--------

给定由小写英文字母和数字组成的字符串 ``s``。可以任意重新排列字符，但每个字符实例必须恰好使用一次。

请构造一个任意相邻字符分别属于字母和数字两类的字符串。若不存在合法排列，返回空字符串；若答案不唯一，可返回任意一个。

``1 <= s.length <= 500``。

自建示例
--------

两类字符数量相差一时由较多的一类开头：

.. code-block:: text

   输入：s = "a1b2c"
   输出："a1b2c"
   解释：三个字母与两个数字能够严格交替排列。

数量差超过一时无法交替：

.. code-block:: text

   输入：s = "abc1"
   输出：""
   解释：三个字母之间只有一个数字，无法隔开全部相邻字母。
