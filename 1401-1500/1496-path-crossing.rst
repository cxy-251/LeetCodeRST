1496. Path Crossing
===================

题目信息
--------

:题号: 1496
:难度: Easy
:主题: 字符串、坐标模拟、哈希集合
:原题: `LeetCode 1496 <https://leetcode.com/problems/path-crossing/>`_
:重点: 从原点开始按 ``N/S/E/W`` 每次移动一格；若任意坐标被访问至少两次，包括再次回到原点，则路径相交

题目重述
--------

给定字符串 ``path``，从坐标 ``(0,0)`` 出发。字符 ``N``、``S``、``E``、``W`` 分别表示向北、南、东、西移动一格。

若移动过程中到达某个此前已经访问过的坐标，返回 ``true``；否则返回 ``false``。起始原点也属于已访问坐标。

``1 <= path.length <= 10^4``，``path`` 只包含 ``N``、``S``、``E``、``W``。

自建示例
--------

回到起点也属于路径相交：

.. code-block:: text

   输入：path = "NESW"
   输出：true
   解释：四步后再次到达原点 (0,0)。

始终访问新坐标时不相交：

.. code-block:: text

   输入：path = "NN"
   输出：false
   解释：依次到达 (0,1) 和 (0,2)，没有坐标重复。
