1424. Diagonal Traverse II
==========================

题目信息
--------

:题号: 1424
:难度: Medium
:主题: 锯齿数组、对角线遍历、分组
:原题: `LeetCode 1424 <https://leetcode.com/problems/diagonal-traverse-ii/>`_
:重点: 按 ``行下标 + 列下标`` 从小到大遍历对角线，同一对角线内按行下标从大到小输出

题目重述
--------

给定一个每行长度可以不同的二维整数列表 ``nums``。把坐标和 ``i + j`` 相同的元素视为同一条对角线。

按对角线编号从小到大输出元素；在同一条对角线上，从较低的行向较高的行遍历。请返回得到的一维数组。

``1 <= nums.length <= 10^5``，每行非空，所有元素总数不超过 ``10^5``。

自建示例
--------

不规则行长度不会改变对角线顺序：

.. code-block:: text

   输入：nums = [[1,2,3],[4],[5,6]]
   输出：[1,4,2,5,3,6]
   解释：各对角线依次为 [1]、[4,2]、[5,3]、[6]。

只有一个元素时直接返回该元素：

.. code-block:: text

   输入：nums = [[9]]
   输出：[9]
   解释：矩阵中只有一条对角线。
