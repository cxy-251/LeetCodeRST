1403. Minimum Subsequence in Non-Increasing Order
=================================================

题目信息
--------

:题号: 1403
:难度: Easy
:主题: 数组、贪心、排序
:原题: `LeetCode 1403 <https://leetcode.com/problems/minimum-subsequence-in-non-increasing-order/>`_
:重点: 选择元素和严格大于未选元素和的最短子序列；长度并列时选择元素和最大的方案，并按非递增顺序返回

题目重述
--------

给定正整数数组 ``nums``。选择其中若干元素组成子序列，使被选元素总和严格大于剩余元素总和。

请返回元素数量最少的合法子序列；若最短方案不唯一，选择元素和最大的一个。返回结果必须按非递增顺序排列。

``1 <= nums.length <= 500``，``1 <= nums[i] <= 100``。

自建示例
--------

选择最大的两个元素即可超过其余元素：

.. code-block:: text

   输入：nums = [4,3,2,1]
   输出：[4,3]
   解释：被选元素和为 7，剩余元素和为 3；任何单元素方案都不满足条件。

单元素数组必须选择唯一元素：

.. code-block:: text

   输入：nums = [6]
   输出：[6]
   解释：被选元素和为 6，未选元素和为 0。
