1482. Minimum Number of Days to Make m Bouquets
===============================================

题目信息
--------

:题号: 1482
:难度: Medium
:主题: 二分查找、数组、连续分组
:原题: `LeetCode 1482 <https://leetcode.com/problems/minimum-number-of-days-to-make-m-bouquets/>`_
:重点: 每束花需要 ``k`` 朵相邻且已开放的花，每朵花只能使用一次；求制作 ``m`` 束花的最早天数，无解返回 ``-1``

题目重述
--------

给定数组 ``bloomDay``，第 ``i`` 朵花在第 ``bloomDay[i]`` 天开放。制作一束花需要使用 ``k`` 朵位置连续且已经开放的花，使用过的花不能再用于其他花束。

请返回至少制作 ``m`` 束花所需的最少天数。若花朵总数或排列方式使任务永远无法完成，返回 ``-1``。

``1 <= bloomDay.length <= 10^5``，``1 <= bloomDay[i] <= 10^9``，``1 <= m, k <= 10^6``。

自建示例
--------

最后开放的关键花朵决定最早日期：

.. code-block:: text

   输入：bloomDay = [1,3,2,4], m = 2, k = 2
   输出：4
   解释：第 3 天只有前三朵开放，只能组成一束相邻花；第 4 天可分成两组各两朵。

所需花朵数量超过总数时无解：

.. code-block:: text

   输入：bloomDay = [1,2,3], m = 2, k = 2
   输出：-1
   解释：两束花至少需要四朵不同的花。
