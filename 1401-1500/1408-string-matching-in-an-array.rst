1408. String Matching in an Array
=================================

题目信息
--------

:题号: 1408
:难度: Easy
:主题: 字符串、子串匹配、枚举
:原题: `LeetCode 1408 <https://leetcode.com/problems/string-matching-in-an-array/>`_
:重点: 返回所有作为数组中另一不同字符串连续子串的单词；返回顺序不限

题目重述
--------

给定由不同字符串组成的数组 ``words``。若某个字符串是数组中另一个字符串的连续子串，则它应出现在答案中。

请返回所有满足条件的字符串，返回顺序不限。每个输入字符串在结果中至多出现一次。

``1 <= words.length <= 100``，``1 <= words[i].length <= 30``，字符串只包含小写英文字母且互不相同。

自建示例
--------

短字符串可以位于长字符串中间：

.. code-block:: text

   输入：words = ["mass","as","hero"]
   输出：["as"]
   解释："as" 是 "mass" 的连续子串，其他字符串不属于另一字符串。

没有任何包含关系时返回空数组：

.. code-block:: text

   输入：words = ["a","b"]
   输出：[]
   解释：两个不同单字符字符串互不包含。
