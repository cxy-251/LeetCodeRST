1422. Maximum Score After Splitting a String
============================================

题目信息
--------

:题号: 1422
:难度: Easy
:主题: 字符串、前缀计数
:原题: `LeetCode 1422 <https://leetcode.com/problems/maximum-score-after-splitting-a-string/>`_
:重点: 在两个字符之间切分为非空左右子串，得分为左侧零的数量加右侧一的数量

题目重述
--------

给定长度至少为二的二进制字符串 ``s``。选择一个切分位置，把它分成两个连续且非空的子串。

切分得分等于左子串中字符 ``0`` 的数量，加上右子串中字符 ``1`` 的数量。请返回所有合法切分位置中的最大得分。

``2 <= s.length <= 500``，``s`` 只包含 ``0`` 和 ``1``。

自建示例
--------

切在零与一之间可以同时计入两侧全部字符：

.. code-block:: text

   输入：s = "0011"
   输出：4
   解释：切分为 "00" 和 "11"，左侧有两个零，右侧有两个一。

字符串长度为二时只有一个切分位置：

.. code-block:: text

   输入：s = "11"
   输出：1
   解释：切分为 "1" 和 "1"，左侧零为 0，右侧一为 1。
