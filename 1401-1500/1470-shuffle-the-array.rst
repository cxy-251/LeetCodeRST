1470. Shuffle the Array
=======================

题目信息
--------

:题号: 1470
:难度: Easy
:主题: 数组、下标映射
:原题: `LeetCode 1470 <https://leetcode.com/problems/shuffle-the-array/>`_
:重点: 输入形式为 ``[x1,...,xn,y1,...,yn]``，输出交替排列 ``[x1,y1,...,xn,yn]``

题目重述
--------

给定长度为 ``2n`` 的数组 ``nums``，前 ``n`` 个元素记为 ``x1`` 到 ``xn``，后 ``n`` 个元素记为 ``y1`` 到 ``yn``。

请返回按 ``x1,y1,x2,y2,...,xn,yn`` 顺序交替排列的新数组。

``1 <= n <= 500``，``nums.length == 2n``，``1 <= nums[i] <= 1000``。

自建示例
--------

前后两半按对应位置交替合并：

.. code-block:: text

   输入：nums = [1,2,3,4], n = 2
   输出：[1,3,2,4]
   解释：前半部分为 [1,2]，后半部分为 [3,4]。

每半只有一个元素时顺序保持不变：

.. code-block:: text

   输入：nums = [5,6], n = 1
   输出：[5,6]
   解释：交替结果就是 x1、y1。
