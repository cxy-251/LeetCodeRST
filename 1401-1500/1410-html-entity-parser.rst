1410. HTML Entity Parser
========================

题目信息
--------

:题号: 1410
:难度: Medium
:主题: 字符串、解析、模式替换
:原题: `LeetCode 1410 <https://leetcode.com/problems/html-entity-parser/>`_
:重点: 仅把六种指定 HTML 实体转换为对应字符；未知实体保持原样，转换结果不递归解析

题目重述
--------

给定字符串 ``text``，把其中六种 HTML 实体替换为对应字符：``&quot;``、``&apos;``、``&amp;``、``&gt;``、``&lt;``、``&frasl;`` 分别对应双引号、单引号、``&``、``>``、``<``、``/``。

其他以 ``&`` 开始的文本保持不变。请返回完成一次从左到右解析后的字符串。

``1 <= text.length <= 10^5``，输入由英文字母、数字、空格及常见符号组成。

自建示例
--------

多个不同实体可以出现在同一文本中：

.. code-block:: text

   输入：text = "x &lt; y &amp;&amp; y &gt; z"
   输出："x < y && y > z"
   解释：三个受支持的实体分别被替换，其余字符保持原顺序。

未知实体与替换后形成的文本都不会再次解析：

.. code-block:: text

   输入：text = "&copy; &amp;gt;"
   输出："&copy; &gt;"
   解释：&copy; 不受支持；&amp; 被转换为 & 后，剩余 gt; 不会递归转换为大于号。
