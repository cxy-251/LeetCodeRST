1487. Making File Names Unique
==============================

题目信息
--------

:题号: 1487
:难度: Medium
:主题: 字符串、哈希表、命名冲突
:原题: `LeetCode 1487 <https://leetcode.com/problems/making-file-names-unique/>`_
:重点: 按输入顺序创建文件夹；名称已存在时附加最小正整数后缀 ``(k)``，直到得到未使用名称

题目重述
--------

给定按创建顺序排列的名称数组 ``names``。系统依次创建对应文件夹。

若当前名称尚未使用，直接采用；若已存在，则寻找最小正整数 ``k``，使 ``name(k)`` 尚未使用，并采用该新名称。请返回每次实际创建的名称数组。

``1 <= names.length <= 5 * 10^4``，每个名称非空且长度不超过 ``20``。

自建示例
--------

带后缀的输入名称也参与冲突检查：

.. code-block:: text

   输入：names = ["a","a","a(1)","a"]
   输出：["a","a(1)","a(1)(1)","a(2)"]
   解释：第三个输入 a(1) 已被占用，因此生成 a(1)(1)；最后一个 a 使用最小空闲后缀 2。

没有重复名称时保持原样：

.. code-block:: text

   输入：names = ["docs"]
   输出：["docs"]
   解释：名称尚未被使用。
