1847. Closest Room
==================

题目信息
--------

:题号: 1847
:难度: Hard
:主题: 离线查询、有序集合、排序
:原题: `LeetCode 1847 <https://leetcode.com/problems/closest-room/>`_
:重点: 在面积满足下限的房间中选编号最接近偏好值者，平局选较小编号

题目重述
--------

每个房间有唯一编号和面积。对每个查询，在面积不少于 ``minSize`` 的房间中，返回与 ``preferred`` 距离最小的编号；距离相同取较小编号，不存在返回 -1。

自建示例
--------

.. code-block:: text

   输入：rooms = [[1,4],[2,3],[3,5]], queries = [[2,4],[3,6]]
   输出：[1,-1]
   解释：首个查询可选 1、3，距离同为 1，取较小编号 1；第二个查询无房间满足面积。

.. code-block:: text

   输入：rooms = [[4,2]], queries = [[10,2]]
   输出：[4]
   解释：唯一符合条件的房间编号为 4。
