1824. Minimum Sideway Jumps
===========================

题目信息
--------

:题号: 1824
:难度: Medium
:主题: 动态规划、贪心
:原题: `LeetCode 1824 <https://leetcode.com/problems/minimum-sideway-jumps/>`_
:重点: 青蛙沿三条跑道前进，遇到障碍时最少横向跳跃

题目重述
--------

青蛙从位置 0 的第二条跑道出发，只能向前移动或在同一位置横跳到其他无障碍跑道。返回到达终点所需的最少横跳次数。

自建示例
--------

.. code-block:: text

   输入：obstacles = [0,1,2,3,0]
   输出：2
   解释：必须避开依次出现在三条跑道上的障碍，至少横跳两次。

.. code-block:: text

   输入：obstacles = [0,0,0]
   输出：0
   解释：第二条跑道全程无障碍，可以一直向前。
