1832. Check if the Sentence Is Pangram
======================================

题目信息
--------

:题号: 1832
:难度: Easy
:主题: 字符串、集合
:原题: `LeetCode 1832 <https://leetcode.com/problems/check-if-the-sentence-is-pangram/>`_
:重点: 判断 26 个小写英文字母是否都至少出现一次

题目重述
--------

给定只含小写字母的字符串，判断它是否包含英语字母表中的每个字母。

自建示例
--------

.. code-block:: text

   输入：sentence = "abcdefghijklmnopqrstuvwxyz"
   输出：true
   解释：26 个字母恰好各出现一次。

.. code-block:: text

   输入：sentence = "hello"
   输出：false
   解释：多数英文字母没有出现。
