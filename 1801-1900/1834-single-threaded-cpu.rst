1834. Single-Threaded CPU
=========================

题目信息
--------

:题号: 1834
:难度: Medium
:主题: 堆、排序、模拟
:原题: `LeetCode 1834 <https://leetcode.com/problems/single-threaded-cpu/>`_
:重点: CPU 空闲时选择已到达任务中处理时间最短者，平局选原下标小者

题目重述
--------

每个任务包含进入队列时间和处理时间。单线程 CPU 一旦开始任务便运行到结束；空闲时按处理时间和下标选择任务。返回任务执行顺序。

自建示例
--------

.. code-block:: text

   输入：tasks = [[0,3],[1,1],[2,2]]
   输出：[0,1,2]
   解释：任务 0 先执行到时间 3，随后选择处理时间为 1 的任务 1。

.. code-block:: text

   输入：tasks = [[5,2],[5,2]]
   输出：[0,1]
   解释：进入时间和处理时间均相同，先执行下标较小者。
