1861. Rotating the Box
======================

题目信息
--------

:题号: 1861
:难度: Medium
:主题: 矩阵、双指针、模拟
:原题: `LeetCode 1861 <https://leetcode.com/problems/rotating-the-box/>`_
:重点: 石头先受重力向右移动且不能穿过障碍，再将盒子顺时针旋转

题目重述
--------

盒子由石头 ``#``、障碍 ``*`` 和空位 ``.`` 组成。先让石头在每段中向右落下，再把整个矩阵顺时针旋转 90 度并返回。

自建示例
--------

.. code-block:: text

   输入：box = [["#",".","*","."]]
   输出：[["."],["*"],["#"],["."]]
   解释：石头先移动到障碍左侧，随后矩阵顺时针旋转。

.. code-block:: text

   输入：box = [["#","."]]
   输出：[["#"],["."]]
   解释：石头向右移动后得到 [".","#"]，旋转后如输出所示。
